Справочник узлов Yop2D

Français · English · Español · Deutsch · Italiano · Português · Русский · 中文 · 日本語

Yop2D — бесплатный 2D-движок без кода для Android. Логика игры собирается из узлов (визуальных блоков), соединённых в Blueprint: события запускают цепочку, за ними идут действия и условия. На этой странице описаны все 132 узлов редактора, с их настройками (входами) и выходами.

События

При старте

Срабатывает один раз, как только начинается сцена.

Пример: расставить врагов, показать начальный счёт или включить музыку.

Каждый кадр

Срабатывает постоянно, на каждом кадре игры (примерно 60 раз в секунду).

Пример: следить за пальцем или всё время проверять условие. Не ставь под него «Включить музыку» или «Вызвать функцию».

Конец клика

Срабатывает, когда игрок убирает палец с экрана, в любом месте.

Пример: прекратить стрельбу, когда экран отпущен.

Клик по объекту

Вход: Объект

Срабатывает, когда палец касается выбранного объекта. Если цель — тег («# карта»), событие срабатывает для каждого объекта с этим тегом: тронутый объект становится вовлечённым объектом.

Пример: кнопка «Прыжок», открыть сундук, выбрать ответ.

Конец клика по объекту

Вход: Объект

Срабатывает, когда палец отрывается над выбранным объектом.

Пример: подтвердить кнопку только при отпускании.

Объект удерживается

Вход: Объект

Повторяется на каждом кадре, пока палец остаётся на выбранном объекте.

Пример: кнопки влево / вправо: пока нажимаешь, персонаж идёт.

Палец нажат

Повторяется на каждом кадре, пока палец лежит на экране, в любом месте.

Пример: поднимать корабль, пока экран нажат (используй doigt.x и doigt.y в формулах).

Начало перетаскивания

Вход: Объект

Срабатывает, когда игрок начинает тянуть выбранный объект (он должен быть «Можно перетаскивать»).

Пример: увеличить карту, когда её берут.

Конец перетаскивания

Вход: Объект

Срабатывает, когда игрок отпускает объект, который тянул.

Пример: проверить, лежит ли кусочек пазла на своём месте.

Столкновение A/B

Входы: Объект A, Объект B

Срабатывает один раз, когда объект A начинает касаться объекта B. Чтобы сработать снова, они должны разойтись. Это же событие нужно, чтобы «войти в зону».

Пример: игрок касается зоны финиша → следующий уровень.

Выход из зоны

Входы: Объект A, Объект B

Срабатывает один раз, когда объект A перестаёт касаться объекта B (выходит из зоны).

Пример: закрыть дверь, когда игрок уходит.

Наведение мыши

Вход: Объект

Срабатывает, когда палец, скользя по экрану, доходит до выбранного объекта.

Пример: подсветить кнопку, когда палец проходит над ней.

Конец наведения

Вход: Объект

Срабатывает, когда палец уходит с объекта, над которым был.

Пример: выключить подсветку кнопки.

Столкновение (Физика)

Вход: Объект

Срабатывает, когда выбранный объект (динамическая физика) падает на пол или отскакивает.

Пример: проиграть звук приземления или тряхнуть камеру.

Переменная изменена

Вход: Переменная

Срабатывает каждый раз, когда меняется значение выбранной переменной.

Пример: когда «vie» (здоровье) меняется, обновить полоску здоровья.

Локальное событие

Вход: Имя события

Твоё собственное событие с именем, которое ты выберешь. Его запускает узел «Вызвать событие» в том же Blueprint.

Пример: событие «GameOver», которое вызывают из разных мест.

Клик Действия (Adventure)

Срабатывает, когда игрок нажимает объект «КнопкаДействия» (кнопку действия) на сцене.

Пример: поговорить с персонажем или открыть дверь в приключенческой игре.

Если объект касается тега

Входы: Объект, Тег

Срабатывает один раз за касание, когда выбранный объект касается объекта с этим тегом. Задетый объект становится «Подразумеваемый объект».

Пример: игрок касается монеты (тег «piece») → уничтожить задетый объект и прибавить 1 к счёту.

Сцена и HUD

Перейти к сцене

Вход: Сцена  →  Выход: нет (конец скрипта)

Уходит из текущей сцены в выбранную. Этот узел завершает скрипт.

Пример: перейти на экран «Браво!» после последнего уровня.

Перейти к сцене (по имени)

Вход: Имя сцены  →  Выход: нет (конец скрипта)

Переходит в сцену, имя которой ты пишешь (или формула, которая даёт это имя). Этот узел завершает скрипт.

Пример: формула вроде ="Уровень" + level, чтобы выбрать уровень переменной.

Следующая сцена

Выход: нет (конец скрипта)

Переходит в сцену, которая идёт следующей в списке сцен. Этот узел завершает скрипт.

Пример: игрок дошёл до финиша → следующий уровень.

Предыдущая сцена

Выход: нет (конец скрипта)

Переходит в сцену, которая идёт перед текущей в списке сцен. Этот узел завершает скрипт.

Пример: кнопка «Назад» в меню.

Перезапустить сцену

Выход: нет (конец скрипта)

Запускает сцену заново: объекты на своих местах, локальные переменные с начальными значениями. Глобальные переменные не меняются.

Пример: Game Over, когда здоровье падает до 0.

Открыть HUD

Вход: Сцена

Показывает другую сцену поверх игры, как слой (HUD), со своим Blueprint.

Пример: меню паузы или инвентарь.

Закрыть HUD

Закрывает открытый HUD.

Пример: кнопка «Закрыть» в меню паузы.

Разместить копию сцены

Входы: Сцена, Позиция X, Позиция Y

Ставит копию выбранной сцены (префаб) в игру, в точку X, Y.

Пример: вывести группу врагов, подготовленную в другой сцене.

Уничтожить копии сцены

Вход: Сцена

Удаляет все копии выбранной сцены, поставленные в игру.

Пример: убрать все группы врагов в конце волны.

Выйти из игры

Выход: нет (конец скрипта)

Закрывает экспортированную игру. В редакторе ничего не закрывает: используй кнопку стоп.

Пример: кнопка «Выход» в главном меню.

Короткое сообщение внизу экрана

Вход: Сообщение

Показывает внизу экрана короткое сообщение на несколько секунд. Начни с =, чтобы показать вычисление.

Пример: ="Счёт: " + score

Записать в журнал (для отладки)

Вход: Сообщение

Пишет сообщение в журнал проекта (файл диагностики), ничего не показывая в игре. Начни с =, чтобы записать вычисление.

Пример: ="здоровье = " + vie, чтобы проверить значение во время теста.

Закрепить камеру

Входы: Объект, Следовать по X (да / нет), Следовать по Y (да / нет), Параллакс только по X (да / нет)

Камера следует за выбранным объектом, можно только по горизонтали или только по вертикали. Без объекта камера больше ни за чем не следует.

Пример: следовать за игроком по большому уровню-платформеру.

Границы камеры

Входы: Минимальный X (левый край уровня), Максимальный X (правый край), Минимальный Y (верх), Максимальный Y (низ; всё 0 = без границ)

Не даёт камере выйти за края уровня: она никогда не показывает пустоту за ними. Всё 0 = без границ.

Пример: уровень шириной 6480 пикселей: X мин. 0, X макс. 6480, Y мин. 0, Y макс. 1080, вместе с «Закрепить камеру» на игроке.

Плавность камеры

Вход: Скорость слежения (0.01–1)

Задаёт, как быстро камера догоняет объект: 0.01 = очень мягко, 1 = прилипает к объекту.

Пример: 0.1 — плавная камера с небольшой задержкой.

Вспышка экрана

Входы: Цвет, Интенсивность (%, 0 = нет), Длительность (секунды)

Вспышка цвета на весь экран, которая быстро гаснет (интенсивность в %, длительность в секундах).

Пример: красная вспышка на 0,5 секунды, когда игрока ранят.

Оттенок экрана

Входы: Цвет, Интенсивность (%, 0 = нет), Переход (секунды)

Накладывает цвет на всю игру (под HUD) с плавным переходом. Интенсивность 0 убирает его.

Пример: наступает ночь: тёмно-синий, интенсивность 55, переход 2 секунды.

Затемнение краёв

Входы: Цвет, Интенсивность (%, 0 = нет), Переход (секунды)

Плавно затемняет края экрана, как в кино (под HUD). Интенсивность 0 убирает эффект.

Пример: тревожная атмосфера в пещере: интенсивность 75.

Затемнение экрана

Входы: Направление, Цвет, Длительность (секунды)

Плавно скрывает весь экран в цвет или проявляет его из этого цвета. Затемнение сохраняется при смене сцены.

Пример: «Затемнение экрана» (исчезнуть), «Ждать» 1 секунду, «Перейти к сцене», затем «Затемнение экрана» (появиться) в начале следующего уровня.

Тряска камеры

Входы: Сила, Длительность (миллисекунды, 1000 = 1 с)

Трясёт экран с выбранной силой и длительностью (в миллисекундах).

Пример: взрыв: интенсивность 15, длительность 400.

Вибрация

Вход: Длительность (миллисекунды, 1000 = 1 с)

Заставляет телефон вибрировать выбранное время (в миллисекундах). Без вибромотора ничего не происходит.

Пример: 100 мс, когда игрока ранили.

Сохранить состояние

Запоминает состояние сцены (объекты и переменные) и глобальные переменные, как точка сохранения.

Пример: флажок-чекпоинт в середине уровня.

Восстановить состояние

Возвращает сцену к последнему «Сохранить состояние». Если сохранения ещё нет, ничего не меняется.

Пример: начать с чекпоинта после падения.

Время

Ждать

Вход: Длительность (секунды)

Ждёт выбранное время в секундах, потом продолжает. Остальная игра всё это время идёт дальше.

Пример: показать «Проигрыш!», подождать 2 секунды и перезапустить сцену.

Повторять

Входы: Каждые (секунды), Сколько раз (0 = бесконечно), Имя таймера (необязательно)  →  Выходы: Сразу / Каждый раз / Ход завершён

Запускает выход «Каждый раз» каждые X секунд, заданное число раз (0 = бесконечно), затем «Ход завершён». «Сразу» срабатывает сразу. Если он уже идёт, заново не запускается.

Пример: выпускать врага каждые 3 секунды.

Обратный отсчёт

Входы: Объект, Переменная, Начальное значение (необязательно), Имя таймера (необязательно)  →  Выходы: Каждую секунду / Ход завершён

Каждую секунду отнимает 1 от выбранной переменной (числа) до 0. «Каждую секунду» срабатывает на каждом тике, «Ход завершён» — на 0. «Начальное значение (необязательно)» задаёт начальное значение.

Пример: таймер на 60 секунд: на 0 — Game Over.

Остановить таймер

Вход: Имя (пусто = все)

Останавливает таймер (Повтор или Обратный отсчёт) с этим именем, или все таймеры, если имя пустое.

Пример: остановить таймер, когда игрок выиграл.

Скорость игры (замедление)

Вход: Скорость (1 = обычная, 0.5 = медленно)

Меняет скорость всей игры: 1 = обычная, 0.5 = замедление, 2 = ускорение (от 0 до 4).

Пример: эффект замедления на 2 секунды.

Поставить игру на паузу

Ставит игру на паузу: движения и таймеры останавливаются.

Пример: открыть меню паузы.

Продолжить игру

Продолжает игру после паузы.

Пример: кнопка «Продолжить» в меню паузы.

Стоп-кадр при ударе

Входы: Длительность (секунды), Скорость во время остановки (0 = замерло)

На очень короткое мгновение (в реальных секундах) почти останавливает всю игру, затем скорость возвращается. Делает удары ощутимее.

Пример: когда взрывается враг: длительность 0,06, скорость 0,05.

Внешний вид

Переместить

Входы: Объект, X, Y

Ставит объект сразу в точку X, Y (телепорт).

Пример: вернуть игрока на старт.

Толкнуть объект

Входы: Объект, Добавить X, Добавить Y

Сдвигает объект на заданное расстояние от его текущего места. Физический объект останавливают стены.

Пример: вместе с «Объект удерживается»: «Добавить X» = 5 двигает вправо.

Изменить свойство

Входы: Объект, Свойство, Значение

Меняет свойство объекта из списка (x, y, поворот, прозрачность, текст…).

Пример: задать поворот стрелки часов =temps * 90.

Вращение

Входы: Объект, Угол (градусы)

Поворачивает объект на заданный угол в градусах.

Пример: =koleso.rotation + 5 вместе с «Каждый кадр» постоянно вращает объект «koleso».

Прозрачность

Входы: Объект, Непрозрачность (0–1)

Задаёт прозрачность объекта: 0 = невидимый, 1 = непрозрачный.

Пример: 0.5 для полупрозрачного призрака.

Видимость

Входы: Объект, Видимость (да / нет)

Показывает (true) или прячет (false) объект.

Пример: показать скрытое сначала сообщение «Победа!».

Присвоить тег (семейство объектов)

Входы: Объект, Тег

Даёт объекту новый тег (метку).

Пример: побеждённый враг получает тег «безвредный».

Вперёд / назад

Входы: Объект, Глубина (больше = впереди)

Меняет слой объекта: чем больше число, тем ближе объект к зрителю.

Пример: поставить игрока перед декорацией.

Увеличить / уменьшить

Входы: Объект, Размер по горизонтали (1 = обычный), Размер по вертикали (1 = обычный)

Меняет размер объекта: 1 = обычный, 2 = в два раза больше, 0.5 = в два раза меньше.

Пример: игрок растёт, съев гриб.

Уничтожить объект

Вход: Объект

Удаляет выбранный объект со сцены.

Пример: выбрать «Подразумеваемый объект», чтобы уничтожить монету, которой только что коснулся игрок.

Уничтожить по тегу

Вход: Тег для уничтожения

Удаляет все объекты с этим тегом.

Пример: бомба уничтожает все объекты «Враг».

Изменить изображение

Входы: Объект, Изображение

Заменяет картинку объекта другой картинкой из Assets. Пусто = без картинки.

Пример: персонаж смотрит влево или вправо в зависимости от кнопки.

Изменить цвет

Входы: Объект, Цвет

Меняет цвет объекта.

Пример: кнопка становится зелёной, когда ответ верный.

Клонировать (Spawner)

Входы: Объект A, Объект B

Создаёт копию объекта B (образца) на месте объекта A (точки появления).

Пример: пушка (A), которая выпускает ядра (B).

Цветовой фильтр

Входы: Объект, Фильтр

Накладывает на объект фильтр: чёрно-белый, сепия, инверсия, или «Нет», чтобы убрать.

Пример: перейти в чёрно-белое во время воспоминания.

Смешивание цветов (световой эффект)

Входы: Объект, Фильтр

Меняет, как объект смешивается с тем, что за ним (аддитивный, умножение, экран, инверсия).

Пример: аддитивный — для светящейся лампы или пламени.

Эффект зеркала / Отразить

Входы: Объект, Ось

Отражает объект: по горизонтали (лево / право) или по вертикали (верх / низ).

Пример: персонаж смотрит туда, куда идёт.

Заблокировать / разблокировать объект

Входы: Объект, Заблокирован (да / нет)

Блокирует или разблокирует объект в редакторе (замок). Во время игры ни на что не влияет: чтобы запретить перетаскивание, используй «Изменить поведение».

Прокрутка фона (глубина)

Входы: Объект, Скорость фона (1 = обычная, 0.5 = медленнее, эффект дали)

Задаёт, как быстро объект прокручивается при движении камеры: 1 = обычно, 0.5 = вдвое медленнее (эффект глубины).

Пример: горы на заднем плане, которые медленно проплывают.

Связать два объекта

Входы: Объект A, Объект B

Прикрепляет объект A (ребёнка) к объекту B (родителю): A следует за B, когда тот движется.

Пример: меч, который следует за рукой персонажа.

Светящийся ореол

Входы: Объект, Состояние, Цвет, Размер свечения

Окружает объект мягким свечением выбранного цвета и размера (повторяет форму изображения) или убирает его.

Пример: бонус, светящийся жёлтым, размер 20.

Эффект частиц

Входы: Объект, Шаблон, Количество (0 = как в шаблоне), Цвет (пусто = как в шаблоне), Размер (1 = обычный), Картинка (пусто = формы шаблона)

Выпускает на объекте залп частиц: взрыв, искры, пыль, дым, огонь, дождь, снег, конфетти, шлейф, длинный шлейф, гиперпространство или линии скорости. Количество, цвет и размер настраиваются. С картинкой (настройка «Картинка») каждая частица становится этой картинкой: нарисованный взрыв, звезда, листок…

Пример: подбитый враг взрывается пурпурным: шаблон «Взрыв», цвет #FF40D0.

Включить / выключить частицы

Входы: Объект, Состояние

Включает или выключает объект «Частицы»: он непрерывно испускает частицы или останавливается (уже выпущенные доживают своё).

Пример: включить двигатель, когда корабль летит.

Залп частиц

Входы: Объект, Количество частиц

Сразу выпускает много частиц из объекта «Частицы» с его настройками (шаблон, цвет, размер).

Пример: 80 конфетти при победе на уровне.

Сменить шаблон частиц

Входы: Объект, Шаблон

Меняет шаблон объекта «Частицы» во время игры.

Пример: огонь превращается в дым, когда его тушат.

Мигать

Входы: Объект, Состояние, Скорость (миллисекунды, 1000 = 1 с), Длительность (миллисекунды, 0 = бесконечно)

Заставляет объект мигать с выбранной скоростью (мс), заданное время (мс, 0 = бесконечно), или выключает мигание.

Пример: игрок мигает 1 секунду после удара.

Создать копию объекта

Входы: Объект B, Позиция X, Позиция Y

Создаёт копию объекта B (образца) в точке X, Y. Копия становится «Подразумеваемый объект».

Пример: уронить камень в случайном месте: X = random(0, 800).

Стрелять объектом

Входы: Объект A, Объект B, Имя модели, Направление, Скорость, Уничтожать за экраном (да / нет)

Создаёт снаряд (объект из «Имя модели») у объекта A и запускает его с выбранной скоростью: 0°, 90°, 180°, 270°, к объекту B («К цели») или по углу A.

Пример: корабль стреляет лазерами вверх (270).

Задать прогресс

Входы: Объект, Новый прогресс

Задаёт заполнение полосы прогресса между её минимумом и максимумом.

Пример: «Новый прогресс» = vie, для полоски здоровья.

Пройти сквозь экран

Вход: Объект

То, что уходит за один край экрана, появляется с противоположного (эффект Pac-Man).

Пример: астероид уходит вправо и возвращается слева.

Удерживать в экране

Входы: Объект, Отступ

Не даёт объекту уйти за экран. Отступ останавливает его чуть раньше края.

Пример: корабль игрока всегда остаётся виден.

Удар током

Входы: Объект, Цвет молний, Длительность (секунды, 0 = бесконечно), Сила (0 = остановить, от 1 до 3)

Вокруг объекта трещат молнии: он мигает цветом молнии, дрожит и сыплет искрами. Длительность 0 = бесконечно (электрический забор); сила 0 = остановить.

Пример: маг касается ловушки: «Удар током» на мага (1 секунда), «Ждать» 1 секунду, затем «Перезапустить сцену».

Шлейф за объектом

Входы: Объект, Шаблон, Цвет (пусто = как в шаблоне), Размер (1 = обычный)

Объект оставляет за собой шлейф частиц при движении (шаблон, цвет и размер на выбор). Если задать его образцу выстрела, каждый выстрел получит шлейф. Шаблон «Нет» убирает его.

Пример: выстрелы со светящимся шлейфом: цель = образец выстрела, шаблон «Шлейф».

Создать объект

Входы: Объект, Позиция X, Позиция Y

Создаёт копию выбранного объекта (образца) в точке X, Y.

Пример: поставить ящик в точное место.

Затухание

Входы: Объект, Целевая прозрачность (0–1), Длительность (секунды)

Плавно меняет прозрачность объекта до нужного значения за выбранное время (секунды). Дальнейшие узлы не ждут.

Пример: скрыть заголовок за 1 секунду (целевая прозрачность 0).

Переменные

Изменить переменную

Входы: Объект, Переменная, Значение

Задаёт переменной новое значение (число, текст, да / нет или вычисление).

Пример: снова поставить «score» в 0.

Добавить к переменной

Входы: Объект, Переменная, Добавляемое значение, Вернуться к 0 после (необязательно)

Прибавляет значение к переменной (отрицательное число вычитает). Для текстовой переменной дописывает текст в конец. С «Вернуться к 0 после» переменная крутится как счётчик: после 9 снова 0 (а ниже 0 становится 9).

Пример: очки + 1 за каждую монету; цифра замка: + 1 при каждом касании, вернуться к 0 после 9.

Держать переменную между двумя значениями

Входы: Объект, Переменная, Минимум, Максимум

Держит переменную (число) между минимумом и максимумом.

Пример: здоровье никогда не больше 100.

Случайное число

Входы: Объект, Переменная, Между (мин, макс)

Кладёт в переменную случайное число. random(1, 6) даёт число от 1 до 6.

Пример: бросок кубика.

Добавить в инвентарь

Входы: Объект, Переменная

Кладёт объект в инвентарь (переменную типа «Список инвентаря»). Добавляется только один раз.

Пример: подобрать ключ.

Убрать из инвентаря

Входы: Объект, Переменная

Убирает объект из инвентаря.

Пример: использовать ключ, чтобы открыть дверь.

Если в инвентаре

Входы: Объект, Переменная  →  Выходы: Истина / Ложь / Затем

Идёт по выходу «Истина», если объект в инвентаре, иначе «Ложь».

Пример: дверь открывается, только если ключ в инвентаре.

Объединить два объекта

Входы: Объект A, Объект B, Имя объекта-результата

Заменяет объекты A и B копией объекта, имя которого ты пишешь, на месте A. Если такого образца нет, ничего не меняется.

Пример: палка + тряпка = факел.

Логика

Условие

Вход: Условие  →  Выходы: Истина / Ложь / Затем

Проверяет условие: идёт по «Истина», если оно верно, иначе по «Ложь». «Затем» срабатывает после, в обоих случаях.

Пример: score >= 10 → истина → следующая сцена.

Если джойстик

Выходы: Вверх / Вниз / Влево / Вправо / Покой / Затем

Идёт по выходу, который соответствует направлению джойстика: «Вверх», «Вниз», «Влево», «Вправо», или «Покой», если его не трогают.

Пример: вместе с «Каждый кадр», чтобы включать анимацию ходьбы в нужную сторону.

Если на земле

Вход: Объект  →  Выходы: Истина / Ложь / Затем

«Истина», если низ объекта стоит на неподвижном видимом объекте (пол, платформа), иначе «Ложь».

Пример: разрешать прыжок, только если игрок на земле.

Если движется

Вход: Объект  →  Выходы: Истина / Ложь / Затем

«Истина», если объект сдвинулся с прошлого кадра, иначе «Ложь».

Пример: включать анимацию ходьбы, только когда персонаж движется.

Вызвать функцию

Вход: Функция

Выполняет функцию (Blueprint из раздела «Функции»), потом продолжает. Не ставь под «Каждый кадр».

Пример: функция «ПотерятьЖизнь», которую используют разные враги.

Вызвать событие

Вход: Имя события

Запускает «Локальное событие» с этим именем в том же Blueprint, потом продолжает.

Пример: вызвать «GameOver» и при падении, и по таймеру.

Последовательность

Выходы: 1 / 2 / 3 / 4

Запускает свои выходы по очереди: 1, потом 2, потом 3, потом 4. Выход без связи пропускается.

Пример: при старте: 1 = поставить игрока, 2 = включить музыку, 3 = показать счёт.

Перезарядка

Входы: Объект, Задержка (секунды)  →  Выходы: Готово / Пока нет

Пропускает через «Готово» не чаще одного раза за интервал (в секундах); иначе идёт по «Пока нет». Если выбран объект, у каждого объекта свой интервал.

Пример: стрелять не чаще одного раза в 0.5 секунды.

Если за пределами экрана

Входы: Объект, Отступ (пиксели)  →  Выходы: Истина / Ложь / Затем

«Истина», если объект полностью ушёл за экран (с учётом отступа), иначе «Ложь».

Пример: уничтожать пули, которые улетели за экран.

Если / Иначе

Входы: Если (условие), Иначе если (условие)  →  Выходы: Если / Иначе если / Иначе / Затем

Проверяет первое условие, потом второе: идёт по «Если», «Иначе если» или «Иначе». «Затем» срабатывает после.

Пример: если score >= 100 → золото, иначе если score >= 50 → серебро, иначе → бронза.

По значению

Входы: Проверяемое значение, Случай 1, Случай 2, Случай 3, Случай 4, Случай 5, Случай 6  →  Выходы: 1 / 2 / 3 / 4 / 5 / 6 / Нет / Затем

Сравнивает значение со случаями 1–6 и идёт по выходу первого совпавшего; «Нет», если совпадений нет. Пустой случай пропускается.

Пример: по «оружие»: 1 = меч, 2 = лук, 3 = палочка.

Текст

Изменить текст

Входы: Объект, Новый текст

Заменяет текст объекта «Текст». Начни с =, чтобы показать вычисление.

Пример: ="Счёт: " + score

Показать диалог

Входы: Объект, Имя фразы (в текстах игры)

Пишет в объект «Текст» фразу по ключу из файла диалогов (dialogues.txt). Несколько языков: пишите «privet.ru = Привет», «privet.en = Hello»…; игра берёт язык из переменной «langue», иначе язык телефона. «\n» = новая строка.

Пример: ключ «privet_torgovets» показывает реплику торговца.

Добавить к тексту

Входы: Объект, Переменная, Добавляемый текст

Добавляет текст в конец переменной типа «Текст».

Пример: вводить пароль по одной букве.

Движение и ИИ

Остановить объект

Вход: Объект

Резко останавливает объект: никакой скорости, толчка, прыжка или автодвижения.

Пример: заморозить врага, в которого попало ледяное заклинание.

Остановить движение

Вход: Объект

Выключает автоматические движения объекта: движение вперёд, преследование и бегство.

Пример: враг перестаёт гнаться, когда игрок прячется.

Двигаться вперед

Входы: Объект, Скорость

Объект сам движется туда, куда повёрнут, с выбранной скоростью.

Пример: пуля или едущая машина.

Идти к объекту (путь)

Входы: Объект A, Объект B, Скорость, Диагонали (да / нет)  →  Выходы: Сразу / Прибыл

Объект A идёт к объекту B, сам находя самый короткий путь клетка за клеткой и не проходя сквозь стены («твёрдые» тайлы слоя тайлов, неподвижные физические объекты). Путь пересчитывается, когда B двигается. «Прибыл» срабатывает, когда A касается B.

Пример: призрак, который гонится за игроком по лабиринту.

Идти к точке (путь)

Входы: Объект, Позиция X, Позиция Y, Скорость, Диагонали (да / нет)  →  Выходы: Сразу / Прибыл

Объект A идёт к точке X, Y, обходя стены, самым коротким путём (клетка за клеткой). С =doigt.x и =doigt.y он идёт туда, где коснулись экрана. «Прибыл» срабатывает по прибытии. Если пути нет, объект остаётся на месте.

Пример: нажать на клетку, чтобы отправить туда героя, в стратегии или подземелье.

Остановить путь

Вход: Объект

Объект перестаёт идти по пути («Идти к объекту (путь)» или «Идти к точке (путь)») и остаётся на месте.

Пример: муха останавливается, когда игра выиграна.

Преследовать

Входы: Объект A, Объект B, Скорость

Объект A сам движется к объекту B с выбранной скоростью.

Пример: призрак, который следует за игроком.

Убегать

Входы: Объект A, Объект B, Скорость

Объект A сам удаляется от объекта B с выбранной скоростью.

Пример: курица, которая убегает от игрока.

Толкнуть под углом

Входы: Объект, Угол (0 = вправо, 90 = вниз), Сила

Толкает объект в направлении (в градусах: 0 = вправо, 90 = вниз, 180 = влево, 270 = вверх) с выбранной силой.

Пример: пружина, которая подбрасывает игрока по диагонали.

Импульс (прыжок)

Входы: Объект, Вертикальная сила (минус = вверх)

Подбрасывает объект вверх (отрицательное число) или вниз (положительное) и включает ему физику, чтобы он упал обратно.

Пример: прыжок: сила -15.

Изменить поведение

Входы: Объект, Как он движется, Скорость, Высота прыжка, Это лестница, Можно подобрать

Меняет поведение объекта во время игры — те же варианты, что в окне «Поведение объекта» Инспектора: Декор, Пол / стена, Падает и отскакивает, Персонаж платформера, Патруль (туда-обратно), Персонаж (вид сверху), Перетаскивается пальцем. Можно также изменить скорость, высоту прыжка, «это лестница» и «можно подобрать». Настройки на «(не менять)» сохраняют своё значение.

Пример: неподвижный ящик (Пол / стена) начинает падать, когда дёргают рычаг: Изменить поведение → Падает и отскакивает.

Подпрыгивать

Входы: Объект, Сила (0 = остановить), Длительность (миллисекунды, 1000 = 1 с), Пока движется (да / нет)

Заставляет объект подпрыгивать (небольшой визуальный отскок) с выбранной силой и длительностью. 0 останавливает. Может продолжаться, пока объект движется.

Пример: персонаж, который подпрыгивает при ходьбе.

Повернуть к

Входы: Объект A, Объект B, Смещение угла (градусы)

Поворачивает объект A к объекту B. Смещение поправляет направление картинки (0 = картинка смотрит вправо).

Пример: турель, которая целится в игрока.

Скользить к

Входы: Объект, Позиция X, Позиция Y, Длительность (секунды)

Плавно перемещает объект в точку X, Y за выбранное время (секунды). Дальнейшие узлы не ждут.

Пример: движущаяся платформа или меню, которое въезжает на экран.

Сетки и головоломки

Заполнить сетку

Входы: Объект, Столбцы, Строки, Объекты-образцы (имена через запятую)

Делит объект A (поле) на столбцы и строки и кладёт в каждую клетку копию случайного объекта-образца (минимум 3 образца, имена через запятую). В начале никогда нет готовых рядов, а фишки падают сверху. Используйте перед «Играть на сетке (три в ряд)».

Пример: при запуске — сетка 8 x 8 из конфет «red, orange, yellow, green, blue, pink».

Играть на сетке (три в ряд)

Входы: Объект, Позиция пальца X, Позиция пальца Y  →  Выходы: Для каждой собранной фишки / Ход завершён / Обмен отменён

Сердце игры «три в ряд» (как Candy Crush), ставится под «Палец нажат». Касание фишки выбирает её, касание соседней (или движение пальца к ней) меняет их местами. Обмен остаётся, только если собирается 3 и более одинаковых фишки; иначе они возвращаются («Обмен отменён»). Каждая собранная фишка запускает «Для каждой собранной фишки» (вовлечённый объект — фишка) и исчезает; фишки падают, приходят новые, комбо срабатывают сами. Когда всё успокоилось — «Ход завершён». Если ходов нет, сетка перемешивается сама.

Пример: «Для каждой собранной фишки»: +10 очков и искры на фишке; «Ход завершён»: на один ход меньше.

Перемешать сетку

Вход: Объект

Переставляет все фишки сетки объекта A, не создавая рядов и оставляя хотя бы один возможный ход.

Пример: кнопка «Перемешать», когда игрок застрял.

Перемешать места

Вход: Объект

Случайно меняет местами все объекты с выбранным тегом (Объект A = «# тег»). Дочерние объекты следуют за ними.

Пример: перемешать карты в игре «мемори» в начале партии или стаканчики в напёрстках.

Анимации

Запустить анимацию

Входы: Объект, Анимация, Скорость (кадров/сек), По кругу (да / нет)

Запускает анимацию объекта с выбранной скоростью (кадров в секунду), по кругу или один раз. Если она уже идёт, продолжается без перезапуска.

Пример: анимация «ходьба», когда персонаж идёт.

Остановить анимацию

Вход: Объект

Останавливает анимацию и возвращает её первый кадр.

Пример: персонаж перестаёт идти.

Пауза анимации

Вход: Объект

Ставит анимацию на паузу на текущем кадре.

Пример: заморозить персонажа во время паузы.

Продолжить анимацию

Вход: Объект

Продолжает анимацию с того места, где она стояла.

Пример: после паузы.

Скорость анимации

Входы: Объект, Скорость (кадров/сек)

Меняет скорость анимации (кадров в секунду), не перезапуская её.

Пример: бежать быстрее = анимация быстрее.

Аудио

Воспроизвести звук

Входы: Звуковой файл, Громкость (%, 100 = полная)

Проигрывает звуковой эффект. Несколько звуков могут звучать одновременно.

Пример: «дзынь», когда подобрана монета.

Включить музыку

Входы: Музыкальный файл, По кругу (да / нет), Громкость (%, 100 = полная)

Включает музыку, которая заменяет текущую. Не ставь под «Каждый кадр» (она будет постоянно начинаться заново).

Пример: музыка уровня при старте.

Остановить музыку

Останавливает текущую музыку.

Пример: тишина на экране Game Over.
