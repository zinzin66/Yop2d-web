Yop2D 节点参考

Français · English · Español · Deutsch · Italiano · Português · Русский · 中文 · 日本語

Yop2D 是一款免费、无需代码的 Android 2D 游戏引擎。游戏逻辑由在 Blueprint 中相互连接的节点（可视化积木块）组成：事件启动一条链，接着是动作和条件。本页介绍编辑器中的全部 115 个节点，以及它们的设置（输入）和输出。

分类

事件场景与 HUD时间外观与对象变量与背包逻辑与条件文本与对话移动与 AI动画音频

事件

启动时

场景一开始就运行，只运行一次。

示例： 摆放敌人、显示初始分数或播放音乐。

每帧

在游戏的每一帧都运行（大约每秒 60 次）。

示例： 跟随手指或一直检查某个条件。不要在它下面放 “播放音乐” 或 “调用函数”。

点击结束

玩家在屏幕任意位置抬起手指时运行。

示例： 松开屏幕时停止射击。

点击对象时

输入： 对象

手指碰到所选对象时运行。

示例： “跳跃”按钮、打开宝箱、选择答案。

松开物体

输入： 对象

手指在所选对象上方抬起时运行。

示例： 只在松开按钮时才确认。

按住物体

输入： 对象

只要手指一直按在所选对象上，每一帧都会重复运行。

示例： 左 / 右按钮：按住时角色一直走。

手指按住

只要有手指按在屏幕任意位置，每一帧都会重复运行。

示例： 按住屏幕时让飞船上升（在公式里用 doigt.x 和 doigt.y）。

开始拖拽

输入： 对象

玩家开始拖动所选对象时运行（该对象必须勾选 “可移动 (拖拽)”）。

示例： 拿起卡牌时把它放大。

结束拖拽

输入： 对象

玩家松开正在拖动的对象时运行。

示例： 检查拼图块是否放对了位置。

碰撞 A/B

输入： 对象 A, 对象 B

对象 A 开始碰到对象 B 的那一刻运行一次。两者分开后才会再次运行。“进入区域”也用这个事件。

示例： 玩家碰到终点区域 → 下一关。

离开区域

输入： 对象 A, 对象 B

对象 A 不再碰到对象 B（离开区域）的那一刻运行一次。

示例： 玩家走开时关上门。

鼠标悬停

输入： 对象

手指在屏幕上滑动、到达所选对象时运行。

示例： 手指经过按钮时让它发亮。

悬停结束

输入： 对象

手指离开它刚经过的对象时运行。

示例： 关闭按钮的高亮。

物理撞击

输入： 对象

所选对象（动态物理）落到地面或弹起时运行。

示例： 播放落地音效或让摄像机震动。

当变量改变时

输入： 变量

所选变量的值每次改变时运行。

示例： “vie”（生命值）改变时，更新生命条。

本地事件

输入： 事件名称

你自己的事件，名字由你决定。用同一个 Blueprint 里的 “调用事件” 节点来触发它。

示例： 从多个地方调用的“GameOver”事件。

点击操作按钮 (冒险)

玩家按下场景中的 “操作按钮” 对象（动作按钮）时运行。

示例： 在冒险游戏里和角色说话或开门。

如果对象碰到标签

输入： 对象, 标签

所选对象碰到带有该标签的对象时，每次接触运行一次。被碰到的对象成为 “相关对象”。

示例： 玩家碰到金币（标签“piece”）→ 销毁相关对象，分数加 1。

场景与 HUD

切换场景

输入： 场景  →  输出： 无（脚本结束）

离开当前场景，前往所选场景。这个节点会结束脚本。

示例： 最后一关结束后前往“太棒了！”画面。

按名称切换场景

输入： 场景名称  →  输出： 无（脚本结束）

前往你写下名字的场景（也可以用得出这个名字的公式）。这个节点会结束脚本。

示例： 用 ="关卡" + level 这样的公式，通过变量选择关卡。

下一个场景

输出： 无（脚本结束）

前往场景列表中紧接着的下一个场景。这个节点会结束脚本。

示例： 玩家到达终点 → 下一关。

上一个场景

输出： 无（脚本结束）

前往场景列表中紧挨着的上一个场景。这个节点会结束脚本。

示例： 菜单里的“返回”按钮。

重新开始场景

输出： 无（脚本结束）

从头重新开始场景：对象回到原位，局部变量恢复初始值。全局变量不变。

示例： 生命值降到 0 时 Game Over。

打开 HUD

输入： 场景

把另一个场景像图层（HUD）一样显示在游戏上方，它有自己的 Blueprint。

示例： 暂停菜单或物品栏。

关闭 HUD

关闭打开的 HUD。

示例： 暂停菜单里的“关闭”按钮。

放置场景副本

输入： 场景, X 位置, Y 位置

把所选场景（预制体）的一份副本放进游戏，位置为 X, Y。

示例： 放出在另一个场景里准备好的一组敌人。

销毁场景副本

输入： 场景

删除游戏中所选场景的所有副本。

示例： 一波结束时清除所有敌人组。

退出游戏

输出： 无（脚本结束）

关闭导出的游戏。在编辑器里不会关闭任何东西：请用停止按钮。

示例： 主菜单里的“退出”按钮。

提示消息 (Toast)

输入： 消息

在屏幕底部显示几秒钟的小消息。以 = 开头可以显示计算结果。

示例： ="分数：" + score

写入日志

输入： 消息

把消息写进项目日志（诊断文件），游戏里不显示任何东西。以 = 开头可以写入计算结果。

示例： ="生命 = " + vie，测试时用来检查数值。

锁定相机

输入： 对象, 跟随 X（true / false）, 跟随 Y（true / false）, 仅 X 视差（true / false）

摄像机跟随所选对象，也可以只水平或只垂直跟随。没有选择对象时，摄像机不再跟随。

示例： 在大型平台关卡中跟随玩家。

相机平滑

输入： 跟随速度（0.01 到 1）

设置摄像机追上被跟随对象的速度：0.01 = 非常柔和，1 = 紧贴对象。

示例： 0.1：稍微延迟、平滑跟随的摄像机。

相机抖动

输入： 强度, 持续时间（毫秒）

按所选强度和时长（毫秒）晃动屏幕。

示例： 爆炸：强度 15，时长 400。

振动

输入： 持续时间（毫秒）

让手机振动所选时长（毫秒）。没有振动马达时不会有反应。

示例： 玩家受伤时振动 100 毫秒。

保存状态

记住场景的状态（对象和变量）以及全局变量，就像存档点。

示例： 关卡中间的检查点旗帜。

恢复状态

把场景恢复到上一次 “保存状态” 的样子。如果还没有存档，什么也不变。

示例： 掉下去后从检查点重新开始。

时间

等待

输入： 时长（秒）

等待所选的时间（秒），然后继续。等待期间游戏的其他部分照常运行。

示例： 显示“你输了！”，等待 2 秒，然后重新开始场景。

重复

输入： 每隔（秒）, 次数（0 = 无限）, 计时器名称（可选）  →  输出： 立即 / 每次 / 完成

每隔 X 秒运行一次 “每次” 输出，重复指定次数（0 = 无限），最后运行 “完成”。“立即” 在一开始就运行。如果它已经在运行，不会重复启动。

示例： 每 3 秒生成一个敌人。

倒计时

输入： 对象, 变量, 起始值（可选）, 计时器名称（可选）  →  输出： 每秒 / 完成

每秒把所选变量（数字）减 1，直到 0。每次计时运行 “每秒”，到 0 时运行 “完成”。“起始值（可选）” 设置起始值。

示例： 60 秒倒计时：到 0 时 Game Over。

停止计时器

输入： 名称（留空 = 全部）

停止这个名字的计时器（重复或倒计时）；名字为空时停止所有计时器。

示例： 玩家获胜时停止计时。

游戏速度（慢动作）

输入： 速度（1 = 正常，0.5 = 慢）

改变整个游戏的速度：1 = 正常，0.5 = 慢动作，2 = 加速（0 到 4）。

示例： 持续 2 秒的慢动作效果。

暂停游戏

暂停游戏：移动和计时器都会停止。

示例： 打开暂停菜单。

继续游戏

暂停后继续游戏。

示例： 暂停菜单里的“继续”按钮。

外观与对象

移动对象

输入： 对象, X, Y

把对象直接放到位置 X, Y（瞬移）。

示例： 把玩家放回起点。

推动对象

输入： 对象, 增加 X, 增加 Y

让对象从当前位置移动指定的距离。有物理的对象会被墙挡住。

示例： 和 “按住物体” 连接：“增加 X” = 5 向右移动。

修改属性

输入： 对象, 属性, 值

修改对象的一个属性，从列表中选择（x、y、旋转、透明度、文本……）。

示例： 把指针的旋转设为 =temps * 90。

旋转

输入： 对象, 角度（度）

把对象转到指定角度（度）。

示例： =lunzi.rotation + 5 连接到 “每帧”，让“lunzi”对象一直旋转。

修改不透明度 (Alpha)

输入： 对象, 不透明度（0到1）

设置对象的透明度：0 = 看不见，1 = 不透明。

示例： 0.5：半透明的幽灵。

可见性

输入： 对象, 可见（true / false）

显示（true）或隐藏（false）对象。

示例： 显示一开始隐藏的“你赢了！”消息。

设置标签

输入： 对象, 标签

给对象一个新标签。

示例： 被打败的敌人获得标签“无害”。

改变 Z 轴层级

输入： 对象, Z

改变对象的图层：数字越大，对象越靠前。

示例： 让玩家显示在装饰物前面。

设置大小 (缩放)

输入： 对象, Scale X, Scale Y

改变对象的大小：1 = 正常，2 = 两倍大，0.5 = 一半。

示例： 玩家吃了蘑菇后变大。

销毁对象

输入： 对象

从场景中删除所选对象。

示例： 选择 “相关对象”，销毁玩家刚碰到的金币。

按标签销毁

输入： 要销毁的标签

删除所有带该标签的对象。

示例： 炸弹销毁所有“敌人”对象。

更换图像

输入： 对象, 图像

把对象的图片换成 Assets 里的另一张。留空 = 没有图片。

示例： 角色根据按下的按钮朝左或朝右看。

修改颜色

输入： 对象, 颜色

改变对象的颜色。

示例： 答案正确时按钮变绿。

生成克隆 (生成器)

输入： 对象 A, 对象 B

在对象 A（出生点）的位置创建对象 B（模板）的副本。

示例： 大炮（A）发射炮弹（B）。

颜色滤镜

输入： 对象, 滤镜

给对象加滤镜：黑白、棕褐色、反色，或选“无”去掉滤镜。

示例： 回忆片段时切换成黑白。

混合模式 (效果)

输入： 对象, 滤镜

改变对象与背后内容的混合方式（叠加、正片叠底、滤色、反色）。

示例： 用“叠加”做发光的灯或火焰。

镜像效果 / 翻转

输入： 对象, 轴

翻转对象：水平（左 / 右）或垂直（上 / 下）。

示例： 角色面朝行走的方向。

修改锁定状态

输入： 对象, 锁定（true / false）

在编辑器中锁定或解锁对象（小锁图标）。在游戏中没有任何作用：要禁止拖动对象，请使用 “设为可拖动”。

视差系数

输入： 对象, 系数（如 0.5）

设置摄像机移动时对象的滚动速度：1 = 正常，0.5 = 慢一半（景深效果）。

示例： 背景里缓慢移动的山。

链接两个对象

输入： 对象 A, 对象 B

把对象 A（子对象）绑到对象 B（父对象）上：B 移动时 A 跟着移动。

示例： 跟随角色手部的剑。

发光 (Glow)

输入： 对象, 状态, 颜色

打开或关闭对象周围的彩色光晕。

示例： 提示可以捡起的物品。

闪烁 (Blink)

输入： 对象, 状态, 速度（毫秒）, 持续时间（毫秒，0 = 无限）

让对象按所选速度（毫秒）闪烁一段时间（毫秒，0 = 一直闪），或停止闪烁。

示例： 玩家受伤后闪烁 1 秒。

生成克隆（X/Y位置）

输入： 对象 B, X, Y

在位置 X, Y 创建对象 B（模板）的副本。副本成为 “相关对象”。

示例： 在随机位置落下石头：X = random(0, 800)。

发射对象

输入： 对象 A, 对象 B, 模型名称, 方向, 速度

在对象 A 处创建一个投射物（“模型名称” 里写的对象），并按所选速度发射：0°、90°、180°、270°、朝向对象 B（“朝向目标”）或按 A 的角度。

示例： 向上发射激光的飞船（270）。

设置进度

输入： 对象, 新进度

设置进度条的填充量，介于最小值和最大值之间。

示例： “新进度” = vie，用于生命条。

屏幕穿透

输入： 对象

从屏幕一边出去的东西会从另一边回来（吃豆人效果）。

示例： 从右边飞出、又从左边回来的小行星。

保持在屏幕内

输入： 对象, 边距

不让对象离开屏幕。边距会让它在边缘前一点停下。

示例： 玩家的飞船始终可见。

创建对象

输入： 对象, X 位置, Y 位置

在位置 X, Y 创建所选对象（模板）的副本。

示例： 在指定位置放一个箱子。

淡入淡出

输入： 对象, 目标不透明度（0 到 1）, 持续时间（秒）

在所选时间（秒）内，把对象的透明度平滑地变到目标值。后面的节点不会等待。

示例： 1 秒内淡出标题（目标透明度 0）。

变量与背包

修改变量

输入： 对象, 变量, 值

给变量一个新值（数字、文本、true / false 或计算结果）。

示例： 把“score”重置为 0。

增加变量值

输入： 对象, 变量, 要增加的值

把数值加到变量上（负数就是减）。文本变量会把文字加到末尾。

示例： 每个金币 score + 1，每次受伤生命 - 1。

限制值 (Clamp)

输入： 对象, 变量, 最小值, 最大值

让变量（数字）保持在最小值和最大值之间。

示例： 生命值永远不超过 100。

随机数

输入： 对象, 变量, 值：random(min, max)

把一个随机数放进变量。random(1, 6) 得到 1 到 6 之间的数。

示例： 掷骰子。

加入物品栏

输入： 对象, 变量

把对象放进物品栏（类型为“物品栏列表”的变量）。同一个对象只会加入一次。

示例： 捡起钥匙。

从物品栏移除

输入： 对象, 变量

把对象从物品栏中移除。

示例： 用钥匙开门。

如果在物品栏中

输入： 对象, 变量  →  输出： 真 / 假 / 然后

对象在物品栏里时走 “真” 输出，否则走 “假”。

示例： 只有钥匙在物品栏里时门才会打开。

组合对象

输入： 对象 A, 对象 B, 结果对象名称

用你写下名字的那个对象的副本，替换对象 A 和 B，放在 A 的位置。如果这个模板不存在，什么也不变。

示例： 木棍 + 布 = 火把。

逻辑与条件

条件

输入： 条件  →  输出： 真 / 假 / 然后

检查一个条件：成立时走 “真”，否则走 “假”。之后两种情况都会运行 “然后”。

示例： score >= 10 → 真 → 下一个场景。

如果摇杆

输出： 上 / 下 / 左 / 右 / 静止 / 然后

根据摇杆方向走对应的输出：“上”、“下”、“左”、“右”，没碰摇杆时走 “静止”。

示例： 连接到 “每帧”，朝正确方向播放行走动画。

如果在地面

输入： 对象  →  输出： 真 / 假 / 然后

对象底部站在固定且可见的对象（地面、平台）上时为 “真”，否则为 “假”。

示例： 只允许玩家在地面上时跳跃。

如果在移动

输入： 对象  →  输出： 真 / 假 / 然后

对象从上一帧起移动过时为 “真”，否则为 “假”。

示例： 只在角色移动时播放行走动画。

调用函数

输入： 函数

运行一个函数（在“函数”区域里创建的 Blueprint），然后继续。不要放在 “每帧” 下面。

示例： 多个敌人共用的“扣血”函数。

调用事件

输入： 事件名称

运行同一个 Blueprint 里这个名字的 “本地事件”，然后继续。

示例： 从掉落和计时两个地方调用“GameOver”。

顺序

输出： 1 / 2 / 3 / 4

按顺序依次运行它的输出：1，然后 2，然后 3，然后 4。没有连线的输出会被跳过。

示例： 开始时：1 = 放置玩家，2 = 播放音乐，3 = 显示分数。

冷却

输入： 对象, 延迟（秒）  →  输出： 就绪 / 还没

每个间隔（秒）内最多从 “就绪” 通过一次；否则走 “还没”。选择了对象时，每个对象有自己的间隔。

示例： 最多每 0.5 秒射击一次。

如果在屏幕外

输入： 对象, 边距（像素）  →  输出： 真 / 假 / 然后

对象完全离开屏幕（加上边距）时为 “真”，否则为 “假”。

示例： 销毁飞出屏幕的子弹。

如果 / 否则

输入： 如果（条件）, 否则如果（条件）  →  输出： 如果 / 否则如果 / 否则 / 然后

先检查第一个条件，再检查第二个：走 “如果”、“否则如果” 或 “否则”。之后运行 “然后”。

示例： 如果 score >= 100 → 金牌，否则如果 score >= 50 → 银牌，否则 → 铜牌。

按值

输入： 要检测的值, 情况 1, 情况 2, 情况 3, 情况 4, 情况 5, 情况 6  →  输出： 1 / 2 / 3 / 4 / 5 / 6 / 无 / 然后

把要测试的值依次和情况 1 到 6 比较，走第一个相同情况的输出；都不相同时走 “无”。空着的情况会被跳过。

示例： 根据“武器”：1 = 剑，2 = 弓，3 = 魔杖。

文本与对话

修改文本

输入： 对象, 新文本

替换文本对象的文字。以 = 开头可以显示计算结果。

示例： ="分数：" + score

显示对话

输入： 对象, 对话键

从对话文件（dialogues.txt）中找到这个键对应的句子，写进文本对象。

示例： 键“nihao_shangren”显示商人的台词。

追加到文本

输入： 对象, 变量, 要追加的文本

把文字加到文本类型变量的末尾。

示例： 一个字母一个字母地输入密码。

移动与 AI

停止对象

输入： 对象

让对象立刻停下：不再有速度、推力、跳跃或自动移动。

示例： 冻住被冰冻法术击中的敌人。

停止移动

输入： 对象

关闭对象的自动移动：持续前进、追逐和逃跑。

示例： 玩家躲起来时，敌人停止追逐。

持续前进

输入： 对象, 速度

对象按所选速度，朝它面对的方向自动前进。

示例： 子弹或行驶中的汽车。

追踪对象

输入： 对象 A, 对象 B, 速度

对象 A 按所选速度自动朝对象 B 移动。

示例： 跟着玩家的幽灵。

躲避对象

输入： 对象 A, 对象 B, 速度

对象 A 按所选速度自动远离对象 B。

示例： 躲着玩家跑的小鸡。

设置弹跳

输入： 对象, 弹跳（0 到 1）

设置物理对象的弹性：0 = 不弹，1 = 弹得很高。

示例： 0.8：弹力球。

按角度推动

输入： 对象, 角度（0 = 右，90 = 下）, 力度

按所选力度，把对象朝某个方向推（角度：0 = 右，90 = 下，180 = 左，270 = 上）。

示例： 把玩家斜着弹出去的弹簧。

冲力（跳跃）

输入： 对象, 垂直力（负数 = 向上）

把对象向上（负数）或向下（正数）弹出，并给它物理效果让它落回来。

示例： 跳跃：力度 -15。

启用物理

输入： 对象, 会下落（true / false）

给对象加上物理：true 时会随重力下落；false 时像地面一样固定不动。

示例： 有人站上去就会塌掉的平台。

设为可拖动

输入： 对象, 可用手指拖动（true / false）

允许（true）或禁止（false）在游戏中用手指拖动对象。

示例： 锁住已经放对位置的拼图块。

蹦跳

输入： 对象, 强度（0 = 停止）, 持续时间（毫秒）, 移动时持续（true / false）

让对象按所选强度和时长蹦跳（小小的视觉弹跳）。0 表示停止。可以设置成对象移动时一直蹦跳。

示例： 走路时一蹦一跳的角色。

朝向

输入： 对象 A, 对象 B, 角度偏移（度）

让对象 A 转向对象 B。角度偏移用来修正图片朝向（0 = 图片朝右）。

示例： 瞄准玩家的炮塔。

滑向

输入： 对象, X 位置, Y 位置, 持续时间（秒）

在所选时间（秒）内把对象平滑地移动到位置 X, Y。后面的节点不会等待。

示例： 移动的平台，或滑入屏幕的菜单。

动画

播放动画

输入： 对象, 动画, 速度（帧/秒）, 循环（true / false）

按所选速度（每秒帧数）播放对象的某个动画，可以循环或只播一次。如果已经在播放，就继续播而不重新开始。

示例： 角色前进时播放“行走”动画。

停止动画

输入： 对象

停止动画并回到它的第一帧。

示例： 角色停止行走。

暂停动画

输入： 对象

把动画暂停在当前帧。

示例： 暂停时让角色定住。

继续动画

输入： 对象

从暂停的地方继续播放动画。

示例： 暂停结束后。

动画速度

输入： 对象, 速度（帧/秒）

改变动画速度（每秒帧数），不会重新开始播放。

示例： 跑得越快 = 动画越快。

音频

播放音效

输入： 音效文件

播放一个音效。可以同时播放多个音效。

示例： 捡到金币时的“叮”声。

播放音乐

输入： 音乐文件, 循环（true / false）

播放一段音乐，替换当前的音乐。不要放在 “每帧” 下面（它会不停地从头开始）。

示例： 开始时播放关卡音乐。

停止音乐

停止当前的音乐。

示例： Game Over 画面保持安静。
