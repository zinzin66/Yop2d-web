Référence des nœuds de Yop2D

Français · English · Español · Deutsch · Italiano · Português · Русский · 中文 · 日本語

Yop2D est un moteur de jeu 2D gratuit et sans code pour Android. La logique d'un jeu se construit avec des nœuds (blocs visuels) reliés entre eux dans le Blueprint : les événements lancent une chaîne, les actions et conditions s'enchaînent. Cette page décrit les 127 nœuds de l'éditeur, avec leurs réglages (entrées) et leurs sorties.

Événements

Au Démarrage

Se lance une seule fois, dès que la scène démarre.

Exemple : placer les ennemis, afficher le score de départ ou lancer la musique.

À chaque image

Se lance en boucle, à chaque image du jeu (environ 60 fois par seconde).

Exemple : suivre la position du doigt ou vérifier une condition en permanence. Évite d'y mettre « Jouer la musique » ou « Appeler une fonction ».

Fin de Clic

Se lance quand le joueur lève le doigt de l'écran, n'importe où.

Exemple : arrêter de tirer quand on lâche l'écran.

Au Clic sur Objet

Entrée : Objet

Se lance quand le doigt touche l'objet choisi.

Exemple : un bouton « Saut », ouvrir un coffre, choisir une réponse.

Fin de Clic sur Objet

Entrée : Objet

Se lance quand le doigt se lève au-dessus de l'objet choisi.

Exemple : valider un bouton seulement quand on le relâche.

Maintenu sur Objet

Entrée : Objet

Se répète à chaque image tant que le doigt reste posé sur l'objet choisi.

Exemple : des boutons gauche / droite : tant qu'on appuie, le personnage avance.

Doigt appuyé

Se répète à chaque image tant qu'un doigt est posé sur l'écran, n'importe où.

Exemple : faire monter un vaisseau tant qu'on appuie (utilise doigt.x et doigt.y dans les formules).

Début de Glisser

Entrée : Objet

Se lance quand le joueur commence à faire glisser l'objet choisi (il doit être « Déplaçable (glissable en mode Play) »).

Exemple : agrandir une carte quand on la prend.

Fin de Glisser

Entrée : Objet

Se lance quand le joueur lâche l'objet qu'il faisait glisser.

Exemple : vérifier si une pièce de puzzle est posée au bon endroit.

Collision A/B

Entrées : Objet A, Objet B

Se lance une fois, au moment où l'objet A commence à toucher l'objet B. Il faudra qu'ils se séparent pour qu'il se relance. C'est aussi l'événement à utiliser pour « entrer dans une zone ».

Exemple : le joueur touche la zone d'arrivée → niveau suivant.

Sortie de zone

Entrées : Objet A, Objet B

Se lance une fois, au moment où l'objet A cesse de toucher l'objet B (il sort de la zone).

Exemple : refermer une porte quand le joueur s'éloigne.

Au Survol

Entrée : Objet

Se lance quand le doigt, en glissant sur l'écran, arrive sur l'objet choisi.

Exemple : allumer un bouton quand le doigt passe dessus.

Fin de Survol

Entrée : Objet

Se lance quand le doigt quitte l'objet qu'il survolait.

Exemple : éteindre la surbrillance d'un bouton.

Au Choc (Physique)

Entrée : Objet

Se lance quand l'objet choisi (physique dynamique) retombe sur un sol ou rebondit.

Exemple : jouer un bruit d'atterrissage ou secouer la caméra.

Quand Variable Change

Entrée : Variable

Se lance à chaque fois que la valeur de la variable choisie change.

Exemple : quand « vie » change, mettre à jour la barre de vie.

Événement Local

Entrée : Nom de l'événement

Un événement à toi, avec le nom que tu choisis. Il se lance avec le nœud « Appeler un événement » placé dans le même Blueprint.

Exemple : un événement « GameOver » appelé depuis plusieurs endroits.

Au Clic Action (Aventure)

Se lance quand le joueur appuie sur l'objet « BtnAction » (bouton d'action) de la scène.

Exemple : parler à un personnage ou ouvrir une porte dans un jeu d'aventure.

Si objet touche Tag

Entrées : Objet, Tag

Se lance une fois par contact quand l'objet choisi touche un objet qui porte ce tag. L'objet touché devient l'« Objet Impliqué ».

Exemple : le joueur touche une pièce (tag « piece ») → détruire l'objet impliqué et ajouter 1 au score.

Scène & HUD

Changer de scène

Entrée : Scène  →  Sortie : aucune (fin du script)

Quitte la scène actuelle et va à la scène choisie. Ce nœud termine le script.

Exemple : aller à l'écran « Bravo ! » après le dernier niveau.

Aller à la scène (par son nom)

Entrée : Nom de la scène  →  Sortie : aucune (fin du script)

Va à la scène dont tu écris le nom (ou une formule qui donne ce nom). Ce nœud termine le script.

Exemple : une formule comme ="Niveau" + niveau pour choisir le niveau avec une variable.

Scène suivante

Sortie : aucune (fin du script)

Va à la scène placée juste après dans la liste des scènes. Ce nœud termine le script.

Exemple : le joueur atteint l'arrivée → niveau suivant.

Scène précédente

Sortie : aucune (fin du script)

Va à la scène placée juste avant dans la liste des scènes. Ce nœud termine le script.

Exemple : un bouton « Retour » dans un menu.

Recommencer la scène

Sortie : aucune (fin du script)

Relance la scène depuis le début : objets à leur place et variables locales remises à leur valeur de départ. Les variables globales ne changent pas.

Exemple : Game Over quand la vie tombe à 0.

Ouvrir un HUD

Entrée : Scène

Affiche une autre scène par-dessus le jeu, comme un calque (HUD), avec son propre Blueprint.

Exemple : un menu de pause ou un inventaire.

Fermer le HUD

Ferme le HUD ouvert.

Exemple : le bouton « Fermer » du menu de pause.

Placer une copie d'une scène

Entrées : Scène, Position X, Position Y

Place une copie de la scène choisie (prefab) dans le jeu, à la position X, Y.

Exemple : faire apparaître un groupe d'ennemis préparé dans une autre scène.

Détruire les copies d'une scène

Entrée : Scène

Supprime toutes les copies de la scène choisie placées dans le jeu.

Exemple : effacer tous les groupes d'ennemis à la fin d'une vague.

Quitter le jeu

Sortie : aucune (fin du script)

Ferme le jeu exporté. Dans l'éditeur, il ne ferme rien : utilise le bouton stop.

Exemple : un bouton « Quitter » dans le menu principal.

Toast

Entrée : Message

Affiche un petit message en bas de l'écran pendant quelques secondes. Commence par = pour afficher un calcul.

Exemple : ="Score : " + score

Écrire dans le journal

Entrée : Message

Écrit un message dans le journal du projet (fichier de diagnostic), sans rien afficher dans le jeu. Commence par = pour écrire un calcul.

Exemple : ="vie = " + vie, pour vérifier une valeur pendant un test.

Fixer la caméra

Entrées : Objet, Suivre en X (true / false), Suivre en Y (true / false), Parallaxe en X seulement (true / false)

La caméra suit l'objet choisi. Tu peux la faire suivre seulement à l'horizontale ou à la verticale. Sans objet, la caméra ne suit plus rien.

Exemple : suivre le joueur dans un grand niveau de plateforme.

Limites de la caméra

Entrées : X minimum (bord gauche du niveau), X maximum (bord droit), Y minimum (haut), Y maximum (bas ; tout à 0 = sans limites)

Empêche la caméra de sortir des bords du niveau : elle ne montre jamais le vide au-delà. Tout à 0 = plus de limites.

Exemple : niveau de 6480 pixels de large : X minimum 0, X maximum 6480, Y minimum 0, Y maximum 1080, avec « Fixer la caméra » sur le joueur.

Élasticité de la caméra

Entrée : Vitesse de suivi (0.01 à 1)

Règle la vitesse à laquelle la caméra rattrape l'objet suivi : 0.01 = très souple, 1 = collée à l'objet.

Exemple : 0.1 pour une caméra douce qui suit avec un léger retard.

Flash de l'écran

Entrées : Couleur, Intensité (%, 0 = aucune), Durée (secondes)

Fait un éclair de couleur sur tout l'écran, qui s'efface en quelques instants (intensité en %, durée en secondes).

Exemple : un flash rouge de 0,5 seconde quand le joueur est touché.

Teinte de l'écran

Entrées : Couleur, Intensité (%, 0 = aucune), Transition (secondes)

Pose une couleur sur tout le jeu (sous le HUD), avec une transition douce. Intensité 0 pour l'enlever.

Exemple : la nuit tombe : bleu foncé, intensité 55, transition 2 secondes.

Bords assombris

Entrées : Couleur, Intensité (%, 0 = aucune), Transition (secondes)

Assombrit doucement les bords de l'écran, comme au cinéma (sous le HUD). Intensité 0 pour l'enlever.

Exemple : une ambiance angoissante dans une grotte : intensité 75.

Fondu de l'écran

Entrées : Sens, Couleur, Durée (secondes)

Fait disparaître tout l'écran vers une couleur, ou le fait réapparaître depuis elle. Le fondu continue d'une scène à l'autre.

Exemple : « Fondu de l'écran » (disparaître), « Attendre » 1 seconde, « Changer de scène », puis « Fondu de l'écran » (apparaître) au démarrage du niveau suivant.

Tremblement de la caméra

Entrées : Intensité, Durée (ms)

Secoue l'écran avec la force et la durée choisies (en millisecondes).

Exemple : une explosion : intensité 15, durée 400.

Vibration

Entrée : Durée (ms)

Fait vibrer le téléphone pendant la durée choisie (en millisecondes). Sans vibreur, il ne se passe rien.

Exemple : 100 ms quand le joueur est touché.

Sauvegarder l'état

Mémorise l'état de la scène (objets et variables) et les variables globales, comme un point de sauvegarde.

Exemple : un drapeau de checkpoint au milieu du niveau.

Restaurer l'état

Remet la scène comme au dernier « Sauvegarder l'état ». S'il n'y a pas encore de sauvegarde, rien ne change.

Exemple : repartir du checkpoint après une chute.

Temps

Attendre

Entrée : Durée (secondes)

Attend la durée choisie, en secondes, puis continue avec la suite. Le reste du jeu continue pendant l'attente.

Exemple : afficher « Perdu ! », attendre 2 secondes, puis recommencer la scène.

Répéter

Entrées : Toutes les (secondes), Nombre de fois (0 = sans fin), Nom du minuteur (facultatif)  →  Sorties : Tout de suite / À chaque fois / Terminé

Lance la sortie « À chaque fois » toutes les X secondes, un certain nombre de fois (0 = sans fin), puis « Terminé ». « Tout de suite » part dès le début. S'il tourne déjà, il ne se relance pas.

Exemple : faire apparaître un ennemi toutes les 3 secondes.

Compte à rebours

Entrées : Objet, Variable, Départ (facultatif), Nom du minuteur (facultatif)  →  Sorties : Chaque seconde / Terminé

Enlève 1 à la variable choisie (un nombre) chaque seconde jusqu'à 0. « Chaque seconde » se lance à chaque tic, « Terminé » à 0. « Départ (facultatif) » donne la valeur de départ.

Exemple : un chrono de 60 secondes : à 0, Game Over.

Arrêter un minuteur

Entrée : Nom du minuteur (vide = tous)

Arrête le minuteur (Répéter ou Compte à rebours) qui porte ce nom, ou tous les minuteurs si le nom est vide.

Exemple : arrêter le chrono quand le joueur gagne.

Vitesse du jeu (ralenti)

Entrée : Vitesse (1 = normal, 0.5 = ralenti)

Change la vitesse de tout le jeu : 1 = normal, 0.5 = ralenti, 2 = accéléré (de 0 à 4).

Exemple : un effet ralenti pendant 2 secondes.

Mettre le jeu en pause

Met le jeu en pause : les mouvements et les minuteurs s'arrêtent.

Exemple : ouvrir le menu de pause.

Reprendre le jeu

Relance le jeu après une pause.

Exemple : le bouton « Continuer » du menu de pause.

Arrêt sur image (impact)

Entrées : Durée (secondes), Vitesse pendant l'arrêt (0 = figé)

Ralentit presque jusqu'à l'arrêt tout le jeu pendant un très court instant (en secondes réelles), puis le jeu reprend sa vitesse. Donne du « punch » aux impacts.

Exemple : quand un ennemi explose : durée 0,06, vitesse 0,05.

Apparence & Objets

Déplacer Objet

Entrées : Objet, X, Y

Place l'objet directement à la position X, Y (téléportation).

Exemple : remettre le joueur au point de départ.

Pousser objet

Entrées : Objet, Ajout X, Ajout Y

Déplace l'objet de la distance donnée à partir de sa position actuelle. Un objet physique est arrêté par les murs.

Exemple : relié à « Maintenu sur Objet » : « Ajout X » = 5 fait avancer vers la droite.

Modifier une propriété

Entrées : Objet, Propriété, Valeur

Change une propriété de l'objet choisie dans une liste (x, y, rotation, opacité, texte…).

Exemple : mettre la rotation d'une aiguille à =temps * 90.

Rotation

Entrées : Objet, Angle (degrés)

Tourne l'objet à l'angle donné, en degrés.

Exemple : =roue.rotation + 5 relié à « À chaque image » fait tourner l'objet « roue » en continu.

Modifier l'Opacité (Alpha)

Entrées : Objet, Opacité (0 à 1)

Règle la transparence de l'objet : 0 = invisible, 1 = opaque.

Exemple : 0.5 pour un fantôme à moitié transparent.

Visibilité

Entrées : Objet, Visible (true / false)

Montre (true) ou cache (false) l'objet.

Exemple : afficher un message « Gagné ! » caché au départ.

Définir le Tag

Entrées : Objet, Tag

Donne un nouveau tag (étiquette) à l'objet.

Exemple : un ennemi vaincu prend le tag « inoffensif ».

Changer Z-Order

Entrées : Objet, Z

Change le calque de l'objet : plus le nombre est grand, plus l'objet passe devant les autres.

Exemple : faire passer le joueur devant un décor.

Définir la taille (Scale)

Entrées : Objet, Scale X, Scale Y

Change la taille de l'objet : 1 = normal, 2 = deux fois plus grand, 0.5 = moitié.

Exemple : le joueur grandit après avoir mangé un champignon.

Détruire Objet

Entrée : Objet

Supprime l'objet choisi de la scène.

Exemple : choisir « Objet Impliqué » pour détruire la pièce que le joueur vient de toucher.

Détruire par Tag

Entrée : Tag à détruire

Supprime tous les objets qui portent ce tag.

Exemple : une bombe détruit tous les objets « Ennemi ».

Changer Image

Entrées : Objet, Image

Remplace l'image de l'objet par une autre image des Assets. Vide = pas d'image.

Exemple : le personnage regarde à gauche ou à droite selon le bouton.

Modifier Couleur

Entrées : Objet, Couleur

Change la couleur de l'objet.

Exemple : un bouton devient vert quand la réponse est bonne.

Générer un clone (Spawner)

Entrées : Objet A, Objet B

Crée une copie de l'objet B (le modèle) à l'endroit de l'objet A (le point d'apparition).

Exemple : un canon (A) qui fait apparaître des boulets (B).

Filtre Couleur

Entrées : Objet, Filtre

Applique un filtre à l'objet : Noir et Blanc, Sépia, Inversion, ou Aucun pour l'enlever.

Exemple : passer en noir et blanc pendant un souvenir.

Mode de fusion (Effet)

Entrées : Objet, Filtre

Change la façon dont l'objet se mélange avec ce qu'il y a derrière (Additif, Multiplicatif, Écran, Inversion).

Exemple : Additif pour une lumière ou une flamme qui brille.

Effet Miroir / Inverser

Entrées : Objet, Axe

Retourne l'objet : Horizontal (gauche / droite) ou Vertical (haut / bas).

Exemple : le personnage regarde du côté où il marche.

Modifier Verrouillage

Entrées : Objet, Verrouillé (true / false)

Verrouille ou déverrouille l'objet dans l'éditeur (le cadenas). N'a aucun effet pendant le jeu : pour empêcher de faire glisser un objet, utilise « Rendre déplaçable ».

Facteur de Parallaxe

Entrées : Objet, Facteur (ex : 0.5)

Règle la vitesse de défilement de l'objet quand la caméra bouge : 1 = normal, 0.5 = deux fois plus lent (effet de profondeur).

Exemple : des montagnes au fond qui défilent lentement.

Lier deux objets

Entrées : Objet A, Objet B

Attache l'objet A (l'enfant) à l'objet B (le parent) : A suit B quand il bouge.

Exemple : une épée qui suit la main du personnage.

Surbrillance (Glow)

Entrées : Objet, État, Couleur, Taille du halo

Entoure l'objet d'un halo lumineux doux, de la couleur et de la taille choisies (il suit la forme des images), ou l'enlève.

Exemple : un bonus qui brille en jaune, taille 20.

Effet de particules

Entrées : Objet, Modèle, Nombre (0 = celui du modèle), Couleur (vide = celle du modèle), Taille (1 = normale)

Lance une gerbe de particules sur l'objet : explosion, étincelles, poussière, fumée, feu, pluie, neige, confettis, traînée, sillage, hyperespace ou lignes de vitesse. Nombre, couleur et taille réglables.

Exemple : un ennemi touché explose en magenta : modèle Explosion, couleur #FF40D0.

Allumer / éteindre les particules

Entrées : Objet, État

Allume ou éteint un objet « Particules » : il émet en continu ou s'arrête (les particules déjà lancées finissent leur vie).

Exemple : allumer le réacteur quand le vaisseau avance.

Salve de particules

Entrées : Objet, Nombre de particules

Lance d'un coup un nombre de particules depuis un objet « Particules », avec ses réglages (modèle, couleur, taille).

Exemple : 80 confettis quand le niveau est gagné.

Changer le modèle de particules

Entrées : Objet, Modèle

Change le modèle d'un objet « Particules » pendant le jeu.

Exemple : un feu qui devient de la fumée quand on l'éteint.

Clignotement (Blink)

Entrées : Objet, État, Vitesse (ms), Durée (ms, 0 = infini)

Fait clignoter l'objet à la vitesse choisie (ms), pendant une durée (ms, 0 = sans fin), ou arrête le clignotement.

Exemple : le joueur clignote 1 seconde après avoir été touché.

Générer clone (Position X/Y)

Entrées : Objet B, X, Y

Crée une copie de l'objet B (le modèle) à la position X, Y. La copie devient l'« Objet Impliqué ».

Exemple : faire tomber une pierre à une position au hasard : X = random(0, 800).

Tirer un objet

Entrées : Objet A, Objet B, Nom du modèle, Direction, Vitesse, Détruire hors de l'écran (true / false)

Crée un projectile (l'objet nommé dans « Nom du modèle ») à l'endroit de l'objet A, et le lance à la vitesse choisie : 0°, 90°, 180°, 270°, vers l'objet B (« Vers la cible ») ou selon l'angle de A.

Exemple : un vaisseau qui tire des lasers vers le haut (270).

Définir la Progression

Entrées : Objet, Nouvelle progression

Règle le remplissage d'une barre de progression, entre son minimum et son maximum.

Exemple : « Nouvelle progression » = vie, pour une barre de vie.

Traverser l'écran

Entrée : Objet

Ce qui sort d'un côté de l'écran réapparaît du côté opposé (effet Pac-Man).

Exemple : un astéroïde qui sort à droite et revient à gauche.

Garder dans l'écran

Entrées : Objet, Marge

Empêche l'objet de sortir de l'écran. La marge l'arrête un peu avant le bord.

Exemple : le vaisseau du joueur reste toujours visible.

Électrocution

Entrées : Objet, Couleur des éclairs, Durée (secondes, 0 = sans fin), Intensité (0 = arrêter, 1 à 3)

Des éclairs crépitent autour de l'objet : il clignote dans la couleur de l'éclair, tremble et lâche des étincelles. Durée 0 = sans fin (clôture électrique) ; intensité 0 = arrêter.

Exemple : le magicien touche un piège : « Électrocution » sur le magicien (1 seconde), « Attendre » 1 seconde, puis « Recommencer la scène ».

Traînée derrière l'objet

Entrées : Objet, Modèle, Couleur (vide = celle du modèle), Taille (1 = normale)

L'objet laisse une traînée de particules derrière lui quand il bouge (modèle, couleur, taille au choix). Posée sur le modèle d'un tir, chaque tir en hérite. Modèle « Aucun » pour l'enlever.

Exemple : des tirs qui laissent une traînée lumineuse : cible = le modèle du tir, modèle Traînée.

Créer un objet

Entrées : Objet, Position X, Position Y

Crée une copie de l'objet choisi (le modèle) à la position X, Y.

Exemple : ajouter une caisse à un endroit précis.

Fondu

Entrées : Objet, Opacité cible (0 à 1), Durée (secondes)

Change doucement l'opacité de l'objet jusqu'à la valeur cible, pendant la durée choisie (secondes). La suite continue sans attendre.

Exemple : faire disparaître un titre en 1 seconde (opacité cible 0).

Variables & Inventaire

Modifier Variable

Entrées : Objet, Variable, Valeur

Donne une nouvelle valeur à la variable (un nombre, un texte, true / false ou un calcul).

Exemple : remettre « score » à 0.

Ajouter à Variable

Entrées : Objet, Variable, Valeur à ajouter

Ajoute la valeur à la variable (un nombre négatif retire). Pour une variable texte, ajoute le texte à la fin.

Exemple : score + 1 à chaque pièce, vie - 1 à chaque coup.

Limiter Valeur (Clamp)

Entrées : Objet, Variable, Minimum, Maximum

Garde la variable (un nombre) entre un minimum et un maximum.

Exemple : la vie ne dépasse jamais 100.

Nombre aléatoire

Entrées : Objet, Variable, Valeur : random(min, max)

Met un nombre au hasard dans la variable. random(1, 6) donne un nombre entre 1 et 6.

Exemple : un lancer de dé.

Ajouter à l'inventaire

Entrées : Objet, Variable

Met l'objet dans l'inventaire (une variable de type Liste d'Inventaire). Il n'y est ajouté qu'une fois.

Exemple : ramasser une clé.

Retirer de l'inventaire

Entrées : Objet, Variable

Retire l'objet de l'inventaire.

Exemple : utiliser la clé pour ouvrir la porte.

Si dans l'inventaire

Entrées : Objet, Variable  →  Sorties : Vrai / Faux / Ensuite

Suit la sortie Vrai si l'objet est dans l'inventaire, Faux sinon.

Exemple : la porte ne s'ouvre que si la clé est dans l'inventaire.

Combinaison d'objets

Entrées : Objet A, Objet B, Nom de l'objet résultat

Remplace les objets A et B par une copie de l'objet dont tu écris le nom, à la place de A. Si ce modèle n'existe pas, rien ne change.

Exemple : bâton + chiffon = torche.

Logique & Conditions

Condition

Entrée : Condition  →  Sorties : Vrai / Faux / Ensuite

Teste une condition : suit la sortie Vrai si elle est juste, Faux sinon. « Ensuite » se lance après, dans les deux cas.

Exemple : score >= 10 → Vrai → scène suivante.

Si joystick

Sorties : Haut / Bas / Gauche / Droite / Repos / Ensuite

Suit la sortie qui correspond à la direction du joystick : Haut, Bas, Gauche, Droite, ou Repos s'il n'est pas touché.

Exemple : relié à « À chaque image » pour jouer l'animation de marche dans la bonne direction.

Si au sol

Entrée : Objet  →  Sorties : Vrai / Faux / Ensuite

Vrai si le bas de l'objet est posé sur un objet fixe et visible (sol, plateforme), Faux sinon.

Exemple : n'autoriser le saut que si le joueur est au sol.

Si en mouvement

Entrée : Objet  →  Sorties : Vrai / Faux / Ensuite

Vrai si l'objet a bougé depuis l'image précédente, Faux sinon.

Exemple : jouer l'animation de marche seulement quand le personnage bouge.

Appeler une fonction

Entrée : Fonction

Lance une fonction (un Blueprint créé dans la section Fonctions), puis continue. À ne pas mettre sous « À chaque image ».

Exemple : une fonction « PerdreVie » utilisée par plusieurs ennemis.

Appeler un événement

Entrée : Nom de l'événement

Lance l'« Événement Local » qui porte ce nom, dans le même Blueprint, puis continue.

Exemple : appeler « GameOver » depuis la chute et depuis le chrono.

Séquence

Sorties : 1 / 2 / 3 / 4

Lance ses sorties l'une après l'autre : 1, puis 2, puis 3, puis 4. Une sortie sans lien est ignorée.

Exemple : au démarrage : 1 = placer le joueur, 2 = lancer la musique, 3 = afficher le score.

Cooldown

Entrées : Objet, Délai (secondes)  →  Sorties : Prêt / Pas encore

Laisse passer par « Prêt » au maximum une fois par délai (en secondes) ; sinon, c'est « Pas encore ». Avec un objet choisi, chaque objet a son propre délai.

Exemple : tirer au maximum une fois toutes les 0.5 seconde.

Si hors écran

Entrées : Objet, Marge (pixels)  →  Sorties : Vrai / Faux / Ensuite

Vrai si l'objet est entièrement sorti de l'écran (plus la marge), Faux sinon.

Exemple : détruire les balles qui sortent de l'écran.

Si / Sinon

Entrées : Si (condition), Sinon si (condition)  →  Sorties : Si / Sinon si / Sinon / Ensuite

Teste la première condition, puis la deuxième : suit « Si », « Sinon si » ou « Sinon ». « Ensuite » se lance après.

Exemple : si score >= 100 → or, sinon si score >= 50 → argent, sinon → bronze.

Selon la valeur

Entrées : Valeur à tester, Cas 1, Cas 2, Cas 3, Cas 4, Cas 5, Cas 6  →  Sorties : 1 / 2 / 3 / 4 / 5 / 6 / Aucun / Ensuite

Compare la valeur à tester avec les cas 1 à 6 et suit la sortie du premier cas identique ; « Aucun » si rien ne correspond. Un cas vide est ignoré.

Exemple : selon « arme » : 1 = épée, 2 = arc, 3 = baguette.

Textes & Dialogues

Modifier Texte

Entrées : Objet, Nouveau texte

Remplace le texte d'un objet Texte. Commence par = pour afficher un calcul.

Exemple : ="Score : " + score

Afficher un dialogue

Entrées : Objet, Clé du dialogue

Écrit dans l'objet Texte la phrase qui correspond à la clé, dans le fichier des dialogues (dialogues.txt). Plusieurs langues : écrire « bonjour.fr = Bonjour », « bonjour.en = Hello »… ; le jeu prend la langue de la variable « langue », sinon celle du téléphone. « \n » = retour à la ligne.

Exemple : la clé « bonjour_marchand » affiche la réplique du marchand.

Ajouter au texte

Entrées : Objet, Variable, Texte à ajouter

Ajoute du texte à la fin d'une variable de type Texte.

Exemple : écrire un mot de passe lettre par lettre.

Mouvements & IA

Arrêter l'objet

Entrée : Objet

Arrête net l'objet : plus de vitesse, de poussée, de saut ni de déplacement automatique.

Exemple : geler un ennemi touché par un sort de glace.

Stopper les mouvements

Entrée : Objet

Coupe les déplacements automatiques de l'objet : avancer en continu, poursuivre et fuir.

Exemple : l'ennemi arrête de poursuivre quand le joueur se cache.

Avancer en continu

Entrées : Objet, Vitesse

L'objet avance tout seul, dans la direction où il est tourné, à la vitesse choisie.

Exemple : une balle ou une voiture qui roule.

Poursuivre un objet

Entrées : Objet A, Objet B, Vitesse

L'objet A avance tout seul vers l'objet B, à la vitesse choisie.

Exemple : un fantôme qui suit le joueur.

Fuir un objet

Entrées : Objet A, Objet B, Vitesse

L'objet A s'éloigne tout seul de l'objet B, à la vitesse choisie.

Exemple : une poule qui fuit le joueur.

Changer le rebond

Entrées : Objet, Rebond (0 à 1)

Règle le rebond d'un objet physique : 0 = ne rebondit pas, 1 = rebondit fort.

Exemple : 0.8 pour une balle rebondissante.

Pousser selon un angle

Entrées : Objet, Angle (0 = droite, 90 = bas), Force

Pousse l'objet dans une direction (en degrés : 0 = droite, 90 = bas, 180 = gauche, 270 = haut) avec la force choisie.

Exemple : un ressort qui envoie le joueur en diagonale.

Impulsion (saut)

Entrées : Objet, Force verticale (négatif = monte)

Lance l'objet vers le haut (nombre négatif) ou vers le bas (positif), et lui donne la physique pour qu'il retombe.

Exemple : un saut : force -15.

Activer la physique

Entrées : Objet, Tombe (true / false)

Donne la physique à l'objet : Tombe = true, il tombe avec la gravité ; false, il reste fixe comme un sol.

Exemple : une plateforme qui s'écroule quand on marche dessus.

Rendre déplaçable

Entrées : Objet, Déplaçable au doigt (true / false)

Autorise (true) ou interdit (false) de faire glisser l'objet avec le doigt pendant le jeu.

Exemple : bloquer une pièce de puzzle bien placée.

Sautiller

Entrées : Objet, Intensité (0 = arrêter), Durée (ms), Continue tant que ça bouge (true / false)

Fait sautiller l'objet (petit rebond visuel) avec l'intensité et la durée choisies. 0 arrête. Il peut continuer tant que l'objet bouge.

Exemple : un personnage qui sautille en marchant.

Orienter vers

Entrées : Objet A, Objet B, Décalage d'angle (degrés)

Tourne l'objet A vers l'objet B. Le décalage corrige le sens de l'image (0 = l'image regarde à droite).

Exemple : une tourelle qui vise le joueur.

Glisser vers

Entrées : Objet, Position X, Position Y, Durée (secondes)

Déplace l'objet en douceur jusqu'à la position X, Y, pendant la durée choisie (secondes). La suite continue sans attendre.

Exemple : une plateforme qui se déplace ou un menu qui entre à l'écran.

Animations

Jouer l'animation

Entrées : Objet, Animation, Vitesse (images/seconde), En boucle (true / false)

Joue une animation de l'objet, à la vitesse choisie (images par seconde), en boucle ou une seule fois. Si elle est déjà en cours, elle continue sans recommencer.

Exemple : l'animation « marche » quand le personnage avance.

Arrêter l'animation

Entrée : Objet

Arrête l'animation et revient à sa première image.

Exemple : le personnage s'arrête de marcher.

Pause de l'animation

Entrée : Objet

Met l'animation en pause sur l'image en cours.

Exemple : figer le personnage pendant la pause.

Reprendre l'animation

Entrée : Objet

Reprend l'animation là où elle était en pause.

Exemple : après la pause.

Vitesse de l'animation

Entrées : Objet, Vitesse (images/seconde)

Change la vitesse de l'animation (images par seconde) sans la relancer.

Exemple : courir plus vite = animation plus rapide.

Audio

Jouer un son

Entrées : Fichier son, Volume (%, 100 = plein)

Joue un bruitage. Plusieurs sons peuvent se jouer en même temps.

Exemple : un « bling » quand on ramasse une pièce.

Jouer la musique

Entrées : Fichier musique, En boucle (true / false), Volume (%, 100 = plein)

Lance une musique, qui remplace la musique en cours. À ne pas mettre sous « À chaque image » (elle recommencerait sans arrêt).

Exemple : la musique du niveau, au démarrage.

Arrêter la musique

Arrête la musique en cours.

Exemple : silence pendant l'écran de Game Over.
