Yop2D ノードリファレンス

Français · English · Español · Deutsch · Italiano · Português · Русский · 中文 · 日本語

Yop2D は、Android 向けの無料・コード不要の 2D ゲームエンジンです。ゲームのロジックは、Blueprint の中でつないだノード（ビジュアルブロック）で作ります。イベントがつながりを始め、そのあとにアクションや条件が続きます。このページでは、エディターの 149 個のノードを、設定（入力）と出力とともに説明します。

カテゴリー

イベントシーンとHUD時間外観とオブジェクト変数とインベントリロジックと条件テキストとダイアログ移動とAIグリッドとパズルアニメーションオーディオストーリーと会話値（緑の線）

イベント

起動時

シーンが始まったとき、一度だけ動きます。

例： 敵を配置する、最初のスコアを表示する、音楽を流す。

毎フレーム

ゲームの毎フレーム（1 秒に約 60 回）、ずっと動き続けます。

例： 指の位置を追う、条件をいつも確認する。この下に 「音楽を再生」 や 「関数を呼ぶ」 を置かないでください。

クリック終了

プレイヤーが画面のどこかで指を離したときに動きます。

例： 画面から指を離したら射撃をやめる。

オブジェクトクリック時

入力： オブジェクト

指が選んだオブジェクトに触れたときに動きます。 対象をタグ（「# カード」）にすると、そのタグの付いたどのオブジェクトでも始まります：さわったオブジェクトが「関係するオブジェクト」になります。

例： 「ジャンプ」ボタン、宝箱を開ける、答えを選ぶ。

オブジェクトを離した時

入力： オブジェクト

選んだオブジェクトの上で指を離したときに動きます。

例： ボタンを離したときだけ決定する。

オブジェクトを押している間

入力： オブジェクト

指が選んだオブジェクトに触れている間、毎フレームくり返し動きます。

例： 左 / 右ボタン：押している間、キャラクターが進む。

指で押している間

画面のどこかに指が触れている間、毎フレームくり返し動きます。

例： 押している間、宇宙船を上昇させる（数式で doigt.x と doigt.y を使う）。

ドラッグ開始

入力： オブジェクト

プレイヤーが選んだオブジェクトをドラッグし始めたときに動きます（オブジェクトは 「移動可能 (ドラッグ可能)」 である必要があります）。

例： カードを持ったら大きくする。

ドラッグ終了

入力： オブジェクト

プレイヤーがドラッグしていたオブジェクトを離したときに動きます。

例： パズルのピースが正しい場所に置かれたか確認する。

衝突 A/B

入力： オブジェクト A, オブジェクト B

オブジェクト A がオブジェクト B に触れ始めた瞬間に一度だけ動きます。もう一度動くには、いったん離れる必要があります。「ゾーンに入る」にもこのイベントを使います。

例： プレイヤーがゴールゾーンに触れる → 次のステージ。

ゾーンから出る

入力： オブジェクト A, オブジェクト B

オブジェクト A がオブジェクト B から離れた（ゾーンから出た）瞬間に一度だけ動きます。

例： プレイヤーが離れたらドアを閉める。

ホバー時

入力： オブジェクト

画面をなぞる指が、選んだオブジェクトの上に来たときに動きます。

例： 指が通ったらボタンを光らせる。

ホバー終了

入力： オブジェクト

指がその上にあったオブジェクトから外れたときに動きます。

例： ボタンの光を消す。

物理的な衝突時

入力： オブジェクト

選んだオブジェクト（動的な物理）が地面に着地したり、跳ね返ったりしたときに動きます。

例： 着地の音を鳴らす、カメラを揺らす。

変数が変更された時

入力： 変数

選んだ変数の値が変わるたびに動きます。

例： 「vie」（体力）が変わったら体力バーを更新する。

ローカルイベント

入力： イベント名

好きな名前をつけた、自分だけのイベントです。同じ Blueprint にある 「イベントを呼ぶ」 ノードで動かします。

例： いろいろな場所から呼び出す「GameOver」イベント。

アクションボタンクリック時 (アドベンチャー)

プレイヤーがシーンの 「アクションボタン」 オブジェクト（アクションボタン）を押したときに動きます。

例： アドベンチャーゲームでキャラクターと話す、ドアを開ける。

オブジェクトがタグに触れた場合

入力： オブジェクト, タグ

選んだオブジェクトがこのタグを持つオブジェクトに触れたとき、接触ごとに一度だけ動きます。触れたオブジェクトは 「関連オブジェクト」 になります。

例： プレイヤーがコイン（タグ「piece」）に触れる → 関連オブジェクトを削除して、スコアを 1 増やす。

シーンとHUD

シーンを切り替える

入力： シーン  →  出力： なし（スクリプト終了）

今のシーンを出て、選んだシーンに移ります。このノードでスクリプトは終わります。

例： 最後のステージのあと「よくできました！」画面に移る。

名前でシーンへ移動

入力： シーン名  →  出力： なし（スクリプト終了）

名前を書いたシーン（またはその名前になる数式）に移ります。このノードでスクリプトは終わります。

例： ="ステージ" + level のような数式で、変数を使ってステージを選ぶ。

次のシーン

出力： なし（スクリプト終了）

シーンの一覧で、すぐ次にあるシーンに移ります。このノードでスクリプトは終わります。

例： プレイヤーがゴールに着く → 次のステージ。

前のシーン

出力： なし（スクリプト終了）

シーンの一覧で、すぐ前にあるシーンに移ります。このノードでスクリプトは終わります。

例： メニューの「戻る」ボタン。

シーンをやり直す

出力： なし（スクリプト終了）

シーンを最初からやり直します。オブジェクトは元の場所に、ローカル変数は最初の値に戻ります。グローバル変数は変わりません。

例： 体力が 0 になったら Game Over。

HUDを開く

入力： シーン

別のシーンを、ゲームの上にレイヤー（HUD）として表示します。そのシーンには自分の Blueprint があります。

例： ポーズメニューやインベントリ。

HUDを閉じる

開いている HUD を閉じます。

例： ポーズメニューの「閉じる」ボタン。

シーンのコピーを配置

入力： シーン, X位置, Y位置

選んだシーン（プレハブ）のコピーを、X, Y の位置でゲームに置きます。

例： 別のシーンで作った敵のグループを出現させる。

シーンのコピーを破棄

入力： シーン

ゲームに置いた、選んだシーンのコピーをすべて消します。

例： ウェーブの終わりに敵のグループをすべて消す。

ゲームを終了

出力： なし（スクリプト終了）

書き出したゲームを閉じます。エディターでは何も閉じません。停止ボタンを使ってください。

例： タイトルメニューの「終了」ボタン。

画面下の小さなメッセージ

入力： メッセージ

画面の下に短いメッセージを数秒間表示します。= で始めると計算結果を表示できます。

例： ="スコア：" + score

ログに書く（デバッグ用）

入力： メッセージ

プロジェクトのログ（診断ファイル）にメッセージを書きます。ゲームには何も表示されません。= で始めると計算結果を書けます。

例： ="体力 = " + vie で、テスト中に値を確認する。

カメラを固定

入力： オブジェクト, Xを追う（はい / いいえ）, Yを追う（はい / いいえ）, X方向のみ視差（はい / いいえ）

カメラが選んだオブジェクトを追いかけます。横だけ、縦だけにもできます。オブジェクトがないと、カメラは何も追いかけません。

例： 大きなアクションステージでプレイヤーを追う。

カメラの範囲

入力： 最小X（レベルの左端）, 最大X（右端）, 最小Y（上端）, 最大Y（下端、すべて0 = 制限なし）

カメラがレベルの端から出ないようにします：外側の何もない所は映りません。すべて0 = 制限なし。

例： 幅6480ピクセルのレベル：最小X 0、最大X 6480、最小Y 0、最大Y 1080、プレイヤーに 「カメラを固定」 と一緒に使う。

カメラの滑らかさ

入力： 追従速度（0.01〜1）

カメラが追いかけるオブジェクトに追いつく速さを決めます。0.01 = とてもゆるやか、1 = ぴったりくっつく。

例： 0.1 で、少し遅れてなめらかについてくるカメラ。

画面フラッシュ

入力： 色, 強さ（%、0 = なし）, 時間（秒）

画面全体を一瞬ある色で光らせ、すぐに消します（強さは %、時間は秒）。

例： プレイヤーが攻撃されたときに 0.5 秒の赤いフラッシュ。

画面の色合い

入力： 色, 強さ（%、0 = なし）, 切り替え（秒）

ゲーム全体（HUD の下）に色を重ね、なめらかに切り替えます。強さ 0 で消えます。

例： 夜になる：濃い青、強さ 55、切り替え 2 秒。

周辺減光

入力： 色, 強さ（%、0 = なし）, 切り替え（秒）

映画のように画面の端をやわらかく暗くします（HUD の下）。強さ 0 で消えます。

例： 洞窟の不気味な雰囲気：強さ 75。

画面フェード

入力： 方向, 色, 時間（秒）

画面全体をある色へフェードアウト、またはその色からフェードインします。フェードはシーンが変わっても続きます。

例： 「画面フェード」（フェードアウト）、「待つ」 1 秒、「シーンを切り替える」、次のステージの開始時に 「画面フェード」（フェードイン）。

ふんいき（雨、雪、夜…）

入力： ふってくるもの, 光, 強さ, まわりの音（雨、風、かみなり…）, 出てくる時間（秒）

画面全体にふんいきをつけ、次の「ふんいき」ノードまで続きます：ふってくるもの（雨、かみなりつきの嵐、雪、花びら、落ち葉、ホタル、ハート、あわ、きり）と光（夜、夕焼け、思い出、夢、こわい、暗い）。古いものが消えながら新しいものが出てきます。

例： 「立ち去る」を選んだら嵐と夜の光。「なし」と「ふつう」で全部消える。

画面をズーム

入力： ズーム（%、100 = ふつう）, どこへ, 時間（秒）

ゲーム画面全体（シーン、または物語の背景とキャラ）を、まんなか、顔、横、上、下に向けてなめらかに大きくします。100 = もとにもどす。会話ボックスと HUD は動きません。

例： ハナがこわがったら顔へズーム 140 を2秒、そのあとズーム 100。

画面の切りかえ（まる、星…）

入力： 形, 向き, 色, 時間（秒）

閉じていく形（まる、星、ひし形、ワイプ、カーテン、ブラインド）で画面をおおい、そのあと続きます。「画面が開く」まで画面はおおわれたまま：その間にシーンや背景を変えます。

例： まるく閉じる → 「シーンを切り替える」 → まるく開く。

カメラの振動

入力： 強さ, 長さ（ミリ秒、1000 = 1秒）

選んだ強さと時間（ミリ秒）で画面を揺らします。

例： 爆発：強さ 15、時間 400。

バイブレーション

入力： 長さ（ミリ秒、1000 = 1秒）

選んだ時間（ミリ秒）だけスマホを振動させます。振動機能がない場合は何も起きません。

例： プレイヤーがダメージを受けたら 100 ミリ秒。

状態を保存

シーンの状態（オブジェクトと変数）とグローバル変数を、セーブポイントのように覚えておきます。

例： ステージの途中にあるチェックポイントの旗。

状態を復元

シーンを最後の 「状態を保存」 の状態に戻します。まだセーブがなければ何も変わりません。

例： 落ちたあとチェックポイントからやり直す。

時間

待つ

入力： 時間（秒）

選んだ時間（秒）だけ待ってから、続きを動かします。待っている間もゲームのほかの部分は動き続けます。

例： 「負け！」を表示して 2 秒待ち、シーンをやり直す。

繰り返す

入力： 間隔（秒）, 回数（0 = 無限）, タイマー名（省略可）  →  出力： すぐに / 毎回 / 手番おわり

X 秒ごとに 「毎回」 の出力を、決めた回数（0 = ずっと）動かし、最後に 「手番おわり」 を動かします。「すぐに」 は最初にすぐ動きます。すでに動いているときは、もう一度は始まりません。

例： 3 秒ごとに敵を出す。

カウントダウン

入力： オブジェクト, 変数, 開始値（省略可）, タイマー名（省略可）  →  出力： 毎秒 / 手番おわり

選んだ変数（数値）を 1 秒ごとに 1 ずつ減らし、0 まで数えます。毎回 「毎秒」 が動き、0 で 「手番おわり」 が動きます。「開始値（省略可）」 で最初の値を決めます。

例： 60 秒のタイマー：0 で Game Over。

タイマーを止める

入力： 名前（空 = すべて）

この名前のタイマー（くり返し・カウントダウン）を止めます。名前が空なら、すべてのタイマーを止めます。

例： プレイヤーが勝ったらタイマーを止める。

ゲーム速度（スロー）

入力： 速度（1 = 通常、0.5 = スロー）

ゲーム全体の速さを変えます。1 = ふつう、0.5 = スローモーション、2 = 速い（0 から 4 まで）。

例： 2 秒間のスローモーション演出。

ゲームを一時停止

ゲームを一時停止します。動きとタイマーが止まります。

例： ポーズメニューを開く。

ゲームを再開

一時停止のあと、ゲームを再開します。

例： ポーズメニューの「つづける」ボタン。

ヒットストップ

入力： 時間（秒）, 止まっている間の速さ（0 = 静止）

ほんの一瞬（実際の秒数）ゲーム全体をほぼ止め、そのあと元の速さに戻します。当たったときの手ごたえが出ます。

例： 敵が爆発したとき：時間 0.06、速さ 0.05。

外観とオブジェクト

オブジェクトを移動

入力： オブジェクト, X, Y

オブジェクトを X, Y の位置にそのまま置きます（ワープ）。

例： プレイヤーをスタート地点に戻す。

オブジェクトを押す

入力： オブジェクト, X を加算, Y を加算

オブジェクトを今の場所から、指定した距離だけ動かします。物理オブジェクトは壁で止まります。

例： 「オブジェクトを押している間」 とつなぐ：「X を加算」 = 5 で右に進む。

プロパティを変更

入力： オブジェクト, プロパティ, 値

リストから選んだオブジェクトのプロパティ（x、y、回転、不透明度、テキスト…）を変えます。

例： 時計の針の回転を =temps * 90 にする。

回転

入力： オブジェクト, 角度（度）

オブジェクトを指定した角度（度）に回します。

例： =kuruma.rotation + 5 を 「毎フレーム」 につなぐと、「kuruma」オブジェクトがずっと回る。

透明度

入力： オブジェクト, 不透明度（0〜1）

オブジェクトの透明度を決めます。0 = 見えない、1 = 不透明。

例： 0.5 で半透明のおばけ。

可視性

入力： オブジェクト, 表示（はい / いいえ）

オブジェクトを表示（true）または非表示（false）にします。

例： 最初は隠してある「勝ち！」メッセージを表示する。

タグをつける（オブジェクトの仲間）

入力： オブジェクト, タグ

オブジェクトに新しいタグ（ラベル）をつけます。

例： 倒された敵にタグ「無害」をつける。

前へ / 後ろへ

入力： オブジェクト, 奥行き（大きいほど手前）

オブジェクトのレイヤーを変えます。数字が大きいほど、ほかのオブジェクトより手前に表示されます。

例： プレイヤーを背景の飾りより手前にする。

大きく / 小さく

入力： オブジェクト, 横の大きさ（1 = ふつう）, 縦の大きさ（1 = ふつう）

オブジェクトの大きさを変えます。1 = ふつう、2 = 2 倍、0.5 = 半分。

例： キノコを食べたらプレイヤーが大きくなる。

オブジェクトを破壊

入力： オブジェクト

選んだオブジェクトをシーンから消します。

例： 「関連オブジェクト」 を選んで、プレイヤーが触れたばかりのコインを消す。

タグで破壊

入力： 破棄するタグ

このタグを持つオブジェクトをすべて消します。

例： 爆弾で「敵」オブジェクトをすべて消す。

画像を変更

入力： オブジェクト, 画像

オブジェクトの画像を、Assets の別の画像に変えます。空 = 画像なし。

例： 押したボタンによって、キャラクターが左や右を向く。

色を変更

入力： オブジェクト, 色

オブジェクトの色を変えます。

例： 答えが正しいとボタンが緑になる。

クローンを生成 (スポナー)

入力： オブジェクト A, オブジェクト B

オブジェクト B（お手本）のコピーを、オブジェクト A（出現ポイント）の場所に作ります。

例： 大砲（A）から砲弾（B）を出す。

カラーフィルター

入力： オブジェクト, フィルター

オブジェクトにフィルターをかけます。白黒、セピア、反転、または「なし」で外します。

例： 思い出のシーンで白黒にする。

色の混ぜ方（光の効果）

入力： オブジェクト, フィルター

オブジェクトと、その後ろにあるものとの混ざり方を変えます（加算、乗算、スクリーン、反転）。

例： 光る明かりや炎には「加算」。

ミラー効果 / 反転

入力： オブジェクト, 軸

オブジェクトを反転します。水平（左右）または垂直（上下）。

例： キャラクターが歩く方向を向く。

オブジェクトをロック / 解除

入力： オブジェクト, ロック（はい / いいえ）

エディターでオブジェクトをロック・ロック解除します（カギのマーク）。ゲーム中には何の効果もありません。オブジェクトをドラッグできないようにするには 「ふるまいを変える」 を使ってください。

背景のスクロール（奥行き）

入力： オブジェクト, 背景の速さ（1 = ふつう、0.5 = ゆっくり、遠くに見える）

カメラが動いたときの、オブジェクトのスクロールの速さを決めます。1 = ふつう、0.5 = 半分の速さ（奥行きの演出）。

例： ゆっくり流れる背景の山。

2つのオブジェクトをリンク

入力： オブジェクト A, オブジェクト B

オブジェクト A（子）をオブジェクト B（親）にくっつけます。B が動くと A もついていきます。

例： キャラクターの手についていく剣。

光るオーラ

入力： オブジェクト, 状態, 色, 光の大きさ

選んだ色と大きさの、やわらかい光でオブジェクトを包みます（画像の形に沿います）。または光を消します。

例： 黄色く光るボーナス、大きさ 20。

パーティクル効果

入力： オブジェクト, プリセット, 数（0 = プリセットのまま）, 色（空 = プリセットの色）, 大きさ（1 = 標準）, 画像（空 = プリセットの形）

オブジェクトからパーティクルを一度に放ちます：爆発、火花、砂ぼこり、煙、炎、雨、雪、紙吹雪、軌跡、長い軌跡、ハイパースペース、スピードライン。数・色・大きさを設定できます。 画像（「画像」設定）を選ぶと、パーティクル1つ1つがその画像になる：描いた爆発、星、葉っぱ…

例： 撃たれた敵がマゼンタで爆発：プリセット「爆発」、色 #FF40D0。

パーティクルのオン / オフ

入力： オブジェクト, 状態

「パーティクル」オブジェクトをオン／オフします。オンの間は出し続け、オフで止まります（出たパーティクルは最後まで残ります）。

例： 宇宙船が進むときにエンジンの炎をつける。

パーティクル一斉放出

入力： オブジェクト, パーティクルの数

「パーティクル」オブジェクトから、その設定（プリセット・色・大きさ）で一度にたくさんのパーティクルを出します。

例： ステージクリアで紙吹雪 80 個。

パーティクルのプリセットを変更

入力： オブジェクト, プリセット

ゲーム中に「パーティクル」オブジェクトのプリセットを変えます。

例： 消した火が煙に変わる。

点滅する

入力： オブジェクト, 状態, 速度（ミリ秒、1000 = 1秒）, 継続時間（ミリ秒、0 = ずっと）

選んだ速さ（ミリ秒）で、決めた時間（ミリ秒、0 = ずっと）オブジェクトを点滅させるか、点滅を止めます。

例： ダメージを受けたあと、プレイヤーが 1 秒点滅する。

オブジェクトのコピーを作る

入力： オブジェクト B, X 位置, Y 位置

オブジェクト B（お手本）のコピーを X, Y の位置に作ります。コピーは 「関連オブジェクト」 になります。

例： ランダムな位置に石を落とす：X = random(0, 800)。

オブジェクトを発射

入力： オブジェクト A, オブジェクト B, モデル名, 方向, 速度, 画面外で消す（はい / いいえ）

オブジェクト A の場所に弾（「モデル名」 に書いたオブジェクト）を作り、選んだ速さで飛ばします。向きは 0°、90°、180°、270°、オブジェクト B の方向（「ターゲットへ」）、または A の角度。

例： 上向き（270）にレーザーを撃つ宇宙船。

進捗を設定

入力： オブジェクト, 新しい進捗

プログレスバーの量を、最小値と最大値のあいだで決めます。

例： 体力バーなら、「新しい進捗」 = vie。

画面をループする

入力： オブジェクト

画面の端から出たものが、反対側から出てきます（パックマンの効果）。

例： 右から出て左から戻ってくる小惑星。

画面内に収める

入力： オブジェクト, 余白

オブジェクトが画面の外に出ないようにします。余白を決めると、端の少し手前で止まります。

例： プレイヤーの宇宙船がいつも見えるようにする。

感電

入力： オブジェクト, 稲妻の色, 時間（秒、0 = 無限）, 強さ（0 = 停止、1〜3）

オブジェクトのまわりで稲妻がはじける：稲妻の色で点滅し、震えて火花を散らします。時間 0 = 無限（電気柵）、強さ 0 = 停止。

例： 魔法使いが罠に触れる：魔法使いに 「感電」（1秒）、「待つ」 1秒、そのあと 「シーンをやり直す」。

オブジェクトの軌跡

入力： オブジェクト, プリセット, 色（空 = プリセットの色）, 大きさ（1 = 標準）

オブジェクトが動くと、後ろにパーティクルの軌跡を残します（プリセット・色・大きさを選べます）。弾のもとになるオブジェクトに設定すると、すべての弾に軌跡がつきます。プリセット「なし」で消えます。

例： 光る軌跡を残す弾：対象 = 弾のもと、プリセット「軌跡」。

オブジェクトを作成

入力： オブジェクト, X位置, Y位置

選んだオブジェクト（お手本）のコピーを X, Y の位置に作ります。

例： 決まった場所に木箱を置く。

フェード

入力： オブジェクト, 目標の不透明度（0〜1）, 長さ（秒）

選んだ時間（秒）で、オブジェクトの不透明度をなめらかに目標の値まで変えます。次のノードは待たずに動きます。

例： タイトルを 1 秒で消す（目標の不透明度 0）。

変数とインベントリ

変数を変更

入力： オブジェクト, 変数, 値

変数に新しい値（数値、テキスト、はい / いいえ、または計算）を入れます。

例： 「score」を 0 に戻す。

変数に加算

入力： オブジェクト, 変数, 加算する値, これをこえたら0にもどす（なくてもよい）

変数に値を加える（マイナスの数なら引く）。テキスト変数なら最後に文字を足す。「これをこえたら0にもどす」を入れると、カウンターのように回る：9の次は0（0より下は9）。

例： コインごとにスコア + 1；錠前の数字：タップごとに + 1、9をこえたら0にもどす。

変数を2つの値の間に保つ

入力： オブジェクト, 変数, 最小値, 最大値

変数（数値）を最小値と最大値のあいだに保ちます。

例： 体力が 100 をこえないようにする。

ランダムな数

入力： オブジェクト, 変数, （最小, 最大）の間

変数にランダムな数を入れます。random(1, 6) は 1 から 6 の数になります。

例： サイコロをふる。

インベントリに追加

入力： オブジェクト, 変数

オブジェクトをインベントリ（「インベントリリスト」型の変数）に入れます。同じものは一度しか入りません。

例： カギを拾う。

インベントリから削除

入力： オブジェクト, 変数

オブジェクトをインベントリから取り出します。

例： カギを使ってドアを開ける。

インベントリにあるなら

入力： オブジェクト, 変数  →  出力： 真 / 偽 / その後

オブジェクトがインベントリにあれば 「真」、なければ 「偽」 の出力に進みます。

例： カギがインベントリにあるときだけドアが開く。

2つのオブジェクトを合わせる

入力： オブジェクト A, オブジェクト B, 結果オブジェクトの名前

オブジェクト A と B を、名前を書いたオブジェクトのコピーに置きかえます（A の場所に置きます）。そのお手本がなければ何も変わりません。

例： 棒 + 布 = たいまつ。

ロジックと条件

条件

入力： 条件  →  出力： 真 / 偽 / その後

条件を調べます。正しければ 「真」、ちがえば 「偽」 に進みます。どちらの場合も、そのあと 「その後」 が動きます。

例： score >= 10 → 真 → 次のシーン。

ジョイスティックが

出力： 上 / 下 / 左 / 右 / 静止 / その後

ジョイスティックの向きに合った出力に進みます。「上」、「下」、「左」、「右」、触れていないときは 「静止」。

例： 「毎フレーム」 とつないで、正しい向きの歩くアニメーションを流す。

地面にいるなら

入力： オブジェクト  →  出力： 真 / 偽 / その後

オブジェクトの下が、固定された見えるオブジェクト（地面、足場）の上にあれば 「真」、なければ 「偽」。

例： 地面にいるときだけジャンプできるようにする。

動いているなら

入力： オブジェクト  →  出力： 真 / 偽 / その後

前のフレームからオブジェクトが動いていれば 「真」、動いていなければ 「偽」。

例： キャラクターが動いているときだけ歩くアニメーションを流す。

関数を呼ぶ

入力： 関数

関数（「関数」の欄で作った Blueprint）を動かしてから、続きに進みます。「毎フレーム」 の下には置かないでください。

例： いろいろな敵が使う「ライフを減らす」関数。

イベントを呼ぶ

入力： イベント名

同じ Blueprint にある、この名前の 「ローカルイベント」 を動かしてから、続きに進みます。

例： 落下とタイマーの両方から「GameOver」を呼ぶ。

シーケンス

出力： 1 / 2 / 3 / 4

出力を順番に動かします。1、次に 2、次に 3、次に 4。つながっていない出力はとばします。

例： 開始時：1 = プレイヤーを置く、2 = 音楽を流す、3 = スコアを表示する。

クールダウン

入力： オブジェクト, 遅延（秒）  →  出力： 準備完了 / まだ

決めた間隔（秒）に最大 1 回だけ 「準備完了」 を通します。それ以外は 「まだ」 に進みます。オブジェクトを選ぶと、オブジェクトごとに別の間隔になります。

例： 0.5 秒に 1 回までしか撃てないようにする。

画面外にいるなら

入力： オブジェクト, 余白（ピクセル）  →  出力： 真 / 偽 / その後

オブジェクトが画面（と余白）から完全に出ていれば 「真」、そうでなければ 「偽」。

例： 画面の外に出た弾を消す。

もし / それ以外

入力： もし（条件）, そうでなければもし（条件）  →  出力： もし / そうでなければもし / それ以外 / その後

1 つ目の条件、次に 2 つ目の条件を調べて、「もし」、「そうでなければもし」、「それ以外」 のどれかに進みます。そのあと 「その後」 が動きます。

例： score >= 100 なら金、そうでなく score >= 50 なら銀、それ以外は銅。

値によって

入力： 検査する値, ケース 1, ケース 2, ケース 3, ケース 4, ケース 5, ケース 6  →  出力： 1 / 2 / 3 / 4 / 5 / 6 / なし / その後

調べる値をケース 1 から 6 と比べて、最初に同じだったケースの出力に進みます。どれも同じでなければ 「なし」。空のケースはとばします。

例： 「武器」によって：1 = 剣、2 = 弓、3 = 杖。

テキストとダイアログ

テキストを変更

入力： オブジェクト, 新しいテキスト

テキストオブジェクトの文字を置きかえます。= で始めると計算結果を表示できます。

例： ="スコア：" + score

ダイアログを表示

入力： オブジェクト, 文の名前（ゲームのテキスト内）

会話ファイル（dialogues.txt）から、キーに合った文をテキストオブジェクトに書きます。 複数の言語：「konnichiwa.ja = こんにちは」、「konnichiwa.en = Hello」… と書く。ゲームは変数 「langue」 の言語を使い、なければスマホの言語を使います。「\n」 = 改行。

例： キー「konnichiwa_shounin」で商人のセリフを表示する。

テキストに追加

入力： オブジェクト, 変数, 追加するテキスト

テキスト型の変数の最後に文字を足します。

例： パスワードを 1 文字ずつ入力する。

移動とAI

オブジェクトを停止

入力： オブジェクト

オブジェクトをその場でぴたっと止めます。速さ、押す力、ジャンプ、自動の動きがなくなります。

例： 氷の魔法が当たった敵を凍らせる。

移動を停止

入力： オブジェクト

オブジェクトの自動の動き（前進し続ける、追いかける、逃げる）を止めます。

例： プレイヤーが隠れたら敵が追いかけるのをやめる。

継続的に前進

入力： オブジェクト, 速度

オブジェクトが向いている方向に、選んだ速さで自分で進みます。

例： 弾や走っている車。

オブジェクトへ行く（道さがし）

入力： オブジェクト A, オブジェクト B, 速度, ななめ移動 (はい / いいえ)  →  出力： すぐに / とうちゃく

オブジェクトAが、かべ（タイル背景の「ソリッド」タイル、動かない物理オブジェクト）を通らずに、1マスずつ一番近い道を自分で見つけてオブジェクトBへ向かいます。Bが動くと道を計算しなおします。AがBにふれると 「とうちゃく」 が動きます。

例： 迷路でプレイヤーを追いかけるおばけ。

場所へ行く（道さがし）

入力： オブジェクト, X位置, Y位置, 速度, ななめ移動 (はい / いいえ)  →  出力： すぐに / とうちゃく

オブジェクトAが、かべをよけて一番近い道（1マスずつ）で X、Y の場所へ行きます。=doigt.x と =doigt.y にすると、画面にさわった場所へ行きます。着いたら 「とうちゃく」 が動きます。道がないときは、その場にとどまります。

例： 作戦ゲームやダンジョンで、マスにさわって主人公をそこへ行かせる。

道さがしを止める

入力： オブジェクト

オブジェクトが道さがしの移動（「オブジェクトへ行く（道さがし）」 または 「場所へ行く（道さがし）」）をやめて、その場に止まります。

例： ゲームに勝ったらハエが止まる。

オブジェクトを追跡

入力： オブジェクト A, オブジェクト B, 速度

オブジェクト A が、選んだ速さでオブジェクト B に向かって自分で進みます。

例： プレイヤーを追いかけるおばけ。

オブジェクトから逃げる

入力： オブジェクト A, オブジェクト B, 速度

オブジェクト A が、選んだ速さでオブジェクト B から自分で離れます。

例： プレイヤーから逃げるニワトリ。

角度を付けて押す

入力： オブジェクト, 角度（0 = 右、90 = 下）, 力

選んだ力で、オブジェクトをある方向に押します（角度：0 = 右、90 = 下、180 = 左、270 = 上）。

例： プレイヤーをななめに飛ばすバネ。

インパルス（ジャンプ）

入力： オブジェクト, 縦方向の力（マイナス = 上）

オブジェクトを上（マイナスの数）または下（プラスの数）に飛ばし、落ちてくるように物理を与えます。

例： ジャンプ：力 -15。

ふるまいを変える

入力： オブジェクト, どう動く, はやさ, ジャンプの高さ, はしごにする, 拾える

ゲーム中にオブジェクトのふるまいを変える。インスペクターの「オブジェクトのふるまい」画面と同じ選択肢：かざり、地面 / かべ、落ちてはずむ、アクションゲームのキャラ、パトロール（行ったり来たり）、上から見たキャラ、指でドラッグ。速さ、ジャンプの高さ、「はしごにする」「拾える」も変えられる。「（変えない）」のままの設定は元の値のまま。

例： 止まっている箱（地面 / かべ）がレバーを引くと落ちはじめる：ふるまいを変える → 落ちてはずむ。

ぴょんぴょん跳ねる

入力： オブジェクト, 強さ（0 = 停止）, 長さ（ミリ秒、1000 = 1秒）, 動いている間続ける（はい / いいえ）

選んだ強さと時間で、オブジェクトをぴょんぴょん跳ねさせます（見た目だけの小さなはずみ）。0 で止まります。オブジェクトが動いている間、続けることもできます。

例： 歩きながらぴょんぴょん跳ねるキャラクター。

向きを合わせる

入力： オブジェクト A, オブジェクト B, 角度のずれ（度）

オブジェクト A をオブジェクト B の方へ向けます。角度のずれで画像の向きを直します（0 = 画像が右を向いている）。

例： プレイヤーをねらう砲台。

スライド移動

入力： オブジェクト, X位置, Y位置, 長さ（秒）

選んだ時間（秒）で、オブジェクトを X, Y の位置までなめらかに動かします。次のノードは待たずに動きます。

例： 動く足場や、画面に入ってくるメニュー。

グリッドとパズル

グリッドをうめる

入力： オブジェクト, 列の数, 行の数, お手本オブジェクト（名前をカンマで区切る）

オブジェクトA（ばん）を列と行に分け、それぞれのマスにランダムなお手本オブジェクトのコピーを置きます（お手本は3つ以上、名前はカンマで区切る）。最初からそろっていることはなく、ピースは上から落ちてきます。「グリッドで遊ぶ（3つそろえる）」 の前に使います。

例： スタート時に、8 x 8 のキャンディ「red, orange, yellow, green, blue, pink」をならべる。

グリッドで遊ぶ（3つそろえる）

入力： オブジェクト, 指の X 位置, 指の Y 位置  →  出力： そろったピースごとに / 手番おわり / 入れかえ失敗

「3つそろえる」ゲーム（Candy Crush のような）の心ぞう部分で、「指で押している間」 の下に置きます。ピースをタッチすると選ばれ、となりのピースをタッチ（または指をすべらせる）と入れかわります。同じピースが3つ以上ならんだときだけ入れかえが残り、そうでなければもどります（「入れかえ失敗」）。そろったピースはそれぞれ 「そろったピースごとに」 を動かし（関係するオブジェクトはそのピース）、消えます。上のピースが落ち、新しいピースが来て、連鎖も自動で起きます。すべて止まると 「手番おわり」。動かせる手がなければ、グリッドは自動でまざります。

例： 「そろったピースごとに」：+10点とピースにキラキラ。「手番おわり」：のこり手数を1へらす。

グリッドをまぜる

入力： オブジェクト

オブジェクトAのグリッドのピースをすべて並べかえます。そろいは作らず、動かせる手を最低1つ残します。

例： プレイヤーがつまったときの「まぜる」ボタン。

場所をまぜる

入力： オブジェクト

選んだタグの付いたすべてのオブジェクトの場所をランダムに入れかえます（オブジェクトA =「# タグ」）。子オブジェクトもいっしょに動きます。

例： 神経衰弱のカードを最初にまぜる、カップ当てゲームのカップをまぜる。

アニメーション

アニメを再生

入力： オブジェクト, アニメーション, 速さ（コマ/秒）, ループ（はい / いいえ）

オブジェクトのアニメーションを、選んだ速さ（1 秒あたりのコマ数）で、くり返しまたは 1 回だけ流します。すでに流れていれば、最初に戻らずにそのまま続きます。

例： キャラクターが進むとき「歩く」アニメーション。

アニメを停止

入力： オブジェクト

アニメーションを止めて、最初のコマに戻します。

例： キャラクターが歩くのをやめる。

アニメを一時停止

入力： オブジェクト

アニメーションを今のコマで一時停止します。

例： ポーズ中にキャラクターを止める。

アニメを再開

入力： オブジェクト

一時停止したところからアニメーションを再開します。

例： ポーズのあと。

アニメの速さ

入力： オブジェクト, 速さ（コマ/秒）

アニメーションの速さ（1 秒あたりのコマ数）を、最初からやり直さずに変えます。

例： 速く走る = 速いアニメーション。

オーディオ

効果音を再生

入力： 音声ファイル, 音量（%、100 = 最大）

効果音を鳴らします。いくつかの音を同時に鳴らせます。

例： コインを拾ったときの「チャリン」。

音楽を再生

入力： 音楽ファイル, ループ（はい / いいえ）, 音量（%、100 = 最大）

音楽を流します。今流れている音楽と入れかわります。「毎フレーム」 の下には置かないでください（ずっと最初からやり直しになります）。

例： ステージの音楽を開始時に流す。

音楽を停止

今流れている音楽を止めます。

例： Game Over 画面では静かにする。

ストーリーと会話

セリフを言う

入力： だれが話す, 表情, セリフ, 画面の位置, キャラの登場, エフェクト, 音・ボイス, つぎへ進む  →  出力： その後

会話ゲーム：選んだキャラが会話ボックスで1文字ずつセリフを言い、プレイヤーが画面をタッチすると続きます。キャラは表情つきで出ます（キャラのカード：画像、色、声）。特別な言葉：[c]色[/c]、[t]ふるえる[/t]、[o]波打つ[/o]、[p] で間、{score} で変数；「🌐 9言語」ボタンで翻訳。

例： ハナ（うれしい）が「こんにちは！」と言い、「選択肢を出す」 で2つの答えを出す。

選択肢を出す

入力： だれが聞く, 表情, 質問（なくてもよい）, 答え 1, 答え 2, 答え 3, 答え 4, 答えの条件 1, 答えの条件 2, 答えの条件 3, 答えの条件 4, 選べない答え, 答え 1 の画像（なくてもよい）, 答え 2 の画像（なくてもよい）, 答え 3 の画像（なくてもよい）, 答え 4 の画像（なくてもよい）, タイマー（秒、0 = なし）  →  出力： 答え 1 / 答え 2 / 答え 3 / 答え 4 / 時間切れ

2〜4個の答えを大きなボタンで出します。答えごとに出口があり、物語が木のように分かれます。答えに条件をつけられます（満たさないとグレーまたは非表示）。タイマーをつけると「時間切れ」の出口が増えます。 それぞれの答えに画像もつけられる（くわしい設定）：答えが大きな絵つきカードになる。

例： 「宝物を開ける」はハッピーエンド、「立ち去る」は悲しいエンドへ。

背景を変える

入力： 背景の画像（空 = なし）, 切りかえ

画像を全画面の背景にして、物語のキャラの後ろに置きます（フェードまたはすぐ）。画像が空 = 背景なし。

例： 最初は草原、ハナがネコを探しに行くと森。

キャラを出す / 消す

入力： キャラ, キャラが…, 表情, 画面の位置, キャラの登場

物語のキャラを登場させたり（表情、位置、登場：フェード、すべりこみ、ジャンプ）、表情を変えたり、退場させたりします。セリフはなし。

例： ハナが話している間にリンが右から登場。

物語を終える

入力： エンディングの名前（なくてもよい：「エンディングとギャラリー」に入る）

物語の会話ボックス、キャラ、背景を消して、ゲームに戻ります。「エンディングの名前」を入れると、そのエンディングはずっと記録され、「物語のタイトル画面」の「エンディングとギャラリー」に入ります。セーブは消えます。

例： 最後のセリフのあと「小屋の友だち」、そしてタイトル画面にもどる。

友情（ハート）

入力： だれ？, ふやすハート（−1 でへらす）, ハートの最大数

キャラクターの友情ハートを増やす（−1 で減らす）。最大値はこえない。物語のあいだハートは左上に表示され、「+1 ❤」がふわっと上がる（会話のスタイルで非表示にできる）。セーブにふくまれ、◀ 戻る でも元にもどる。

例： やさしい答え「そばにいるよ」のあと：ハナ +1。

もし友情が…

入力： だれ？, が, 個のハート  →  出力： 真 / 偽

キャラクターの友情ハートで物語の続きを選ぶ：比べた結果が正しければ「真」、ちがえば「偽」の出口へ。キャラクターへの接し方で変わるエンディングに。

例： ハナの友情が 4 以上 → しあわせなエンド、そうでなければ悲しいエンド。

物語のタイトル画面

入力： 物語のタイトル, 背景の画像（空 = いまの背景）  →  出力： はじめから

画像の上に物語のタイトルと大きなボタンを出します：「つづきから」（やめたところから再開。背景、キャラ、音楽、変数ももどる：物語はセリフごとに自動でセーブ）、「はじめから」（出口：物語の最初）、「エンディングとギャラリー」（見つけたエンディングと見た背景。ほかはカギつき）。物語の中では ◀ もどる ボタンで前のセリフに、選択の前にももどれます。

例： 「スタート時」のすぐあとに置く。どの「物語を終える」もここにもどる。

プレイヤーに文字を書いてもらう（名前…）

入力： 変数, 質問, はじめの答え

キーボードつきの小さな窓を開きます：プレイヤーが文字（名前…）を書き、選んだ変数に入ります。OK で続きます。セリフの中で {prenom} がこの文字になります。

例： 「名前は？」→ 変数 prenom → 「セリフを言う」「よろしくね、{prenom}！」。

値（緑の線）

ランダムな数

入力： から, まで  →  出力： なし（スクリプト終了）

緑のノード（値）：「から」と「まで」のあいだのランダムな数を出す。使うたびに新しく決まる。設定ウィンドウの 🔗 ボタンで設定につなごう。

例： コインを 0〜800 のランダムな X に出す。

オブジェクトの値

入力： オブジェクト, なに  →  出力： なし（スクリプト終了）

緑のノード（値）：ゲーム中に、えらんだオブジェクトの値を出す：x や y の位置、はば、回転、不透明度など。

例： コインをプレイヤーと同じ高さに置く（Y ← オブジェクトの値：player, y）。

変数の値

入力： 変数  →  出力： なし（スクリプト終了）

緑のノード（値）：ゲーム中の変数（スコア、ライフなど）の今の値を出す。

例： テキストにスコアを表示する（テキスト ← 変数の値：score）。

計算

入力： A, 計算のしかた, B  →  出力： なし（スクリプト終了）

緑のノード（値）：A + B、A − B、A × B、A ÷ B を計算する。A と B は数でもいいし、さらに緑の線をつないでもいい（計算をつなげる）。

例： 2倍のポイントをあげる（値 ← 計算：score × 2）。

2つのオブジェクトの距離

入力： オブジェクト A, オブジェクト B  →  出力： なし（スクリプト終了）

緑のノード（値）：ゲーム中に、2つのオブジェクトの中心のあいだの距離（ピクセル）を出す。

例： 敵が近いほど画面を強くゆらす。
