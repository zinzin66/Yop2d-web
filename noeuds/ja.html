Yop2D ノードリファレンス

Français · English · Español · Deutsch · Italiano · Português · Русский · 中文 · 日本語

Yop2D は、Android 向けの無料・コード不要の 2D ゲームエンジンです。ゲームのロジックは、Blueprint の中でつないだノード（ビジュアルブロック）で作ります。イベントがつながりを始め、そのあとにアクションや条件が続きます。このページでは、エディターの 230 個のノードを、設定（入力）と出力とともに説明します。

カテゴリー

イベントシーンとHUD時間外観とオブジェクト変数とインベントリロジックと条件テキストとダイアログ移動とAIグリッドとパズル値（緑の線）画面の切りかえアニメーションオーディオストーリーと会話画面フィルター物理

イベント

起動時

シーンが始まったとき、一度だけ動きます。

例： 敵を配置する、最初のスコアを表示する、音楽を流す。

毎フレーム

ゲームの毎フレーム（1 秒に約 60 回）、ずっと動き続けます。

例： 指の位置を追う、条件をいつも確認する。この下に 「音楽を再生」 や 「関数を呼ぶ」 を置かないでください。

クリック終了

プレイヤーが画面のどこかで指を離したときに動きます。

例： 画面から指を離したら射撃をやめる。

オブジェクトクリック時

入力： オブジェクト

指が選んだオブジェクトに触れたときに動きます。 対象をタグ（「# カード」）にすると、そのタグの付いたどのオブジェクトでも始まります：さわったオブジェクトが「関係するオブジェクト」になります。

例： 「ジャンプ」ボタン、宝箱を開ける、答えを選ぶ。

オブジェクトを離した時

入力： オブジェクト

選んだオブジェクトの上で指を離したときに動きます。

例： ボタンを離したときだけ決定する。

オブジェクトを押している間

入力： オブジェクト

指が選んだオブジェクトに触れている間、毎フレームくり返し動きます。

例： 左 / 右ボタン：押している間、キャラクターが進む。

指で押している間

画面のどこかに指が触れている間、毎フレームくり返し動きます。

例： 押している間、宇宙船を上昇させる（数式で doigt.x と doigt.y を使う）。

戻るボタンを押したとき

プレイヤーがスマホの「戻る」ボタン（矢印またはジェスチャー）を押したときに動きます。ポーズメニューを開いたり、前の画面に戻ったりするのに便利です。このノードがないと、ゲーム中に戻るボタンは何もしません。

例： 戻る → 「ゲームを一時停止」、そして「再開 / 終了」メニューを表示。

新しいシーンが始まるたび

新しいシーンが開くたびに実行されます。すべてのシーンで動く「グローバルロジック」向けです。たとえば、選んだ軍隊を各マップに配置するときに使います。ふつうのシーンでは「開始時」で十分です。

ドラッグ開始

入力： オブジェクト

プレイヤーが選んだオブジェクトをドラッグし始めたときに動きます（オブジェクトは 「移動可能 (ドラッグ可能)」 である必要があります）。

例： カードを持ったら大きくする。

ドラッグ終了

入力： オブジェクト

プレイヤーがドラッグしていたオブジェクトを離したときに動きます。

例： パズルのピースが正しい場所に置かれたか確認する。

衝突 A/B

入力： オブジェクト A, オブジェクト B

オブジェクト A がオブジェクト B に触れ始めた瞬間に一度だけ動きます。もう一度動くには、いったん離れる必要があります。「ゾーンに入る」にもこのイベントを使います。

例： プレイヤーがゴールゾーンに触れる → 次のステージ。

ゾーンから出る

入力： オブジェクト A, オブジェクト B

オブジェクト A がオブジェクト B から離れた（ゾーンから出た）瞬間に一度だけ動きます。

例： プレイヤーが離れたらドアを閉める。

ホバー時

入力： オブジェクト

画面をなぞる指が、選んだオブジェクトの上に来たときに動きます。

例： 指が通ったらボタンを光らせる。

ホバー終了

入力： オブジェクト

指がその上にあったオブジェクトから外れたときに動きます。

例： ボタンの光を消す。

物理的な衝突時

入力： オブジェクト

選んだオブジェクト（動的な物理）が地面に着地したり、跳ね返ったりしたときに動きます。

例： 着地の音を鳴らす、カメラを揺らす。

変数が変更された時

入力： 変数

選んだ変数の値が変わるたびに動きます。

例： 「vie」（体力）が変わったら体力バーを更新する。

ローカルイベント

入力： イベント名

好きな名前をつけた、自分だけのイベントです。同じ Blueprint にある 「イベントを呼ぶ」 ノードで動かします。

例： いろいろな場所から呼び出す「GameOver」イベント。

アクションボタンクリック時 (アドベンチャー)

プレイヤーがシーンの 「アクションボタン」 オブジェクト（アクションボタン）を押したときに動きます。

例： アドベンチャーゲームでキャラクターと話す、ドアを開ける。

オブジェクトがタグに触れた場合

入力： オブジェクト, タグ

選んだオブジェクトがこのタグを持つオブジェクトに触れたとき、接触ごとに一度だけ動きます。触れたオブジェクトは 「関連オブジェクト」 になります。 「触れた側」の設定で、イベントをオブジェクトの一方の側（上・下・左・右）に限定できます。「オブジェクトの上」は上から何かが来る場合で、たとえばエレベーターにつぶされるときです。「どこでも」（初期設定）は側を問いません。

例： プレイヤーがコイン（タグ「piece」）に触れる → 関連オブジェクトを削除して、スコアを 1 増やす。

シーンとHUD

シーンを切り替える

入力： シーン  →  出力： なし（スクリプト終了）

今のシーンを出て、選んだシーンに移ります。このノードでスクリプトは終わります。

例： 最後のステージのあと「よくできました！」画面に移る。

名前でシーンへ移動

入力： シーン名  →  出力： なし（スクリプト終了）

名前を書いたシーン（またはその名前になる数式）に移ります。このノードでスクリプトは終わります。

例： ="ステージ" + level のような数式で、変数を使ってステージを選ぶ。

次のシーン

出力： なし（スクリプト終了）

シーンの一覧で、すぐ次にあるシーンに移ります。このノードでスクリプトは終わります。

例： プレイヤーがゴールに着く → 次のステージ。

前のシーン

出力： なし（スクリプト終了）

シーンの一覧で、すぐ前にあるシーンに移ります。このノードでスクリプトは終わります。

例： メニューの「戻る」ボタン。

シーンをやり直す

出力： なし（スクリプト終了）

シーンを最初からやり直します。オブジェクトは元の場所に、ローカル変数は最初の値に戻ります。グローバル変数は変わりません。

例： 体力が 0 になったら Game Over。

HUDを開く

入力： シーン

別のシーンを、ゲームの上にレイヤー（HUD）として表示します。そのシーンには自分の Blueprint があります。

例： ポーズメニューやインベントリ。

HUDを閉じる

開いている HUD を閉じます。

例： ポーズメニューの「閉じる」ボタン。

シーンのコピーを配置

入力： シーン, X位置, Y位置

選んだシーン（プレハブ）のコピーを、X, Y の位置でゲームに置きます。

例： 別のシーンで作った敵のグループを出現させる。

シーンのコピーを破棄

入力： シーン

ゲームに置いた、選んだシーンのコピーをすべて消します。

例： ウェーブの終わりに敵のグループをすべて消す。

ゲームを終了

出力： なし（スクリプト終了）

書き出したゲームを閉じます。エディターでは何も閉じません。停止ボタンを使ってください。

例： タイトルメニューの「終了」ボタン。

画面下の小さなメッセージ

入力： メッセージ

画面の下に短いメッセージを数秒間表示します。= で始めると計算結果を表示できます。

例： ="スコア：" + score

ログに書く（デバッグ用）

入力： メッセージ

プロジェクトのログ（診断ファイル）にメッセージを書きます。ゲームには何も表示されません。= で始めると計算結果を書けます。

例： ="体力 = " + vie で、テスト中に値を確認する。

カメラを固定

入力： オブジェクト, Xを追う（はい / いいえ）, Yを追う（はい / いいえ）, X方向のみ視差（はい / いいえ）

カメラが選んだオブジェクトを追いかけます。横だけ、縦だけにもできます。オブジェクトがないと、カメラは何も追いかけません。

例： 大きなアクションステージでプレイヤーを追う。

カメラの範囲

入力： 最小X（レベルの左端）, 最大X（右端）, 最小Y（上端）, 最大Y（下端、すべて0 = 制限なし）

カメラがレベルの端から出ないようにします：外側の何もない所は映りません。すべて0 = 制限なし。

例： 幅6480ピクセルのレベル：最小X 0、最大X 6480、最小Y 0、最大Y 1080、プレイヤーに 「カメラを固定」 と一緒に使う。

指でカメラを動かす

入力： オン（はい / いいえ）, 横にうごかす（はい / いいえ）, たてにうごかす（はい / いいえ）

指でなぞって画面をうごかす機能を、オン（またはオフ）にします。シーンをなぞるとカメラが動き、ふつうのタップはそのままタップです（タワーやボタン）。HUDのボタンでは動きません。カメラは「カメラのはんい」の外に出ません。

例： スタート時：カメラのはんい（0, 3840, 0, 1080）、つぎに「指でカメラを動かす」。プレイヤーは2画面ぶんの広さのマップをなぞって見られます。

カメラの滑らかさ

入力： 追従速度（0.01〜1）

カメラが追いかけるオブジェクトに追いつく速さを決めます。0.01 = とてもゆるやか、1 = ぴったりくっつく。

例： 0.1 で、少し遅れてなめらかについてくるカメラ。

画面フラッシュ

入力： 色, 強さ（%、0 = なし）, 時間（秒）

画面全体を一瞬ある色で光らせ、すぐに消します（強さは %、時間は秒）。

例： プレイヤーが攻撃されたときに 0.5 秒の赤いフラッシュ。

画面の色合い

入力： 色, 強さ（%、0 = なし）, 切り替え（秒）

ゲーム全体（HUD の下）に色を重ね、なめらかに切り替えます。強さ 0 で消えます。

例： 夜になる：濃い青、強さ 55、切り替え 2 秒。

周辺減光

入力： 色, 強さ（%、0 = なし）, 切り替え（秒）

映画のように画面の端をやわらかく暗くします（HUD の下）。強さ 0 で消えます。

例： 洞窟の不気味な雰囲気：強さ 75。

画面フェード

入力： 方向, 色, 時間（秒）

画面全体をある色へフェードアウト、またはその色からフェードインします。フェードはシーンが変わっても続きます。

例： 「画面フェード」（フェードアウト）、「待つ」 1 秒、「シーンを切り替える」、次のステージの開始時に 「画面フェード」（フェードイン）。

ふんいき（雨、雪、夜…）

入力： ふってくるもの, 光, 強さ, まわりの音（雨、風、かみなり…）, 出てくる時間（秒）

画面全体にふんいきをつけ、次の「ふんいき」ノードまで続きます：ふってくるもの（雨、かみなりつきの嵐、雪、花びら、落ち葉、ホタル、ハート、あわ、きり）と光（夜、夕焼け、思い出、夢、こわい、暗い）。古いものが消えながら新しいものが出てきます。

例： 「立ち去る」を選んだら嵐と夜の光。「なし」と「ふつう」で全部消える。

画面をズーム

入力： ズーム（%、100 = ふつう）, どこへ, 時間（秒）

ゲーム画面全体（シーン、または物語の背景とキャラ）を、まんなか、顔、横、上、下に向けてなめらかに大きくします。100 = もとにもどす。会話ボックスと HUD は動きません。

例： ハナがこわがったら顔へズーム 140 を2秒、そのあとズーム 100。

暗さと光のふんいき

入力： 夜の色, 暗さ（%、0 = 昼、100 = ほぼ真っ暗）, 変わる時間（秒：30 = 夕焼けのよう）

選んだ色でゲーム全体を暗くします（ボタンやスコアの下）。暗さ 0 = 昼、100 = 真っ暗（光源のまわりは除く）。暗さと色はなめらかに変わります。30秒かければ、昼からオレンジの夕暮れ、そして青い夜へ、夕焼けのように移ります。

例： 夕焼け：「暗さと光のふんいき」 オレンジ、暗さ 40、6秒で。「待つ」 6秒。そのあと 「暗さと光のふんいき」 夜の青、暗さ 90、6秒で。

昼と夜のサイクル

入力： 1日の長さ（秒、0 = 止める）, 始まる時間…, ずっとくり返す（はい）／1日だけ（いいえ）

ゲーム全体を、昼からオレンジの夕方、青い夜、夜明け、そしてまた昼へと、自動でなめらかに変えます。1日の長さ（にぎやかなゲームなら30〜120秒）、始まる時間、ずっとくり返すかを選べます。ポーズ中はサイクルも止まります。長さ 0 = サイクルを止める（空はそのまま）。「暗さと光のふんいき」 で手動設定するとそちらが優先されます。光源（「光源（たいまつ、ランタン…）」）はつけたまま。夜はよく目立ちます。

例： 生きている世界：開始時に 「昼と夜のサイクル」、90秒、「昼」から、ループ。

カメラの振動

入力： 強さ, 長さ（ミリ秒、1000 = 1秒）

選んだ強さと時間（ミリ秒）で画面を揺らします。

例： 爆発：強さ 15、時間 400。

バイブレーション

入力： 長さ（ミリ秒、1000 = 1秒）

選んだ時間（ミリ秒）だけスマホを振動させます。振動機能がない場合は何も起きません。

例： プレイヤーがダメージを受けたら 100 ミリ秒。

状態を保存

シーンの状態（オブジェクトと変数）とグローバル変数を、セーブポイントのように覚えておきます。

例： ステージの途中にあるチェックポイントの旗。

状態を復元

シーンを最後の 「状態を保存」 の状態に戻します。まだセーブがなければ何も変わりません。

例： 落ちたあとチェックポイントからやり直す。

変数をファイルに保存

入力： セーブ名, 変数（空 = すべて）

変数（グローバル変数と今のシーンの変数）の値を、端末のファイルに書き込みます。プレイヤーがゲームを閉じて開き直しても残ります。「セーブ名」を変えれば複数のセーブが作れます。「変数」を空にするとすべて保存、名前をカンマで区切って書くこともできます（score, vies）。「状態を保存」 と違い、ゲームを閉じても残ります。

例： プレイヤーが点を取ったとき：「score」 に 「変数に加算」、そのあと 「変数をファイルに保存」。点が入るたびにスコアがファイルに書きこまれます。

ファイルから変数を読み込む

入力： セーブ名, 変数（空 = すべて）  →  出力： 読み込み完了 / セーブなし

「変数をファイルに保存」 が書いた値（同じセーブ名）を元に戻します。今も存在する変数は、保存した値を取り戻します。うまくいけば「読み込み完了」、最初のプレイでは「セーブなし」の出口に進みます。「ゲーム開始時」の直後に置くことが多いです。

例： 「起動時」 の直後に：「ファイルから変数を読み込む」、つづけて 「プロパティを変更」 で、見つかったスコアを表示します。

時間

待つ

入力： 時間（秒）

選んだ時間（秒）だけ待ってから、続きを動かします。待っている間もゲームのほかの部分は動き続けます。

例： 「負け！」を表示して 2 秒待ち、シーンをやり直す。

繰り返す

入力： 間隔（秒）, 回数（0 = 無限）, タイマー名（省略可）  →  出力： すぐに / 毎回 / 手番おわり

X 秒ごとに 「毎回」 の出力を、決めた回数（0 = ずっと）動かし、最後に 「手番おわり」 を動かします。「すぐに」 は最初にすぐ動きます。すでに動いているときは、もう一度は始まりません。

例： 3 秒ごとに敵を出す。

カウントダウン

入力： オブジェクト, 変数, 開始値（省略可）, タイマー名（省略可）  →  出力： 毎秒 / 手番おわり

選んだ変数（数値）を 1 秒ごとに 1 ずつ減らし、0 まで数えます。毎回 「毎秒」 が動き、0 で 「手番おわり」 が動きます。「開始値（省略可）」 で最初の値を決めます。

例： 60 秒のタイマー：0 で Game Over。

タイマーを止める

入力： 名前（空 = すべて）

この名前のタイマー（くり返し・カウントダウン）を止めます。名前が空なら、すべてのタイマーを止めます。

例： プレイヤーが勝ったらタイマーを止める。

ゲーム速度（スロー）

入力： 速度（1 = 通常、0.5 = スロー）

ゲーム全体の速さを変えます。1 = ふつう、0.5 = スローモーション、2 = 速い（0 から 4 まで）。

例： 2 秒間のスローモーション演出。

ゲームを一時停止

ゲームを一時停止します。動きとタイマーが止まります。

例： ポーズメニューを開く。

ゲームを再開

一時停止のあと、ゲームを再開します。

例： ポーズメニューの「つづける」ボタン。

ヒットストップ

入力： 時間（秒）, 止まっている間の速さ（0 = 静止）

ほんの一瞬（実際の秒数）ゲーム全体をほぼ止め、そのあと元の速さに戻します。当たったときの手ごたえが出ます。

例： 敵が爆発したとき：時間 0.06、速さ 0.05。

外観とオブジェクト

オブジェクトを移動

入力： オブジェクト, X, Y

オブジェクトを X, Y の位置にそのまま置きます（ワープ）。

例： プレイヤーをスタート地点に戻す。

オブジェクトを押す

入力： オブジェクト, X を加算, Y を加算

オブジェクトを今の場所から、指定した距離だけ動かします。物理オブジェクトは壁で止まります。

例： 「オブジェクトを押している間」 とつなぐ：「X を加算」 = 5 で右に進む。

プロパティを変更

入力： オブジェクト, プロパティ, 値

リストから選んだオブジェクトのプロパティ（x、y、回転、不透明度、テキスト…）を変えます。

例： 時計の針の回転を =temps * 90 にする。

回転

入力： オブジェクト, 角度（度）

オブジェクトを指定した角度（度）に回します。

例： =kuruma.rotation + 5 を 「毎フレーム」 につなぐと、「kuruma」オブジェクトがずっと回る。

透明度

入力： オブジェクト, 不透明度（0〜1）

オブジェクトの透明度を決めます。0 = 見えない、1 = 不透明。

例： 0.5 で半透明のおばけ。

可視性

入力： オブジェクト, 表示（はい / いいえ）

オブジェクトを表示（true）または非表示（false）にします。

例： 最初は隠してある「勝ち！」メッセージを表示する。

タグをつける（オブジェクトの仲間）

入力： オブジェクト, タグ

オブジェクトに新しいタグ（ラベル）をつけます。

例： 倒された敵にタグ「無害」をつける。

前へ / 後ろへ

入力： オブジェクト, 奥行き（大きいほど手前）

オブジェクトのレイヤーを変えます。数字が大きいほど、ほかのオブジェクトより手前に表示されます。

例： プレイヤーを背景の飾りより手前にする。

大きく / 小さく

入力： オブジェクト, 横の大きさ（1 = ふつう）, 縦の大きさ（1 = ふつう）

オブジェクトの大きさを変えます。1 = ふつう、2 = 2 倍、0.5 = 半分。

例： キノコを食べたらプレイヤーが大きくなる。

オブジェクトを破壊

入力： オブジェクト

選んだオブジェクトをシーンから消します。

例： 「関連オブジェクト」 を選んで、プレイヤーが触れたばかりのコインを消す。

タグで破壊

入力： 破棄するタグ

このタグを持つオブジェクトをすべて消します。

例： 爆弾で「敵」オブジェクトをすべて消す。

画像を変更

入力： オブジェクト, 画像

オブジェクトの画像を、Assets の別の画像に変えます。空 = 画像なし。

例： 押したボタンによって、キャラクターが左や右を向く。

色を変更

入力： オブジェクト, 色

オブジェクトの色を変えます。

例： 答えが正しいとボタンが緑になる。

クローンを生成 (スポナー)

入力： オブジェクト A, オブジェクト B

オブジェクト B（お手本）のコピーを、オブジェクト A（出現ポイント）の場所に作ります。

例： 大砲（A）から砲弾（B）を出す。

カラーフィルター

入力： オブジェクト, フィルター

オブジェクトにフィルターをかけます。白黒、セピア、反転、または「なし」で外します。

例： 思い出のシーンで白黒にする。

色の混ぜ方（光の効果）

入力： オブジェクト, フィルター

オブジェクトと、その後ろにあるものとの混ざり方を変えます（加算、乗算、スクリーン、反転）。

例： 光る明かりや炎には「加算」。

ミラー効果 / 反転

入力： オブジェクト, 軸

オブジェクトを反転します。水平（左右）または垂直（上下）。

例： キャラクターが歩く方向を向く。

オブジェクトをロック / 解除

入力： オブジェクト, ロック（はい / いいえ）

エディターでオブジェクトをロック・ロック解除します（カギのマーク）。ゲーム中には何の効果もありません。オブジェクトをドラッグできないようにするには 「ふるまいを変える」 を使ってください。

背景のスクロール（奥行き）

入力： オブジェクト, 背景の速さ（1 = ふつう、0.5 = ゆっくり、遠くに見える）

カメラが動いたときの、オブジェクトのスクロールの速さを決めます。1 = ふつう、0.5 = 半分の速さ（奥行きの演出）。

例： ゆっくり流れる背景の山。

2つのオブジェクトをリンク

入力： オブジェクト A, オブジェクト B

オブジェクト A（子）をオブジェクト B（親）にくっつけます。B が動くと A もついていきます。

例： キャラクターの手についていく剣。

光るオーラ

入力： オブジェクト, 状態, 色, 光の大きさ

選んだ色と大きさの、やわらかい光でオブジェクトを包みます（画像の形に沿います）。または光を消します。

例： 黄色く光るボーナス、大きさ 20。

パーティクル効果

入力： オブジェクト, プリセット, 数（0 = プリセットのまま）, 色（空 = プリセットの色）, 大きさ（1 = 標準）, 画像（空 = プリセットの形）

オブジェクトからパーティクルを一度に放ちます：爆発、火花、砂ぼこり、煙、炎、雨、雪、紙吹雪、軌跡、長い軌跡、ハイパースペース、スピードライン。数・色・大きさを設定できます。 画像（「画像」設定）を選ぶと、パーティクル1つ1つがその画像になる：描いた爆発、星、葉っぱ…

例： 撃たれた敵がマゼンタで爆発：プリセット「爆発」、色 #FF40D0。

パーティクルのオン / オフ

入力： オブジェクト, 状態

「パーティクル」オブジェクトをオン／オフします。オンの間は出し続け、オフで止まります（出たパーティクルは最後まで残ります）。

例： 宇宙船が進むときにエンジンの炎をつける。

パーティクル一斉放出

入力： オブジェクト, パーティクルの数

「パーティクル」オブジェクトから、その設定（プリセット・色・大きさ）で一度にたくさんのパーティクルを出します。

例： ステージクリアで紙吹雪 80 個。

パーティクルのプリセットを変更

入力： オブジェクト, プリセット

ゲーム中に「パーティクル」オブジェクトのプリセットを変えます。

例： 消した火が煙に変わる。

点滅する

入力： オブジェクト, 状態, 速度（ミリ秒、1000 = 1秒）, 継続時間（ミリ秒、0 = ずっと）

選んだ速さ（ミリ秒）で、決めた時間（ミリ秒、0 = ずっと）オブジェクトを点滅させるか、点滅を止めます。

例： ダメージを受けたあと、プレイヤーが 1 秒点滅する。

オブジェクトのコピーを作る

入力： オブジェクト B, X 位置, Y 位置

オブジェクト B（お手本）のコピーを X, Y の位置に作ります。コピーは 「関連オブジェクト」 になります。

例： ランダムな位置に石を落とす：X = random(0, 800)。

オブジェクトを発射

入力： オブジェクト A, オブジェクト B, モデル名, 方向, 速度, 画面外で消す（はい / いいえ）, たまの寿命（秒、0＝ずっと）

オブジェクト A の場所に弾（「モデル名」 に書いたオブジェクト）を作り、選んだ速さで飛ばします。向きは 0°、90°、180°、270°、オブジェクト B の方向（「ターゲットへ」）、または A の角度。

例： 上向き（270）にレーザーを撃つ宇宙船。

誘導ミサイルを撃つ（カーブ）

入力： オブジェクト A, オブジェクト B, モデル名（画像は右向き）, 開始方向（0 = 右、90 = 下、180 = 左、270 = 上）, 速度, 旋回：1ステップの度数（小さい = 大きなカーブ）, 狙う前の待ち時間（秒）, 寿命（秒、0 = 無限）

ミサイルを発射します。最初は決めた方向へ進み、そのあと少しずつ目標へ向きを変えて、本物のカーブを描きます。「オブジェクトA」が撃つ側、「オブジェクトB」が追う目標です。モデルは画像が右向きの隠しオブジェクトです。「旋回」が小さいと大きなカーブになります。寿命が来て何にも当たらなかったミサイルは爆発します。

例： 敵が宇宙船にミサイルを撃つ：オブジェクトA＝敵、オブジェクトB＝宇宙船、寿命3秒。

一定時間後にオブジェクトを消す（秒）

入力： オブジェクト, 待ち時間（秒）

選んだオブジェクトを、遅れ（秒）のあとに消します。爆発のアニメーションが終わったあとに爆発を消すのに便利です。

例： 「クローンを生成 (スポナー)」と「アニメを再生」のあと、0.4秒後に爆発の画像を消す。

チームカラー（絵のピンクをおきかえる）

入力： オブジェクト, チームの色, 絵でおきかえる色（ふつうはピンク）, ゆるさ（1〜100）：大きいと近い色もおきかえる

すべてのチームで絵は1つ：色をつけたい部分（マント、旗、かざり）を目印の色（ふつうは明るいピンク #FF00FF）でぬっておくと、このノードがオブジェクトのそのピンクをチームの色におきかえます。絵のかげやハイライトは残ります（こいピンクはこい青になる）。ゆるさは、目印の色からどれだけはなれた色までおきかえるかです。画像は変わらず、表示のときだけ変えるので、ゲームのはじめごとにもう一度行います。

例： 同じ画像で2つの軍：プレイヤーは青、てきは赤。

進捗を設定

入力： オブジェクト, 新しい進捗

プログレスバーの量を、最小値と最大値のあいだで決めます。

例： 体力バーなら、「新しい進捗」 = vie。

画面をループする

入力： オブジェクト

画面の端から出たものが、反対側から出てきます（パックマンの効果）。

例： 右から出て左から戻ってくる小惑星。

画面内に収める

入力： オブジェクト, 余白

オブジェクトが画面の外に出ないようにします。余白を決めると、端の少し手前で止まります。

例： プレイヤーの宇宙船がいつも見えるようにする。

感電

入力： オブジェクト, 稲妻の色, 時間（秒、0 = 無限）, 強さ（0 = 停止、1〜3）

オブジェクトのまわりで稲妻がはじける：稲妻の色で点滅し、震えて火花を散らします。時間 0 = 無限（電気柵）、強さ 0 = 停止。

例： 魔法使いが罠に触れる：魔法使いに 「感電」（1秒）、「待つ」 1秒、そのあと 「シーンをやり直す」。

光源（たいまつ、ランタン…）

入力： オブジェクト, 光の色, 半径（ピクセル：中心からの距離）, 明るさ（%、100 = ふつう、200 = とても強い）, 色のかがやき（%、0 = なし、200 = とても強い）, ゆらぎ, 点灯のしかた, 横にずらす（ピクセル）, 縦にずらす（ピクセル、マイナス = 上）

オブジェクトに光をとりつけます。オブジェクトが動くと光もついていきます（キャラのたいまつ、ランタン、火…）。ほかのオブジェクトの子でもだいじょうぶです。設定：色、半径（ピクセル、中心からの距離）、明るさ（100 = ふつう、300まで：強く遠くまで）、色のかがやき（0 = なし）、ゆらぎ（なし、ろうそく、たいまつ、ちかちか）、ずらし。1つのオブジェクトに光は1つ、同時に最大8つ。「暗さと光のふんいき」 の暗さをつきぬけます。暗さがないときは、かがやきだけが足されます。 「点灯のしかた」：「暗いときだけ」にすると、日が暮れると光がひとりでつきます（「昼と夜のサイクル」 との相性ばつぐん）。

例： キャラのたいまつ：主人公の子の「ランタン」オブジェクトにつけて、半径 360、ゆらぎは「たいまつ」。

オブジェクトの光を消す

入力： オブジェクト

オブジェクトにとりつけた光を消します。もう一度つけるには、「光源（たいまつ、ランタン…）」 をまた使います。

例： 「ランタン」ボタンで主人公の光を消す。

オブジェクトの下の影

入力： オブジェクト, 影, 影の濃さ（%）, 影の幅（オブジェクトの%）, 縦にずらす（ピクセル、マイナス = 上）

オブジェクトの下にやわらかい影を置きます（「いいえ」で消します）。オブジェクトが動くと影もついていきます。濃さと幅を調整できます。背景に立つキャラに、すぐ立体感が出ます。 インスペクターの「オブジェクトの下の影」にチェックを入れても設定できます（ノードは不要）。

例： 主人公の足もとの影：濃さ 50、幅 70。

オブジェクトの軌跡

入力： オブジェクト, プリセット, 色（空 = プリセットの色）, 大きさ（1 = 標準）

オブジェクトが動くと、後ろにパーティクルの軌跡を残します（プリセット・色・大きさを選べます）。弾のもとになるオブジェクトに設定すると、すべての弾に軌跡がつきます。プリセット「なし」で消えます。

例： 光る軌跡を残す弾：対象 = 弾のもと、プリセット「軌跡」。

オブジェクトを作成

入力： オブジェクト, X位置, Y位置

選んだオブジェクト（お手本）のコピーを X, Y の位置に作ります。

例： 決まった場所に木箱を置く。

フェード

入力： オブジェクト, 目標の不透明度（0〜1）, 長さ（秒）

選んだ時間（秒）で、オブジェクトの不透明度をなめらかに目標の値まで変えます。次のノードは待たずに動きます。

例： タイトルを 1 秒で消す（目標の不透明度 0）。

変数とインベントリ

変数を変更

入力： オブジェクト, 変数, 値

変数に新しい値（数値、テキスト、はい / いいえ、または計算）を入れます。

例： 「score」を 0 に戻す。

変数に加算

入力： オブジェクト, 変数, 加算する値, これをこえたら0にもどす（なくてもよい）

変数に値を加える（マイナスの数なら引く）。テキスト変数なら最後に文字を足す。「これをこえたら0にもどす」を入れると、カウンターのように回る：9の次は0（0より下は9）。

例： コインごとにスコア + 1；錠前の数字：タップごとに + 1、9をこえたら0にもどす。

変数を2つの値の間に保つ

入力： オブジェクト, 変数, 最小値, 最大値

変数（数値）を最小値と最大値のあいだに保ちます。

例： 体力が 100 をこえないようにする。

ランダムな数

入力： オブジェクト, 変数, （最小, 最大）の間

変数にランダムな数を入れます。random(1, 6) は 1 から 6 の数になります。

例： サイコロをふる。

インベントリに追加

入力： オブジェクト, 変数

オブジェクトをインベントリ（「インベントリリスト」型の変数）に入れます。同じものは一度しか入りません。

例： カギを拾う。

インベントリから削除

入力： オブジェクト, 変数

オブジェクトをインベントリから取り出します。

例： カギを使ってドアを開ける。

インベントリにあるなら

入力： オブジェクト, 変数  →  出力： 真 / 偽 / つぎに

オブジェクトがインベントリにあれば 「真」、なければ 「偽」 の出力に進みます。

例： カギがインベントリにあるときだけドアが開く。

2つのオブジェクトを合わせる

入力： オブジェクト A, オブジェクト B, 結果オブジェクトの名前

オブジェクト A と B を、名前を書いたオブジェクトのコピーに置きかえます（A の場所に置きます）。そのお手本がなければ何も変わりません。

例： 棒 + 布 = たいまつ。

ロジックと条件

条件

入力： 条件  →  出力： 真 / 偽 / つぎに

条件を調べます。正しければ 「真」、ちがえば 「偽」 に進みます。どちらの場合も、そのあと 「つぎに」 が動きます。

例： score >= 10 → 真 → 次のシーン。

ジョイスティックが

出力： 上 / 下 / 左 / 右 / 静止 / つぎに

ジョイスティックの向きに合った出力に進みます。「上」、「下」、「左」、「右」、触れていないときは 「静止」。

例： 「毎フレーム」 とつないで、正しい向きの歩くアニメーションを流す。

地面にいるなら

入力： オブジェクト  →  出力： 真 / 偽 / つぎに

オブジェクトの下が、固定された見えるオブジェクト（地面、足場）の上にあれば 「真」、なければ 「偽」。

例： 地面にいるときだけジャンプできるようにする。

動いているなら

入力： オブジェクト  →  出力： 真 / 偽 / つぎに

前のフレームからオブジェクトが動いていれば 「真」、動いていなければ 「偽」。

例： キャラクターが動いているときだけ歩くアニメーションを流す。

関数を呼ぶ

入力： 関数

関数（「関数」の欄で作った Blueprint）を動かしてから、続きに進みます。「毎フレーム」 の下には置かないでください。

例： いろいろな敵が使う「ライフを減らす」関数。

イベントを呼ぶ

入力： イベント名

同じ Blueprint にある、この名前の 「ローカルイベント」 を動かしてから、続きに進みます。

例： 落下とタイマーの両方から「GameOver」を呼ぶ。

シーケンス

出力： 1 / 2 / 3 / 4

出力を順番に動かします。1、次に 2、次に 3、次に 4。つながっていない出力はとばします。

例： 開始時：1 = プレイヤーを置く、2 = 音楽を流す、3 = スコアを表示する。

クールダウン

入力： オブジェクト, 遅延（秒）  →  出力： 準備完了 / まだ

決めた間隔（秒）に最大 1 回だけ 「準備完了」 を通します。それ以外は 「まだ」 に進みます。オブジェクトを選ぶと、オブジェクトごとに別の間隔になります。

例： 0.5 秒に 1 回までしか撃てないようにする。

画面外にいるなら

入力： オブジェクト, 余白（ピクセル）  →  出力： 真 / 偽 / つぎに

オブジェクトが画面（と余白）から完全に出ていれば 「真」、そうでなければ 「偽」。

例： 画面の外に出た弾を消す。

もし / それ以外

入力： もし（条件）, そうでなければもし（条件）  →  出力： もし / そうでなければもし / それ以外 / つぎに

1 つ目の条件、次に 2 つ目の条件を調べて、「もし」、「そうでなければもし」、「それ以外」 のどれかに進みます。そのあと 「つぎに」 が動きます。

例： score >= 100 なら金、そうでなく score >= 50 なら銀、それ以外は銅。

値によって

入力： 検査する値, ケース 1, ケース 2, ケース 3, ケース 4, ケース 5, ケース 6  →  出力： 1 / 2 / 3 / 4 / 5 / 6 / なし / つぎに

調べる値をケース 1 から 6 と比べて、最初に同じだったケースの出力に進みます。どれも同じでなければ 「なし」。空のケースはとばします。

例： 「武器」によって：1 = 剣、2 = 弓、3 = 杖。

テキストとダイアログ

テキストを変更

入力： オブジェクト, 新しいテキスト

テキストオブジェクトの文字を置きかえます。= で始めると計算結果を表示できます。

例： ="スコア：" + score

ダイアログを表示

入力： オブジェクト, 文の名前（ゲームのテキスト内）

会話ファイル（dialogues.txt）から、キーに合った文をテキストオブジェクトに書きます。 複数の言語：「konnichiwa.ja = こんにちは」、「konnichiwa.en = Hello」… と書く。ゲームは変数 「langue」 の言語を使い、なければスマホの言語を使います。「\n」 = 改行。

例： キー「konnichiwa_shounin」で商人のセリフを表示する。

テキストに追加

入力： オブジェクト, 変数, 追加するテキスト

テキスト型の変数の最後に文字を足します。

例： パスワードを 1 文字ずつ入力する。

移動とAI

動きを再生（ステップ）

入力： オブジェクト, 動きの名前

アセット → 動きで作った動きをオブジェクトに再生します（ステップ：位置・回転・大きさ・透明度）。途中の動きはエンジンが計算します。動いている間、オブジェクトの重力と操作は止まります。次のノードは待たずに続きます。

例： 上下に繰り返し動く橋や、スライドするドア。

動きを止める

入力： オブジェクト

オブジェクトで再生中の動きを止めます。その場所に留まります。

例： プレイヤーがボタンを押したら橋を止める。

ルートをたどる

入力： オブジェクト, ルートの名前, はやさ（1びょうあたりのピクセル）, すすむ向きに回る（はい / いいえ）, よこへのランダムなずれ（ピクセル、±：それぞれ自分のレーンを歩く）, ほかをよける：重ならないよう横にずれて、おそいものを追いこす（はい / いいえ）, よけるのに使えるはば（道の中心から左右それぞれのピクセル）, 画像の角度（0＝右向き、90＝下向き）  →  出力： すぐに / とうちゃく

アセットの「ルート」ツールで描いたルートに沿って、オブジェクトを動かします。スタート地点に置かれ、選んだはやさで点から点へ進みます。分かれ道では、設定したとおり（ランダム・順番・へんすう）に出口を選びます。出口のない点につくと「ゴールについた」の出口が動きます。「よこへのランダムなずれ」を使うと、それぞれが自分のレーンを歩きます（ランダムにずれる）。てきが重ならず、ならんで進みます。「ほかをよける」を使うと、おそいものに追いついたものは横にずれて追いこし、自分のレーンにもどります。道がせまいときは後ろについて行きます。

例： てきが出てくる：ルート「てきの道」をたどる、はやさ 150。「ゴールについた」→ 基地にダメージ、そのあとオブジェクトを消す。

ルートをやめる

入力： オブジェクト

オブジェクトをその場でとめます。もうルートをたどらず、「ゴールについた」も動きません。

例： わなでてきが凍った：ルートをやめる、あとで「ルートをたどる」を使うとまた動きます。

オブジェクトを停止

入力： オブジェクト

オブジェクトをその場でぴたっと止めます。速さ、押す力、ジャンプ、自動の動きがなくなります。

例： 氷の魔法が当たった敵を凍らせる。

移動を停止

入力： オブジェクト

オブジェクトの自動の動き（前進し続ける、追いかける、逃げる）を止めます。

例： プレイヤーが隠れたら敵が追いかけるのをやめる。

継続的に前進

入力： オブジェクト, 速度

オブジェクトが向いている方向に、選んだ速さで自分で進みます。

例： 弾や走っている車。

オブジェクトへ行く（道さがし）

入力： オブジェクト A, オブジェクト B, 速度, ななめ移動 (はい / いいえ), 止まり方, 道をふさぐタグ（ほかのユニット、カンマ区切り）  →  出力： すぐに / とうちゃく

オブジェクトAが、かべ（タイル背景の「ソリッド」タイル、動かない物理オブジェクト）を通らずに、1マスずつ一番近い道を自分で見つけてオブジェクトBへ向かいます。Bが動くと道を計算しなおします。AがBにふれると 「とうちゃく」 が動きます。「止まり方」の設定で、となりのマスにきれいに真ん中で止まれます（グリッドゲーム）。「道をふさぐタグ」で、ほかのユニットをよけて進みます。

例： 迷路でプレイヤーを追いかけるおばけ。

場所へ行く（道さがし）

入力： オブジェクト, X位置, Y位置, 速度, ななめ移動 (はい / いいえ), 道をふさぐタグ（ほかのユニット、カンマ区切り）  →  出力： すぐに / とうちゃく

オブジェクトAが、かべをよけて一番近い道（1マスずつ）で X、Y の場所へ行きます。=doigt.x と =doigt.y にすると、画面にさわった場所へ行きます。着いたら 「とうちゃく」 が動きます。道がないときは、その場にとどまります。

例： 作戦ゲームやダンジョンで、マスにさわって主人公をそこへ行かせる。

道さがしを止める

入力： オブジェクト

オブジェクトが道さがしの移動（「オブジェクトへ行く（道さがし）」 または 「場所へ行く（道さがし）」）をやめて、その場に止まります。

例： ゲームに勝ったらハエが止まる。

マスに置く（列、行）

入力： オブジェクト, 列（0 = 1つ目）, 行（0 = 1つ目）

オブジェクトAを選んだマスのちょうど真ん中に置きます（列と行は左上を0として数えます）。グリッドはシーンのタイルマップのものです。🔗ボタンで 「タッチした列」 と 「タッチした行」 をつなぐと、指でタッチしたマスに送れます。

例： ボードゲームで、タッチしたマスに駒を動かす。

自分のマスの真ん中に合わせる

入力： オブジェクト

オブジェクトAは今のマスにいたまま、ちょうど真ん中に戻ります。移動が2つのマスの間で止まったときに便利です。

例： 移動のあと、ヒーローを真ん中に直す。

マスへ行く（道）

入力： オブジェクト, 列, 行, 速度, ななめ移動 (はい / いいえ), 道をふさぐタグ（ほかのユニット、カンマ区切り）  →  出力： すぐに / とうちゃく

オブジェクトがマス（列、行）の真ん中まで歩きます。壁、さえぎる地形、指定したタグのユニットをよけます。ふつうは指でタッチしたマス。マスに着くと「着いた」の出口が1回出ます。

例： タッチした青いマスにヒーローを行かせる。

コマを1マス動かす

入力： オブジェクト, むき, 速度, 道をふさぐタグ（ほかのユニット、カンマ区切り）  →  出力： とうちゃく / ふさがれている（壁・地形・ユニット・はし）

駒を1マス（上、下、左、右）、きれいに真ん中へ動かします。そのマスが壁、さえぎる地形、ユニット（タグ）、マップのはしなら「ブロック」の出口。そうでなければ1歩の終わりに「着いた」。

例： ◀ ▶ ▲ ▼ ボタンでボードゲームの駒を動かす。

オブジェクトを追跡

入力： オブジェクト A, オブジェクト B, 速度

オブジェクト A が、選んだ速さでオブジェクト B に向かって自分で進みます。

例： プレイヤーを追いかけるおばけ。

オブジェクトから逃げる

入力： オブジェクト A, オブジェクト B, 速度

オブジェクト A が、選んだ速さでオブジェクト B から自分で離れます。

例： プレイヤーから逃げるニワトリ。

角度を付けて押す

入力： オブジェクト, 角度（0 = 右、90 = 下）, 力

選んだ力で、オブジェクトをある方向に押します（角度：0 = 右、90 = 下、180 = 左、270 = 上）。

例： プレイヤーをななめに飛ばすバネ。

インパルス（ジャンプ）

入力： オブジェクト, 縦方向の力（マイナス = 上）

オブジェクトを上（マイナスの数）または下（プラスの数）に飛ばし、落ちてくるように物理を与えます。

例： ジャンプ：力 -15。

ふるまいを変える

入力： オブジェクト, どう動く, はやさ, ジャンプの高さ, はしごにする, 拾える

ゲーム中にオブジェクトのふるまいを変える。インスペクターの「オブジェクトのふるまい」画面と同じ選択肢：かざり、地面 / かべ、落ちてはずむ、アクションゲームのキャラ、パトロール（行ったり来たり）、上から見たキャラ、指でドラッグ。速さ、ジャンプの高さ、「はしごにする」「拾える」も変えられる。「（変えない）」のままの設定は元の値のまま。

例： 止まっている箱（地面 / かべ）がレバーを引くと落ちはじめる：ふるまいを変える → 落ちてはずむ。

ぴょんぴょん跳ねる

入力： オブジェクト, 強さ（0 = 停止）, 長さ（ミリ秒、1000 = 1秒）, 動いている間続ける（はい / いいえ）

選んだ強さと時間で、オブジェクトをぴょんぴょん跳ねさせます（見た目だけの小さなはずみ）。0 で止まります。オブジェクトが動いている間、続けることもできます。

例： 歩きながらぴょんぴょん跳ねるキャラクター。

向きを合わせる

入力： オブジェクト A, オブジェクト B, 角度のずれ（度）

オブジェクト A をオブジェクト B の方へ向けます。角度のずれで画像の向きを直します（0 = 画像が右を向いている）。

例： プレイヤーをねらう砲台。

スライド移動

入力： オブジェクト, X位置, Y位置, 長さ（秒）

選んだ時間（秒）で、オブジェクトを X, Y の位置までなめらかに動かします。次のノードは待たずに動きます。

例： 動く足場や、画面に入ってくるメニュー。

グリッドとパズル

次のターンへ

入力： チームの順番（タグをカンマで区切る）

ゲームを次のチームに渡します。チームをタグで順番に書きます（例：プレイヤー,てき）。最初の呼び出し（たとえば 「起動時」 のあと）は最初のチームから始まり、全チームが行動するとターン数が増えます。各ターンの始めに、ローカルイベント「tour_<チーム>」があれば実行されます（例：「tour_てき」）。

例： 「ターン終了」ボタンに 「次のターンへ」 をつける。

もし…の番なら

入力： チーム（タグ）  →  出力： 真 / 偽

書いたチーム（そのタグ）の番なら「はい」、そうでなければ「いいえ」。

例： プレイヤーが自分の番のあいだだけ自分のユニットをタッチできるようにする。

行動済みにする

入力： オブジェクト

ユニット（オブジェクトA）がこのターンに行動したことを覚えます。次のターンが始まるとすべて消えます。

例： ヒーローが同じターンに2回動かないようにする。

もしユニットが行動済みなら

入力： オブジェクト  →  出力： 真 / 偽

ユニット（オブジェクトA）がこのターンにもう行動していたら「はい」、そうでなければ「いいえ」。

例： もう行動したヒーローを動かせないようにする。

行けるマスを表示

入力： オブジェクト, ゾーンの種類, 歩数（または射程）, マスの色, マスの見え方（0 = 見えない、100 = 不透明）, 各マスに枠線, 各マスに歩数を表示, 壁が通れない（移動）, 通れなくするタグ（カンマ区切り）, 歩数が増える地形（タグ=コスト、例：forest=2, water=3）, ゾーン名（任意：複数表示用）, 射程の形（攻撃とジャンプ）, 最小射程（0 = なし、2 = 近い2マスは除く）, 自分の位置（列,行 例：2,1 ; -2,1 ; 0,3）, オブジェクトのいるマスを除く

選んだオブジェクトが行ける（または攻撃できる）マスに色をつけます。壁はさえぎり、さえぎるタグ（ほかのユニット）や歩数が多くかかる地形（森=2）も足せます。色、見やすさ、わく、数字は調整できます。「ゾーンの名前」で複数を同時に表示できます（移動は青、攻撃は赤）。

例： ヒーローをタッチしたとき、移動できる範囲を表示する。

マスを隠す

入力： ゾーン名（任意）

色のついたマスを消します（すべて、または名前をつけたゾーン）。

例： ヒーローが着いたら範囲を隠す。

もしマスに行けるなら

入力： 列, 行, ゾーン名（任意）  →  出力： 真 / 偽

マス（列、行）が表示されているマスのひとつなら「はい」。ふつうは指でタッチしたマス。そうでなければ「いいえ」。

例： 遠すぎる移動を「遠すぎる！」で断る。

ユニットカードをあたえる

入力： オブジェクト, HP, 攻撃, 防御, 移動（歩）, 攻撃の射程（マス）, その他の能力値（例：munitions = 3, armure = 2）

オブジェクトにカードをあたえます：体力、こうげき、ぼうぎょ、移動、射程（オブジェクト変数「vie」「attaque」「defense」「mouvement」「portee」）。式でどこからでも読めます。たとえば =ヒーロー.mouvement は行けるマスの歩数です。このノードは各ユニットの 「起動時」 のあと、または使い回せるユニットのプレハブに置きます。

例： 弓兵を作る：体力8、こうげき4、ぼうぎょ0、移動4、射程3。

こうげきする

入力： オブジェクト A, オブジェクト B, 攻撃の強さ（%）, 相手の地形の防御を数える, 最低でも1ダメージ, HPが0になったら相手をこわす, 自由なダメージ式（例：attaquant.attaque * 2 - cible.armure）、空欄 = 通常の計算, 相手のタグによるボーナス（例：きば = 150、かるい = 120：ダメージの %）, 攻撃する側のタグによるボーナス（例：やり = 130）, 攻撃のたびに減るステータス（例：たま。0なら攻撃できない）, かんつう：ぼうぎょを無視する %（0 = なし）, はんげき：生きのこり、こうげき者がはんいにいるとき返す %（0 = なし）, 高さボーナス：高さの差1段ごとのダメージ %（例：15。高いほど強い）, まもり：目標の防御を高める隣の味方のタグ（例：やり）, まもり：隣の味方1人ごとの防御アップ  →  出力： まだ生きている / HPが0 / こうげき者がたおれた（はんげき）

オブジェクトAがBをこうげきします：ダメージ = Aのこうげき × パワー × ボーナス − Bのぼうぎょ − Bの地形のぼうぎょ。出口は「まだ生きている」「HPが0」（チェックがあれば目標はきえる）と、はんげきで倒れたときの「こうげき者がたおれた」。どちらも、ユニットカードが必要です。donnees.txt の「regle: やり > きば = 150」は自動で使われます。詳細設定：タグのボーナス（「きば = 150」）、かんつう（ぼうぎょを無視する割合。やりやクロスボウ用）、はんげき（目標が生きのこり、こうげき者がはんいにいるとき返す割合）、高さボーナス（高さの差1段ごとのダメージ割合。高いほうが強い）、まもり（選んだタグの隣の味方1人ごとに目標のぼうぎょが上がる：たてのかべ）、自由な式、こうげきごとに減るステータス（たま）。

例： やり（かんつう40）で重い騎兵に。丘の上の弓兵（高さ +15 %）。

データをあてる（ユニット・ぶき）

入力： オブジェクト, donnees.txtの名前（例：きし）  →  出力： みつかった / みつからない

donnees.txt（アセット → セリフ、または assets_ludexa/Textes/donnees.txt）に書いたユニットやぶきの値をすべてオブジェクトAにあたえます：HP、こうげき、ぼうぎょ、いどう、はんい、ねだん…とタグ。1行で足ります：「unite きし: vie=12, attaque=5, defense=2, mouvement=4, portee=1, tags=きば おもい」。ファイルを直すだけでバランスを変えられ、ノードはそのままです。出口は「みつかった」「みつからない」。ファイルには「arme つるぎ: attaque=5」「etat どく: duree=3, degats=2」「regle: やり > きば = 150」（やりタグの攻撃者がきばタグの相手に150 %、「こうげきする」が自動で使います）やマスの高さも書けます。

例： ゲーム開始時に、ヒーローごとに：データをあてる「きし」。

マスの高さをきめる

入力： はじめの列, はじめの行, 列の数, 行の数, 高さ（0 = たいら）

グリッドのマスの長方形に高さ（レベル：0 = たいら、1、2、3…）をあたえます：はじめの列と行、列の数と行の数。高さは「こうげきする」の高さボーナスになり、戦場のきりでは視界をさえぎります（丘の向こうは見えない）。donnees.txt に書くこともできます（「hauteur 3,4 = 2」や、1マス1けたの「hauteurs:」ブロック）。式 hauteur(列, 行) か、緑のノード「タッチしたマスの高さ」「オブジェクトの下のマスの高さ」で読みます。

例： 高さ2の3 x 2マスの丘。そこに立つ弓兵は強くこうげきできます。

じょうたいをあたえる（どく・おそい…）

入力： オブジェクト, じょうたいの名前（例：どく。donnees.txtで設定）, ターン数（空 = donnees.txtの値）, ターンごとのダメージ（空 = donnees.txt）, 変えるステータス（例：mouvement。空 = donnees.txt）, ステータスの変化（例：-2）

ユニットにターン数のあいだ状態をあたえます：どく（毎ターンダメージ）、おそい（いどうが下がる）、しゅくふく（こうげきが上がる）…すべて donnees.txt に書けます（「etat どく: duree=3, degats=2」「etat おそい: duree=2, stat=mouvement, delta=-2」）。その場合は状態の名前だけで足ります。ダメージはユニットのチームのターンのはじめに入り、そのあと状態が1ターン減ります。おわると変えたステータスはもとにもどります。同じ状態をもう一度あたえると、2倍にならずのびます。ユニットは「etat_<名前>」（のこりターン）というステータスをもち、式で読めます。「つぎのターンへ」が必要です。

例： どくの矢：こうげきする → まだ生きている → 目標に「どく」をあたえる。

じょうたいをとりのぞく

入力： オブジェクト, じょうたいの名前（空 = すべて）

ユニットから状態をとりのぞきます（名前で。空ならすべて）。状態で変わったステータスはすぐにもとの値にもどります。

例： なかまのどくを治す僧りょ。

もしユニットがじょうたいなら…

入力： オブジェクト, じょうたいの名前（空 = すべて）  →  出力： 真 / 偽

ユニットが状態をもっているかしらべます（名前が空ならどれでも）。出口は「はい」「いいえ」。

例： ユニットが「こおり」状態なら動けない。

オブジェクトのまわりのはんいこうか

入力： オブジェクト, こうか, つよさ（ダメージ・かいふく）, はんけい（マス）, えいきょうするタグ（空 = みんな）, じょうたいの名前（じょうたいをあたえるとき）, 1マスはなれるごとの減り方（%）, かたち, まん中のオブジェクトにもあたる

オブジェクトA（まん中）のまわりのオブジェクトにいっぺんに作用します：ダメージ、かいふく、または状態。設定：つよさ、マスの半径、えいきょうするタグ（空 = みんな）、かたち（ひし形、またはななめも入れた四角）、1マスはなれるごとの減り方（爆発：遠いほど弱い）、まん中のオブジェクトにもあたるか。ダメージはぼうぎょを無視します。火の玉、みんなのかいふく、おどろかす叫び。条件でひがい数をかぞえるには、式 compter("タグ") と voisins(オブジェクト, "タグ", マス数) を使います。

例： 火の玉：半径2、つよさ6、1マスで30 %減る、「てき」ユニットに。

けいけんちをえる

入力： オブジェクト, えたけいけんち, レベル2までのけいけんち（あとは x レベル）, レベルごとの上がり方（例：vie=2, attaque=1）  →  出力： レベルアップ / とりけすものなし

ユニットにけいけんちをあたえます。しきい値（しきい値 × いまのレベル）に着くとレベルが1つ上がり、あまったけいけんちは残り、上がり分がたされます（「vie=2, attaque=1」。さいだいHPもHPといっしょに上がる）。ユニットは「xp」と「niveau」（はじめは1）をもちます。出口は「レベルアップ」「レベルアップなし」。上がったときにファンファーレやメッセージを出せます。

例： てきをたおすたびに30のけいけんちをえる勇者。

いちをおぼえる

入力： オブジェクト

いどうの前に、ユニットのいまの位置をおぼえます。「いどうをとりけす」と組み合わせると、プレイヤーはやり直せます（アドバンスウォーズで行動前に「キャンセル」するのと同じ）。

例： 「マスへ行く」の直前に：いちをおぼえる。

いどうをとりけす

入力： オブジェクト  →  出力： とりけした / とりけすものなし

「いちをおぼえる」でおぼえた位置にユニットをもどし、「行動ずみ」をけして、ステータス「bouge」「agi」を0にします。出口は「とりけした」「とりけすものなし」。

例： ユニットの行動メニューの「キャンセル」ボタン。

コンピューターのように動く（AI）

入力： オブジェクト, てきのタグ（例：プレイヤー）, たたかい方, いどうのはやさ, 道をふさぐほかのタグ（例：なかま）  →  出力： とうちゃく / ターゲットなし

ユニットをコンピューターのように自動で動かします。行ける場所（いどう、かべ、地形、じゃまするユニット）を調べ、てき（タグ）をさがし、たたかい方に合わせて、こうげきするのにいちばんよいマスをえらびます：こうげき重視（ダメージ最大、とどめを優先）、ようじん深い（はんげきをさける）、まもり重視（ぼうぎょの高いマスが好き）。だれもはんいにいないときは、いちばん近いてきに近づきます。着くと出口「とうちゃく」が出て、関係オブジェクトはえらんだ目標、ユニットのステータス「cible_ia」は1（こうげきできる）か0（近づいただけ）になります。ユニットのいどう、はんい（と「portee_min」）、ユニットカードを使います。てきがもういないときは出口「てきがいない」。

例： モンスターのターン：モンスターごとに「コンピューターのように動く」（てき = プレイヤー）→ 着いたら cible_ia が1なら、こうげきする。

戦場のきりを更新する

入力： 見えるチームのタグ（例：プレイヤー）, 見えないときにかくすてきのタグ（例：てき）, ふつうの視野（マス。なければユニットの « vision »）, しらないマスの暗さ（0〜100）, 見たマスをおぼえておく

チームが見えるはんいを計算し、のこりの地図を暗いベールでおおいます：チームのユニット（タグ）は、まわりを「vision」（マス）まで見わたします（なければノードのふつうの視野）。地形のかべ、「bloque_vue = oui」の地形（深い森）、より高いマスは視界をさえぎります。もう見たマスは半分暗いまま（きおく、おこのみで）。見えないてきタグのユニットはかくれます。いどうのあとやターンのはじめにもう一度実行します。式 vue(列, 行) はそのマスが見えていれば1です。「戦場のきりを消す」ですべて見えます。

例： プレイヤーのターンのはじめごとに：きりを更新（チーム プレイヤー、てき てき、視野3）。

例： はじめにモンスターに体力10をあたえる。

ダメージをあたえる

入力： オブジェクト, ダメージ, HPが0になったらこわす, いる地形の防御をひく  →  出力： まだ生きている / HPが0

オブジェクトの体力を減らします（0より下にはなりません）。出口は2つ：「まだ生きている」と「体力ゼロ」（チェックを入れるとオブジェクトは壊れます。「関係するオブジェクト」は当たったままです）。

例： ヒーローがモンスターをたたく：ダメージ3、そのあと結果に合わせて小さなメッセージ。

例： ヒーローの体力を5回復するポーション。

ステータスを変える

入力： オブジェクト, ステータス名（例：たま）, どうする, いくつ

オブジェクトに自分で作ったステータス（たま・よろい・マナ・ねんりょう…）を、たす・ひく・ある数にする、で変えます。まだ無ければ 0 で作られます。あとはどこでも読めます：=アーチャー.たま。

例： うった後：ステータスを変える → オブジェクト「アーチャー」、ステータス「たま」、ひく 1。

もしステータスが…

入力： オブジェクト, ステータス名（例：たま）, くらべる, あたい  →  出力： 真 / 偽

オブジェクトのステータスをある数とくらべて、「はい」か「いいえ」に進みます：たとえば「たまが 0 より大きい」。無いステータスは 0 として数えます。

例： うつ前に：アーチャーの「たま」が 0 より大きいなら → うつ。そうでなければ →「矢がない」と表示。

ターゲットを選ぶ

入力： オブジェクト, ターゲット候補のタグ（カンマ区切り）, どのターゲットを選ぶ？, 射程（マス数、0 = 無制限、例：=モンスター.portee）, 最小射程（0 = なし）, 射程の形, 自分の位置（列,行 例：2,1 ; -2,1）, 能力値（「能力値」ルール用、例：defense）, ピクセルの円形はんい（0＝マス数のはんいを使う）  →  出力： ターゲット発見 / ターゲットなし

オブジェクトAは、指定したタグを持つオブジェクトのうち射程内にいるもの（「行けるマスを表示」と同じ形）から1つ選びます。いちばん近い、HPが最も少ない／多い、能力値が最も低い／高い、のどれかです。「ターゲット発見」の出口では、それが「関係するオブジェクト」になります（攻撃や移動に使えます）。「ターゲットなし」は射程内に誰もいないとき。モンスターや砲台の頭脳にぴったりです。

例： モンスター：「ターゲットを選ぶ」（タグ「ヒーロー」、いちばん近い）、そして「ターゲットあり」から 「こうげきする」。

グリッドをうめる

入力： オブジェクト, 列の数, 行の数, お手本オブジェクト（名前をカンマで区切る）

オブジェクトA（ばん）を列と行に分け、それぞれのマスにランダムなお手本オブジェクトのコピーを置きます（お手本は3つ以上、名前はカンマで区切る）。最初からそろっていることはなく、ピースは上から落ちてきます。「グリッドで遊ぶ（3つそろえる）」 の前に使います。

例： スタート時に、8 x 8 のキャンディ「red, orange, yellow, green, blue, pink」をならべる。

グリッドで遊ぶ（3つそろえる）

入力： オブジェクト, 指の X 位置, 指の Y 位置  →  出力： そろったピースごとに / 手番おわり / 入れかえ失敗

「3つそろえる」ゲーム（Candy Crush のような）の心ぞう部分で、「指で押している間」 の下に置きます。ピースをタッチすると選ばれ、となりのピースをタッチ（または指をすべらせる）と入れかわります。同じピースが3つ以上ならんだときだけ入れかえが残り、そうでなければもどります（「入れかえ失敗」）。そろったピースはそれぞれ 「そろったピースごとに」 を動かし（関係するオブジェクトはそのピース）、消えます。上のピースが落ち、新しいピースが来て、連鎖も自動で起きます。すべて止まると 「手番おわり」。動かせる手がなければ、グリッドは自動でまざります。

例： 「そろったピースごとに」：+10点とピースにキラキラ。「手番おわり」：のこり手数を1へらす。

入力： オブジェクト

オブジェクトAのグリッドのピースをすべて並べかえます。そろいは作らず、動かせる手を最低1つ残します。

例： プレイヤーがつまったときの「まぜる」ボタン。

場所をまぜる

入力： オブジェクト

選んだタグの付いたすべてのオブジェクトの場所をランダムに入れかえます（オブジェクトA =「# タグ」）。子オブジェクトもいっしょに動きます。

例： 神経衰弱のカードを最初にまぜる、カップ当てゲームのカップをまぜる。

画面の切りかえ

画面の切りかえ（まる、星…）

入力： 形, 向き, 色, 時間（秒）, 中心：物（名前。まる・星・ひし形・ハート・主人公）  →  出力： 次へ / すぐに

形（19種類から選択：円、星、ハート、カーテン、時計、市松模様、うずまき…）で画面をおおったり、あらわにしたりします。「閉じる」は画面をおおったままにし、「開く」はあらわにします。「つぎ」は終わったとき、「すぐに」はすぐに動きます。

例： 円が閉じる → 「シーンを切り替える」 → 円が開く。ひとつでシーンを切り替えるなら：「切りかえ効果つきでシーンへ」。

切りかえ効果つきでシーンへ

入力： シーン, 形, 色, 閉じる時間（秒）, 閉じたままの時間（秒）, 開く時間（秒）, 開くときの形, 中心：物（名前。まる・星・ひし形・ハート・主人公）  →  出力： なし（スクリプト終了）

トランジション付きでシーンを切り替えます。画面が形（円、星、ハート、カーテン、うずまき…19種類）でおおわれ、新しいシーンが現れ、また画面が開きます。出力はありません。そのあとは新しいシーンの「開始時」で設定します。

例： ドアにさわる：主人公の上で円が閉じて、シーン「家」へ。

アニメの速さ

ストーリーと会話

セリフを言う

入力： だれが話す, 表情, セリフ, 画面の位置, キャラの登場, エフェクト, 音・ボイス, つぎへ進む  →  出力： つぎに

会話ゲーム：選んだキャラが会話ボックスで1文字ずつセリフを言い、プレイヤーが画面をタッチすると続きます。キャラは表情つきで出ます（キャラのカード：画像、色、声）。特別な言葉：[c]色[/c]、[t]ふるえる[/t]、[o]波打つ[/o]、[p] で間、{score} で変数；「🌐 9言語」ボタンで翻訳。

例： ハナ（うれしい）が「こんにちは！」と言い、「選択肢を出す」 で2つの答えを出す。

選択肢を出す

入力： だれが聞く, 表情, 質問（なくてもよい）, 答え 1, 答え 2, 答え 3, 答え 4, 答えの条件 1, 答えの条件 2, 答えの条件 3, 答えの条件 4, 選べない答え, 答え 1 の画像（なくてもよい）, 答え 2 の画像（なくてもよい）, 答え 3 の画像（なくてもよい）, 答え 4 の画像（なくてもよい）, タイマー（秒、0 = なし）  →  出力： 答え 1 / 答え 2 / 答え 3 / 答え 4 / 時間切れ

2〜4個の答えを大きなボタンで出します。答えごとに出口があり、物語が木のように分かれます。答えに条件をつけられます（満たさないとグレーまたは非表示）。タイマーをつけると「時間切れ」の出口が増えます。 それぞれの答えに画像もつけられる（くわしい設定）：答えが大きな絵つきカードになる。

例： 「宝物を開ける」はハッピーエンド、「立ち去る」は悲しいエンドへ。

背景を変える

入力： 背景の画像（空 = なし）, 切りかえ, 背景のゆっくりした動き, 動きの長さ（秒）, 中間のレイヤー・透明（空 = なし）, キャラの手前の前景・透明（空 = なし）, 動きの大きさ

画像を全画面の背景にして、物語のキャラの後ろに置きます（フェードまたはすぐ）。画像が空 = 背景なし。

例： 最初は草原、ハナがネコを探しに行くと森。

背景を横切る

入力： 横切る画像, 動き（ステップ）, どこを通る？, 画像の高さ（ピクセル）, 画像のアニメーション（名前・任意）, アニメーション速度（毎秒コマ数）

アセット → 動きで作った動きに沿って、画像（鳥・雲・蚊など）をストーリーの背景に横切らせます。キャラクターの後ろか前を選べます（テキストボックスは常に最前面）。「高さ」で画像の大きさを決めます。 画像がアニメーション（羽ばたく鳥など）なら、「画像のアニメーション」に名前を、「速さ（1秒あたりの枚数）」に速さを書きます。

例： Hanaが話している間に、鳥が空を横切る。

横切る画像を止める

ストーリーの背景を横切っている画像をすべて消します（「背景を横切る」 で開始したもの）。

例： 会話が終わったら蚊が去る。

キャラを出す / 消す

入力： キャラ, キャラが…, 表情, 画面の位置, キャラの登場

物語のキャラを登場させたり（表情、位置、登場：フェード、すべりこみ、ジャンプ）、表情を変えたり、退場させたりします。セリフはなし。

例： ハナが話している間にリンが右から登場。

キャラを動かす

入力： キャラ, 移動先…, 大きさ（100 = ふつう、120 = 大きめ）, ジャンプの回数, 長さ（秒）, 動きのタイプ, ふるえる, 終わるまで待つ

すでに画面にいるキャラを動かします。別の位置へすべる、大きく／小さくなる、ぴょんぴょん跳ぶ、ふるえる。長さと動きのタイプ（一定、なめらか、速→ゆっくり、少し行き過ぎる、バウンド）を決められます。「終わるまで待つ」を選ぶと動きが終わるまで話が止まり、選ばなければ動きながら話が進みます。先に 「キャラを出す / 消す」 でキャラを出しておく必要があります。

例： ハナが「待ってー！」と言いながら、バウンドして左から右へすべる。

ノベルモード（全画面テキスト）

入力： どうする？

「ノベルモード」に切りかえます。背景が暗くなり、文字が画面いっぱいに広がって、「セリフを言う」 の文が本のように順に並びます。ページがいっぱいになると自動でめくられます。「新しいページ」はすぐに文字を消し、「会話ボックスに戻す」はいつものボックスに戻します。

例： 夜のナレーションをノベルモードで見せて、会話は会話ボックスに戻す。

SMSモード（スマホで会話）

入力： どうする？, だれから（上に名前と写真）, 「わたし」はだれ（セリフは右側）, 名前の下の文字（空 = 「オンライン」）

会話をスマホのSMSのように表示します。「セリフを言う」 のセリフが吹き出しになり（書く人は左、出る前に「…」が3つ）、「選択肢を出す」 の答えはスマホの下で選び、右側に届きます。ナレーターは真ん中に小さな文字（例：「昨夜 22:14」）を書きます。「だれから」は上の名前と写真、「「わたし」はだれ」は選択なしで右側に書くキャラを決めます。「チャットを消す」はスマホを空にし、「会話ボックスにもどる」でモードを終えます。設定はすべて会話スタイルで：色、大きさ、「…」の時間、スマホの全画面など。

例： SMSモード（オン、だれから：ハナ）→ セリフを言う（ハナ：「いる？」）→ 選択肢を出す（「うん、どうしたの」/「どうして？」）。

実績を解除する

入力： 実績の名前, 説明（リストに出る）, 実績の画像（空 = 星）, かくれている間のヒント（空 = なし）

実績を解除します。画面の上に「実績を解除！」のバナーがすべり出ます（公開したゲームでは最初の1回だけ、エディターでは見られるように毎回）。実績は 「物語のタイトル画面」 の「エンディングとギャラリー」の「実績」タブに入り、手に入れるまでは「???」にかくれます（ヒントを書けば表示）。物語の最後や秘密の分岐、「友情（ハート）」 のあとなどに置きましょう。バナーは会話スタイルで設定します：色、枠の画像、時間、場所（上か下）、音。

例： 物語を終える（エンディング「なくした靴下」）→ 実績を解除する（名前「なくした靴下」、説明「かくしエンディングを発見」）。

リプレイできる場面（ギャラリー）

入力： 場面のはじめか終わり, 場面の名前（ギャラリー）

プレイヤーがあとから見返せる場面に印をつけます。「物語のタイトル画面」 の「エンディングとギャラリー」（「リプレイできる場面」タブ）で見られます。「場面のはじめ」に1つ置くと、そこを通ったときに場面が解放され、物語の状態が記憶されます。「場面の終わり」にもう1つ置くと、リプレイ時はそこで終わってギャラリーに戻ります。リプレイ中は何も保存されません。「音楽を再生」 で流した音楽も「音楽」タブで解放されます。

例： 「空き地」：ハナと出会う場面のはじめに1つ、彼女が去った直後にもう1つ。

物語を終える

入力： エンディングの名前（なくてもよい：「エンディングとギャラリー」に入る）

物語の会話ボックス、キャラ、背景を消して、ゲームに戻ります。「エンディングの名前」を入れると、そのエンディングはずっと記録され、「物語のタイトル画面」の「エンディングとギャラリー」に入ります。セーブは消えます。

例： 最後のセリフのあと「小屋の友だち」、そしてタイトル画面にもどる。

友情（ハート）

入力： だれ？, ふやすハート（−1 でへらす）, ハートの最大数

キャラクターの友情ハートを増やす（−1 で減らす）。最大値はこえない。物語のあいだハートは左上に表示され、「+1 ❤」がふわっと上がる（会話のスタイルで非表示にできる）。セーブにふくまれ、◀ 戻る でも元にもどる。

例： やさしい答え「そばにいるよ」のあと：ハナ +1。

もし友情が…

入力： だれ？, が, 個のハート  →  出力： 真 / 偽

キャラクターの友情ハートで物語の続きを選ぶ：比べた結果が正しければ「真」、ちがえば「偽」の出口へ。キャラクターへの接し方で変わるエンディングに。

例： ハナの友情が 4 以上 → しあわせなエンド、そうでなければ悲しいエンド。

物語のタイトル画面

入力： 物語のタイトル, 背景の画像（空 = いまの背景）  →  出力： はじめから

画像の上に物語のタイトルと大きなボタンを出します：「つづきから」（やめたところから再開。背景、キャラ、音楽、変数ももどる：物語はセリフごとに自動でセーブ）、「はじめから」（出口：物語の最初）、「エンディングとギャラリー」（見つけたエンディングと見た背景。ほかはカギつき）。物語の中では ◀ もどる ボタンで前のセリフに、選択の前にももどれます。

例： 「スタート時」のすぐあとに置く。どの「物語を終える」もここにもどる。

プレイヤーに文字を書いてもらう（名前…）

入力： 変数, 質問, はじめの答え

キーボードつきの小さな窓を開きます：プレイヤーが文字（名前…）を書き、選んだ変数に入ります。OK で続きます。セリフの中で {prenom} がこの文字になります。

例： 「名前は？」→ 変数 prenom → 「セリフを言う」「よろしくね、{prenom}！」。

画面フィルター

画面フィルター

入力： フィルター, 強さ（%）, あらわれる時間（秒）, 続く時間（秒、0 = ずっと）, 次のシーンでも続ける, ボタンと文字（HUD）にもかける, 懐中電灯：照らす物（名前。空 = カメラが追う物）, 懐中電灯：光の大きさ（%）  →  出力： つぎに / 終わったら

ボタンや文字も含めて、ゲーム全体に「雰囲気」を与えます。テレビ、VHS、白黒、水中、悪夢、懐中電灯…32種類から選べます。ゆっくり現れ、好きな時間だけ続き（0 = 止めるまで）、次のシーンにも引き継げます。「つぎに」はすぐに、「終わったら」は時間が終わったときに動きます。

例： 主人公がダメージを受けた：「ケガ」フィルターを2秒間。または洞窟で「懐中電灯」。

フィルターを止める

入力： 消える時間（秒）  →  出力： つぎに / 終わったら

今の画面フィルターをゆっくり消します。「つぎに」はすぐに、「終わったら」はフィルターが消えたときに動きます。

例： 主人公が洞窟を出る：1秒で懐中電灯を消す。

物理

物理の世界を設定

入力： 下向きの重力（%、100 = ふつう、0 = 宇宙、マイナス = 上向き）, 右向きの重力（%、マイナス = 左向き：ずっと吹く風）, 精度, 止まった物は眠る（スマホが軽くなる）

シーンの物理の世界を設定します：下向きの重力（100 % = ふつう、0 = 宇宙、マイナス = 物が上に落ちる）、横向きの重力（ずっと吹く風）、計算の細かさ、止まった物を眠らせるかどうか。「開始時」の下で1回だけ使います。「リアルな物理」のふるまい（⚙ ふるまい）を持つオブジェクトだけに効きます。

例： 月のステージ：重力 20 %。

物理オブジェクトを設定

入力： オブジェクト, オブジェクトの種類, 素材（重さ・はずみ・すべりにくさを一度に）, ふれる形, 重さ（%、100 = ふつう、空 = そのまま）, はずみ（0〜100、空 = そのまま）, すべりにくさ（0 = 氷、100 = ねばる、空 = そのまま）, オブジェクトの重力（%、0 = 浮く、空 = そのまま）, 空気のブレーキ（0〜20、空 = そのまま）, 最高速度（ピクセル毎秒、0 = 無制限、空 = そのまま）, ぜったい回らない, ゴースト（通り抜けられる）, とても速い物（うすいかべをすり抜けない）, オブジェクトの層（1〜8、空 = そのまま）

ゲーム中に物理オブジェクトの設定を変えます：種類（ふつう・固定・ガイド付き・物理をやめる）、素材（木・石・金属・ゴム・ボール・氷・羽）、形、重さ、はずみ、すべりにくさ、重力、空気のブレーキ、最高速度、回るかどうか、ゴーストか・とても速いか、層。空のまま、または「（変えない）」の設定はそのままです。まだ物理のないオブジェクトは、種類を選ぶと物理がつきます。

例： ボーナスを取るとボールがゴムになる（素材「ゴム」）。

押す（物理の力）

入力： オブジェクト, 右へ押す（マイナス = 左）, 下へ押す（マイナス = 上）, やり方, どこを押す（中心以外だと回る）, 重さは関係する？

物理オブジェクトを力で押します。「ずっと押す」：毎フレームくり返します（「毎フレーム」や「指が押されている間」の下）。押している間、どんどん速くなります（ロケット・風・扇風機）。「ひと押し」：すぐに速さを足します（ジャンプ・キック）。ふつうは軽くても重くても同じ効果ですが、詳細設定で重さを関係させたり、中心以外を押して回転させたりできます。値：ピクセル毎秒（ずっと押すときは毎秒毎秒）。

例： ロケットゲーム：「指が押されている間」→ 上へずっと押す（-2500）。

速さを決める（物理）

入力： オブジェクト, 右への速さ（ピクセル毎秒、空 = そのまま）, 下への速さ（マイナス = 上、空 = そのまま）, 回転の速さ（度毎秒、空 = そのまま）, やり方, 全部いっぺんに止める？

物理オブジェクトの速さをピクセル毎秒で決めます：右向き、下向き（マイナス = 上）、回転（度毎秒）。空の欄はその速さを変えません。「おきかえる」はその速さにし、「たす」は今の速さに足します。「全部止める」で全部の速さが0になります。ジャンプ（下向き -900）、急停止、一定の速さで進むキャラに便利です。

例： プラットフォームのジャンプ：下向きの速さ = -900。「もし物理オブジェクトが…」 が「のっている」と言ったときだけ。

投げる（角度と速さ）

入力： オブジェクト, 角度（度：0 = 右、-90 = 上、90 = 下、180 = 左）, さいしょの速さ（ピクセル毎秒）, やり方

物理オブジェクトを好きな向きに投げます：角度（0 = 右、-90 = 上、90 = 下、180 = 左）と最初の速さを決めます。あとは重力にまかせて、物は弧をえがきます。パチンコゲーム・大砲・ボール投げに最適。角度は式でもOK（たとえば物と指の間の角度）。

例： パチンコ：指をはなしたら、ゴムの角度で鳥を飛ばす。

爆発（ふきとばし）

入力： オブジェクト, 中心：X位置（空 = オブジェクトの中心）, 中心：Y位置（空 = オブジェクトの中心）, ふきとばす範囲（ピクセル）, 中心の強さ（与える速さ、ピクセル毎秒）, このタグの物だけ（空 = すべて）

ある点のまわりの物理オブジェクトをふきとばします：中心に近いほど強く飛び、回りはじめます。中心は選んだオブジェクトの真ん中、または書いた (x, y) の点です。範囲と強さ（中心で与える速さ）を決めます。オプション：あるタグの物だけ。このノードは何も壊しません。「パーティクル効果」や「オブジェクトを消す」と組み合わせて本物の爆発にしましょう。

例： 爆弾：地面にふれたら半径500・強さ1800で爆発し、爆弾を消す。

2つのオブジェクトをつなぐ

入力： オブジェクト A, オブジェクト B, つなぎ方, つなぎの名前（あとで調整・切断するため）, オブジェクトAのつなぐ場所, オブジェクトBの場所（棒・バネ・ロープ）, 点を右にずらす（ピクセル）, 点を下にずらす（ピクセル）, 2つはぶつかる？, 長さ（ピクセル、0 = さいしょのきょり）, バネ・サスペンションのかたさ（1 = やわらかい、10 = かたい）, ダンパー（0〜100：大きいほどはずまない）, 下のリミット（ちょうつがいは度、スライダーはピクセル；空 = なし）, 上のリミット（度またはピクセル；空 = なし）, レール・サスペンションの向き（度：0 = 横、90 = 縦；空 = 自動）, モーター：速さ（ちょうつがい・車輪は度毎秒、スライダーはピクセル毎秒；0 = なし）, モーター・ブレーキの強さ（1 = 弱い、10 = ふつう、100 = とても強い）

2つのオブジェクトを、本物みたいに支え合ったり一緒に動いたりするようにつなぎます。つなぎ方：ちょうつがい（1点を中心に回る：ドア・振り子）、かたい棒（きょり固定）、バネ（のびちぢみ・かたさ設定）、ロープ（いちばん長いきょり）、スライダー（レールをすべる・リミットとモーター）、ようせつ（くっつける）、サスペンション付き車輪（車：A = 車体、B = 車輪、モーター付き）、ブレーキ（上から見た図）。Bは省略でき、Bがないと、Aは背景の固定点にぶら下がります。名前をつけると、あとで「つなぎを調整」「つなぎを切る」で使えます。詳細設定：それぞれの場所、リミット、レールの向き、モーター、2つがぶつかるか。どちらも「リアルな物理」のふるまいが必要です（固定の支えは除く）。

例： 振り子：A = ボール、B = 上にある小さな固定オブジェクト、種類は「ちょうつがい」か「かたい棒」。つり橋：ちょうつがいでつないだ板。

つなぎを調整

入力： つなぎの名前, モーター：速さ（0 = 止める、空 = そのまま）, モーターの強さ（空 = そのまま）, バネ・サスペンションのかたさ（空 = そのまま）, 新しい長さ（ピクセル、空 = そのまま）, 新しい下のリミット（空 = そのまま）, 新しい上のリミット（空 = そのまま）, リミット

「2つのオブジェクトをつなぐ」で作ったつなぎ（名前で探します）を変えます：モーターの開始・停止・加速、強さ、バネ・サスペンションのかたさ、棒・ロープの長さ、リミット。空の欄はそのまま。例：ボタンを押すと車輪のモーターが動き出す車。

例： 「アクセル」ボタン：つなぎ「うしろ車輪」をモーター = 720 にする。はなしたらモーター = 0。

つなぎを切る

入力： 切るつなぎの名前, または：全部のつなぎを切るオブジェクトの名前

つなぎを切ります：つなぎの名前、またはオブジェクトの名前（そのオブジェクトのつなぎ全部）を書きます。物はバラバラになってそれぞれ落ちます（崩れる橋・切れたロープ・外れるゴンドラ）。

例： わなの橋：ヒーローがレバーにふれたら、つなぎ「板_3」を切る。

指でつかむ（物理）

入力： 動作, このタグの物だけ（空 = すべて）, つかみのやわらかさ

物理オブジェクトを指でつかんで引っぱれます。本物みたいにゴムっぽく指についてきて、ほかの物を押したり、はさまったりします。「指が押されている間」の下に置いて（動作「指でつかんで引っぱる」）使います：指を置いている間、下にある物が引っぱられ、指を上げると自動ではなれます（「はなす」動作でもOK）。タグで対象をしぼったり、つかみのやわらかさを決めたりできます。

例： 木箱パズル：指先で箱を動かして塔を作る。

もし物理オブジェクトが…

入力： オブジェクト, しつもん, この速さから数える（ピクセル毎秒）  →  出力： 真 / 偽

物理オブジェクトについて質問し、「はい」か「いいえ」の出口に進みます：何かの上にのっているか（ジャンプを許すため）、何かにふれているか、上の何かにふれているか、じっとしている（眠っている）か、速く動いているか、落ちているか、のぼっているか。「速く動いている」「落ちている」「のぼっている」の境目（ピクセル毎秒）は詳細設定で決めます。式の中で直接読むこともできます：オブジェクト.vitesse、オブジェクト.masse、オブジェクト.vitesseRotation。

例： プラットフォームのジャンプ：「ジャンプボタン」→ もし何かの上にのっているなら → 下向きの速さを -900 にする。
