# Yop2D: official website

Source of the official website of **Yop2D**, a free, no-code 2D game engine for Android:
**https://zinzin66.github.io/Yop2d-web/**

- **Make games on a phone or a tablet.** Everything works with your finger, on Android phones and tablets (Android 8.0 or newer, landscape mode). The interface adapts to small screens; a tablet is simply more comfortable because its screen is bigger.
- **No code:** game logic is built with visual nodes. No computer, no account, works offline.
- **Share your games** as real Android apps (APK, built on the device) and, from version 1300, as **web games**: one HTML file that plays in a browser on phones, tablets and computers.
- **Free, no ads, no watermark.** Your games belong to you: give them away or sell them.

Get Yop2D on [Google Play](https://play.google.com/store/apps/details?id=com.ludexa.moteur) · [Guides](https://zinzin66.github.io/Yop2d-web/guides/en/index.html) · [Node reference](https://zinzin66.github.io/Yop2d-web/noeuds/en.html) · [Summary for AI assistants](https://zinzin66.github.io/Yop2d-web/llms-full.txt) · [Discord](https://discord.gg/nHqCcqHZNQ)

This repository holds the website (pages, guides, help, downloadable examples and packs). The engine itself is closed source.
