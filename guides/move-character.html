How to move a character in Yop2D

Beginner guide · no code

In Yop2D, there are three simple ways to move a character, without writing any code. Pick the one that fits your game. Node names below are given in English; in the app they appear in your interface language.

Method 1: with on-screen buttons (left / right)

Great for a platformer, or any game where the character moves along a line.

  1. In your scene, create your character (a square or an image) and name it player.
  2. Create two objects to use as buttons, for example two squares named btnLeft and btnRight. Place them at the bottom of the screen.
  3. Open the scene's node editor.
  4. Add the "Held on object" event and choose btnLeft as its target.
  5. Link it to a "Push object" node: target player, x = -5, y = 0.
  6. Do the same for btnRight, with x = 5.
  7. Start the game: as long as your finger stays on a button, the character moves.
👉 To go faster, increase the value (for example 8 or 10). You can hold one button and tap another at the same time, handy to move and jump.

Method 2: with a virtual joystick

Great for a top-down game, where the character moves in every direction. No nodes needed.

  1. Add a Joystick object to your scene and place it at the bottom left.
  2. Select the joystick. In the inspector, set "Joystick target" to your character.
  3. Start the game: the character follows the joystick direction.
👉 Beginner mode: if you forget to choose a target, Yop2D automatically moves the object named player. To move another object, set the joystick target to "None", then select the object you want.
👉 Going further: to control the speed yourself or react to the direction, use the formulas joystick.x and joystick.y (between -1 and 1) in a "Push object" node linked to "Every frame", for example =joystick.x * 5.

Method 3: drag it with a finger

Great for a puzzle, a card game, or any game where you move pieces around.

  1. Select your object in the scene editor.
  2. In the inspector, check "Draggable".
  3. Start the game: you can drag the object with your finger.
👉 To react when the player lets go of the object (for example to check whether it is in the right place), use the "Drag end" event.
👉 To lock or unlock the object during the game (a puzzle piece in the right place, for example), use the "Set draggable" node.

Tips

  • To make the character jump, enable physics on it and use the "Impulse (jump)" node.
  • The example games included with Yop2D use these methods: open them to see complete, working scripts.
