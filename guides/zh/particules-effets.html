如何添加粒子和特效？

新手教程 · 无需代码

Français · English · Español · Deutsch · Italiano · Português · Русский · 中文 · 日本語

Yop2D 有两种方式产生粒子：“粒子效果” 节点一次性喷出一阵粒子（非常适合爆炸），粒子 对象则不停地产生粒子（火焰、烟雾、雨、拖尾……）。另外还有一些节点可以为整个屏幕添加特效：闪光、色调、暗角和淡入淡出。

你需要：
  • 一个能运行的游戏，里面有一个名为 player、可以移动的角色；
  • 带有标签 ennemi 的敌人。
👉 想看到所有这些效果的实际表现，请在 Yop2D 主屏幕打开示例 Effects showcase：每个效果一个按钮，并显示要使用的节点名称。

第 1 步：碰到敌人时爆炸

  1. 打开场景的 蓝图。
  2. 添加事件 “如果对象碰到标签”：目标 player，标签 ennemi。
  3. 添加 “粒子效果”。目标选择 事件中涉及的对象：也就是玩家刚刚碰到的敌人。预设：爆炸。
  4. 添加 “销毁对象”，目标同样是 事件中涉及的对象。
  5. 按顺序连接这三个节点，然后启动游戏去碰一个敌人：它会先爆炸再消失。

⚠️ 顺序很重要： “粒子效果” 必须放在 “销毁对象” 之前。敌人被销毁后，就没有对象可以显示爆炸了。
👉 你可以修改 颜色（例如 #FF40D0 做出品红色的爆炸）和 大小（2 = 两倍大）。也可以试试 火花、彩纸 或 烟雾。

第 2 步：角色身后的拖尾

  1. 添加一个对象：在 特效 类别中选择 粒子。它在编辑器里显示为橙色虚线区域，在游戏中不可见。
  2. 在检查器的 粒子 部分，点按 预设： 并选择 长拖尾。
  3. 同样在检查器里，点按 父对象：无 按钮并选择 player：这个对象会一直跟着角色。
  4. 把它放在角色正后方，然后启动游戏并移动：角色身后会跟着一条长长的发光拖尾。
👉 蓝图里什么都不用加：只要勾选了 游戏开始时启用，粒子 对象就会自己工作。想在游戏中开启或关闭它，请使用 “开启 / 关闭粒子” 节点。
  • 火焰：火把或篝火。
  • 烟雾：烟囱上方。
  • 雨 或 雪：把对象拉宽，铺满屏幕的整个顶部。
  • 超空间 和 速度线：营造高速飞行的感觉。

第 3 步：整个屏幕的特效

  • “屏幕闪光”：一次颜色闪光。例如在玩家被击中后立刻闪红光 0.5 秒。
  • “屏幕色调”：给整个游戏蒙上一层颜色。夜晚用 55% 的深蓝色，强度设为 0 就回到白天。
  • “暗角”：屏幕四周变暗，就像看电影一样。
  • “屏幕淡入淡出”：屏幕变黑，然后重新出现。

👉 色调和暗角位于 HUD 之下：分数和按钮依然清晰可读。闪光和淡入淡出则会覆盖整个屏幕。

第 4 步：触电和定格

  • “触电”：闪电在对象周围噼啪作响，对象闪烁并抖动。持续时间 0 = 无限：非常适合提醒玩家危险的电击陷阱。
  • “打击停顿”：在撞击瞬间来一段极短的慢动作（0.08 秒），让爆炸更有冲击力。

如果不起作用

  • 爆炸没有出现： 检查 “粒子效果” 是否放在 “销毁对象” 之前。
  • 拖尾没有跟着角色： 检查 粒子 对象的父对象是否是 player，以及 游戏开始时启用 是否已勾选。
  • 粒子颜色不对： 颜色“无”会保留预设的颜色；选择一种真正的颜色才能改变它们。
  • 屏幕一直是黑的： 在 “屏幕淡入淡出” 淡出（变为该颜色） 之后，还需要一个 “屏幕淡入淡出” 淡入（从该颜色）。
