节点的输入和输出

新手教程 · 无需代码

Français · English · Español · Deutsch · Italiano · Português · Русский · 中文 · 日本語

节点上有小圆圈：它们就是输入和输出。连接它们的线决定了节点的执行顺序。记住一条简单的规则：一个输出只有一根线，一个输入可以有多根。

节点的小圆圈

左边是输入圆圈（进入）：节点从这里接收执行的指令。右边是输出圆圈（例如 下一步）：节点从这里把接力棒交给下一个。有些节点有多个输出，比如 条件 有 真 和 假。

一个输出只接一根线

如果从已连接的输出再拉一根新线，新线会替换旧线。所以一个输出只能通向一个地方。

一个输入可接多根线

  1. 从第一个输出拉一根线，连到目标节点的输入圆圈。
  2. 再从另一个输出（或另一个节点）拉第二根线，连到同一个输入圆圈。
  3. 第一根线保持不变：只要其中任何一条路径到达，该节点就会执行。
👉 例子：倒计时有一个每秒触发的输出，和一个结束时触发的输出。把两者接到同一个修改文字的节点：两种情况下都会显示时间，不用做两个节点。

{ } 窗口里的文字

在 Blueprint 的 { } 窗口里，脚本以文字形式写出。当一个节点被两条路径到达时，它只描述一次；另一条路径以箭头 ↩ 结束，意思是“这个节点上面已经描述过了”。

👉 要断开一根线，点一下它。要在别处重新连，就从输出拉一根新线。
