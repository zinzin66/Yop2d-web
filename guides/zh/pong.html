如何制作 Pong？

新手教程 · 无需代码

Français · English · Español · Deutsch · Italiano · Português · Русский · 中文 · 日本語

在 Pong 里，一个球在你的球拍（下方）和机器人的球拍（上方）之间来回反弹。球从一方球拍后面飞过时，另一方得一分。和打砖块指南一样，球靠两个变量移动：vx（向两侧的速度）和 vy（向上或向下的速度）。

你需要：
  • 一个名为 Ball 的图像，放在屏幕中间（例如 60 x 60 px）；
  • 一个名为 Player 的图像，放在下方（例如 200 x 80 px，约 y = 1690）；
  • 一个名为 Bot 的图像，放在上方（大小相同，y = 140）；
  • 两个名为 ScorePlayer 和 ScoreBot 的文本对象，文字为 0；
  • 四个名为 WallLeft、WallRight、GoalPlayer 和 GoalBot 的区域。
👉 本指南针对 1080 x 1920 的竖屏游戏。图片可以使用免费的 Puzzle（打砖块）素材包（Kenney，免版权，CC0），在资源库的可下载素材包标签中：paddleBlu（你的球拍）、paddleRed（机器人）、ballBlue（球）。你也可以用自己的图。

第 1 步：名称、行为和变量

  1. 选中每个对象，在检查器里写下它的名称，要和上面的列表完全一致。名称里有空格或字母不同，节点就找不到它。
  2. 选中 Ball，点击 ⚙ 物体行为，选择装饰。对 Player 和 Bot 做同样的事：只有节点会移动它们。
  3. 在 变量 部分，创建两个类型为数字、范围为局部的变量：vx 和 vy，初始值 0。再创建两个类型为整数、范围为局部的变量：scorePlayer 和 scoreBot，初始值 0。
👉 最常见的错误：忘了名称或忘了行为。什么都不会坏，但什么也不会发生。如果游戏没有反应，先检查这一步。

第 2 步：墙和球门

球会在看不见的墙上反弹：在屏幕周围放四个区域。区域在游戏中是不可见的，但球可以碰到它。

  1. 添加一个名为 WallLeft 的区域：X = -300，Y = -400，宽 300，高 2800。
  2. 添加一个名为 WallRight 的区域：X = 1080，Y = -400，宽 300，高 2800。
  3. 添加一个名为 GoalBot 的区域：X = -300，Y = -300，宽 1680，高 300（在屏幕上方）。
  4. 添加一个名为 GoalPlayer 的区域：X = -300，Y = 1920，宽 1680，高 300（在屏幕下方）。
👉 墙故意做得很厚：快速的球穿不过去。两面墙把球弹回去；两个球门负责计分。

第 3 步：球出发并移动

  1. 添加事件 “启动时”，然后依次添加两个 “修改变量” 节点：变量 vx，值 6；再是变量 vy，值 9。
  2. 添加事件 “每帧”，然后添加 “推动对象”：目标 Ball，增加 X = vx，增加 Y = vy。直接把这两个名称写进输入框。

→
修改变量vy · 9

👉 它怎么移动？ “每帧” 每秒触发约 60 次。每次，球向侧面移动 vx 像素，向上或向下移动 vy 像素。如果都是 0，球就停下。要改变方向，只需改变这两个数字：反弹就是这么做的。

第 4 步：我的球拍跟着手指

  1. 添加事件 “手指按住”：手指在屏幕上时它会不断重复。
  2. 添加 “移动对象”：目标 Player，X = doigt.x - Player.largeur / 2，Y = 1690。手指位置在设置窗口左侧的列表里；减去球拍宽度的一半，让手指位于球拍中心。
  3. 添加 “保持在屏幕内”：目标 Player，边距 = 0，让球拍不会从两侧跑出去。

第 5 步：反弹

反弹其实就是给 vx 或 vy 一个新数字。我们用 random(a, b)，它会在 a 和 b 之间选一个数：每次反弹都不一样。

  1. “碰撞 A/B”（对象 A = WallLeft，对象 B = Ball）→ “修改变量”：vx = random(4, 12)。正数：球向右飞。
  2. “碰撞 A/B”（WallRight，Ball）→ “修改变量”：vx = -random(4, 12)。负号让它变成负数：球向左飞。
  3. “碰撞 A/B”（Ball，Player）→ “修改变量”：vy = random(-13, -9)（球向上飞），再 “修改变量”：vx = Ball.x / 10 - Player.x / 10 - 7。
  4. “碰撞 A/B”（Ball，Bot）→ “修改变量”：vy = random(9, 13)（球向下飞），再 “修改变量”：vx = random(-6, 6)。

→
修改变量vx · random(4, 12)
碰撞 A/BWallRight · Ball
→
修改变量vx · -random(4, 12)
碰撞 A/BBall · Player
→
修改变量vy · random(-13, -9)
→

碰撞 A/BBall · Bot
→

→
修改变量vx · random(-6, 6)
👉 球拍为什么用这个算式？它比较球和球拍的位置：打在中间，球直着飞；靠近边缘，球斜着飞。-7 用来抵消球拍比球宽的差别（这样中间得到 0）。

第 6 步：机器人追球

机器人不聪明：每一帧，它只是朝球靠近一点点。

  1. 添加事件 “每帧”，然后添加 “修改属性”：目标 Bot，属性 = x，值 = Bot.x * 0.94 + Ball.x * 0.06 - 6。
  2. 添加 “保持在屏幕内”：目标 Bot，边距 = 0。
每帧
→
修改属性Bot · x
→
保持在屏幕内Bot · 0
👉 它是怎么工作的？机器人保留自己位置的 94 %，再取球位置的 6 %（- 6 让它对准球的中心）。用 0.06 时它够慢，可以被打败。试试 0.03 和 0.97（很容易），或 0.15 和 0.85（很难）：两个数加起来必须是 1，- 6 也要换成 - 3 或 - 15。
👉 注意：不要把位置写进“X 速度”。速度是小数字，位置是大数字：机器人就不会动了。

第 7 步：进球和比分

  1. “碰撞 A/B”（GoalBot，Ball）→ “增加变量值”：变量 scorePlayer，要增加的值 = 1 → “修改文本”：目标 ScorePlayer，新文本 = =scorePlayer。
  2. 机器人同理：“碰撞 A/B”（GoalPlayer，Ball）→ “增加变量值”：scoreBot + 1 → “修改文本”：目标 ScoreBot，=scoreBot。
  3. 要重新发球，依次添加：“修改变量” vx = 0，“修改变量” vy = 0，“移动对象” Ball 到 X = 510、Y = 930，“等待” 1 秒，然后 “修改变量” vx = 6 和 “修改变量” vy = 9。
  4. 把两个球门的末端都连到这段发球的第一个节点：一个输入可以接收多根线。

👉 文字开头的 = 号告诉 Yop2D 去计算这个值，而不是原样写出来（见指南收集金币并计分）。

继续深入

  • 5 分获胜：每次进球后，添加一个 “条件” =scorePlayer >= 5，再加 “屏幕底部小提示” 和 “重新开始场景”（见指南生命与 Game Over）。
  • 音效：在每次反弹后添加 “播放音效”。
  • 你自己的风格：换掉图片和背景；名称保持不变。
  • 游戏没有反应？回到第 1 步：少了名称或行为。机器人不动？检查它的行为是不是装饰，以及公式是否写在值里。
