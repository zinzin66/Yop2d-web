如何制作塔防游戏？

新手教程 · 无需代码

Français · English · Español · Deutsch · Italiano · Português · Русский · 中文 · 日本語

在塔防游戏中，敌人沿着路线前进，你建造塔，在敌人到达你的基地之前向它们射击。这里的敌人沿着你亲手画的路线前进，每座塔会选择最近的敌人并向它开火，金币用来建造新的塔。

你需要：
  • 一个名为 map 的图像：游戏背景，1920 x 1080 px，上面画着一条道路；
  • 几个用作建造位置的图像（例如 120 x 120 px）；
  • 一个代表 enemy 的图像（例如 64 x 64 px），一个代表 tower（120 x 120 px），一个代表 cannon（90 x 34 px，朝右）和一个代表 bullet（24 x 24 px）；
  • 两个文本对象：creditsText 和 lifeText，放在屏幕上方。
👉 本指南针对 1920 x 1080 横屏游戏编写。示例 Tower defense (cubes)（“示例”标签）在文件夹 Images/TD 中带有现成的图片：打开它，把喜欢的图片复制到你的项目里。你也可以画自己的图片，本指南适用于任何风格。场景 Enemy 和 Tower 会在游戏中被多次复制：参见指南 现成对象。

第 1 步：变量

  1. 在左侧面板中打开 变量 部分，创建两个变量，作用域都是 全局（所有场景都能使用），类型为 整数：
  • credits：初始值 150（建造塔的金币）；
  • base_life：初始值 20（你的基地能承受多少个敌人）。

第 2 步：画出路线

敌人沿着一条路线前进：由相互连接的点组成。你用“路线”工具把它画在地图上面。

  1. 打开 Assets 窗口（资源面板），点按路线。路线编辑器打开，背景是你的场景。
  2. 点按新路线，命名为 Path。
  3. 用放置点工具点按场景，在左侧敌人进入的地方放第一个点：它就是起点。沿着你的道路继续点按：每个新点都会连接到前一个点。
  4. 把最后一个点放在你的基地上：它没有出口，是终点。
  5. 点按预览，看一个点沿着路线走一遍。然后关闭编辑器：路线会自动保存。
👉 要更改起点，点按一个点并选择设为起点。移动点用移动工具；删除点用擦除。

第 3 步：Enemy 场景

敌人是单独的一个场景：你送进游戏的每个敌人都是它的一个副本，各有自己的生命。你只需要建一次。

  1. 创建一个名为 Enemy 的新场景（菜单 ＋，然后 创建场景）。
  2. 在场景 Enemy 中，在 X = 0、Y = 0 处添加一个名为 enemy 的图像，并给它标签 enemy。
  3. 打开场景 Enemy 的 蓝图，添加事件 “启动时”。
  4. 添加 “给物体生命值”：目标 enemy，生命值 = 3（敌人能承受 3 次攻击）。
  5. 添加 “沿路线前进”：目标 enemy，路线名称 = Path，速度（像素/秒） = 150。
  6. 按顺序连接这三个节点。

第 4 步：派出敌人波次

现在回到你的主场景（Game），让敌人一个接一个出发。

  1. 打开场景 Game 的 蓝图，添加事件 “启动时”。
  2. 添加两个 “修改变量” 节点：credits = 150，然后 base_life = 20。这样每局新游戏都从干净的状态开始，即使在 Game Over 之后也是如此。
  3. 添加 “等待”：时长（秒） = 3（第一个敌人出现前的停顿）。
  4. 添加 “重复”：每隔（秒） = 1.5，次数（0 = 无限） = 15，计时器名称（可选） = waves。
  5. 从 每次 输出添加 “放置场景副本”：场景 Enemy。X 和 Y 保持不变：敌人会自己移到路线的起点。
  6. 按顺序连接这些节点。

第 5 步：Tower 场景

塔也是一个场景。它在射程内寻找最近的敌人，把炮管转向它并开火。

  1. 创建一个名为 Tower 的新场景。在 X = 0、Y = 0 处添加一个图像 tower，然后在它前面的 X = 15、Y = 43 处添加一个图像 cannon。
  2. 在场景 Game 中，在屏幕之外（例如 X = -300、Y = -300）添加一个名为 bullet 的图像，并给它标签 bullet：这是塔每次射击时复制的模型。
  3. 打开场景 Tower 的 蓝图，添加事件 “启动时”，然后添加 “重复”：每隔（秒） = 0.2，次数（0 = 无限） = 0（无限）。塔每秒环顾 5 次。
  4. 从 每次 输出添加 “选择目标”：目标 tower，可能目标的标签（用逗号分隔） = enemy，选哪个目标？ = “最近的”，并在高级设置中设置 以像素计的圆形射程（0 = 使用格数射程） = 330。
  5. 从 找到目标 输出添加 “朝向”：目标 cannon，第二个对象选择 事件中涉及的对象（被选中的敌人）。
  6. 添加 “冷却”：目标 cannon，延迟（秒） = 1.2（最多每 1.2 秒射击一次）。
  7. 从 就绪 输出添加 “发射对象”：目标 cannon，模型名称 = bullet，速度 = 14，子弹存活时间（秒，0 = 不限） = 1.6，离开屏幕后销毁（是 / 否） = 否。保持 方向 不变：子弹朝炮管所指的方向飞出。

第 6 步：击中敌人

这一部分放在场景 Enemy 中：知道子弹何时击中自己的是敌人。

  1. 打开场景 Enemy 的 蓝图，添加事件 “如果对象碰到标签”：目标 enemy，标签 bullet。
  2. 添加 “销毁对象”，并选择 事件中涉及的对象 作为目标：它就是那颗子弹，会消失。
  3. 添加 “造成伤害”：目标 enemy，伤害 = 1。默认情况下，敌人的生命降到零时会被摧毁。
  4. 从 生命值为 0 输出添加 “增加变量值”：变量 credits，值 15（奖励）。
  5. 按顺序连接这些节点。

第 7 步：建造塔

玩家点按一个建造位置来建造塔。需要 50 金币。

  1. 选中每个建造位置，在检查器中给它标签 spot。
  2. 在场景 Game 中添加事件 “点击对象时”，并选择 # spot 作为对象（所有带标签 spot 的对象）。
  3. 添加 “条件” =credits >= 50。
  4. 在 真 输出：“增加变量值”：变量 credits，值 -50。
  5. 然后 “放置场景副本”：场景 Tower。对于 X，点按 🔗，选择 “对象的数值”，对象 事件中涉及的对象，什么 = x。对 Y 也一样，用 y：塔会正好出现在玩家点按的位置。
  6. 添加 “销毁对象”，目标选择 事件中涉及的对象：建造位置消失。
  7. 在 假 输出：“屏幕底部小提示”，消息为金币不足。

  1. 在场景 Game 中添加事件 “每帧”。
  2. 添加 “修改文本”：目标 creditsText，新文本 = ="金币：" + credits。
  3. 再添加一个 “修改文本”：目标 lifeText，新文本 = ="基地：" + base_life。

第 9 步：基地生命与游戏结束

敌人走到路线终点时，你的基地会失去一点生命。基地生命耗尽时，游戏结束。

  1. 在场景 Enemy 中，找到第 3 步的 “沿路线前进” 节点。从它的 到达 输出添加 “增加变量值”：变量 base_life，值 -1。
  2. 添加 “销毁对象”：目标 enemy。
  3. 添加 “条件” =base_life <= 0。在 真 输出添加 “调用事件”，事件名为 game_over。
  4. 在场景 Game 中添加事件 “本地事件”，使用同样的名称 game_over。
  5. 添加 “停止计时器”：名称（留空 = 全部） = waves（不再派出敌人），然后添加 “按标签销毁”：要销毁的标签 = enemy。
  6. 添加 “屏幕底部小提示”，消息为游戏结束，然后 “等待” 2 秒，再 “重新开始场景”。

开始玩吧：用金币建一两座塔，看看它们怎么拦住敌人。放几个过去，看看基地怎样失去生命。

更进一步

  • 胜利：用变量统计敌人（一个死亡或到达时加 1）。当数字达到你派出的总数时，显示消息并获胜。
  • 升级塔：点按一座塔，打开一个带“升级”按钮的小窗口，升级要花金币，并更换炮管图片和射速。打开示例 Tower defense (cubes) 看看是怎么做的。
  • 多种敌人：再做一个场景（Enemy2），生命更多、速度不同，让每一波派出其中一种或另一种（打开示例 Tower defense (cubes) 看看是怎么做的）。
  • 路口：在路线工具中点按一个点并选择这个点是路口：敌人随机选择一条路，分支之后还可以汇合。
  • 多条车道，不堵车：在 “沿路线前进” 中，把 随机侧向偏移（像素，±：每个单位走自己的车道） 和 避让其他单位：侧身避免重叠并超过较慢的单位（是 / 否） 设为是：敌人并排行走并互相超越。
  • 大地图：把地图做成两倍宽，然后在开始时添加 “相机边界” 和 “用手指拖动相机”，让玩家用手指滚动地图。
  • 声音和火花：每次射击时添加 “播放音效”，敌人死亡时添加 “粒子效果”（参见指南 粒子和特效）。

如果不起作用

  • 敌人不动：检查 路线名称 设置是否是你路线的名称（Path），并且路线有起点。检查场景 Enemy 是否有它的 “启动时” 事件。
  • 塔不射击：检查敌人身上的标签 enemy、“发射对象” 里的名称 bullet，以及对象 bullet 是否在场景 Game 中（在屏幕外，但没有被删除）。如果敌人一直在射程之外，请调大 以像素计的圆形射程（0 = 使用格数射程）。
  • 子弹没有伤害：子弹必须有标签 bullet，并且事件 “如果对象碰到标签” 必须在场景 Enemy 中，而不是在 Game 中。
  • 塔出现在错误的位置：对于 “放置场景副本” 的 X 和 Y，使用绿色的 “对象的数值” 节点并选择 事件中涉及的对象，就像第 7 步那样。
  • 金币或基地生命不变：检查变量 credits 和 base_life 的作用域是否为 全局。
