如何把我的游戏变成网页游戏（HTML）？

新手教程 · 无需代码

Français · English · Español · Deutsch · Italiano · Português · Русский · 中文 · 日本語 · العربية

ℹ️ 需要 Yop2D 1300 或更新的版本（版本号的最后一个数字，例如 1.0.1300）。如果你的版本更旧，请更新 Yop2D。

从 1300 版开始，Yop2D 可以生成网页游戏：整个游戏（图片、声音、节点）都装在一个 .html 文件里。这个文件可以在浏览器（推荐 Chrome）中运行，手机、平板、电脑都可以，无需安装，也不需要网络。

你需要：
  • Yop2D 1300 版或更新版本；
  • 一个在编辑器里用 ▶ 测试时能正常运行的游戏；
  • 玩游戏的设备上装有 Chrome 浏览器（推荐）。

第 1 步：生成文件

  1. 在开始界面点击你的项目来选中它。
  2. 点击 构建 APK，会打开 生成游戏 窗口。
  3. 选择 网页游戏（HTML）。
  4. 选择保存位置（例如“下载”），然后等待提示“你的网页游戏已准备好！”。
👉 文件包含整个游戏：图片或音乐很多的游戏，文件会更大（通常 1 到 5 MB）。

第 2 步：开始玩

  1. 用 Chrome 打开文件（文件管理器 → 下载 → 点击文件 → Chrome）。
  2. 游戏开始。点一下屏幕：声音和全屏就会开启。
  3. 在电脑上用鼠标玩；Esc 键相当于手机的返回键。
👉 有些应用（聊天软件、文件查看器）会在小窗口中打开文件，无法全屏：游戏会用橙色文字提示。这时请改用 Chrome 打开。

第 3 步：分享你的游戏

  • 给朋友： 直接发送 .html 文件（邮件、聊天软件、U 盘）。对方不需要 Yop2D。
  • 在 itch.io 上： 把文件改名为 index.html，放进一个 .zip 压缩包，把压缩包上传到你的 itch.io 页面，并勾选“This file will be played in the browser”。游戏就能直接在页面上玩。
  • 游戏归你所有：没有 Yop2D 标志，没有广告，可以免费赠送或出售。

网页游戏支持哪些功能

网页游戏读取的节点和安卓应用相同：物理、灯光、粒子、屏幕滤镜、转场、图块、预制体、摇杆、行为、塔防、回合制游戏、带存档的选择型故事、图库和玩家设置…… 存档（“保存变量”、故事中的 💾 存档位）保存在设备的浏览器里：关闭游戏再打开，存档依然在。

如果不能运行

  • 没有“网页游戏（HTML）”选项： 你的 Yop2D 版本低于 1300：请更新。
  • 白屏或画面不动： 用 Chrome 打开文件，不要用文件查看器。
  • 没有声音： 点一下屏幕（浏览器需要第一次触摸）。在 iPhone 和 iPad 上，某些声音可能无法播放：这种情况尚未验证。
  • 存档不见了： 清除浏览器数据会删除存档；换一个浏览器或设备也看不到它。
  • 某个功能和应用里表现不同： 网页游戏是新功能。请在 Discord 上告诉我们节点名称：我们会尽快修复。
