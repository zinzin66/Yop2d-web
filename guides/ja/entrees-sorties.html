ノードの入力と出力

初心者ガイド · コード不要

Français · English · Español · Deutsch · Italiano · Português · Русский · 中文 · 日本語

ノードには丸があります。これが入力と出力です。丸をつなぐ線が、ノードを実行する順番を決めます。覚えるルールは1つ：出力の線は1本、入力の線は何本でもOK。

ノードの丸

左は入力の丸（入力）：ここでノードが「実行して」という合図を受け取ります。右は出力の丸（例：次へ）：ここから次のノードにバトンを渡します。条件 のように、真 と 偽 など複数の出力を持つノードもあります。

出力につなげる線は1本だけ

すでにつながっている出力から新しい線を引くと、新しい線が古い線と入れ替わります。出力は1か所にしか進めません。

入力には複数の線をつなげられる

  1. 最初の出力から、つなぎたいノードの入力の丸まで線を引きます。
  2. 別の出力（または別のノード）から、同じ入力の丸まで2本目の線を引きます。
  3. 1本目の線はそのまま残ります。どちらかの道が届けば、そのノードが実行されます。
👉 例：カウントダウンには、1秒ごとに出る出力と、終わったときに出る出力があります。両方を、文字を変える同じノードにつなぎましょう。どちらの場合も時間が表示され、ノードを2つ作る必要はありません。

{ } ウィンドウの文章

Blueprint の { } ウィンドウでは、スクリプトが文章で書かれています。2つの道が届くノードは1回だけ説明され、もう一方の道は矢印 ↩ で終わります。これは「このノードは上で説明済み」という意味です。

👉 線を切るには、線をタッチします。別の場所につなぎ直すには、出力から新しい線を引きます。
