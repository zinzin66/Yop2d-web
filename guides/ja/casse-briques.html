ブロック崩しを作るには？

初心者ガイド · コード不要

Français · English · Español · Deutsch · Italiano · Português · Русский · 中文 · 日本語

ブロック崩しでは、ボールが壁と、指で動かすパドルではね返り、ブロックをこわします。ここでは 2 つの変数でボールを動かします。vx（右向きの速さ）と vy（下向きの速さ）です。壁にふれたら、ほかの数字をあげるだけです。

用意するもの：
  • paddle という名前の画像を、画面の下に置きます（たとえば 208 x 48 px、y = 1700 あたり）。
  • ball という名前の画像を、画面の真ん中に置きます（たとえば 44 x 44 px）。
  • ブロック：画面の上にならべる画像（たとえば 128 x 64 px、1 列に 8 個）。
  • テキストオブジェクトを 2 つ：scoreText（テキスト 「点数：0」）と livesText（テキスト 「ライフ：3」）を、画面の上に置きます。
👉 このガイドは 1080 x 1920 の縦向きのゲーム用に書かれています。画像は無料のパック Puzzle (brick breaker)（Kenney、自由に使える、CC0）のものです。Yop2D のライブラリのダウンロードできるパックタブからダウンロードしてください。paddleBlu（パドル）、ballBlue（ボール）、element_blue_rectangle_glossy（ブロック、青・緑・赤・黄・紫・灰色）が入っています。自分で描いた絵も使えます。

ステップ 1：タグと変数

  1. ブロックを 1 つ選びます。インスペクターの タグ (ラベル) 欄に brick と書きます。すべてのブロックで同じようにします。
  2. 左のパネルで 変数 のセクションを開き、変数を 5 つ作ります。どれも範囲は ローカル、タイプは 整数 です。
  • score：初期値 0。
  • lives：初期値 3。
  • bricks：ゲームのブロックの数（たとえば 24）。すべてこわれたかどうかを知るために使います。
  • vx と vy：初期値 0。ボールの速さで、ゲーム開始時に決めます。
👉 ブロックを増やしたり減らしたりしたい？ bricks の初期値を変えるだけです。数が大きすぎると勝てず、小さすぎると早く勝ってしまいます。

ステップ 2：見えない壁

ボールは見えない壁ではね返ります。画面のまわりにゾーンを 4 つ置きます。ゾーンはゲーム中は見えませんが、ボールはふれることができます。

  1. left_wall という名前のゾーンを追加します：X = -300、Y = -400、幅 300、高さ 2800。
  2. right_wall という名前のゾーンを追加します：X = 1080、Y = -400、幅 300、高さ 2800。
  3. top_wall という名前のゾーンを追加します：X = -300、Y = -300、幅 1680、高さ 300。
  4. bottom_wall という名前のゾーンを追加します：X = -300、Y = 1920、幅 1680、高さ 300。
👉 壁はわざと厚くしてあります。速いボールもすりぬけられません。はじめの 3 つはボールをはね返し、bottom_wall はライフを失うために使います。

ステップ 3：パドルが指についてくる

  1. paddle を選び、⚙ Comportement de l'objet をタッチして、指でドラッグ を選びます。プレイヤーがパドルをつかんで動かせます。
  2. シーンのブループリントを開き、イベント 「毎フレーム」 を追加します。
  3. 「プロパティを変更」 を追加します：対象 paddle、プロパティ = y、値 = 1700。
  4. 「画面内に収める」 を追加します：対象 paddle、余白 = 0。
  5. 3 つのノードを順番につなぎます。

👉 なぜこの 2 つのノード？ 「指でドラッグ」 だと、パドルはどの向きにも動いてしまいます。フレームごとに同じ高さにもどし、画面の外に出ないようにすると、左右にしか動きません。

ステップ 4：ボールが動きだす

  1. イベント 「起動時」 を追加し、続けて 「変数を変更」 を 2 つつなげます：変数 vx、値 6、次に変数 vy、値 -9。
  2. イベント 「毎フレーム」 を追加し、続けて 「オブジェクトを押す」：対象 ball。
  3. 「オブジェクトを押す」 の設定ウィンドウで、X を加算 の横の 🔗 ボタンをタッチし、「変数の値」 を選びます。出てきた緑のノードで変数 vx を選びます。
  4. Y を加算 でも同じようにして、変数 vy を選びます。
  5. それぞれのイベントをノードにつないでゲームを実行します。ボールは右上に飛んで、画面の外に出ていきます。
起動時
→
変数を変更vx · 6
→
変数を変更vy · -9
毎フレーム
→
オブジェクトを押すball · X ← vx · Y ← vy
👉 緑のノードは、何も書かずに設定に値をあたえます。ここでは 「変数の値」 が 「オブジェクトを押す」 に 「フレームごとに、右へ vx、下へ vy 動いてね」 と伝えます。
👉 マイナス = 上。 Yop2D では Y が画面の下に向かって大きくなります。vy = -9 でボールは上に飛びます。

ステップ 5：壁ではね返る

それぞれの壁が、ボールに新しい数字をあたえます。イベント 「衝突 A/B」 を 3 つ追加します（オブジェクト A = ball）。

  1. オブジェクト B = left_wall → 「変数を変更」：変数 vx、値 6（ボールは右にもどる）。
  2. オブジェクト B = right_wall → 「変数を変更」：変数 vx、値 -6（ボールは左にもどる）。
  3. オブジェクト B = top_wall → 「変数を変更」：変数 vy、値 9（ボールは下にもどる）。

→
変数を変更vx · 6

→
変数を変更vx · -6
衝突 A/Bball · top_wall
→
変数を変更vy · 9

ステップ 6：パドルではね返る

  1. イベント 「衝突 A/B」 を追加します：オブジェクト A = ball、オブジェクト B = paddle。
  2. 「変数を変更」 を追加します：変数 vy、値 -9（ボールが上にもどる）。
  3. 2 つ目の 「変数を変更」 を追加します：変数 vx。値の横の 🔗 をタッチし、「ランダムな数」 を選んで、から = -6、まで = 6 にします。
  4. ノードを順番につなぎます。
衝突 A/Bball · paddle
→
変数を変更vy · -9
→
変数を変更vx · ← ランダムな数（-6 から 6）
👉 パドルではね返るたびに、ボールはランダムな向きに飛びます。ゲームは 2 回と同じになりません。

ステップ 7：ブロックをこわす

  1. イベント 「オブジェクトがタグに触れた場合」 を追加します：対象 ball、タグ brick。
  2. 「オブジェクトを破壊」 を追加し、対象に イベントに関与するオブジェクト を選びます。ボールがいまふれたブロックのことです。
  3. 「条件」 =vy < 0 を追加します（「ボールが上に向かっている」）。出力 真 → 「変数を変更」：変数 vy、値 9。出力 偽 → 「変数を変更」：変数 vy、値 -9。
  4. 条件の 「つぎに」 の出力から、「変数に加算」 を追加します：変数 score、加算する値 = 10。
  5. 「変数に加算」 を追加します：変数 bricks、加算する値 = -1。
  6. 「テキストを変更」 を追加します：対象 scoreText、新しいテキスト = ="点数：" + score。

👉 なぜ =vy < 0？ vy が 0 より小さいとき、ボールは上に向かっています。ブロックをこわしたあと、下に向かいます。そうでなければ下に向かっているので、上にもどります。
👉 テキストの最初の = の記号は、テキストをそのまま書くのではなく計算することを Yop2D に伝えます（ガイドコインを集めて点数を数えるを見てください）。

ステップ 8：勝つ

ステップ 7 の 「テキストを変更」 のあとに、次を追加します。

  1. 「条件」 =bricks <= 0.
  2. 真 の出力で：「変数を変更」 vx = 0、「変数を変更」 vy = 0（ボールが止まる）、次に 「画面下の小さなメッセージ」 でメッセージ 勝ったよ！、次に 「待つ」 2 秒、最後に 「シーンをやり直す」。

👉 「シーンをやり直す」 は、オブジェクトを元の場所にもどし、ローカル の変数を初期値にもどします。ライフ 3、0 点、すべてのブロックで、ゲームが最初からやり直しになります。

ステップ 9：ライフとゲームオーバー

ボールが bottom_wall（画面の下）にふれると、プレイヤーはライフを 1 つ失います。

  1. イベント 「衝突 A/B」 を追加します：オブジェクト A = ball、オブジェクト B = bottom_wall。
  2. 「変数に加算」：変数 lives、加算する値 = -1。
  3. 「テキストを変更」：対象 livesText、新しいテキスト = ="ライフ：" + lives。
  4. 「条件」 =lives <= 0.
  5. 出力 真（ライフなし）：「オブジェクトを移動」 ball を X = 518、Y = 1000 へ、「変数を変更」 vx = 0、「変数を変更」 vy = 0（ボールを真ん中にもどして止める）、次に 「画面下の小さなメッセージ」 「ゲームオーバー！」、「待つ」 2 秒、「シーンをやり直す」。
  6. 出力 偽（ライフが残っている）：「オブジェクトを移動」 ball を X = 518、Y = 1000 へ、次に 「変数を変更」 vy = -9、次に 「変数を変更」 vx = 6。

👉 なぜ待つ前にボールを止めるの？ 2 秒待っているあいだも、ゲームは動き続けています。ボールが画面の下に残ったままだと、フレームごとにライフが減り、ライフの数がとても小さくなってしまいます。真ん中にもどして止めておけば、じゃまをしません。

さらに進むために

  • 音： 「オブジェクトを破壊」 のあとに 「効果音を再生」 を追加します（ブロックがこわれるときの「カチッ」）。パドルのイベントにも追加できます。
  • いろいろな色： 色がちがっても、すべてのブロックに同じタグ brick をつければ、設定は 1 つで足ります。
  • もっと速いボール： 数字 6、-6、9、-9 を全部変えます（たとえば 8、-8、12、-12）。
  • 火花： ブロックがこわれるときに 「パーティクル効果」 を追加します（ガイドパーティクルとエフェクトを見てください）。

うまく動かないときは

  • ボールが動かない： 開始時に vx と vy が変わっているか、「オブジェクトを押す」 が緑の 「変数の値」 ノードにつながっているかを確かめます（X を加算 をタッチ：その行に緑の線が見えるはずです）。
  • ボールが壁やブロックをすりぬける： 名前（ball、paddle、left_wall…）とタグ brick が、どこでも同じ書き方（大文字なし）か確かめます。ボールが速すぎるときは、ブロックを少し大きくするか、ボールをおそくします。
  • パドルが上や下に動く： 「プロパティを変更」 ノードは 毎フレーム につなぎ、プロパティ = y にします。
  • 勝つのが早すぎる、または勝てない： 変数 bricks は、ゲームのブロックの数とちょうど同じ値にします。
  • くらべるには、テストプロジェクトを開きます（ノードはパートごとに整理され、枠とふせんで各部分を説明しています）。
