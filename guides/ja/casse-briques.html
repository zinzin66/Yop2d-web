ブロック崩しを作るには？

初心者ガイド · コード不要

Français · English · Español · Deutsch · Italiano · Português · Русский · 中文 · 日本語

ブロック崩しでは、ボールがはしと、指で動かすパドルではね返り、ブロックをこわします。ここでは 2 つの小さな変数でボールを動かします。vx（右向きの速さ）と vy（下向きの速さ）です。ボールがはね返るときは、変数の正負を入れかえるだけです。

用意するもの：
  • paddle という名前の画像を、画面の下に置きます（たとえば 208 x 48 px、y = 1700 あたり）。
  • ball という名前の画像を、画面の真ん中に置きます（たとえば 44 x 44 px）。
  • ブロック：画面の上にならべる画像（たとえば 128 x 64 px、1 列に 8 個）。
  • テキストオブジェクトを 2 つ：scoreText（テキスト 「点数：0」）と livesText（テキスト 「ライフ：3」）を、画面の上に置きます。
👉 このガイドは 1080 x 1920 の縦向きのゲーム用に書かれています。画像は無料のパック Puzzle (brick breaker)（Kenney、自由に使える、CC0）のものです。Yop2D のライブラリのダウンロードできるパックタブからダウンロードしてください。paddleBlu（パドル、208 x 48）、ballBlue（ボール、44 x 44）、element_blue_rectangle_glossy（ブロック、128 x 64、青・緑・赤・黄・紫・灰色）が入っています。自分で描いた絵も使えます。その場合は、式の数字をその大きさに合わせて変えてください。

ステップ 1：タグと変数

  1. ブロックを 1 つ選びます。インスペクターの タグ (ラベル) 欄に brick と書きます。すべてのブロックで同じようにします。
  2. 左のパネルで 変数 のセクションを開き、変数を 5 つ作ります。どれも範囲は ローカル、タイプは 整数 です。
  • score：初期値 0。
  • lives：初期値 3。
  • bricks：ゲームのブロックの数（たとえば 27）。すべてこわれたかどうかを知るために使います。
  • vx と vy：初期値 0。ボールの速さで、ゲーム開始時に決めます。
👉 ブロックを増やしたり減らしたりしたい？ bricks の初期値を変えるだけです。数が大きすぎると勝てず、小さすぎると早く勝ってしまいます。

ステップ 2：パドルが指についてくる

  1. シーンのブループリントを開きます。
  2. イベント 「指で押している間」 を追加します（画面に指があるあいだ、くり返されます）。
  3. 「オブジェクトを移動」 を追加します：対象 paddle、X = =clamp(doigt.x - 104, 0, 872)、Y = 1700。
  4. 2 つのノードをつないでゲームを実行します。パドルが指についてきて、画面の外には出ません。
指で押している間
→
オブジェクトを移動paddle · =clamp(doigt.x - 104, 0, 872) · 1700
👉 式の読み方は？ doigt.x は指の位置です（「doigt」 はフランス語で「指」の意味）。パドルを指の下の中央に置くため、104（パドルの半分）を引きます。clamp(…, 0, 872) は画面の中にとどめます。872 = 1080 − 208（パドルの幅）です。

ステップ 3：ボールが動きだす

  1. イベント 「起動時」 を追加し、続けて 「変数を変更」 を 2 つつなげます：変数 vx = 6、次に変数 vy = -9。
  2. イベント 「毎フレーム」 を追加し、続けて 「オブジェクトを押す」：対象 ball、X を足す = =vx、Y を足す = =vy。
  3. それぞれのイベントをノードにつないでゲームを実行します。ボールは右上に飛んで、画面の外に出ていきます。
起動時
→
変数を変更vx · 6
→
変数を変更vy · -9
毎フレーム
→
オブジェクトを押すball · =vx · =vy
👉 マイナス = 上。 Yop2D では Y が画面の下に向かって大きくなります。vy = -9 でボールは上に飛びます。もっと速くしたいときは 8 と -12 にしましょう。

ステップ 4：はしではね返る

「オブジェクトを押す」 のすぐあとで、ボールがはしにふれたかをフレームごとに調べます。「条件」 を 3 つつなげ、そのたびに 「つぎに」 の出力をたどります（どんな場合でも実行されます）。

  1. 左のはし：「条件」 =ball.x <= 0。出力 真 → 「変数を変更」：変数 vx、値 =abs(vx)（いつも右向き）。
  2. 右のはし：「条件」 =ball.x >= 1036。出力 真 → 「変数を変更」：変数 vx、値 =-abs(vx)（いつも左向き）。1036 = 1080 − 44（ボールの幅）です。
  3. 上：「条件」 =ball.y <= 0。出力 真 → 「変数を変更」：変数 vy、値 =abs(vy)（いつも下向き）。
  4. それぞれの 「条件」 を、「つぎに」 の出力で次の 「条件」 につなぎます。最初のものは 「オブジェクトを押す」 の出力につなぎます。
オブジェクトを押すball
→
条件=ball.x <= 0
真 →
変数を変更vx · =abs(vx)
条件=ball.x >= 1036
真 →
変数を変更vx · =-abs(vx)
条件=ball.y <= 0
真 →
変数を変更vy · =abs(vy)
👉 なぜ abs？ abs(vx) はいつも正の数です。左のはしでは、2 フレーム続けてふれても、ボールは必ず右に向かうので、はしにはさまりません。

ステップ 5：パドルではね返る

  1. イベント 「衝突 A/B」 を追加します：オブジェクト A = ball、オブジェクト B = paddle。
  2. 「変数を変更」 を追加します：変数 vy、値 =-abs(vy)（ボールが上にもどる）。
  3. 2 つ目の 「変数を変更」 を追加します：変数 vx、値 =(ball.x + 22 - paddle.x - 104) / 13。
  4. 3 つのノードを順番につなぎます。
衝突 A/Bball · paddle
→
変数を変更vy · =-abs(vy)
→
変数を変更vx · =(ball.x + 22 - paddle.x - 104) / 13
👉 最後の式は何のため？ ボールがパドルのどこに当たったかを測ります。真ん中ならまっすぐ上、左はしなら左、右はしなら右に飛びます。プレイヤーがねらえるようになります。（22 = ボールの半分、104 = パドルの半分。）

ステップ 6：ブロックをこわす

  1. イベント 「オブジェクトがタグに触れた場合」 を追加します：対象 ball、タグ brick。
  2. 「オブジェクトを破壊」 を追加し、対象に イベントに関与するオブジェクト を選びます。ボールがいまふれたブロックのことです。
  3. 「変数を変更」 を追加します：変数 vy、値 =-vy（ボールがはね返る）。
  4. 「変数に加算」 を追加します：変数 score、加算する値 = 10。
  5. 「変数に加算」 を追加します：変数 bricks、加算する値 = -1。
  6. 「テキストを変更」 を追加します：対象 scoreText、新しいテキスト = ="点数：" + score。
  7. すべてのノードを順番につなぎます。
オブジェクトがタグに触れた場合ball · brick
→
オブジェクトを破壊関連オブジェクト
→
変数を変更vy · =-vy
→
変数に加算score · + 10
→

テキストを変更scoreText
👉 ボールがブロックをこわすときは、ブロックの横にふれても、いつも上か下にはね返ります。かんたんで、ブロック崩しにはちょうどいい方法です。

ステップ 7：勝つ

ステップ 6 の 「テキストを変更」 のあとに、次を追加します。

  1. 「条件」 =bricks <= 0.
  2. 真 の出力で：「変数を変更」 vx = 0、「変数を変更」 vy = 0（ボールが止まる）、次に 「画面下の小さなメッセージ」 でメッセージ 勝ったよ！、次に 「待つ」 2 秒、最後に 「シーンをやり直す」。

👉 「シーンをやり直す」 は、オブジェクトを元の場所にもどし、ローカル の変数を初期値にもどします。ライフ 3、0 点、すべてのブロックで、ゲームが最初からやり直しになります。

ステップ 8：ライフとゲームオーバー

ボールがパドルの下に落ちると、プレイヤーはライフを 1 つ失います。ステップ 4 の続きです。3 つ目の 「条件」（上）のあとに 4 つ目を追加し、「つぎに」 の出力でつなぎます。

  1. 「条件」 =ball.y >= 1920、出力 真。
  2. 「変数に加算」：変数 lives、加算する値 = -1。
  3. 「テキストを変更」：対象 livesText、新しいテキスト = ="ライフ：" + lives。
  4. 「条件」 =lives <= 0.
  5. 出力 真（ライフなし）：「オブジェクトを移動」 ball を X = 518、Y = 1000 へ、「変数を変更」 vx = 0、「変数を変更」 vy = 0（ボールを真ん中にもどして止める）、次に 「画面下の小さなメッセージ」 「ゲームオーバー！」、「待つ」 2 秒、「シーンをやり直す」。
  6. 出力 偽（ライフが残っている）：「オブジェクトを移動」 ball を X = 518、Y = 1000 へ、次に 「変数を変更」 vy = -9、次に 「変数を変更」 vx = 6。

👉 なぜ待つ前にボールを止めるの？ 2 秒待っているあいだも、ゲームは動き続けています。ボールが画面の下に残ったままだと、フレームごとにライフが減り、ライフの数がとても小さくなってしまいます（-178！）。真ん中にもどして止めておけば、じゃまをしません。

さらに進むために

  • 音： 「オブジェクトを破壊」 のあとに 「効果音を再生」 を追加します（ブロックがこわれるときの「カチッ」）。パドルのイベントにも追加できます。
  • いろいろな色： 色がちがっても、すべてのブロックに同じタグ brick をつければ、設定は 1 つで足ります。
  • もっと速く： ブロックをこわすたびに 「変数を変更」 =vx * 1.02 を追加すると、ゲームがだんだん難しくなります。
  • 火花： ブロックがこわれるときに 「パーティクル効果」 を追加します（ガイドパーティクルとエフェクトを見てください）。

うまく動かないときは

  • ボールが動かない： 開始時に vx と vy が変わっているか、「オブジェクトを押す」 が式 =vx と =vy を使っているか（先頭に = があるか）を確かめます。
  • ボールがパドルやブロックをすりぬける： 名前（ball、paddle）とタグ brick が、どこでも同じ書き方（大文字なし）か確かめます。ボールが速すぎるときは、ブロックを少し大きくするか、ボールをおそくします。
  • ボールがはね返らずに画面の外へ出る： 「条件」 のノードは 「つぎに」 の出力で順番につなぎ、最初のものは 「オブジェクトを押す」 からつなぐ必要があります。
  • 勝つのが早すぎる、または勝てない： 変数 bricks は、ゲームのブロックの数とちょうど同じ値にします。
  • パドルの動きがおかしい： 式の doigt.x は指のことで、パドルではありません。先頭の = を残し、かっこを閉じます。
