Pong を作るには？

初心者ガイド · コード不要

Français · English · Español · Deutsch · Italiano · Português · Русский · 中文 · 日本語

Pong では、ボールが自分のラケット（下）とロボットのラケット（上）の間をはね返ります。ボールがラケットの後ろを通ると、相手に1点が入ります。ブロック崩しのガイドと同じように、ボールは2つの変数で動きます。vx（横の速さ）と vy（上か下への速さ）です。

用意するもの：
  • Ball という名前の画像。画面の真ん中に置きます（例：60 x 60 px）。
  • Player という名前の画像。下のほうに置きます（例：200 x 80 px、y = 1690 あたり）。
  • Bot という名前の画像。上のほうに置きます（同じ大きさ、y = 140）。
  • ScorePlayer と ScoreBot という名前のテキストオブジェクト2つ。文字は 0 にします。
  • WallLeft、WallRight、GoalPlayer、GoalBot という名前のゾーン4つ。
👉 このガイドは縦向き 1080 x 1920 のゲーム用です。画像には、ライブラリのダウンロードできるパックタブにある無料の Puzzle（ブロック崩し）パック（Kenney、著作権フリー、CC0）を使えます。paddleBlu（自分のラケット）、paddleRed（ロボット）、ballBlue（ボール）です。自分で描いた絵も使えます。

ステップ 1：名前、ふるまい、変数

  1. それぞれのオブジェクトを選び、インスペクターで名前を上のリストとまったく同じに書きます。スペースが入っていたり文字が違ったりすると、ノードは見つけられません。
  2. Ball を選び、⚙ オブジェクトのふるまいをタッチしてかざりを選びます。Player と Bot にも同じようにします。動かすのはノードだけです。
  3. 変数 のセクションで、数値型・ローカル範囲の変数を2つ作ります。vx と vy、初期値は 0 です。さらに整数型・ローカル範囲の変数を2つ作ります。scorePlayer と scoreBot、初期値は 0 です。
👉 いちばん多い間違い：名前を忘れる、ふるまいを忘れる。何もこわれませんが、何も起こりません。ゲームが動かないときは、まずこのステップを確認しましょう。

ステップ 2：壁とゴール

ボールは見えない壁ではね返ります。画面のまわりにゾーンを4つ置きます。ゾーンはゲーム中は見えませんが、ボールはさわることができます。

  1. WallLeft という名前のゾーンを追加：X = -300、Y = -400、幅 300、高さ 2800。
  2. WallRight という名前のゾーンを追加：X = 1080、Y = -400、幅 300、高さ 2800。
  3. GoalBot という名前のゾーンを追加：X = -300、Y = -300、幅 1680、高さ 300（画面の上）。
  4. GoalPlayer という名前のゾーンを追加：X = -300、Y = 1920、幅 1680、高さ 300（画面の下）。
👉 壁はわざと厚くしてあります。速いボールでも通りぬけられません。2つの壁はボールをはね返し、2つのゴールは点数を数えます。

ステップ 3：ボールが出発して動く

  1. イベント 「起動時」 を追加し、続けて 「変数を変更」 ノードを2つつなげます。変数 vx、値 6、次に変数 vy、値 9。
  2. イベント 「毎フレーム」 を追加し、続けて 「オブジェクトを押す」 を追加します。対象は Ball、X を加算 = vx、Y を加算 = vy。この2つの名前をそのまま欄に書きます。

👉 どうやって動くの？ 「毎フレーム」 は1秒に約60回動きます。そのたびに、ボールは横へ vx ピクセル、上か下へ vy ピクセル進みます。0 と 0 なら止まります。向きを変えるには、この2つの数字を変えるだけ。はね返りはそれをします。

ステップ 4：自分のラケットが指についてくる

  1. イベント 「指で押している間」 を追加します。指が画面にある間、くり返し動きます。
  2. 「オブジェクトを移動」 を追加します。対象は Player、X = doigt.x - Player.largeur / 2、Y = 1690。指の位置は設定ウィンドウの左のリストにあります。ラケットの幅の半分を引いて、指がラケットの真ん中にくるようにします。
  3. 「画面内に収める」 を追加します。対象は Player、余白 = 0。ラケットが横から出ないようにします。

ステップ 5：はね返り

はね返りは、vx か vy に新しい数字を入れるだけです。random(a, b) は a と b の間の数字を選ぶので、はね返りが毎回ちがいます。

  1. 「衝突 A/B」（オブジェクト A = WallLeft、オブジェクト B = Ball）→ 「変数を変更」：vx = random(4, 12)。正の数：ボールは右へ行きます。
  2. 「衝突 A/B」（WallRight、Ball）→ 「変数を変更」：vx = -random(4, 12)。マイナスで負の数になり、ボールは左へ行きます。
  3. 「衝突 A/B」（Ball、Player）→ 「変数を変更」：vy = random(-13, -9)（ボールは上へ）、次に 「変数を変更」：vx = Ball.x / 10 - Player.x / 10 - 7。
  4. 「衝突 A/B」（Ball、Bot）→ 「変数を変更」：vy = random(9, 13)（ボールは下へ）、次に 「変数を変更」：vx = random(-6, 6)。

変数を変更vx · -random(4, 12)

👉 ラケットの計算はなぜこれ？ ボールとラケットの位置を比べます。真ん中ならまっすぐ、はしに近いほど横に飛びます。-7 は、ラケットがボールより広いぶんを直します（真ん中が 0 になります）。

ステップ 6：ロボットがボールを追う

ロボットはかしこくありません。1コマごとに、ボールに少しだけ近づきます。

  1. イベント 「毎フレーム」 を追加し、続けて 「プロパティを変更」 を追加します。対象は Bot、プロパティ = x、値 = Bot.x * 0.94 + Ball.x * 0.06 - 6。
  2. 「画面内に収める」 を追加します。対象は Bot、余白 = 0。
毎フレーム
→
プロパティを変更Bot · x
→
画面内に収めるBot · 0
👉 どういうしくみ？ ロボットは自分の位置の 94 % を残し、ボールの位置の 6 % を取り入れます（- 6 でボールの真ん中に合わせます）。0.06 なら、勝てるくらいゆっくりです。0.03 と 0.97（とてもかんたん）や、0.15 と 0.85（とてもむずかしい）も試してみましょう。2つの数字は足して 1 にし、- 6 は - 3 や - 15 に変えます。
👉 注意：「X の速さ」に位置を書かないでください。速さは小さな数字、位置は大きな数字です。ロボットが動かなくなります。

ステップ 7：ゴールとスコア

  1. 「衝突 A/B」（GoalBot、Ball）→ 「変数に加算」：変数 scorePlayer、加算する値 = 1 → 「テキストを変更」：対象 ScorePlayer、新しいテキスト = =scorePlayer。
  2. ロボットも同じです。「衝突 A/B」（GoalPlayer、Ball）→ 「変数に加算」：scoreBot + 1 → 「テキストを変更」：対象 ScoreBot、=scoreBot。
  3. サーブをやり直すには、続けてこう追加します。「変数を変更」 vx = 0、「変数を変更」 vy = 0、「オブジェクトを移動」 Ball を X = 510、Y = 930 へ、「待つ」 1 秒、次に 「変数を変更」 vx = 6 と 「変数を変更」 vy = 9。
  4. 2つのゴールの終わりを、このサーブの最初のノードにつなぎます。入口には何本もの線をつなげられます。

👉 文字の最初の = は、書いたとおりではなく計算した値を使うよう Yop2D に伝えます（ガイドコインを集めて点数を数えるを見てください）。

もっと先へ

  • 5点で勝ち：ゴールのたびに 「条件」 =scorePlayer >= 5 を追加し、次に 「画面下の小さなメッセージ」 と 「シーンをやり直す」 を追加します（ガイドライフとゲームオーバーを見てください）。
  • 音：はね返りのたびに 「効果音を再生」 を追加しましょう。
  • 自分らしく：画像と背景を変えてみましょう。名前はそのままです。
  • ゲームが動かない？ステップ 1 にもどりましょう。名前かふるまいが足りません。ロボットが動かない？ふるまいがかざりで、式が値に入っているか確認します。
