ゲームを Web ゲーム（HTML）にするには？

初心者ガイド · コード不要

Français · English · Español · Deutsch · Italiano · Português · Русский · 中文 · 日本語 · العربية

ℹ️ Yop2D のバージョン 1300 以降が必要です（バージョン番号の最後の数字。例：1.0.1300）。お使いのバージョンが古い場合は、Yop2D を更新してください。

バージョン 1300 から、Yop2D は Web ゲーム を作れます。ゲーム全体（画像・サウンド・ノード）が 1 つの .html ファイル に入ります。このファイルはブラウザ（Chrome 推奨）で、スマホ・タブレット・パソコンのどれでも、インストールなし・インターネットなしで遊べます。

用意するもの：
  • Yop2D バージョン 1300 以降；
  • エディターの ▶ でテストして正しく動くゲーム；
  • 遊ぶ端末の Chrome ブラウザ（推奨）。

ステップ 1：ファイルを作る

  1. スタート画面でプロジェクトをタップして選びます。
  2. APKをビルド をタップします。ゲームを作る ウィンドウが開きます。
  3. Web ゲーム（HTML） を選びます。
  4. 保存先（例：ダウンロード）を選び、「Web ゲームの準備ができました！」というメッセージを待ちます。
👉 ファイルにはゲーム全体が入っています。画像や音楽が多いゲームほどファイルが大きくなります（多くは 1〜5 MB）。

ステップ 2：遊ぶ

  1. ファイルを Chrome で 開きます（ファイルマネージャー → ダウンロード → ファイルをタップ → Chrome）。
  2. ゲームが始まります。画面を 1 回タップすると、音と全画面がオンになります。
  3. パソコンではマウスで遊べます。Esc キーはスマホの戻るボタンと同じ働きをします。
👉 一部のアプリ（メッセージアプリ、ファイルビューアー）は全画面にできない小さなウィンドウでファイルを開きます。ゲームはそのことをオレンジ色で表示します。その場合は Chrome で開いてください。

ステップ 3：ゲームを共有する

  • 友だちに： .html ファイルをそのまま送るだけ（メール、メッセージ、USB メモリ）。相手に Yop2D は必要ありません。
  • itch.io で： ファイル名を index.html に変え、.zip ファイルに入れて itch.io のページにアップロードし、「This file will be played in the browser」にチェックを入れます。ゲームがページ上で直接遊べます。
  • ゲームはあなたのものです。Yop2D のロゴも広告もなく、無料で配っても販売してもかまいません。

Web ゲームで動くもの

Web ゲームは Android アプリと同じノードを読み込みます：物理、ライト、パーティクル、画面フィルター、トランジション、タイル、プレハブ、ジョイスティック、ふるまい、タワーディフェンス、ターン制ゲーム、セーブ付きの選択型ストーリー、ギャラリー、プレイヤー設定… セーブ（「変数をセーブ」、ストーリーの 💾 スロット）は 端末のブラウザ に保存され、ゲームを閉じて開き直しても残ります。

うまく動かないとき

  • 「Web ゲーム（HTML）」が出ない： Yop2D のバージョンが 1300 より古いです。更新してください。
  • 画面が白い・何も動かない： ファイルビューアーではなく Chrome で開いてください。
  • 音が出ない： 画面を 1 回タップしてください（ブラウザは最初のタッチを待ちます）。iPhone と iPad では一部の音が鳴らないことがあります。このケースはまだ確認していません。
  • セーブが消えた： ブラウザのデータを消すとセーブも消えます。別のブラウザや別の端末にはありません。
  • アプリと違う動きをする： Web ゲームは新しい機能です。ノード名を添えて Discord で教えてください。すぐに直します。
