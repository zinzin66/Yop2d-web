タクティクスゲームを作るには？

初心者ガイド · コード不要

Français · English · Español · Deutsch · Italiano · Português · Русский · 中文 · 日本語

タクティクスゲームでは、プレイヤーがグリッド上で交代で動きます。ユニットを選び、行けるマスを見て、動かし、そのあとこうげきします。このガイドでは、いちばん簡単なゲーム（ヒーロー1人とモンスター1体）を作ります。すべてサンプル Tactics tutorial（スタート画面のサンプルタブ）にもう入っています。そのBlueprintを開くと、各ステップが色つきの枠に入っていて、小さな？が説明してくれます。

用意するもの：
  • 好きなタイルマップ（ゲームのグリッドは、このタイルマップのグリッドそのものです）。
  • タグ joueur がついた hero1 という名前の画像と、タグ ennemi がついた foe1 という名前の画像。
  • マップ全体をおおう terrain という名前のゾーン（マスを選ぶときにタッチするのはこれです）。
  • 今どこまで進んだかを知るための変数 etat（整数、ローカル）：0 = ヒーローを選ぶ、1 = ヒーローを選んだ、2 = ヒーローが動いた。
👉 地形（森、砂、山…）は、タイルエディタのタイルの地形の部分で決めます。歩数のコスト、通れるかどうか、ぼうぎょボーナス。山は通れず、森は2歩かかります。

ステップ1：ユニットのカード

  1. イベント 「起動時」 を追加します。
  2. hero1 に 「ユニットカードをあたえる」 を追加：体力 20、こうげき 6、ぼうぎょ 2、移動 4、射程 1。
  3. foe1 にも2つ目の 「ユニットカードをあたえる」 を追加し、それぞれの数字を入れます。
  4. ノードを順番につなぎ、チームを joueur,ennemi にした 「次のターンへ」 を追加します。
👉 カードはオブジェクトの中に保存されます。式でどこからでも読めます。たとえば =hero1.vie です。

ステップ2：プレイヤーのターン

  1. イベント 「ローカルイベント」 を追加し、名前に tour_joueur と書きます。プレイヤーのターンの始めに自動で動きます。
  2. 「変数を変更」 で etat を 0 にし、「マスを隠す」 で前のマスを消します。

チームごとに、「次のターンへ」 は "tour_" にチーム名をつけたローカルイベント（tour_joueur、次に tour_ennemi）を動かします。

ステップ3：ヒーローをタッチして青いマスを見る

  1. hero1 に 「オブジェクトクリック時」 を追加します。
  2. チーム joueur の 「もし…の番なら」 を追加し、真 の出口に 「条件」 etat < 2 をつなぎます。
  3. 「変数を変更」 を追加：etat = 1。
  4. hero1 に 「行けるマスを表示」 を追加：ゾーンの種類 移動（壁は通れない）、歩数 =hero1.mouvement、青い色、各マスに歩数を表示 = はい、通れなくするタグ = joueur,ennemi。
👉 マスの数字は、そこに着くのに必要な歩数です。森のマスは2かかるので、ヒーローはそんなに遠くへ行けません。

ステップ4：青いマスをタッチして、ヒーローが歩く

  1. terrain に 「オブジェクトクリック時」 を追加し、「条件」 etat = 1 をつなぎます。
  2. 「もしマスに行けるなら」 を追加します。列と行は 🔗 をタッチして、緑のノード 「タッチした列」 と 「タッチした行」 を選びます。式を書く必要はありません。
  3. 真 の出口：「変数を変更」 etat = 4（ヒーローが歩いている）、そのあと hero1 に 「マスへ行く（道）」。同じ緑のノードを使い、道をふさぐタグ = joueur,ennemi にします。
  4. とうちゃく の出口で、「イベントを呼ぶ」 でローカルイベント apres_deplacement を呼びます。

ステップ5：こうげき範囲、そしてこうげき

  1. ローカルイベント apres_deplacement で：「マスを隠す」、etat = 2、そのあと 「行けるマスを表示」 を種類 攻撃・射程（壁を越える）、歩数 =hero1.portee、赤い色、ゾーン名 attaque で追加します。
  2. foe1 に 「オブジェクトクリック時」、「条件」 etat = 2、ゾーン名 attaque の 「もしマスに行けるなら」 を追加します。
  3. 真 で：「こうげきする」（オブジェクトA = hero1、オブジェクトB = foe1）。ダメージは、こうげきからモンスターのぼうぎょと、その地形のぼうぎょを引いたものです。
  4. 出口 まだ生きている：体力のテキストを更新します。出口 HPが0：モンスターは壊れるので、勝利を追加します。

ステップ6：モンスターのターン

  1. ローカルイベント tour_ennemi を追加します。
  2. foe1 に 「オブジェクトへ行く（道さがし）」 を追加：オブジェクトB = hero1、止まり方 = となりのマスのまん中、道をふさぐタグ = joueur,ennemi。
  3. とうちゃく の出口で、foe1 が hero1 を 「こうげきする」 するローカルイベントを呼びます。
  4. 数秒後（「待つ」）に 「道さがしを止める」、そのあと 「次のターンへ」：ターンがプレイヤーに戻ります。

さらに進むには

  • ヒーローが複数いるとき： 「行動済みにする」 と 「もしユニットが行動済みなら」 を追加すると、1ターンに1回だけ行動できます（サンプル Tactics demo がそうしています）。
  • 体力バー：=hero1.vie と =hero1.vie_max をテキストや進行バーで読みます。
  • 回復： 「かいふくする」 は最大値を超えずに体力を戻します。
  • ボードゲーム： 「コマを1マス動かす」 は駒を1マス、きれいに真ん中へ動かします（◀ ▶ ▲ ▼ ボタン）。

うまくいかないとき

  • 青いマスが出ない：ヒーローに 「もし…の番なら」 で書いたタグが必要で、「次のターンへ」 が最初に動いている必要があります。
  • マスが絵と合わない：グリッドは、シーンの最初のタイルマップのものです。タイルマップがないと、マスは80 pxです。
  • ヒーローが動かない：タッチしたマスが青いか、その時 etat が 1 かを確かめます。
  • くらべるには、サンプル Tactics tutorial を開きます。Blueprintの各部分が、説明する枠に入っています。
