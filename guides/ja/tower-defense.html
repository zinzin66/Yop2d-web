タワーディフェンスの作り方は？

初心者ガイド · コード不要

Français · English · Español · Deutsch · Italiano · Português · Русский · 中文 · 日本語

タワーディフェンスでは、敵が道に沿って進み、あなたは基地にたどり着く前に撃つタワーを建てます。ここでは、敵は自分で描いた道をたどり、各タワーは一番近い敵を選んで撃ち、クレジットで新しいタワーを建てます。

用意するもの：
  • map という名前の画像：ゲームの背景（1920 x 1080 px）で、道が描かれたもの；
  • 建設場所用の画像がいくつか（例：120 x 120 px）；
  • enemy 用の画像（例：64 x 64 px）、tower 用（120 x 120 px）、cannon 用（90 x 34 px、右向き）、bullet 用（24 x 24 px）；
  • テキストオブジェクトが 2 つ：creditsText と lifeText（画面の上のほう）。
👉 このガイドは 1920 x 1080 の横向きのゲーム用です。サンプル Tower defense (cubes)（「サンプル」タブ）のフォルダ Images/TD に、できあがった画像が入っています：開いて、気に入ったものを自分のプロジェクトにコピーしましょう。自分で描いた画像でも、どんなスタイルでも使えます。シーン Enemy と Tower はゲーム中に何度もコピーされます：ガイド 既製のオブジェクト を見てください。

ステップ 1：変数

  1. 左のパネルで 変数 のセクションを開き、変数を 2 つ作ります。どちらも範囲は グローバル（すべてのシーンから使える）、型は 整数 です：
  • credits：初期値 150（タワーを建てるお金）；
  • base_life：初期値 20（基地が耐えられる敵の数）。

ステップ 2：道を描く

敵は道をたどります：つながった点でできています。ルートツールで、マップの上に描きます。

  1. Assets ウィンドウ（リソースパネル）を開いてルートをタップします。ルートエディタが開き、後ろにシーンが見えます。
  2. 新しいルートをタップして、名前を Path にします。
  3. 点を置くツールで、敵が入ってくる左側のシーンをタップして最初の点を置きます：これがスタートです。道に沿ってタップし続けると、新しい点は前の点とつながります。
  4. 最後の点を基地の上に置きます：出口がなく、これがゴールです。
  5. ながれを見るをタップすると、点が道を進むのが見えます。そのあとエディタを閉じます：ルートは自動で保存されます。
👉 スタートを変えるには、点をタップしてこの点をスタートにするを選びます。点を動かすにはうごかすツール、消すにはけすを使います。

ステップ 3：Enemy シーン

敵は独立したシーンです：ゲームに送り出す敵はすべてそのシーンのコピーで、それぞれ自分のライフを持ちます。作るのは 1 回だけです。

  1. Enemy という名前の新しいシーンを作ります（メニュー ＋、次に シーンを作成）。
  2. シーン Enemy に、enemy という名前の画像を X = 0、Y = 0 に追加し、タグ enemy を付けます。
  3. シーン Enemy の ブループリント を開き、イベント 「起動時」 を追加します。
  4. 「オブジェクトにHPをあたえる」 を追加：対象 enemy、HP = 3（敵は 3 発に耐えます）。
  5. 「ルートをたどる」 を追加：対象 enemy、ルートの名前 = Path、はやさ（1びょうあたりのピクセル） = 150。
  6. 3 つのノードを順番につなぎます。

ステップ 4：ウェーブを送り出す

メインのシーン（Game）に戻って、敵を 1 体ずつ送り出します。

  1. シーン Game の ブループリント を開き、イベント 「起動時」 を追加します。
  2. 「変数を変更」 ノードを 2 つ追加：credits = 150、次に base_life = 20。こうすると、ゲームオーバーのあとでも新しいゲームは毎回きれいな状態で始まります。
  3. 「待つ」 を追加：時間（秒） = 3（最初の敵の前の間）。
  4. 「繰り返す」 を追加：間隔（秒） = 1.5、回数（0 = 無限） = 15、タイマー名（省略可） = waves。
  5. 毎回 の出力から 「シーンのコピーを配置」 を追加：シーン Enemy。X と Y はそのままにします：敵は自分で道のスタートに移動します。
  6. ノードを順番につなぎます。

ステップ 5：Tower シーン

タワーもシーンです。射程内で一番近い敵を探し、砲身をそちらに向けて撃ちます。

  1. Tower という名前の新しいシーンを作ります。画像 tower を X = 0、Y = 0 に追加し、その手前の X = 15、Y = 43 に画像 cannon を追加します。
  2. シーン Game に、bullet という名前の画像を画面の外（例：X = -300、Y = -300）に追加し、タグ bullet を付けます：タワーが撃つたびにコピーするお手本です。
  3. シーン Tower の ブループリント を開き、イベント 「起動時」 を追加し、続けて 「繰り返す」：間隔（秒） = 0.2、回数（0 = 無限） = 0（ずっと）。タワーは 1 秒に 5 回まわりを見ます。
  4. 毎回 の出力から 「ターゲットを選ぶ」 を追加：対象 tower、ターゲット候補のタグ（カンマ区切り） = enemy、どのターゲットを選ぶ？ = 「いちばん近い」、そして詳細設定で ピクセルの円形はんい（0＝マス数のはんいを使う） = 330。
  5. ターゲット発見 の出力から 「向きを合わせる」 を追加：対象 cannon、2 つめのオブジェクトには イベントに関与するオブジェクト（選ばれた敵）を選びます。
  6. 「クールダウン」 を追加：対象 cannon、遅延（秒） = 1.2（多くても 1.2 秒に 1 回の発射）。
  7. 準備完了 の出力から 「オブジェクトを発射」 を追加：対象 cannon、モデル名 = bullet、速度 = 14、たまの寿命（秒、0＝ずっと） = 1.6、画面外で消す（はい / いいえ） = いいえ。方向 はそのままにします：弾は砲身が向いている方向に飛びます。

ステップ 6：敵に当てる

この部分はシーン Enemy に入れます：弾が当たったことを知っているのは敵です。

  1. シーン Enemy の ブループリント を開き、イベント 「オブジェクトがタグに触れた場合」 を追加します：対象 enemy、タグ bullet。
  2. 「オブジェクトを破壊」 を追加し、対象に イベントに関与するオブジェクト を選びます：消える弾のことです。
  3. 「ダメージをあたえる」 を追加：対象 enemy、ダメージ = 1。初期設定では、ライフがゼロになると敵は壊れます。
  4. HPが0 の出力から 「変数に加算」 を追加：変数 credits、値 15（ごほうび）。
  5. ノードを順番につなぎます。

ステップ 7：タワーを建てる

プレイヤーは建設場所をタップしてタワーを建てます。50 クレジットかかります。

  1. 建設場所を 1 つずつ選び、インスペクターでタグ spot を付けます。
  2. シーン Game で、イベント 「オブジェクトクリック時」 を追加し、オブジェクトに # spot（タグ spot を持つすべてのオブジェクト）を選びます。
  3. 「条件」 =credits >= 50 を追加します。
  4. 真 の出力：「変数に加算」：変数 credits、値 -50。
  5. 次に 「シーンのコピーを配置」：シーン Tower。X は 🔗 をタップして 「オブジェクトの値」 を選び、オブジェクト イベントに関与するオブジェクト、なに = x にします。Y も y で同じようにします：タワーはプレイヤーがタップした場所にぴったり現れます。
  6. 「オブジェクトを破壊」 を追加し、対象を イベントに関与するオブジェクト にします：建設場所が消えます。
  7. 偽 の出力：「画面下の小さなメッセージ」、メッセージはクレジットが足りません。

ステップ 8：画面の数字

  1. シーン Game で、イベント 「毎フレーム」 を追加します。
  2. 「テキストを変更」 を追加：対象 creditsText、新しいテキスト = ="クレジット：" + credits。
  3. 2 つめの 「テキストを変更」 を追加：対象 lifeText、新しいテキスト = ="基地：" + base_life。
  4. 3 つのノードを順番につなぎます。

ステップ 9：基地のライフとゲームオーバー

敵が道のゴールにたどり着くと、基地のライフが 1 つ減ります。ライフがなくなるとゲームオーバーです。

  1. シーン Enemy で、ステップ 3 の 「ルートをたどる」 ノードを使います。その とうちゃく の出力から 「変数に加算」 を追加：変数 base_life、値 -1。
  2. 「オブジェクトを破壊」 を追加：対象 enemy。
  3. 「条件」 =base_life <= 0 を追加します。真 の出力に、イベント名 game_over で 「イベントを呼ぶ」 を追加します。
  4. シーン Game に、同じ名前 game_over のイベント 「ローカルイベント」 を追加します。
  5. 「タイマーを止める」 を追加：名前（空 = すべて） = waves（もう敵を送り出しません）、続けて 「タグで破壊」：破棄するタグ = enemy。
  6. メッセージゲームオーバーで 「画面下の小さなメッセージ」 を追加し、次に 「待つ」 2 秒、そして 「シーンをやり直す」。

遊んでみましょう：クレジットでタワーを 1、2 基建てて、敵を止めるのを見てください。何体か通して、基地のライフが減るのも確かめましょう。

さらに進むには

  • 勝利：変数で敵を数えます（1 体倒れる、またはゴールにつくたびに +1）。送り出した総数になったら、メッセージを出して勝ちにします。
  • タワーを強くする：タワーをタップして、クレジットがかかる「強化」ボタンのある小さなウィンドウを開き、砲身の画像と連射の速さを変えます。サンプル Tower defense (cubes) を開いて作り方を見てください。
  • 敵の種類を増やす：ライフが多く速さの違う 2 つめのシーン（Enemy2）を作り、ウェーブごとにどちらかを送り出します（サンプル Tower defense (cubes) を開いて作り方を見てください）。
  • 分かれ道：ルートツールで点をタップしてこの点は分かれ道ですを選びます：敵はランダムに道を選び、枝はまた合流できます。
  • 複数のレーン、渋滞なし： 「ルートをたどる」 で よこへのランダムなずれ（ピクセル、±：それぞれ自分のレーンを歩く） と ほかをよける：重ならないよう横にずれて、おそいものを追いこす（はい / いいえ） を「はい」にします：敵は横に並んで歩き、追い越します。
  • 大きなマップ：マップを 2 倍の幅にして、開始時に 「カメラの範囲」 と 「指でカメラを動かす」 を追加し、プレイヤーが指でマップをスクロールできるようにします。
  • 音と火花：撃つたびに 「効果音を再生」 を、敵が倒れたら 「パーティクル効果」 を追加します（ガイド パーティクルとエフェクト を見てください）。

うまく動かないときは

  • 敵が動かない：設定 ルートの名前 が道の名前（Path）になっているか、道にスタートがあるかを確かめます。シーン Enemy にイベント 「起動時」 があるかも確かめます。
  • タワーが撃たない：敵のタグ enemy、「オブジェクトを発射」 の名前 bullet、そしてオブジェクト bullet がシーン Game にあること（画面の外で、消されていない）を確かめます。敵が射程の外のままなら ピクセルの円形はんい（0＝マス数のはんいを使う） を大きくします。
  • 弾がダメージを与えない：弾にはタグ bullet が必要で、イベント 「オブジェクトがタグに触れた場合」 は Game ではなくシーン Enemy に入れます。
  • タワーが違う場所に出る： 「シーンのコピーを配置」 の X と Y には、ステップ 7 のように、緑の 「オブジェクトの値」 ノードと イベントに関与するオブジェクト を使います。
  • クレジットや基地のライフが変わらない：変数 credits と base_life の範囲が グローバル になっているか確かめます。
