Как двигать персонажа?

Руководство для новичков · без кода

Français · English · Español · Deutsch · Italiano · Português · Русский · 中文 · 日本語

В Yop2D есть три простых способа двигать персонажа без кода. Выбери тот, что подходит твоей игре.

Способ 1: кнопками на экране (влево / вправо)

Отлично подходит для платформера или игры, где персонаж ходит по линии.

  1. Добавь на сцену персонажа (Квадрат или Изображение) и назови его player.
  2. Добавь два объекта-кнопки, например два Кнопка (или два квадрата) с именами btnLeft и btnRight. Поставь их внизу экрана.
  3. Открой Blueprint сцены.
  4. Добавь событие «Объект удерживается» и выбери цель btnLeft.
  5. Добавь узел «Толкнуть объект»: цель player, Добавить X = -5, Добавить Y = 0.
  6. Соедини выход события со входом «Толкнуть объект».
  7. Сделай то же для btnRight, с Добавить X = 5.
  8. Сохрани и запусти игру: пока палец лежит на кнопке, персонаж идёт.

👉 «Объект удерживается» повторяется на каждом кадре, пока палец остаётся на кнопке: поэтому персонаж идёт без остановки. Чтобы двигаться быстрее, увеличь число (например, 8 или 10).

Способ 2: виртуальным джойстиком

Отлично подходит для игры с видом сверху, где персонаж ходит во все стороны. Узлы не нужны.

  1. Добавь на сцену объект Джойстик (категория Интерактивные) и поставь его слева внизу.
  2. Выбери джойстик. В инспекторе, раздел «Джойстик», нажми кнопку «Объект для движения» и выбери персонажа.
  3. Сохрани и запусти игру: персонаж следует за джойстиком.
👉 Хитрость: если дать персонажу тег Player (или Joueur), джойстик двигает его сам, даже если в «Объект для движения» ничего не выбрано. Осторожно: этот тег важнее выбора в инспекторе.
👉 Дальше: формулы joystick.x и joystick.y дают направление (от -1 до 1). Их можно использовать в узле «Толкнуть объект», соединённом с «Каждый кадр», например =joystick.x * 5. У узла «Если джойстик» есть выходы Вверх, Вниз, Влево, Вправо и Покой.

Способ 3: перетаскивать пальцем

Отлично подходит для пазла, карточной игры или игры, где двигают фишки.

  1. Выбери объект в редакторе сцены.
  2. В инспекторе отметь «Можно перетаскивать».
  3. Запусти игру: объект можно тянуть пальцем.
👉 Чтобы отреагировать, когда игрок отпускает объект (например, проверить, на своём ли он месте), используй событие «Конец перетаскивания».
👉 Чтобы разрешить или запретить перетаскивание во время игры (например, для правильно поставленного кусочка пазла), используй узел «Сделать перетаскиваемым».

Советы

  • Чтобы персонаж прыгал, смотри руководство Как заставить персонажа прыгать.
  • Пример «Платформер», который идёт с Yop2D, использует способ 1: открой его, чтобы увидеть готовый работающий Blueprint.
