Объясняем узлы заметками и рамками

Руководство для новичков · без кода

Français · English · Español · Deutsch · Italiano · Português · Русский · 中文 · 日本語

Скрипт из узлов быстро разрастается. Заметки работают как комментарии: ты пишешь — для себя или для тех, кто откроет твою игру, — для чего нужна группа узлов. В игре они ничего не меняют. Их два вида: Стикер (где угодно) и Рамка (обводит узлы).

Стикер

  1. В Blueprint нажми на верхней панели кнопку стикера (маленький сложенный квадрат): появится стикер.
  2. Нажми на него, чтобы изменить: дай заголовок (по желанию), напиши пояснение, выбери один из 6 цветов и нажми ОК.
  3. Перетащи его, чтобы подвинуть. Потяни за уголок, чтобы увеличить.
  4. Нажми на маленький –, чтобы свернуть его в значок i. Нажми на значок, чтобы развернуть.
👉 Чтобы удалить стикер, нажми на него, затем Удалить.

Рамка

  1. Нажми на верхней панели кнопку выделения (квадрат из точек).
  2. Выбери узлы: протяни прямоугольник по пустому месту вокруг них или нажимай на них по одному.
  3. На нижней панели нажми Обвести рамкой.
  4. Нажми на полосу рамки, чтобы задать заголовок и цвет.
👉 Когда ты тянешь полосу рамки, узлы внутри неё двигаются вместе с ней.

Знак «?» на рамке

У каждой рамки есть маленький знак ?: он открывает облачко с пояснением. В облачке Изменить меняет текст, Удалить убирает рамку (узлы остаются), а Закрыть закрывает облачко. Отлично подходит для примера или шаблона, который объясняет сам себя.

Полезно знать

  • Отменить и Вернуть работают и для заметок.
  • Заметки сохраняются вместе с Blueprint (кнопка 💾).
  • «Упорядочить узлы» не двигает рамки: сначала упорядочи, потом обводи.
  • Старая версия Yop2D, которая снова откроет и сохранит проект, потеряет заметки: обнови Yop2D, прежде чем делиться проектом.
