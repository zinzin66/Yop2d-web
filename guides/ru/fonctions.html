Как создать свои узлы («Мои узлы»)?

Руководство для новичков · без кода

Français · English · Español · Deutsch · Italiano · Português · Русский · 中文 · 日本語

Свой узел — это небольшая группа узлов, которой ты даёшь имя (программисты говорят «функция»). Ты делаешь его один раз, а потом запускаешь когда хочешь одним узлом из любой сцены. Так ты создаёшь свои блоки: не повторяешь одно и то же десять раз, а твои Blueprint остаются аккуратными.

Тебе понадобится:
  • открытый в редакторе проект.

Шаг 1: создать свой узел

  1. Открой панель Ресурсы (слева в редакторе) и разверни раздел Мои узлы.
  2. Нажми ＋, напиши короткое имя (например Дать_очки) и подтверди.
  3. Нажми на имя своего узла, чтобы выбрать его, а затем на кнопку, которая открывает его Blueprint (значок связанных узлов).
👉 Твой узел — это файл твоего проекта: он экспортируется вместе с игрой и работает во всех сценах.

Шаг 2: положить в него узлы

  1. Ты в Blueprint своего узла (в заголовке написано «Мой узел: …»). Поставь событие «При старте»: с него твой узел начинается.
  2. Затем соедини нужные узлы. Для примера: «Добавить к переменной» (переменная score), потом «Короткое сообщение внизу экрана».
  3. Сохрани с помощью 💾.

Шаг 3: запустить свой узел

  1. В Blueprint сцены добавь узел «Запустить один из моих узлов».
  2. Нажми на строку выбора и выбери свой узел.
  3. Когда выполнение доходит до этого узла, запускаются узлы, которые ты в него положил, а затем Blueprint продолжается.
👉 Будь внимателен: не ставь «Запустить один из моих узлов» под «Каждый кадр» случайно — твой узел будет запускаться на каждом кадре.

Шаг 4: добавить настройки

Без настроек твой узел всегда делает одно и то же. Настройки позволяют менять его каждый раз: сколько очков, какое сообщение, какая скорость…

  1. В Blueprint своего узла нажми кнопку Настройки моего узла (значок с ползунками в верхней панели).
  2. Нажми + Добавить значение. Дай ему имя (например очки), тип (Число, Текст или Да / нет) и начальное значение (например 10). Подтверди и сохрани с помощью 💾.
  3. Внутри узла используй настройку, написав =очки вместо числа. Например, поставь =очки в значение узла «Добавить к переменной». Для сообщения поставь =сообщение в настройку текста узла «Короткое сообщение внизу экрана».
  4. Вернись в Blueprint сцены: узел «Запустить один из моих узлов» теперь показывает по строке на каждую настройку. Измени значение: здесь 50 очков, там 10 очков.
👉 Настройка может быть и вычислением, например =score * 2. Если оставить строку как есть, используется начальное значение. Внутри узла настройка главнее переменной с таким же именем.

Если не получается

  • «Узел не найден»: его переименовали или удалили. Выбери его заново в «Запустить один из моих узлов».
  • Ничего не происходит: проверь, что в начале твоего узла есть событие «При старте» и что ты сохранил с помощью 💾.
  • Строки настроек не появляются: сначала сохрани узел с его настройками, затем снова открой узел «Запустить один из моих узлов».
  • Имя настройки не принимается: пиши его одним словом (буквы, цифры и _), без пробелов.
  • Узел, который запускает сам себя: Yop2D останавливается после нескольких вызовов, чтобы игра не зависла.
