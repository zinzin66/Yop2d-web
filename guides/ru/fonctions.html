Как создать свои блоки (функции)?

Руководство для новичков · без кода

Français · English · Español · Deutsch · Italiano · Português · Русский · 中文 · 日本語

Функция — это небольшая группа узлов, которой ты даёшь имя. Ты делаешь её один раз, а потом запускаешь когда хочешь одним узлом из любой сцены. Так ты создаёшь свои блоки: не повторяешь одно и то же десять раз, а твои Blueprint остаются аккуратными.

Тебе понадобится:
  • открытый в редакторе проект.

Шаг 1: создать функцию

  1. Открой панель Ресурсы (слева в редакторе) и разверни раздел Функции.
  2. Нажми ＋, напиши короткое имя (например Дать_очки) и подтверди.
  3. Нажми на имя своей функции, чтобы выбрать её, а затем на кнопку, которая открывает её Blueprint (значок связанных узлов).
👉 Функция — это файл твоего проекта: она экспортируется вместе с игрой и работает во всех сценах.

Шаг 2: положить в неё узлы

  1. Ты в Blueprint функции (в заголовке написано «Функция: …»). Поставь событие «При старте»: с него функция начинается.
  2. Затем соедини нужные узлы. Для примера: «Добавить к переменной» (переменная score), потом «Короткое сообщение внизу экрана».
  3. Сохрани с помощью 💾.

Шаг 3: вызвать функцию

  1. В Blueprint сцены добавь узел «Вызвать функцию».
  2. Нажми на строку Функция и выбери свою функцию.
  3. Когда выполнение доходит до этого узла, запускаются узлы функции, а затем Blueprint продолжается.
👉 Будь внимателен: не ставь «Вызвать функцию» под «Каждый кадр» случайно — функция будет запускаться на каждом кадре.

Шаг 4: добавить настройки (входные значения)

Без настроек функция всегда делает одно и то же. Входные значения позволяют настраивать её при каждом вызове: сколько очков, какое сообщение, какая скорость…

  1. В Blueprint функции нажми кнопку Входные значения функции (значок с ползунками в верхней панели).
  2. Нажми + Добавить значение. Дай ему имя (например очки), тип (Число, Текст или Да / нет) и начальное значение (например 10). Подтверди и сохрани с помощью 💾.
  3. Внутри функции используй значение, написав =очки вместо числа. Например, поставь =очки в значение узла «Добавить к переменной». Для сообщения поставь =сообщение в настройку текста узла «Короткое сообщение внизу экрана».
  4. Вернись в Blueprint сцены: узел «Вызвать функцию» теперь показывает по строке на каждое значение. Измени значение: здесь 50 очков, там 10 очков.
👉 Значение может быть и вычислением, например =score * 2. Если оставить строку как есть, используется начальное значение. Внутри функции входное значение главнее переменной с таким же именем.

Если не получается

  • «Функция не найдена»: её переименовали или удалили. Выбери её заново в «Вызвать функцию».
  • Ничего не происходит: проверь, что в начале функции есть событие «При старте» и что ты сохранил с помощью 💾.
  • Строки настроек не появляются: сначала сохрани функцию с её входными значениями, затем снова открой узел «Вызвать функцию».
  • Имя значения не принимается: пиши его одним словом (буквы, цифры и _), без пробелов.
  • Функция, которая вызывает саму себя: Yop2D останавливается после нескольких вызовов, чтобы игра не зависла.
