Как сделать тактическую игру?

Руководство для новичков · без кода

Français · English · Español · Deutsch · Italiano · Português · Русский · 中文 · 日本語

В тактической игре игроки ходят по очереди на сетке: выбираешь юнит, видишь клетки, куда он может дойти, двигаешь его, и затем он атакует. Это руководство строит самую простую игру: один герой и один монстр. Всё уже готово в примере Tactics tutorial (вкладка Примеры стартового экрана): открой его Blueprint, каждый шаг лежит в цветной рамке с маленьким ?, который его объясняет.

Тебе понадобится:
  • карта тайлов на твой выбор (сетка игры это сетка этой карты тайлов);
  • Изображение с именем hero1 и тегом joueur и ещё одно с именем foe1 и тегом ennemi;
  • Зона с именем terrain, покрывающая всю карту (на неё нажимают, чтобы выбрать клетку);
  • переменная etat (целое, локальная), чтобы знать, где мы: 0 = выбрать героя, 1 = герой выбран, 2 = герой передвинут.
👉 Местность (лес, песок, гора…) настраивается в редакторе тайлов, в части Местность тайлов: стоимость в шагах, блокирует или нет, бонус защиты. Гора преграждает путь, лес стоит 2 шага.

Шаг 1: карточки юнитов

  1. Добавь событие «При старте».
  2. Добавь «Дать карточку юнита» для hero1: здоровье 20, атака 6, защита 2, движение 4, дальность 1.
  3. Добавь второй «Дать карточку юнита» для foe1 со своими числами.
  4. Соедини ноды по порядку и добавь «Перейти к следующему ходу» с командами joueur,ennemi.
👉 Карточка хранится в объекте: её можно прочитать где угодно формулой, например =hero1.vie.

Шаг 2: ход игрока

  1. Добавь событие «Локальное событие» и напиши имя tour_joueur. Оно запускается само в начале хода игрока.
  2. Поставь etat в 0 нодой «Изменить переменную», затем «Скрыть клетки», чтобы стереть старые клетки.

Для каждой команды «Перейти к следующему ходу» запускает локальное событие "tour_" и имя команды: tour_joueur, затем tour_ennemi.

Шаг 3: нажми на героя и увидишь синие клетки

  1. Добавь «Клик по объекту» на hero1.
  2. Добавь «Если ходит…» с командой joueur, затем на выходе Истина — «Условие» etat < 2.
  3. Добавь «Изменить переменную»: etat = 1.
  4. Добавь «Показать доступные клетки» на hero1: тип зоны Движение (стены мешают), число шагов =hero1.mouvement, синий цвет, Писать число шагов на клетках = да, Эти теги преграждают путь = joueur,ennemi.
👉 Числа на клетках — это шаги, нужные, чтобы туда дойти. Клетки леса стоят 2: герой уходит не так далеко.

Шаг 4: нажми на синюю клетку, герой пойдёт

  1. Добавь «Клик по объекту» на terrain, затем «Условие» etat = 1.
  2. Добавь «Если клетка доступна». Для столбца и строки нажми 🔗 и выбери зелёные ноды «Нажатый столбец» и «Нажатая строка»: писать формулы не нужно.
  3. На выходе Истина: «Изменить переменную» etat = 4 (герой идёт), затем «Идти к клетке (путь)» на hero1 с теми же зелёными нодами и Эти теги преграждают путь = joueur,ennemi.
  4. На выходе Прибыл вызови локальное событие apres_deplacement нодой «Вызвать событие».

Шаг 5: зона атаки, затем атака

  1. В локальном событии apres_deplacement: «Скрыть клетки», etat = 2, затем «Показать доступные клетки» с типом Атака / дальность (поверх стен), число шагов =hero1.portee, красный цвет, с именем зоны attaque.
  2. Добавь «Клик по объекту» на foe1, «Условие» etat = 2 и «Если клетка доступна» с именем зоны attaque.
  3. На Истина: «Атаковать» (объект A = hero1, объект B = foe1). Урон — это атака минус защита монстра минус защита его местности.
  4. Выход Ещё жив: обнови текст его здоровья. Выход Здоровья нет: монстр уничтожен, добавь победу.

Шаг 6: ход монстров

  1. Добавь локальное событие tour_ennemi.
  2. Добавь «Идти к объекту (путь)» на foe1, объект B = hero1, Остановиться = На соседней клетке, по центру, Эти теги преграждают путь = joueur,ennemi.
  3. На выходе Прибыл вызови локальное событие, где foe1 «Атаковать» hero1.
  4. Через несколько секунд («Ждать»): «Остановить путь», затем «Перейти к следующему ходу»: ход возвращается игроку.

Идти дальше

  • Несколько героев: добавь «Отметить как сходившего» и «Если юнит уже ходил», чтобы герой ходил один раз за ход (так делает пример Tactics demo).
  • Полоса здоровья: читай =hero1.vie и =hero1.vie_max в тексте или полосе прогресса.
  • Лечение: «Лечить» возвращает здоровье, не превышая максимум.
  • Настольная игра: «Сдвинуть фишку на клетку» двигает фигуру на одну клетку точно по центру (кнопки ◀ ▶ ▲ ▼).

Если не работает

  • Нет синих клеток: у героя должен быть тег, записанный в «Если ходит…», а «Перейти к следующему ходу» должен быть запущен в начале.
  • Клетки не совпадают с рисунком: сетка — это сетка первой карты тайлов сцены. Без карты тайлов клетки по 80 px.
  • Герой не двигается: проверь, что нажатая клетка синяя и что etat равно 1 в этот момент.
  • Для сравнения открой пример Tactics tutorial: каждая часть Blueprint лежит в рамке, которая её объясняет.
