Как сделать tower defense?

Руководство для новичков · без кода

Français · English · Español · Deutsch · Italiano · Português · Русский · 中文 · 日本語

В tower defense враги идут по пути, а ты строишь башни, которые стреляют в них, пока они не дошли до твоей базы. Здесь враги идут по пути, который ты рисуешь сам, каждая башня выбирает ближайшего врага и стреляет в него, а кредиты оплачивают новые башни.

Тебе понадобится:
  • Изображение с именем map: фон игры, 1920 x 1080 px, с нарисованной дорогой;
  • несколько Изображение для мест застройки (например, 120 x 120 px);
  • Изображение для enemy (например, 64 x 64 px), одно для tower (120 x 120 px), одно для cannon (90 x 34 px, смотрит вправо) и одно для bullet (24 x 24 px);
  • два объекта Текст: creditsText и lifeText, вверху экрана.
👉 Это руководство написано для игры в горизонтальном формате 1920 x 1080. Пример Tower defense (cubes) (вкладка «Примеры») содержит готовые картинки в папке Images/TD: открой его и скопируй в свой проект те, что нравятся. Можно нарисовать и свои, руководство подходит для любого стиля. Сцены Enemy и Tower копируются в игру много раз: смотри руководство Готовый объект.

Шаг 1: переменные

  1. В левой панели открой раздел Переменные и создай две переменные, обе с областью Глобальная (их могут использовать все сцены) и типом Целое:
  • credits: начальное значение 150 (деньги на постройку башен);
  • base_life: начальное значение 20 (сколько врагов выдержит твоя база).

Шаг 2: нарисовать путь

Враги идут по пути: точки, соединённые между собой. Ты рисуешь его поверх своей карты инструментом «Маршрут».

  1. Открой окно Assets (панель «Ресурсы») и нажми Маршрут. Откроется редактор маршрутов, а на заднем плане будет твоя сцена.
  2. Нажми Новый маршрут и назови его Path.
  3. Инструментом Ставить точки коснись сцены, чтобы поставить первую точку слева, где входят враги: это Старт. Продолжай касаться вдоль дороги: каждая новая точка соединяется с предыдущей.
  4. Поставь последнюю точку на свою базу: у неё нет выхода, это Финиш.
  5. Нажми Посмотреть, чтобы увидеть, как точка проходит по пути. Затем закрой редактор: маршрут сохранится сам.
👉 Чтобы сменить старт, коснись точки и выбери Сделать эту точку стартом. Чтобы переместить точку, возьми инструмент Двигать; чтобы убрать, используй Стереть.

Шаг 3: сцена Enemy

Враг — это отдельная сцена: каждый враг, которого ты отправляешь в игру, — её копия со своей жизнью. Ты строишь её один раз.

  1. Создай новую сцену с именем Enemy (меню ＋, затем Создать сцену).
  2. В сцене Enemy добавь Изображение с именем enemy в X = 0, Y = 0 и дай ей тег enemy.
  3. Открой Blueprint сцены Enemy и добавь событие «При старте».
  4. Добавь «Дать объекту здоровье»: цель enemy, Очки здоровья = 3 (враг выдерживает 3 попадания).
  5. Добавь «Идти по маршруту»: цель enemy, Название маршрута = Path, Скорость (пикселей в секунду) = 150.
  6. Соедини три узла по порядку.

Шаг 4: запустить волны

Теперь вернись в главную сцену (Game) и отправляй врагов один за другим.

  1. Открой Blueprint сцены Game и добавь событие «При старте».
  2. Добавь два узла «Изменить переменную»: credits = 150, затем base_life = 20. Так каждая новая игра начинается с чистого листа, даже после Game Over.
  3. Добавь «Ждать»: Длительность (секунды) = 3 (пауза перед первым врагом).
  4. Добавь «Повторять»: Каждые (секунды) = 1.5, Сколько раз (0 = бесконечно) = 15, Имя таймера (необязательно) = waves.
  5. С выхода Каждый раз добавь «Разместить копию сцены»: сцена Enemy. Оставь X и Y как есть: враг сам встанет на старт пути.
  6. Соедини узлы по порядку.

Шаг 5: сцена Tower

Башня — тоже сцена. Она ищет ближайшего врага в зоне досягаемости, поворачивает пушку к нему и стреляет.

  1. Создай новую сцену с именем Tower. Добавь Изображение tower в X = 0, Y = 0, затем Изображение cannon в X = 15, Y = 43, перед ней.
  2. В сцене Game добавь Изображение с именем bullet за пределами экрана (например, X = -300, Y = -300) и дай ей тег bullet: это образец, который башня копирует при каждом выстреле.
  3. Открой Blueprint сцены Tower и добавь событие «При старте», затем «Повторять»: Каждые (секунды) = 0.2, Сколько раз (0 = бесконечно) = 0 (бесконечно). Башня осматривается 5 раз в секунду.
  4. С выхода Каждый раз добавь «Выбрать цель»: цель tower, Теги возможных целей (через запятую) = enemy, Какую цель выбрать? = «Ближайшая», а в дополнительных настройках Дальность в пикселях по кругу (0 = дальность в клетках) = 330.
  5. С выхода Цель найдена добавь «Повернуть к»: цель cannon, а вторым объектом выбери Объект, участвующий в событии (выбранный враг).
  6. Добавь «Перезарядка»: цель cannon, Задержка (секунды) = 1.2 (не чаще одного выстрела в 1,2 секунды).
  7. С выхода Готово добавь «Стрелять объектом»: цель cannon, Имя модели = bullet, Скорость = 14, Время жизни выстрела (секунды, 0 = без предела) = 1.6, Уничтожать за экраном (да / нет) = нет. Оставь Направление как есть: снаряд вылетает туда, куда смотрит пушка.

Шаг 6: попасть во врагов

Эта часть находится в сцене Enemy: именно враг знает, когда в него попадает снаряд.

  1. Открой Blueprint сцены Enemy и добавь событие «Если объект касается тега»: цель enemy, Тег bullet.
  2. Добавь «Уничтожить объект» и выбери Объект, участвующий в событии целью: это снаряд, он исчезает.
  3. Добавь «Нанести урон»: цель enemy, Урон = 1. По умолчанию враг уничтожается, когда его жизнь доходит до нуля.
  4. С выхода Здоровья нет добавь «Добавить к переменной»: переменная credits, значение 15 (награда).
  5. Соедини узлы по порядку.

Шаг 7: строить башни

Игрок строит башню, коснувшись места застройки. Это стоит 50 кредитов.

  1. Выбери каждое место застройки и дай ему в Инспекторе тег spot.
  2. В сцене Game добавь событие «Клик по объекту» и выбери объектом # spot (все объекты с тегом spot).
  3. Добавь «Условие» =credits >= 50.
  4. На выходе Истина: «Добавить к переменной»: переменная credits, значение -50.
  5. Затем «Разместить копию сцены»: сцена Tower. Для X коснись 🔗, выбери «Значение объекта», объект Объект, участвующий в событии, Что = x. Сделай то же для Y с y: башня появляется ровно там, где коснулся игрок.
  6. Добавь «Уничтожить объект» с целью Объект, участвующий в событии: место застройки исчезает.
  7. На выходе Ложь: «Короткое сообщение внизу экрана» с сообщением Не хватает кредитов.

Шаг 8: цифры на экране

  1. В сцене Game добавь событие «Каждый кадр».

Шаг 9: жизни базы и конец игры

Когда враг доходит до конца пути, твоя база теряет жизнь. Когда жизней не остаётся, игра окончена.

  1. В сцене Enemy возьми узел «Идти по маршруту» из шага 3. С его выхода Прибыл добавь «Добавить к переменной»: переменная base_life, значение -1.
  2. Добавь «Уничтожить объект»: цель enemy.
  3. Добавь «Условие» =base_life <= 0. На выходе Истина добавь «Вызвать событие» с именем события game_over.
  4. В сцене Game добавь событие «Локальное событие» с тем же именем game_over.
  5. Добавь «Остановить таймер»: Имя (пусто = все) = waves (больше враги не посылаются), затем «Уничтожить по тегу»: Тег для уничтожения = enemy.
  6. Добавь «Короткое сообщение внизу экрана» с сообщением Игра окончена, затем «Ждать» 2 секунды, затем «Перезапустить сцену».

Играй: построй одну-две башни на свои кредиты и смотри, как они останавливают врагов. Пропусти нескольких, чтобы увидеть, как база теряет жизни.

Что дальше

  • Победа: считай врагов переменной (+1, когда один погибает или доходит). Когда число достигает всего отправленного, покажи сообщение и выиграй.
  • Улучшить башню: коснись башни, чтобы открыть маленькое окно с кнопкой «Улучшить», которая стоит кредитов и меняет картинку пушки и скорострельность. Открой пример Tower defense (cubes), чтобы посмотреть, как это сделано.
  • Несколько типов врагов: сделай вторую сцену (Enemy2) с большей жизнью и другой скоростью и пусть каждая волна посылает то одного, то другого (открой пример Tower defense (cubes), чтобы посмотреть, как).
  • Развилки: в инструменте «Маршрут» коснись точки и выбери Эта точка — развилка: враги выбирают дорогу случайно, а ветки могут снова сойтись.
  • Несколько полос без пробок: в «Идти по маршруту» поставь Случайное смещение в сторону (пиксели, ±: у каждого своя полоса) и Обходить других: сдвигаться, чтобы не накладываться, и обгонять медленных (да / нет) на да: враги идут рядом и обгоняют друг друга.
  • Большая карта: сделай карту вдвое шире, затем добавь при запуске «Границы камеры» и «Прокручивать камеру пальцем», чтобы игрок двигал карту пальцем.
  • Звуки и искры: добавь «Воспроизвести звук» при каждом выстреле и «Эффект частиц», когда враг погибает (смотри руководство Частицы и эффекты).

Если не работает

  • Враги не двигаются: проверь, что настройка Название маршрута — это имя твоего пути (Path) и что у пути есть Старт. Проверь, что у сцены Enemy есть событие «При старте».
  • Башня не стреляет: проверь тег enemy у врага, имя bullet в «Стрелять объектом» и что объект bullet лежит в сцене Game (за экраном, но не удалён). Увеличь Дальность в пикселях по кругу (0 = дальность в клетках), если враги остаются вне досягаемости.
  • Снаряды не наносят урон: у снаряда должен быть тег bullet, а событие «Если объект касается тега» должно быть в сцене Enemy, а не в Game.
  • Башня появляется не там: для X и Y узла «Разместить копию сцены» используй зелёные узлы «Значение объекта» с Объект, участвующий в событии, как в шаге 7.
  • Кредиты или жизни базы не меняются: проверь, что у переменных credits и base_life область Глобальная.
