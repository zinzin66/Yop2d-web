Как сделать Pong?

Руководство для новичков · без кода

Français · English · Español · Deutsch · Italiano · Português · Русский · 中文 · 日本語

В Pong мяч отскакивает между твоей ракеткой (внизу) и ракеткой робота (вверху). Когда мяч пролетает за ракеткой, другой игрок получает очко. Как и в руководстве по арканоиду, мяч двигается благодаря двум переменным: vx (его скорость в сторону) и vy (его скорость вверх или вниз).

Тебе понадобится:
  • Изображение с именем Ball, в середине экрана (например, 60 x 60 px);
  • Изображение с именем Player, внизу (например, 200 x 80 px, около y = 1690);
  • Изображение с именем Bot, вверху (тот же размер, y = 140);
  • два объекта Текст с именами ScorePlayer и ScoreBot, с текстом 0;
  • четыре Зона с именами WallLeft, WallRight, GoalPlayer и GoalBot.
👉 Это руководство написано для игры в портретной ориентации 1080 x 1920. Для картинок возьми бесплатный пакет Puzzle (арканоид) (Kenney, свободная лицензия, CC0) в Библиотеке, вкладка Пакеты для скачивания: paddleBlu (твоя ракетка), paddleRed (робот), ballBlue (мяч). Можно использовать и собственные рисунки.

Шаг 1: имена, поведение и переменные

  1. Выбери каждый объект и впиши его имя в инспекторе — точно так, как в списке выше. Имя с пробелом или с другой буквой узлы не найдут.
  2. Выбери Ball, нажми ⚙ Поведение объекта и выбери Декор. Сделай то же для Player и Bot: двигать их будут только узлы.
  3. В разделе Переменные создай две переменные типа Число, область Локальная: vx и vy, начальное значение 0. Создай ещё две типа Целое, область Локальная: scorePlayer и scoreBot, начальное значение 0.
👉 Самая частая ошибка: забытое имя или забытое поведение. Ничего не ломается, но ничего не происходит. Если игра ничего не делает, сначала проверь этот шаг.

Шаг 2: стены и ворота

Мяч отскакивает от стен, которых не видно: четыре Зона вокруг экрана. Зона невидима во время игры, но мяч может её касаться.

  1. Добавь Зона с именем WallLeft: X = -300, Y = -400, ширина 300, высота 2800.
  2. Добавь Зона с именем WallRight: X = 1080, Y = -400, ширина 300, высота 2800.
  3. Добавь Зона с именем GoalBot: X = -300, Y = -300, ширина 1680, высота 300 (над экраном).
  4. Добавь Зона с именем GoalPlayer: X = -300, Y = 1920, ширина 1680, высота 300 (под экраном).
👉 Стены нарочно толстые: быстрый мяч не пролетит сквозь них. Две стены возвращают мяч; двое ворот будут считать очки.

Шаг 3: мяч стартует и движется

  1. Добавь событие «При старте», затем два узла «Изменить переменную» подряд: переменная vx, значение 6, затем переменная vy, значение 9.
  2. Добавь событие «Каждый кадр», затем «Толкнуть объект»: цель Ball, Добавить X = vx, Добавить Y = vy. Просто впиши эти два имени в поля.
При старте
→
Изменить переменнуюvx · 6
→
Изменить переменнуюvy · 9
Каждый кадр
→
Толкнуть объектBall · vx · vy
👉 Как он движется? «Каждый кадр» срабатывает примерно 60 раз в секунду. Каждый раз мяч смещается на vx пикселей в сторону и на vy пикселей вверх или вниз. При 0 и 0 он останавливается. Чтобы изменить направление, мы меняем только эти два числа: именно это и делают отскоки.

Шаг 4: моя ракетка следует за пальцем

  1. Добавь событие «Палец нажат»: оно повторяется, пока палец касается экрана.
  2. Добавь «Переместить»: цель Player, X = doigt.x - Player.largeur / 2, Y = 1690. Положение пальца есть в списке слева в окне настройки; мы вычитаем половину ширины ракетки, чтобы палец был в её центре.
  3. Добавь «Удерживать в экране»: цель Player, Отступ = 0, чтобы ракетка не выходила за края.
Палец нажат
→
ПереместитьPlayer · doigt.x · 1690
→
Удерживать в экранеPlayer · 0

Шаг 5: отскоки

Отскок — это просто новое число для vx или vy. Мы используем random(a, b), которая выбирает число между a и b: ни один отскок не повторяется.

  1. «Столкновение A/B» (Объект A = WallLeft, Объект B = Ball) → «Изменить переменную»: vx = random(4, 12). Положительное число: мяч летит вправо.
  2. «Столкновение A/B» (WallRight, Ball) → «Изменить переменную»: vx = -random(4, 12). Знак минус делает число отрицательным: мяч летит влево.
  3. «Столкновение A/B» (Ball, Player) → «Изменить переменную»: vy = random(-13, -9) (мяч летит вверх), затем «Изменить переменную»: vx = Ball.x / 10 - Player.x / 10 - 7.
  4. «Столкновение A/B» (Ball, Bot) → «Изменить переменную»: vy = random(9, 13) (мяч летит вниз), затем «Изменить переменную»: vx = random(-6, 6).

Столкновение A/BWallRight · Ball
→
Изменить переменнуюvx · -random(4, 12)

👉 Зачем такой расчёт для ракетки? Он сравнивает положение мяча и ракетки: в центре мяч летит прямо, у края — в сторону. -7 учитывает, что ракетка шире мяча (тогда центр даёт 0).

Шаг 6: робот гонится за мячом

Робот не очень умён: на каждом кадре он немного приближается к мячу.

  1. Добавь событие «Каждый кадр», затем «Изменить свойство»: цель Bot, Свойство = x, Значение = Bot.x * 0.94 + Ball.x * 0.06 - 6.
  2. Добавь «Удерживать в экране»: цель Bot, Отступ = 0.
Каждый кадр
→
Изменить свойствоBot · x
→
Удерживать в экранеBot · 0
👉 Как это работает? Робот сохраняет 94 % своего места и берёт 6 % места мяча (- 6 центрирует его на мяче). При 0.06 он достаточно медленный, чтобы его можно было обыграть. Попробуй 0.03 и 0.97 (очень легко) или 0.15 и 0.85 (очень трудно): два числа должны давать в сумме 1, а - 6 становится - 3 или - 15.
👉 Внимание: не пиши положение в «скорость X». Скорость — маленькое число, положение — большое: робот не будет двигаться.

Шаг 7: голы и счёт

  1. «Столкновение A/B» (GoalBot, Ball) → «Добавить к переменной»: переменная scorePlayer, Добавляемое значение = 1 → «Изменить текст»: цель ScorePlayer, Новый текст = =scorePlayer.
  2. То же для робота: «Столкновение A/B» (GoalPlayer, Ball) → «Добавить к переменной»: scoreBot + 1 → «Изменить текст»: цель ScoreBot, =scoreBot.
  3. Чтобы подать мяч снова, добавь подряд: «Изменить переменную» vx = 0, «Изменить переменную» vy = 0, «Переместить» Ball в X = 510, Y = 930, «Ждать» 1 секунду, затем «Изменить переменную» vx = 6 и «Изменить переменную» vy = 9.
  4. Соедини конец обоих голов с первым узлом этой подачи: один вход может принимать несколько проводов.

👉 Знак = в начале текста говорит Yop2D вычислить значение, а не записывать его как есть (см. руководство Сбор монет и подсчёт очков).

Что дальше

  • Победа при 5 очках: после каждого гола добавь «Условие» =scorePlayer >= 5, затем «Короткое сообщение внизу экрана» и «Перезапустить сцену» (см. руководство Жизни и Game Over).
  • Звуки: добавь «Воспроизвести звук» после каждого отскока.
  • Свой стиль: поменяй картинки и фон; имена остаются теми же.
  • Игра ничего не делает? Вернись к шагу 1: не хватает имени или поведения. Робот не двигается? Проверь, что у него поведение Декор и что формула стоит в поле Значение.
