Как сделать игру-арканоид?

Руководство для новичков · без кода

Français · English · Español · Deutsch · Italiano · Português · Русский · 中文 · 日本語

В арканоиде мяч отскакивает от стен и от платформы, которую ты двигаешь пальцем, и разбивает блоки. Здесь мяч движется благодаря двум переменным: vx (его скорость вправо) и vy (его скорость вниз). Когда он касается стены, мы просто даём ему другое число.

Тебе понадобится:
  • Изображение с именем paddle, внизу экрана (например, 208 x 48 px, около y = 1700);
  • Изображение с именем ball, в середине экрана (например, 44 x 44 px);
  • блоки: Изображение вверху экрана (например, 128 x 64 px, по 8 в ряд);
  • два объекта Текст: scoreText (текст «Очки: 0») и livesText (текст «Жизни: 3»), вверху экрана.
👉 Это руководство написано для игры в вертикальном формате 1080 x 1920. Картинки взяты из бесплатного набора Puzzle (brick breaker) (Kenney, свободное использование, CC0). Скачай его в Библиотеке Yop2D, на вкладке Наборы для загрузки: там есть paddleBlu (платформа), ballBlue (мяч) и element_blue_rectangle_glossy (блок, синий, зелёный, красный, жёлтый, фиолетовый и серый). Можно использовать и свои рисунки.

Шаг 1: теги и переменные

  1. Выбери блок. В инспекторе, в поле Тег (Метка), напиши brick. Сделай то же самое для каждого блока.
  2. На левой панели открой раздел Переменные и создай пять переменных, все с областью Локальная и типом Целое:
  • score: начальное значение 0;
  • lives: начальное значение 3;
  • bricks: количество блоков в твоей игре (например, 24). Оно нужно, чтобы понять, когда всё разбито;
  • vx и vy: начальное значение 0. Это скорость мяча, она задаётся при запуске.
👉 Блоком больше или меньше? Просто измени начальное значение bricks. Если число слишком большое, ты никогда не выиграешь; если слишком маленькое, выиграешь слишком рано.

Шаг 2: невидимые стены

Мяч отскакивает от стен, которых не видно: четыре Зона, расставленные вокруг экрана. Зона невидима во время игры, но мяч может её касаться.

  1. Добавь Зона с именем left_wall: X = -300, Y = -400, ширина 300, высота 2800.
  2. Добавь Зона с именем right_wall: X = 1080, Y = -400, ширина 300, высота 2800.
  3. Добавь Зона с именем top_wall: X = -300, Y = -300, ширина 1680, высота 300.
  4. Добавь Зона с именем bottom_wall: X = -300, Y = 1920, ширина 1680, высота 300.
👉 Стены сделаны толстыми специально: быстрый мяч не сможет пролететь сквозь них. Первые три отправляют мяч обратно; bottom_wall нужна, чтобы терять жизнь.

Шаг 3: платформа следует за пальцем

  1. Выбери paddle, нажми ⚙ Comportement de l'objet и выбери Перетаскивается пальцем: игрок берёт платформу и двигает её.
  2. Открой Blueprint сцены и добавь событие «Каждый кадр».
  3. Добавь «Изменить свойство»: цель paddle, Свойство = y, Значение = 1700.
  4. Добавь «Удерживать в экране»: цель paddle, Отступ = 0.
  5. Соедини три узла по порядку.
Каждый кадр
→
Изменить свойствоpaddle · y · 1700
→
Удерживать в экранеpaddle · 0
👉 Зачем эти два узла? «Перетаскивается пальцем» позволяет двигать платформу в любую сторону. На каждом кадре мы возвращаем её на ту же высоту и не даём выйти за экран: она двигается только влево и вправо.

Шаг 4: мяч стартует

  1. Добавь событие «При старте», затем два узла «Изменить переменную» подряд: переменная vx, значение 6, потом переменная vy, значение -9.
  2. Добавь событие «Каждый кадр», затем «Толкнуть объект»: цель ball.
  3. В окне настроек «Толкнуть объект» нажми кнопку 🔗 рядом с Добавить X, выбери «Значение переменной», затем выбери переменную vx в зелёном узле, который появится.
  4. Сделай то же самое для Добавить Y с переменной vy.
  5. Соедини каждое событие с его узлами и запусти игру: мяч летит вверх и вправо, а затем уходит за экран.

→

→
Изменить переменнуюvy · -9

👉 Зелёный узел задаёт значение настройке, ничего не печатая. Здесь «Значение переменной» говорит «Толкнуть объект»: «на каждом кадре смещайся на vx вправо и на vy вниз».
👉 Минус = вверх. В Yop2D ось Y растёт к низу экрана: vy = -9 отправляет мяч вверх.

Шаг 5: отскок от стен

Каждая стена даёт мячу новое число. Добавь три события «Столкновение A/B» (Объект A = ball):

  1. Объект B = left_wall → «Изменить переменную»: переменная vx, значение 6 (мяч летит обратно вправо).
  2. Объект B = right_wall → «Изменить переменную»: переменная vx, значение -6 (мяч летит обратно влево).
  3. Объект B = top_wall → «Изменить переменную»: переменная vy, значение 9 (мяч летит обратно вниз).

Шаг 6: отскок от платформы

  1. Добавь событие «Столкновение A/B»: Объект A = ball, Объект B = paddle.
  2. Добавь «Изменить переменную»: переменная vy, значение -9 (мяч снова летит вверх).
  3. Добавь второй «Изменить переменную»: переменная vx. Нажми 🔗 рядом со значением, выбери «Случайное число», затем задай От = -6 и До = 6.
  4. Соедини узлы по порядку.
Столкновение A/Bball · paddle
→
Изменить переменнуюvy · -9
→
Изменить переменнуюvx · ← случайное число (от -6 до 6)
👉 При каждом отскоке от платформы мяч вылетает в случайном направлении: игра никогда не повторяется.

Шаг 7: разбить блоки

  1. Добавь событие «Если объект касается тега»: цель ball, Тег brick.
  2. Добавь «Уничтожить объект» и выбери целью Объект, участвующий в событии: это блок, которого мяч только что коснулся.
  3. Добавь «Условие» =vy < 0 («мяч летит вверх»). Выход Истина → «Изменить переменную»: переменная vy, значение 9. Выход Ложь → «Изменить переменную»: переменная vy, значение -9.
  4. От выхода «Затем» условия добавь «Добавить к переменной»: переменная score, Добавляемое значение = 10.
  5. Добавь «Добавить к переменной»: переменная bricks, Добавляемое значение = -1.
  6. Добавь «Изменить текст»: цель scoreText, Новый текст = ="Очки: " + score.

👉 Почему =vy < 0? Если vy меньше 0, мяч летит вверх: после разрушения блока он летит вниз. Иначе он летит вниз, а затем снова вверх.
👉 Знак = в начале текста говорит Yop2D вычислить текст, а не писать его как есть (см. руководство Собирать монеты и считать очки).

Шаг 8: победа

После «Изменить текст» из шага 7 добавь:

  1. «Условие» =bricks <= 0.
  2. На выходе Истина: «Изменить переменную» vx = 0, «Изменить переменную» vy = 0 (мяч останавливается), затем «Короткое сообщение внизу экрана» с сообщением Ты выиграл!, затем «Ждать» 2 секунды, затем «Перезапустить сцену».

👉 «Перезапустить сцену» возвращает объекты на место, а Локальная переменные — к начальному значению: игра начинается заново с 3 жизнями, 0 очков и всеми блоками.

Шаг 9: жизни и Game Over

Когда мяч касается bottom_wall (под экраном), игрок теряет жизнь.

  1. Добавь событие «Столкновение A/B»: Объект A = ball, Объект B = bottom_wall.
  2. «Добавить к переменной»: переменная lives, Добавляемое значение = -1.
  3. «Изменить текст»: цель livesText, Новый текст = ="Жизни: " + lives.
  4. «Условие» =lives <= 0.
  5. Выход Истина (жизней нет): «Переместить» ball в X = 518, Y = 1000, «Изменить переменную» vx = 0, «Изменить переменную» vy = 0 (мяч возвращается в центр и останавливается), затем «Короткое сообщение внизу экрана» «Игра окончена!», «Ждать» 2 секунды, «Перезапустить сцену».
  6. Выход Ложь (жизни остались): «Переместить» ball в X = 518, Y = 1000, затем «Изменить переменную» vy = -9, затем «Изменить переменную» vx = 6.

👉 Зачем останавливать мяч перед ожиданием? Пока длятся 2 секунды ожидания, игра продолжается. Если бы мяч оставался под экраном, он отнимал бы жизнь на каждом кадре, и счётчик жизней ушёл бы очень глубоко в минус. Возвращённый в центр и неподвижный, он больше не мешает.

Что дальше

  • Звуки: добавь «Воспроизвести звук» после «Уничтожить объект» («клак», когда блок разбивается) и в событие платформы.
  • Разные цвета: дай всем блокам один и тот же тег brick, какого бы они ни были цвета: достаточно одной настройки.
  • Более быстрый мяч: измени везде числа 6, -6, 9 и -9 (например, на 8, -8, 12 и -12).
  • Искры: добавь «Эффект частиц», когда блок разбивается (см. руководство Частицы и эффекты).

Если не работает

  • Мяч не движется: проверь, что vx и vy меняются при запуске и что «Толкнуть объект» соединён с зелёными узлами «Значение переменной» (нажми Добавить X: в строке должна быть зелёная нить).
  • Мяч проходит сквозь стену или блоки: проверь имена (ball, paddle, left_wall…) и тег brick, написанный везде одинаково (без заглавных букв). Если мяч очень быстрый, сделай блоки чуть больше или замедли мяч.
  • Платформа уходит вверх или вниз: узел «Изменить свойство» должен быть соединён с Каждый кадр, а Свойство = y.
  • Ты выигрываешь слишком рано или никогда: переменная bricks должна быть равна точному числу блоков в игре.
  • Для сравнения открой тестовый проект (его узлы разложены по разделам, с рамками и стикерами, которые объясняют каждую часть).
