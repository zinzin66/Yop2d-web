Как сделать игру-арканоид?

Руководство для новичков · без кода

Français · English · Español · Deutsch · Italiano · Português · Русский · 中文 · 日本語

В арканоиде мяч отскакивает от краёв и от платформы, которую ты двигаешь пальцем, и разбивает блоки. Здесь мы управляем мячом с помощью двух небольших переменных: vx (его скорость вправо) и vy (его скорость вниз). Когда мяч отскакивает, мы просто меняем знак переменной.

Тебе понадобится:
  • Изображение с именем paddle, внизу экрана (например, 208 x 48 px, около y = 1700);
  • Изображение с именем ball, в середине экрана (например, 44 x 44 px);
  • блоки: Изображение вверху экрана (например, 128 x 64 px, по 8 в ряд);
  • два объекта Текст: scoreText (текст «Очки: 0») и livesText (текст «Жизни: 3»), вверху экрана.
👉 Это руководство написано для игры в вертикальном формате 1080 x 1920. Картинки взяты из бесплатного набора Puzzle (brick breaker) (Kenney, свободное использование, CC0). Скачай его в Библиотеке Yop2D, на вкладке Наборы для загрузки: там есть paddleBlu (платформа, 208 x 48), ballBlue (мяч, 44 x 44) и element_blue_rectangle_glossy (блок, 128 x 64, синий, зелёный, красный, жёлтый, фиолетовый и серый). Можно использовать и свои рисунки: тогда подгони числа в формулах под их размеры.

Шаг 1: теги и переменные

  1. Выбери блок. В инспекторе, в поле Тег (Метка), напиши brick. Сделай то же самое для каждого блока.
  2. На левой панели открой раздел Переменные и создай пять переменных, все с областью Локальная и типом Целое:
  • score: начальное значение 0;
  • lives: начальное значение 3;
  • bricks: количество блоков в твоей игре (например, 27). Оно нужно, чтобы понять, когда всё разбито;
  • vx и vy: начальное значение 0. Это скорость мяча, она задаётся при запуске.
👉 Блоком больше или меньше? Просто измени начальное значение bricks. Если число слишком большое, ты никогда не выиграешь; если слишком маленькое, выиграешь слишком рано.

Шаг 2: платформа следует за пальцем

  1. Открой Blueprint сцены.
  2. Добавь событие «Палец нажат» (оно повторяется, пока палец лежит на экране).
  3. Добавь «Переместить»: цель paddle, X = =clamp(doigt.x - 104, 0, 872), Y = 1700.
  4. Соедини два узла и запусти игру: платформа следует за пальцем и никогда не выходит за экран.
Палец нажат
→
Переместитьpaddle · =clamp(doigt.x - 104, 0, 872) · 1700
👉 Как читать формулу? doigt.x — это положение твоего пальца («doigt» по-французски «палец»). Мы вычитаем 104 (половину платформы), чтобы поставить её по центру под пальцем. clamp(…, 0, 872) удерживает её на экране: 872 = 1080 − 208 (ширина платформы).

Шаг 3: мяч стартует

  1. Добавь событие «При старте», затем два узла «Изменить переменную» подряд: переменная vx = 6, потом переменная vy = -9.
  2. Добавь событие «Каждый кадр», затем «Толкнуть объект»: цель ball, Добавить X = =vx, Добавить Y = =vy.
  3. Соедини каждое событие с его узлами и запусти игру: мяч летит вверх и вправо и уходит за экран.

→

👉 Минус = вверх. В Yop2D ось Y растёт к низу экрана: vy = -9 отправляет мяч вверх. Для более быстрого мяча возьми 8 и -12.

Шаг 4: отскок от краёв

Сразу после «Толкнуть объект» мы на каждом кадре проверяем, касается ли мяч края. Мы соединяем цепочкой три узла «Условие», каждый раз используя выход «Затем» (он срабатывает в любом случае).

  1. Левый край: «Условие» =ball.x <= 0. Выход Истина → «Изменить переменную»: переменная vx, значение =abs(vx) (всегда вправо).
  2. Правый край: «Условие» =ball.x >= 1036. Выход Истина → «Изменить переменную»: переменная vx, значение =-abs(vx) (всегда влево). 1036 = 1080 − 44 (ширина мяча).
  3. Верх: «Условие» =ball.y <= 0. Выход Истина → «Изменить переменную»: переменная vy, значение =abs(vy) (всегда вниз).
  4. Соедини каждый «Условие» со следующим через его выход «Затем». Первый соединяется с выходом «Толкнуть объект».

👉 Почему abs? abs(vx) всегда даёт положительное число. У левого края мяч принудительно летит вправо, даже если он коснулся края два кадра подряд: он никогда не застрянет.

Шаг 5: отскок от платформы

  1. Добавь событие «Столкновение A/B»: Объект A = ball, Объект B = paddle.
  2. Добавь «Изменить переменную»: переменная vy, значение =-abs(vy) (мяч снова летит вверх).
  3. Добавь второй «Изменить переменную»: переменная vx, значение =(ball.x + 22 - paddle.x - 104) / 13.
  4. Соедини три узла по порядку.
Столкновение A/Bball · paddle
→
Изменить переменнуюvy · =-abs(vy)
→
Изменить переменнуюvx · =(ball.x + 22 - paddle.x - 104) / 13
👉 Для чего последняя формула? Она измеряет, в какое место платформы попал мяч: по центру он летит прямо вверх; у левого края — влево; у правого — вправо. Так игрок может целиться. (22 = половина мяча, 104 = половина платформы.)

Шаг 6: разбить блоки

  1. Добавь событие «Если объект касается тега»: цель ball, Тег brick.
  2. Добавь «Уничтожить объект» и выбери целью Объект, участвующий в событии: это блок, которого мяч только что коснулся.
  3. Добавь «Изменить переменную»: переменная vy, значение =-vy (мяч отскакивает).
  4. Добавь «Добавить к переменной»: переменная score, Добавляемое значение = 10.
  5. Добавь «Добавить к переменной»: переменная bricks, Добавляемое значение = -1.
  6. Добавь «Изменить текст»: цель scoreText, Новый текст = ="Очки: " + score.
  7. Соедини все узлы по порядку.

👉 Когда мяч разбивает блок, он всегда отскакивает вверх или вниз, даже если задел блок сбоку. Это просто и хорошо работает в арканоиде.

Шаг 7: победа

После «Изменить текст» из шага 6 добавь:

  1. «Условие» =bricks <= 0.
  2. На выходе Истина: «Изменить переменную» vx = 0, «Изменить переменную» vy = 0 (мяч останавливается), затем «Короткое сообщение внизу экрана» с сообщением Ты выиграл!, затем «Ждать» 2 секунды, затем «Перезапустить сцену».

👉 «Перезапустить сцену» возвращает объекты на место, а Локальная переменные — к начальному значению: игра начинается заново с 3 жизнями, 0 очков и всеми блоками.

Шаг 8: жизни и Game Over

Когда мяч падает ниже платформы, игрок теряет жизнь. Продолжаем цепочку из шага 4: после третьего «Условие» (верхнего) добавь четвёртый, соединённый через выход «Затем».

  1. «Условие» =ball.y >= 1920, выход Истина.
  2. «Добавить к переменной»: переменная lives, Добавляемое значение = -1.
  3. «Изменить текст»: цель livesText, Новый текст = ="Жизни: " + lives.
  4. «Условие» =lives <= 0.
  5. Выход Истина (жизней нет): «Переместить» ball в X = 518, Y = 1000, «Изменить переменную» vx = 0, «Изменить переменную» vy = 0 (мяч возвращается в центр и останавливается), затем «Короткое сообщение внизу экрана» «Игра окончена!», «Ждать» 2 секунды, «Перезапустить сцену».
  6. Выход Ложь (жизни остались): «Переместить» ball в X = 518, Y = 1000, затем «Изменить переменную» vy = -9, затем «Изменить переменную» vx = 6.

Что дальше

  • Звуки: добавь «Воспроизвести звук» после «Уничтожить объект» («клак», когда блок разбивается) и в событие платформы.
  • Разные цвета: дай всем блокам один и тот же тег brick, какого бы они ни были цвета: достаточно одной настройки.
  • Больше скорости: добавляй «Изменить переменную» =vx * 1.02 при каждом разбитом блоке, чтобы игра становилась всё сложнее.
  • Искры: добавь «Эффект частиц», когда блок разбивается (см. руководство Частицы и эффекты).

Если не работает

  • Мяч не движется: проверь, что vx и vy меняются при запуске и что «Толкнуть объект» использует формулы =vx и =vy (со знаком = в начале).
  • Мяч проходит сквозь платформу или блоки: проверь имена (ball, paddle) и тег brick, написанный везде одинаково (без заглавных букв). Если мяч очень быстрый, сделай блоки чуть больше или замедли мяч.
  • Мяч уходит за экран без отскока: узлы «Условие» должны быть соединены друг за другом через выход «Затем», а первый должен идти от «Толкнуть объект».
  • Ты выигрываешь слишком рано или никогда: переменная bricks должна быть равна точному числу блоков в игре.
  • Платформа двигается плохо: в формуле doigt.x — это палец, а не платформа; сохрани = в начале и закрой скобку.
