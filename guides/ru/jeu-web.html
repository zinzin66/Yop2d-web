Как превратить игру в веб-игру (HTML)?

Руководство для новичков · без кода

Français · English · Español · Deutsch · Italiano · Português · Русский · 中文 · 日本語 · العربية

ℹ️ Требуется Yop2D версии 1300 или новее (последнее число номера версии, например 1.0.1300). Если у тебя версия старее, обнови Yop2D.

Начиная с версии 1300, Yop2D умеет создавать веб-игру: вся игра (картинки, звуки, узлы) помещается в один файл .html. Он запускается в браузере (рекомендуется Chrome) на телефоне, планшете или компьютере, без установки и без интернета.

Тебе понадобится:
  • Yop2D версии 1300 или новее;
  • игра, которая работает при проверке кнопкой ▶ в редакторе;
  • браузер Chrome на устройстве, где будут играть (рекомендуется).

Шаг 1: создать файл

  1. На стартовом экране нажмите на свой проект, чтобы выбрать его.
  2. Нажмите Build APK. Откроется окно Создать игру.
  3. Выберите Веб-игра (HTML).
  4. Выберите, куда сохранить файл (например, «Загрузки»), и дождитесь сообщения «Ваша веб-игра готова!».
👉 Файл содержит всю игру: если в игре много картинок или музыки, файл будет больше (обычно от 1 до 5 МБ).

Шаг 2: играть

  1. Откройте файл в Chrome (файловый менеджер → Загрузки → нажать на файл → Chrome).
  2. Игра запустится. Коснитесь экрана один раз: включатся звук и полноэкранный режим.
  3. На компьютере играют мышью; клавиша Esc работает как кнопка «Назад» телефона.
👉 Некоторые приложения (мессенджеры, просмотрщики файлов) открывают файл в маленьком окне без полноэкранного режима: игра пишет об этом оранжевым. Тогда откройте его в Chrome.

Шаг 3: поделиться игрой

  • С другом: просто отправьте файл .html (почта, мессенджер, флешка). Yop2D ему не нужен.
  • На itch.io: переименуйте файл в index.html, положите его в архив .zip, загрузите архив на свою страницу itch.io и отметьте «This file will be played in the browser». Игра будет запускаться прямо на странице.
  • Игра остаётся вашей: без логотипа Yop2D, без рекламы, её можно подарить или продать.

Что работает в веб-игре

Веб-игра читает те же узлы, что и приложение для Android: физика, свет, частицы, фильтры экрана, переходы, тайлы, префабы, джойстики, поведения, tower defense, пошаговые игры, истории с выбором и сохранениями, галерея и настройки игрока… Сохранения («Сохранить переменные», ячейки 💾 истории) хранятся в браузере устройства: они остаются, если закрыть и снова открыть игру.

Если не работает

  • Нет пункта «Веб-игра (HTML)»: ваша версия Yop2D старше 1300: обновите её.
  • Белый экран или ничего не движется: откройте файл в Chrome, а не в просмотрщике.
  • Нет звука: коснитесь экрана один раз (браузеры ждут первого касания). На iPhone и iPad некоторые звуки могут не воспроизводиться: это ещё не проверено.
  • Сохранение пропало: оно удаляется при очистке данных браузера; в другом браузере или на другом устройстве его тоже нет.
  • Что-то работает не так, как в приложении: веб-игра — новинка. Напишите нам в Discord с названием узла: мы быстро исправим.
