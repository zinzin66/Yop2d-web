Как сделать меню с кнопками, переключателем и ползунком?

Руководство для новичков · без кода

Français · English · Español · Deutsch · Italiano · Português · Русский · 中文 · 日本語

Игровому меню нужны красивые кнопки и настройки: переключатель для звука, ползунок для громкости, счётчик для очков. В Yop2D каждый элемент — один объект с текстом внутри, а весь его вид настраивается в одном окне. Можно также скачать пример UI kit (вкладка «Примеры»): он показывает все элементы.

Тебе понадобится:
  • проект, открытый в редакторе;
  • пример «UI kit», если хочешь сначала увидеть результат (необязательно).

Шаг 1: добавь элемент

  1. Нажми + в редакторе, затем раздел Элементы интерфейса.
  2. Выбери: Кнопка, Переключатель, Флажок, Ползунок, Панель или Счётчик.
  3. Элемент появится в центре экрана: двигай его пальцем и меняй размер маркерами, как любой объект.
👉 Текст кнопки находится внутри неё: пиши его в Инспекторе, больше не нужно класть текст поверх кнопки.

Шаг 2: измени стиль

  1. Выбери элемент и нажми Стиль элемента… в Инспекторе.
  2. В разделе Форма выбери прямоугольник, скруглённый, пилюлю, круг, срезанные углы или шестиугольник.
  3. В разделе Картинка выбери Внутри формы (картинка сохраняет форму), Заменяет форму (картинка И ЕСТЬ кнопка) или Значок + текст.
  4. В разделе Цвета и контур настрой цвет, градиент, контур, тень и свечение (неон).
  5. В разделе Текст выбери шрифт, размер, цвет и контур букв.

Шаг 3: задай поведение

  1. В разделе Поведение включи Остаётся нажатой (ВКЛ / ВЫКЛ) для кнопки, которая хранит своё состояние.
  2. Выбери звук при касании и, если хочешь, вибрацию.
  3. Для ползунка задай минимальное значение, максимальное значение и начальное значение.
👉 Отключённый (серый) элемент больше не реагирует на касание: удобно для кнопки «Продолжить», которая пока недоступна.

Шаг 4: читай значение в игре

  1. Переключатель или флажок равен минимальному значению (выключен) или максимальному (включён); ползунок равен своему положению.
  2. В формуле пиши имя_объекта.progression: например «=volume.progression» в «Изменить свойство» текста, чтобы показать громкость.
  3. Для кнопки добавь событие «Клик по объекту» в Blueprint и выбери свою кнопку.

Старые кнопки Yop2D продолжают работать: новые элементы добавляются и ничего не заменяют.
