Как собирать монеты и считать очки?

Руководство для новичков · без кода

Français · English · Español · Deutsch · Italiano · Português · Русский · 中文 · 日本語

Когда игрок касается монеты, нужно три вещи: монета исчезает, счёт растёт на 1, а новый счёт появляется на экране.

Тебе понадобится:
  • персонаж с именем player, который умеет двигаться (см. Как двигать персонажа);
  • несколько монет: объекты Круг (или картинки), например coin1, coin2, coin3;
  • объект Текст с именем scoreText вверху экрана, с текстом «Счёт: 0».

Шаг 1: дать всем монетам один тег

Тег — это метка. Благодаря ему один кусочек Blueprint работает для всех монет, даже если их 50.

  1. Выбери монету.
  2. В инспекторе, поле «Тег (Метка)», впиши piece.
  3. Сделай так для каждой монеты (кнопка «Список» рядом с полем предлагает уже использованные теги).

Шаг 2: создать переменную «score»

Переменная — это ячейка, которая хранит число во время игры.

  1. На левой панели открой раздел Переменные и создай переменную.
  2. Имя: score · Область: Локальная · Тип: Целое · Начальное значение: 0.
👉 Локальная — переменная есть только в этой сцене. Выбери Глобальная, если счёт должен сохраняться на следующем уровне (см. Как перейти на следующий уровень).

Шаг 3: Blueprint

  1. Открой Blueprint сцены.
  2. Добавь событие «Если объект касается тега»: цель player, Тег piece.
  3. Добавь «Уничтожить объект». В качестве цели выбери Объект, участвующий в событии: это монета, которой только что коснулся игрок.
  4. Добавь «Добавить к переменной»: переменная score, Добавляемое значение = 1.
  5. Добавь «Изменить текст»: цель scoreText, Новый текст = ="Счёт: " + score
  6. Соедини четыре узла по порядку, выход со входом.
  7. Сохрани, запусти игру и коснись монеты.

👉 Знак = в начале текста говорит Yop2D вычислить текст, а не написать его как есть. Без него на экране будет дословно "Счёт: " + score. В кавычках — часть, которая не меняется.
👉 Событие срабатывает один раз за касание: если стоять на монете, очки не накручиваются.

Бонус: победа, когда собраны все монеты

  1. После «Изменить текст» добавь узел «Условие» с Условие = =score >= 3 (3 — число монет).
  2. Соедини его выход Истина с узлом «Короткое сообщение внизу экрана» с сообщением Победа! или с «Следующая сцена».

Если не работает

  • Монета не исчезает: проверь, что тег везде написан одинаково (piece) и что цель «Уничтожить объект» — задетый объект.
  • Текст показывает формулу: не хватает = в начале.
  • Счёт остаётся 0: проверь, что «Добавить к переменной» использует переменную score.
  • Для сравнения открой пример «Платформер», который идёт с Yop2D: он собирает монеты именно так.
