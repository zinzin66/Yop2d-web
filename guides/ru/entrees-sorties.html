Входы и выходы узлов

Руководство для новичков · без кода

Français · English · Español · Deutsch · Italiano · Português · Русский · 中文 · 日本語

У узла есть кружки: это его входы и выходы. Провода между ними показывают, в каком порядке выполняются узлы. Простое правило: у выхода один провод, у входа может быть несколько.

Кружки узла

Слева — кружок входа (Вход): через него узел получает приказ выполниться. Справа — кружки выходов (например, Дальше): через них узел передаёт эстафету следующему. У некоторых узлов несколько выходов, например у Условие есть Истина и Ложь.

К выходу идёт только один провод

Если потянуть новый провод от уже соединённого выхода, он заменит старый. Значит, выход может вести только в одно место.

Вход принимает несколько проводов

  1. Протяни провод от первого выхода к кружку входа нужного узла.
  2. Протяни второй провод от другого выхода (или от другого узла) к тому же кружку входа.
  3. Первый провод остаётся на месте: узел выполнится, как только до него дойдёт любой из этих путей.
👉 Пример: у обратного отсчёта есть выход, срабатывающий каждую секунду, и другой — по окончании. Соедини оба с одним узлом, который меняет текст: время покажется в обоих случаях, и узел не придётся делать дважды.

Текст окна { }

В окне { } Blueprint скрипт записан текстом. Если в узел приходят два пути, он описывается один раз; другой путь заканчивается стрелкой ↩, которая значит «этот узел уже описан выше».

👉 Чтобы убрать провод, коснись его. Чтобы провести его в другое место, потяни новый от выхода.
