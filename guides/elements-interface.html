Comment faire un menu avec des boutons, un interrupteur et un curseur ?

Guide débutant · sans code

Français · English · Español · Deutsch · Italiano · Português · Русский · 中文 · 日本語

Un menu de jeu a besoin de boutons jolis et de réglages : un interrupteur pour le son, un curseur pour le volume, un compteur pour le score. Dans Yop2D, chaque élément est un seul objet avec son texte dedans, et tout son aspect se règle dans une seule fenêtre. Tu peux aussi télécharger l'exemple UI kit (onglet Exemples) : il montre tous les éléments.

Il te faut :
  • un projet ouvert dans l'éditeur ;
  • l'exemple « UI kit » si tu veux voir le résultat avant de commencer (facultatif).

Étape 1 : ajoute un élément

  1. Touche le + de l'éditeur, puis la section Éléments d'interface.
  2. Choisis parmi : Bouton, Interrupteur, Case à cocher, Curseur, Panneau et Compteur.
  3. L'élément arrive au centre de l'écran : déplace-le avec le doigt et agrandis-le avec les poignées, comme n'importe quel objet.
👉 Le texte d'un bouton est dedans : écris-le dans l'Inspecteur, plus besoin de poser un texte par-dessus le bouton.

Étape 2 : change son style

  1. Sélectionne l'élément et touche Style de l'élément… dans l'Inspecteur.
  2. Dans Forme, choisis rectangle, arrondi, pilule, rond, coins coupés ou hexagone.
  3. Dans Image, choisis Dans la forme (l'image garde la forme), Remplace la forme (l'image EST le bouton) ou Icône + texte.
  4. Dans Couleurs et contour, règle la couleur, le dégradé, le contour, l'ombre et le halo lumineux (néon).
  5. Dans Texte, choisis la police, la taille, la couleur et le contour des lettres.

Étape 3 : donne-lui un comportement

  1. Dans Comportement, active Reste enfoncé (ON / OFF) pour un bouton qui garde son état.
  2. Choisis un son au toucher et, si tu veux, une vibration.
  3. Pour un curseur, règle la valeur minimale, la valeur maximale et la valeur de départ.
👉 Un élément désactivé (grisé) ne réagit plus au toucher : pratique pour un bouton « Continuer » qui n'est pas encore disponible.

Étape 4 : lis la valeur dans le jeu

  1. Un interrupteur ou une case vaut sa valeur minimale (éteint) ou maximale (allumé) ; un curseur vaut sa position.
  2. Dans une formule, écris nom_de_l_objet.progression : par exemple « =volume.progression » dans « Modifier une propriété » du texte pour afficher le volume.
  3. Pour un bouton, ajoute l'événement « Au Clic sur Objet » dans le Blueprint et choisis ton bouton.

Les anciens boutons de Yop2D continuent de fonctionner : ces nouveaux éléments s'ajoutent, ils ne remplacent rien.
