Como fazer um Pong?

Guia para iniciantes · sem código

Français · English · Español · Deutsch · Italiano · Português · Русский · 中文 · 日本語

Em um Pong, uma bola rebate entre a sua raquete (embaixo) e a de um robô (em cima). Quando a bola passa atrás de uma raquete, o outro jogador marca um ponto. Como no guia do quebra-tijolos, a bola se move graças a duas variáveis: vx (sua velocidade para os lados) e vy (sua velocidade para cima ou para baixo).

Você precisa de:
  • uma Imagem chamada Ball, no meio da tela (por exemplo 60 x 60 px);
  • uma Imagem chamada Player, embaixo (por exemplo 200 x 80 px, perto de y = 1690);
  • uma Imagem chamada Bot, em cima (mesmo tamanho, y = 140);
  • dois objetos Texto chamados ScorePlayer e ScoreBot, com o texto 0;
  • quatro Zonas chamadas WallLeft, WallRight, GoalPlayer e GoalBot.
👉 Este guia é escrito para um jogo em retrato de 1080 x 1920. Para as imagens, use o pacote gratuito Puzzle (quebra-tijolos) (Kenney, livre de direitos, CC0) na Biblioteca, aba Pacotes para baixar: paddleBlu (sua raquete), paddleRed (o robô), ballBlue (a bola). Você também pode usar seus próprios desenhos.

Passo 1: os nomes, os comportamentos e as variáveis

  1. Selecione cada objeto e escreva o nome dele no inspetor, exatamente como na lista acima. Um nome com espaço ou com outra letra não será encontrado pelos nós.
  2. Selecione Ball, toque em ⚙ Comportamento do objeto e escolha Cenário. Faça o mesmo com Player e Bot: só os nós vão movê-los.
  3. Na seção Variáveis, crie duas variáveis do tipo Número, escopo Local: vx e vy, valor inicial 0. Crie mais duas do tipo Inteiro, escopo Local: scorePlayer e scoreBot, valor inicial 0.
👉 O erro mais comum: um nome esquecido ou um comportamento esquecido. Nada quebra, mas nada acontece. Se o seu jogo não faz nada, confira primeiro este passo.

Passo 2: as paredes e os gols

A bola rebate em paredes que não se veem: quatro Zonas colocadas em volta da tela. Uma zona é invisível durante o jogo, mas a bola pode tocá-la.

  1. Adicione uma Zona chamada WallLeft: X = -300, Y = -400, largura 300, altura 2800.
  2. Adicione uma Zona chamada WallRight: X = 1080, Y = -400, largura 300, altura 2800.
  3. Adicione uma Zona chamada GoalBot: X = -300, Y = -300, largura 1680, altura 300 (acima da tela).
  4. Adicione uma Zona chamada GoalPlayer: X = -300, Y = 1920, largura 1680, altura 300 (abaixo da tela).
👉 As paredes são grossas de propósito: uma bola rápida não consegue atravessá-las. As duas paredes devolvem a bola; os dois gols vão contar os pontos.

Passo 3: a bola sai e avança

  1. Adicione o evento “Ao Iniciar”, depois dois nós “Modificar Variável” em sequência: variável vx, valor 6, depois variável vy, valor 9.
  2. Adicione o evento “A cada frame”, depois “Empurrar objeto”: alvo Ball, Adicionar X = vx, Adicionar Y = vy. Basta escrever os dois nomes nos campos.

👉 Como ela avança? “A cada frame” acontece cerca de 60 vezes por segundo. A cada vez, a bola avança vx pixels para o lado e vy pixels para cima ou para baixo. Com 0 e 0, ela para. Para mudar a direção, só mudamos esses dois números: é o que os rebotes vão fazer.

Passo 4: minha raquete segue meu dedo

  1. Adicione o evento “Dedo pressionado”: ele se repete enquanto seu dedo está na tela.
  2. Adicione “Mover Objeto”: alvo Player, X = doigt.x - Player.largeur / 2, Y = 1690. A posição do dedo está na lista à esquerda da janela de ajustes; tiramos metade da largura da raquete para o dedo ficar no centro dela.
  3. Adicione “Manter na tela”: alvo Player, Margem = 0, para a raquete não sair pelos lados.

Passo 5: os rebotes

Um rebote é só um número novo para vx ou vy. Usamos random(a, b), que escolhe um número entre a e b: nenhum rebote é igual.

  1. “Colisão A/B” (Objeto A = WallLeft, Objeto B = Ball) → “Modificar Variável”: vx = random(4, 12). Um número positivo: a bola vai para a direita.
  2. “Colisão A/B” (WallRight, Ball) → “Modificar Variável”: vx = -random(4, 12). O sinal de menos o deixa negativo: a bola vai para a esquerda.
  3. “Colisão A/B” (Ball, Player) → “Modificar Variável”: vy = random(-13, -9) (a bola sobe), depois “Modificar Variável”: vx = Ball.x / 10 - Player.x / 10 - 7.
  4. “Colisão A/B” (Ball, Bot) → “Modificar Variável”: vy = random(9, 13) (a bola desce), depois “Modificar Variável”: vx = random(-6, 6).

👉 Por que esse cálculo para a raquete? Ele compara a posição da bola com a da raquete: no centro, a bola sai reta; perto de uma borda, sai para o lado. O -7 compensa o fato de a raquete ser mais larga que a bola (assim o centro dá 0).

Passo 6: o robô persegue a bola

O robô não é esperto: a cada imagem, ele se aproxima um pouco da bola.

  1. Adicione o evento “A cada frame”, depois “Modificar uma propriedade”: alvo Bot, Propriedade = x, Valor = Bot.x * 0.94 + Ball.x * 0.06 - 6.
  2. Adicione “Manter na tela”: alvo Bot, Margem = 0.
A cada frame
→
Modificar uma propriedadeBot · x
→
Manter na telaBot · 0
👉 Como funciona? O robô mantém 94 % do seu lugar e pega 6 % do lugar da bola (o - 6 o centraliza na bola). Com 0.06, ele é lento o bastante para ser vencido. Experimente 0.03 e 0.97 (muito fácil) ou 0.15 e 0.85 (muito difícil): os dois números devem somar 1, e o - 6 vira - 3 ou - 15.
👉 Atenção: não escreva uma posição em “velocidade X”. Uma velocidade é um número pequeno, uma posição é um número grande: o robô não se moveria.

Passo 7: os gols e os placares

  1. “Colisão A/B” (GoalBot, Ball) → “Adicionar à Variável”: variável scorePlayer, Valor a adicionar = 1 → “Modificar Texto”: alvo ScorePlayer, Novo texto = =scorePlayer.
  2. O mesmo para o robô: “Colisão A/B” (GoalPlayer, Ball) → “Adicionar à Variável”: scoreBot + 1 → “Modificar Texto”: alvo ScoreBot, =scoreBot.
  3. Para recolocar em jogo, adicione em sequência: “Modificar Variável” vx = 0, “Modificar Variável” vy = 0, “Mover Objeto” Ball para X = 510, Y = 930, “Esperar” 1 segundo, depois “Modificar Variável” vx = 6 e “Modificar Variável” vy = 9.
  4. Ligue o fim dos dois gols ao primeiro nó dessa recolocação: uma entrada pode receber vários fios.

👉 O sinal = no começo do texto diz ao Yop2D para calcular o valor em vez de escrevê-lo como está (veja o guia Coletar moedas e contar pontos).

Para ir mais longe

  • Ganhar com 5 pontos: depois de cada gol, adicione uma “Condição” =scorePlayer >= 5, depois um “Mensagem curta embaixo da tela” e “Reiniciar a cena” (veja o guia Vidas e Game Over).
  • Sons: adicione “Tocar som” depois de cada rebote.
  • Seu estilo: troque as imagens e o fundo; os nomes continuam os mesmos.
  • O jogo não faz nada? Volte ao passo 1: falta um nome ou um comportamento. O robô não se move? Confira se o comportamento dele é Cenário e se a fórmula está em Valor.
