Como transformar meu jogo em um jogo web (HTML)?

Guia para iniciantes · sem código

Français · English · Español · Deutsch · Italiano · Português · Русский · 中文 · 日本語 · العربية

ℹ️ Exige a versão 1300 do Yop2D ou mais recente (o último número da versão, por exemplo 1.0.1300). Se a sua versão for mais antiga, atualize o Yop2D.

Desde a versão 1300, o Yop2D sabe criar um jogo web: o jogo inteiro (imagens, sons, nós) cabe em um único arquivo .html. Esse arquivo roda em um navegador (recomendado: Chrome), no celular, tablet ou computador, sem instalar nada e sem internet.

Você precisa de:
  • Yop2D versão 1300 ou mais recente;
  • um jogo que funciona quando você testa com ▶ no editor;
  • o navegador Chrome no aparelho que vai jogar (recomendado).

Passo 1: criar o arquivo

  1. Na tela inicial, toque no seu projeto para escolhê-lo.
  2. Toque em Build APK. Abre-se uma janela Criar o jogo.
  3. Escolha Jogo web (HTML).
  4. Escolha onde salvar o arquivo (por exemplo Downloads) e espere a mensagem “Seu jogo web está pronto!”.
👉 O arquivo contém o jogo inteiro: um jogo com muitas imagens ou músicas gera um arquivo maior (muitas vezes de 1 a 5 MB).

Passo 2: jogar

  1. Abra o arquivo com o Chrome (gerenciador de arquivos → Downloads → toque no arquivo → Chrome).
  2. O jogo começa. Toque na tela uma vez: o som e a tela cheia são ativados.
  3. No computador, joga-se com o mouse; a tecla Esc funciona como o botão voltar do celular.
👉 Alguns aplicativos (mensagens, visualizadores de arquivos) abrem o arquivo numa janela pequena que recusa a tela cheia: o jogo avisa em laranja. Abra então com o Chrome.

Passo 3: compartilhar seu jogo

  • Com um amigo: basta enviar o arquivo .html (e-mail, mensagens, pen drive). Ele não precisa do Yop2D.
  • No itch.io: renomeie o arquivo para index.html, coloque-o num arquivo .zip, envie esse zip para sua página do itch.io e marque “This file will be played in the browser”. O jogo roda direto na página.
  • Seu jogo continua sendo seu: sem logo do Yop2D, sem anúncios, você pode dar ou vender.

O que funciona no jogo web

O jogo web lê os mesmos nós do aplicativo Android: física, luzes, partículas, filtros de tela, transições, tiles, prefabs, joysticks, comportamentos, tower defense, jogos por turnos, histórias com escolhas e saves, galeria e ajustes do jogador… Os saves (“Salvar as variáveis”, espaços 💾 de uma história) ficam no navegador do aparelho: continuam lá quando você fecha e abre o jogo de novo.

Se não funcionar

  • Não aparece “Jogo web (HTML)”: sua versão do Yop2D é anterior à 1300: atualize.
  • Tela branca ou nada se mexe: abra o arquivo com o Chrome, não com um visualizador.
  • Sem som: toque na tela uma vez (os navegadores esperam um primeiro toque). No iPhone e no iPad alguns sons podem não tocar: este caso ainda não foi verificado.
  • O save sumiu: ele é apagado se os dados do navegador forem limpos; também não existe em outro navegador ou outro aparelho.
  • Algo funciona diferente do aplicativo: o jogo web é novo. Conte para nós no Discord com o nome do nó: corrigimos rápido.
