As entradas e as saídas dos nós

Guia para iniciantes · sem código

Français · English · Español · Deutsch · Italiano · Português · Русский · 中文 · 日本語

Um nó tem círculos: são as suas entradas e saídas. Os fios que os ligam dizem em que ordem os nós são executados. Uma regra simples: uma saída tem um só fio, uma entrada pode ter vários.

Os círculos de um nó

À esquerda, o círculo de entrada (Entrar): é por aí que o nó recebe a ordem de executar. À direita, os círculos de saída (por exemplo Próximo): é por aí que o nó passa a vez ao seguinte. Alguns nós têm várias saídas, como uma Condição com Verdadeiro e Falso.

Uma saída aceita só um fio

Se puxares um fio novo de uma saída que já está ligada, o novo substitui o antigo. Por isso uma saída só pode levar a um sítio.

Uma entrada aceita vários fios

  1. Puxa um fio de uma primeira saída até ao círculo de entrada do nó que queres.
  2. Puxa um segundo fio de outra saída (ou de outro nó) até ao mesmo círculo de entrada.
  3. O primeiro fio fica onde está: o nó é executado assim que um desses caminhos chega a ele.
👉 Exemplo: uma contagem decrescente tem uma saída que dispara a cada segundo e outra quando termina. Liga as duas ao mesmo nó que muda um texto: o tempo aparece nos dois casos, sem criar o nó duas vezes.

O texto da janela { }

Na janela { } do Blueprint, o script é escrito em texto. Quando um nó recebe dois caminhos, é descrito só uma vez; o outro caminho termina com uma seta ↩, que quer dizer “este nó já foi descrito mais acima”.

👉 Para cortar um fio, toca nele. Para o refazer noutro sítio, puxa um novo a partir da saída.
