Come trasformo il mio gioco in un gioco web (HTML)?

Guida per principianti · senza codice

Français · English · Español · Deutsch · Italiano · Português · Русский · 中文 · 日本語 · العربية

ℹ️ Richiede la versione 1300 di Yop2D o successiva (l'ultimo numero della versione, per esempio 1.0.1300). Se la tua versione è più vecchia, aggiorna Yop2D.

Dalla versione 1300, Yop2D sa creare un gioco web: tutto il gioco (immagini, suoni, nodi) sta in un solo file .html. Questo file si gioca in un browser (consigliato Chrome), su telefono, tablet o computer, senza installare nulla e senza internet.

Ti serve:
  • Yop2D versione 1300 o più recente;
  • un gioco che funziona quando lo provi con ▶ nell'editor;
  • il browser Chrome sul dispositivo che giocherà (consigliato).

Passo 1: crea il file

  1. Nella schermata iniziale, tocca il tuo progetto per sceglierlo.
  2. Tocca Crea APK. Si apre una finestra Crea il gioco.
  3. Scegli Gioco web (HTML).
  4. Scegli dove salvare il file (per esempio Download) e aspetta il messaggio «Il tuo gioco web è pronto!».
👉 Il file contiene tutto il gioco: un gioco con molte immagini o musiche dà un file più grande (spesso da 1 a 5 MB).

Passo 2: gioca

  1. Apri il file con Chrome (gestore file → Download → tocca il file → Chrome).
  2. Il gioco parte. Tocca lo schermo una volta: si attivano il suono e lo schermo intero.
  3. Sul computer si gioca con il mouse; il tasto Esc fa come il tasto indietro del telefono.
👉 Alcune app (messaggistica, visualizzatori di file) aprono il file in una piccola finestra che rifiuta lo schermo intero: il gioco lo scrive in arancione. Aprilo allora con Chrome.

Passo 3: condividi il tuo gioco

  • Con un amico: invia semplicemente il file .html (e-mail, messaggistica, chiavetta USB). Non gli serve Yop2D.
  • Su itch.io: rinomina il file in index.html, mettilo in un file .zip, carica lo zip sulla tua pagina itch.io e spunta «This file will be played in the browser». Il gioco si gioca direttamente sulla pagina.
  • Il gioco resta tuo: niente logo Yop2D, niente pubblicità, puoi regalarlo o venderlo.

Cosa funziona nel gioco web

Il gioco web legge gli stessi nodi dell'app Android: fisica, luci, particelle, filtri dello schermo, transizioni, tile, prefab, joystick, comportamenti, tower defense, giochi a turni, storie a scelte con salvataggi, galleria e impostazioni del giocatore… I salvataggi («Salva le variabili», caselle 💾 di una storia) restano nel browser del dispositivo: ci sono ancora quando chiudi e riapri il gioco.

Se non funziona

  • Manca la scelta «Gioco web (HTML)»: la tua versione di Yop2D è precedente alla 1300: aggiornala.
  • Schermo bianco o niente si muove: apri il file con Chrome, non con un visualizzatore.
  • Niente suono: tocca lo schermo una volta (i browser aspettano un primo tocco). Su iPhone e iPad alcuni suoni potrebbero non partire: questo caso non è ancora verificato.
  • Il salvataggio è sparito: si cancella se svuoti i dati del browser; non esiste nemmeno in un altro browser o su un altro dispositivo.
  • Qualcosa funziona diversamente dall'app: il gioco web è nuovo. Diccelo su Discord con il nome del nodo: lo correggiamo in fretta.
