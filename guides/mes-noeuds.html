Comment créer ses propres nœuds ?

Guide débutant · sans code

Français · English · Español · Deutsch · Italiano · Português · Русский · 中文 · 日本語 · العربية

ℹ️ Demande la version 1281 de Yop2D ou plus récente (le dernier nombre du numéro de version, par exemple 1.0.1281). Si ta version est plus ancienne, mets Yop2D à jour.

Quand tu fais plusieurs fois la même suite de nœuds (par exemple : un ennemi qui clignote, fait un son et perd de la vie), tu peux la ranger dans un seul nœud à toi. Tu l'écris une fois, puis tu le lances partout, avec des réglages qui changent d'un endroit à l'autre (la vitesse, le message, l'objet visé…).

Il te faut :
  • un projet ouvert dans l'éditeur ;
  • une petite suite de nœuds que tu aimerais réutiliser.

Étape 1 : créer ton nœud

  1. Dans l'éditeur, ouvre le panneau Ressources et trouve la partie Mes nœuds.
  2. Touche + et donne-lui un nom, par exemple Coup_subi.
  3. Sélectionne-le et touche l'icône du Blueprint : tu arrives sur un Blueprint vide, réservé à ce nœud.
  4. Construis ta suite de nœuds comme d'habitude, puis enregistre (💾). Le titre du Blueprint indique Mon nœud : Coup_subi.

Étape 2 : lui donner des réglages

  1. Dans le Blueprint de ton nœud, touche le bouton Réglages de mon nœud (en haut).
  2. Touche + Ajouter une entrée : donne-lui un nom (par exemple vitesse), choisis son type et sa valeur de départ.
  3. Dans les nœuds de ton nœud, écris le nom de l'entrée dans une formule : =vitesse.
  4. Pour une entrée de type Nombre, c'est un nombre ; Texte, un message ; Oui / non, une case ; Objet, le nom d'un objet de la scène.
👉 Le type Objet : celui qui lance ton nœud choisit sur quel objet il agit. Dans les nœuds de ton nœud, ouvre Sur quoi ? : un groupe Réglages de mon nœud propose « Entrée … de mon nœud ». Un même nœud peut ainsi faire clignoter un ennemi, un coffre ou le héros.

Étape 3 : le poser dans un Blueprint

  1. Ouvre le Blueprint d'une scène.
  2. Dans le panneau des nœuds, la catégorie Mes nœuds est en tête de la liste : touche ton nœud.
  3. Un nœud Lancer un de mes nœuds arrive déjà réglé sur le tien, avec une ligne pour chaque réglage : remplis-les (un nombre, une formule, un nom d'objet…).

Étape 4 : partager un nœud

  1. Ouvre le Blueprint de ton nœud et touche le bouton de sélection ⬚, puis sélectionne tous les nœuds (cadre dans le vide).
  2. Touche ⧉ Copier, et colle le résultat dans un message pour ton ami.
  3. Ton ami crée un nœud vide, ouvre son Blueprint, touche « { } » et colle : la suite apparaît.
👉 Le partage emporte les nœuds, pas les images ni les sons qu'ils utilisent : envoie-les à part. Les réglages (entrées) se recréent avec le bouton Réglages de mon nœud.

Si ça ne marche pas

  • Mon nœud n'apparaît pas dans le menu : il faut qu'il soit enregistré ; ferme et rouvre le Blueprint pour rafraîchir la liste.
  • Ma ligne de réglage est absente : ouvre la fenêtre du nœud « Lancer un de mes nœuds » : les lignes se mettent à jour quand tu changes de nœud.
  • Rien ne se passe : ton nœud doit commencer par un nœud relié à la suite, et le nœud d'appel doit être relié à un événement.
