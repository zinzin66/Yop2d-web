Comment ajouter des particules et des effets ?

Guide débutant · sans code

Français · English · Español · Deutsch · Italiano · Português · Русский · 中文 · 日本語

Yop2D fait des particules de deux façons : le nœud « Effet de particules » lance une gerbe d'un seul coup (parfait pour une explosion), et l'objet Particules en produit sans arrêt (feu, fumée, pluie, traînée…). Des nœuds ajoutent aussi des effets sur tout l'écran : flash, teinte, bords assombris et fondu.

Il te faut :
  • un jeu qui marche, avec un personnage nommé player qui peut se déplacer ;
  • des ennemis qui portent le tag ennemi.
👉 Pour voir tous ces effets en action, ouvre l'exemple Neon shooter sur l'écran d'accueil de Yop2D.

Étape 1 : une explosion quand on touche un ennemi

  1. Ouvre le Blueprint de la scène.
  2. Ajoute l'événement « Si objet touche Tag » : cible player, Tag ennemi.
  3. Ajoute « Effet de particules ». Comme cible, choisis L'objet impliqué dans l'événement : c'est l'ennemi que le joueur vient de toucher. Modèle : Explosion.
  4. Ajoute « Détruire Objet », avec la même cible L'objet impliqué dans l'événement.
  5. Relie les trois nœuds dans l'ordre, puis lance le jeu et touche un ennemi : il explose avant de disparaître.

⚠️ L'ordre compte : « Effet de particules » doit venir avant « Détruire Objet ». Une fois l'ennemi détruit, il n'y a plus d'objet sur lequel placer l'explosion.
👉 Tu peux changer la couleur (par exemple #FF40D0 pour une explosion magenta) et la taille (2 = deux fois plus grosse). Essaie aussi Étincelles, Confettis ou Fumée.

Étape 2 : un sillage derrière le personnage

  1. Ajoute un objet : dans la catégorie Effets, choisis Particules. Dans l'éditeur, il apparaît comme une zone orange en pointillés ; dans le jeu, il est invisible.
  2. Dans l'inspecteur, section PARTICULES, touche Modèle : et choisis Sillage.
  3. Toujours dans l'inspecteur, touche le bouton Parent : Aucun et choisis player : l'objet suivra le personnage partout.
  4. Place-le juste derrière le personnage, puis lance le jeu et déplace-toi : une longue traînée lumineuse suit le personnage.
👉 Rien à mettre dans le Blueprint : un objet Particules fonctionne tout seul tant que la case Actif dès le début du jeu est cochée. Pour l'allumer ou l'éteindre pendant le jeu, utilise le nœud « Allumer / éteindre les particules ».
  • Feu : une torche ou un feu de camp.
  • Fumée : au-dessus d'une cheminée.
  • Pluie ou Neige : étire l'objet sur tout le haut de l'écran.
  • Hyperespace et Lignes de vitesse : pour donner une impression de grande vitesse.

Étape 3 : des effets sur tout l'écran

  • « Flash de l'écran » : un éclair de couleur. Par exemple rouge, 0,5 seconde, juste après que le joueur a été touché.
  • « Teinte de l'écran » : une couleur sur tout le jeu. Bleu foncé à 55 % pour la nuit, et une intensité de 0 pour revenir au jour.
  • « Bords assombris » : les bords de l'écran foncent, comme au cinéma.
  • « Fondu de l'écran » : l'écran devient noir, puis réapparaît.

Si ça ne marche pas

  • L'explosion n'apparaît pas : vérifie que « Effet de particules » est placé avant « Détruire Objet ».
  • Le sillage ne suit pas le personnage : vérifie que l'objet Particules a bien player comme parent, et que la case Actif dès le début du jeu est cochée.
  • Les particules n'ont pas la bonne couleur : la couleur « Aucune » garde les couleurs du modèle ; choisis une vraie couleur pour les changer.
  • L'écran reste noir : après un « Fondu de l'écran » Disparaître (vers la couleur), il faut un « Fondu de l'écran » Apparaître (depuis la couleur).
