Las entradas y las salidas de los nodos

Guía para principiantes · sin código

Français · English · Español · Deutsch · Italiano · Português · Русский · 中文 · 日本語

Un nodo tiene círculos: son sus entradas y sus salidas. Los cables que los unen indican en qué orden se ejecutan los nodos. Una regla sencilla: una salida tiene un solo cable, una entrada puede tener varios.

Los círculos de un nodo

A la izquierda, el círculo de entrada (Entrar): por ahí el nodo recibe la orden de ejecutarse. A la derecha, los círculos de salida (por ejemplo Siguiente): por ahí el nodo pasa el turno al siguiente. Algunos nodos tienen varias salidas, como una Condición con Verdadero y Falso.

Una salida admite un solo cable

Si tiras un cable nuevo desde una salida que ya está conectada, el nuevo sustituye al anterior. Así que una salida solo puede llevar a un sitio.

Una entrada admite varios cables

  1. Tira un cable desde una primera salida hasta el círculo de entrada del nodo que quieras.
  2. Tira un segundo cable desde otra salida (o desde otro nodo) hasta el mismo círculo de entrada.
  3. El primer cable se queda donde está: el nodo se ejecuta en cuanto uno de esos caminos llega hasta él.
👉 Ejemplo: una cuenta atrás tiene una salida que se activa cada segundo y otra cuando termina. Conecta las dos al mismo nodo que cambia un texto: el tiempo se muestra en ambos casos, sin crear el nodo dos veces.

El texto de la ventana { }

En la ventana { } del Blueprint, el script se escribe como texto. Cuando a un nodo llegan dos caminos, solo se describe una vez; el otro camino termina con una flecha ↩, que significa «este nodo ya se describió más arriba».

👉 Para cortar un cable, tócalo. Para rehacerlo en otro sitio, tira uno nuevo desde la salida.
