¿Cómo convertir mi juego en un juego web (HTML)?

Guía para principiantes · sin código

Français · English · Español · Deutsch · Italiano · Português · Русский · 中文 · 日本語 · العربية

ℹ️ Requiere la versión 1300 de Yop2D o una más reciente (el último número de la versión, por ejemplo 1.0.1300). Si tu versión es anterior, actualiza Yop2D.

Desde la versión 1300, Yop2D puede crear un juego web: todo tu juego (imágenes, sonidos, nodos) cabe en un solo archivo .html. Este archivo se juega en un navegador (se recomienda Chrome), en un teléfono, una tableta o un ordenador, sin instalar nada y sin internet.

Necesitas:
  • Yop2D versión 1300 o más reciente;
  • un juego que funcione cuando lo pruebas con ▶ en el editor;
  • el navegador Chrome en el dispositivo que va a jugar (recomendado).

Paso 1: crear el archivo

  1. En la pantalla de inicio, toca tu proyecto para elegirlo.
  2. Toca Build APK. Se abre una ventana Crear el juego.
  3. Elige Juego web (HTML).
  4. Elige dónde guardar el archivo (por ejemplo Descargas) y espera el mensaje «¡Tu juego web está listo!».
👉 El archivo contiene todo el juego: un juego con muchas imágenes o músicas da un archivo más grande (a menudo de 1 a 5 MB).

Paso 2: jugar

  1. Abre el archivo con Chrome (gestor de archivos → Descargas → toca el archivo → Chrome).
  2. El juego empieza. Toca la pantalla una vez: se activan el sonido y la pantalla completa.
  3. En un ordenador se juega con el ratón; la tecla Esc hace lo mismo que el botón atrás del teléfono.
👉 Algunas aplicaciones (mensajería, visores de archivos) abren el archivo en una ventana pequeña que no permite la pantalla completa: el juego lo indica en naranja. Ábrelo entonces con Chrome.

Paso 3: compartir tu juego

  • Con un amigo: envía simplemente el archivo .html (correo, mensajería, memoria USB). No necesita Yop2D.
  • En itch.io: cambia el nombre del archivo a index.html, ponlo en un archivo .zip, sube ese zip a tu página de itch.io y marca «This file will be played in the browser». Tu juego se juega directamente en la página.
  • Tu juego es tuyo: sin logo de Yop2D, sin publicidad, puedes regalarlo o venderlo.

Qué funciona en el juego web

El juego web lee los mismos nodos que la aplicación Android: física, luces, partículas, filtros de pantalla, transiciones, mosaicos, prefabs, joysticks, comportamientos, tower defense, juegos por turnos, historias con elecciones y partidas guardadas, galería y ajustes del jugador… Las partidas guardadas («Guardar las variables», casillas 💾 de una historia) se conservan en el navegador del dispositivo: siguen ahí al cerrar y volver a abrir el juego.

Si no funciona

  • No aparece «Juego web (HTML)»: tu versión de Yop2D es anterior a la 1300: actualízala.
  • Pantalla blanca o nada se mueve: abre el archivo con Chrome, no con un visor.
  • No hay sonido: toca la pantalla una vez (los navegadores esperan un primer toque). En iPhone y iPad algunos sonidos pueden no reproducirse: este caso aún no se ha comprobado.
  • La partida guardada desapareció: se borra si se vacían los datos del navegador; tampoco existe en otro navegador ni en otro dispositivo.
  • Algo no funciona igual que en la aplicación: el juego web es nuevo. Dínoslo en Discord con el nombre del nodo: lo corregimos rápido.
