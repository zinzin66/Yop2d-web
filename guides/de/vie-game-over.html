Wie verliert der Spieler Leben?

Anleitung für Einsteiger · ohne Code

Français · English · Español · Deutsch · Italiano · Português · Русский · 中文 · 日本語

Der Spieler startet mit 3 Leben. Jedes Mal, wenn er eine Gefahr berührt (Stacheln, einen Gegner…), verliert er eines, und die Lebensleiste sinkt. Bei 0 heißt es Game Over: Das Level beginnt von vorn.

Du brauchst:
  • eine Figur namens player, die sich bewegen kann (siehe Eine Figur bewegen);
  • eine oder mehrere Gefahren, zum Beispiel rote Quadrate namens spikes1, spikes2…;
  • eine Lebensleiste: ein Objekt Fortschrittsbalken (Fortschrittsbalken) namens healthBar, oben auf dem Bildschirm.

Schritt 1: Gefahren und Leiste vorbereiten

  1. Wähle jede Gefahr aus und schreibe danger in ihr Feld „Tag (Etikett)“.
  2. Wähle healthBar aus. Im Bereich „FORTSCHRITTSBALKEN“ des Inspektors: Minimalwert = 0, Maximalwert = 3, Aktueller Wert = 3.

Schritt 2: die Variable „vie“ anlegen

  1. Lege im linken Bereich Variablen eine Variable an.
  2. Name: vie (Leben) · Gültigkeit: Lokal · Typ: Ganze Zahl · Startwert: 3.

Schritt 3: ein Leben verlieren

  1. Öffne den Blueprint der Szene.
  2. Füge das Ereignis „Wenn Objekt Tag berührt“ hinzu: Ziel player, Tag danger.
  3. Füge „Zu Variable hinzufügen“ hinzu: Variable vie, Hinzuzufügender Wert = -1 (mit Minuszeichen, zum Abziehen).
  4. Füge „Fortschritt festlegen“ hinzu: Ziel healthBar, Neuer Fortschritt = =vie
  5. Verbinde die drei Knoten der Reihe nach.
Wenn Objekt Tag berührtZiel: player · Tag: danger
→
Zu Variable hinzufügenvie · - 1
→
Fortschritt festlegenhealthBar · =vie
👉 =vie in „Neuer Fortschritt“ bedeutet: „nimm den Wert der Variable vie“. So folgt die Leiste immer der Zahl der Leben.

Schritt 4: das Game Over

  1. Füge nach „Fortschritt festlegen“ den Knoten „Bedingung“ hinzu, mit Bedingung = =vie <= 0 („vie kleiner oder gleich 0“).
  2. Verbinde seinen Ausgang Wahr mit dem Knoten „Szene neu starten“ (Kategorie Szene & HUD).
  3. Speichere, starte das Spiel und berühre dreimal eine Gefahr.

Szene neu starten
👉 „Szene neu starten“ setzt alles auf den Anfang zurück: die Objekte an ihren Platz und die Variablen mit der Gültigkeit „Lokal“ (also vie = 3) auf ihren Startwert.
👉 Lust auf einen echten Endbildschirm? Statt sofort neu zu starten, verbinde den Ausgang Wahr mit „Text ändern“ (ein Text „Verloren!“), dann „Warten“ (2 Sekunden), dann „Szene neu starten“.

Bonus: in die Tiefe fallen

Setze bei einem Jump'n'Run ein Objekt Zone ganz unten in die Szene, namens fallZone (eine Zone ist im Spiel unsichtbar). Dann:

Kollision A/BObjekt A: player · Objekt B: fallZone
→
Szene neu starten

Wenn es nicht klappt

  • Das Leben sinkt nicht: Prüfe den Tag danger bei jeder Gefahr und das Minuszeichen in -1.
  • Die Leiste bewegt sich nicht: Das Ziel von „Fortschritt festlegen“ muss ein Fortschrittsbalken sein, mit einem Maximum von 3.
  • Das Spiel startet nicht neu: Die Bedingung muss über ihren Ausgang Wahr verbunden sein.
