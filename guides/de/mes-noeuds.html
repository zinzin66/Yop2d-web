Wie erstellt man eigene Knoten?

Anleitung für Einsteiger · ohne Code

Français · English · Español · Deutsch · Italiano · Português · Русский · 中文 · 日本語 · العربية

ℹ️ Benötigt Yop2D ab Version 1281 (die letzte Zahl der Versionsnummer, zum Beispiel 1.0.1281). Ist deine Version älter, aktualisiere Yop2D.

Wenn du dieselbe Knotenfolge mehrfach baust (zum Beispiel: ein Gegner blinkt, macht ein Geräusch und verliert Leben), kannst du sie in einem eigenen Knoten ablegen. Du schreibst sie einmal und startest sie überall, mit Einstellungen, die sich von Ort zu Ort ändern (Tempo, Nachricht, Zielobjekt …).

Du brauchst:
  • ein im Editor geöffnetes Projekt;
  • eine kleine Knotenfolge, die du wiederverwenden möchtest.

Schritt 1: deinen Knoten erstellen

  1. Öffne im Editor das Panel Ressourcen und finde Meine Knoten.
  2. Tippe auf + und gib einen Namen, zum Beispiel Treffer_erhalten.
  3. Wähle ihn aus und tippe auf das Blueprint-Symbol: Du landest in einem leeren Blueprint nur für diesen Knoten.
  4. Baue deine Knotenfolge wie gewohnt und speichere (💾). Der Blueprint-Titel lautet Mein Knoten: Treffer_erhalten.

Schritt 2: Einstellungen hinzufügen

  1. Tippe im Blueprint deines Knotens oben auf Einstellungen meines Knotens.
  2. Tippe auf + Eingabe hinzufügen: Gib einen Namen (zum Beispiel tempo), den Typ und den Startwert an.
  3. Schreibe in den Knoten deines Knotens den Namen der Eingabe in eine Formel: =tempo.
  4. Eine Zahl-Eingabe ist eine Zahl; Text eine Nachricht; Ja / nein ein Schalter; Objekt der Name eines Objekts der Szene.
👉 Der Typ Objekt: Wer deinen Knoten startet, wählt, auf welches Objekt er wirkt. Öffne in den Knoten deines Knotens Worauf?: Eine Gruppe Einstellungen meines Knotens bietet „Eingabe … meines Knotens“. So kann derselbe Knoten einen Gegner, eine Truhe oder den Helden blinken lassen.

Schritt 3: in ein Blueprint setzen

  1. Öffne das Blueprint einer Szene.
  2. Im Knoten-Panel steht die Kategorie Meine Knoten ganz oben: Tippe auf deinen Knoten.
  3. Ein Knoten Einen meiner Knoten starten erscheint bereits auf deinen eingestellt, mit einer Zeile pro Einstellung: Fülle sie aus (Zahl, Formel, Objektname …).

Schritt 4: einen Knoten teilen

  1. Öffne das Blueprint deines Knotens, tippe auf den Auswahlknopf ⬚ und wähle alle Knoten (Rahmen im Leeren ziehen).
  2. Tippe auf ⧉ Kopieren und füge das Ergebnis in eine Nachricht für deinen Freund ein.
  3. Dein Freund erstellt einen leeren Knoten, öffnet dessen Blueprint, tippt auf „{ }“ und fügt ein: Die Folge erscheint.
👉 Beim Teilen werden die Knoten mitgenommen, nicht die Bilder und Töne, die sie nutzen: Schicke sie getrennt. Die Einstellungen (Eingaben) legst du mit Einstellungen meines Knotens neu an.

Wenn es nicht funktioniert

  • Mein Knoten fehlt im Menü: Er muss gespeichert sein; schließe das Blueprint und öffne es neu.
  • Meine Einstellungszeile fehlt: Öffne das Fenster des Knotens „Einen meiner Knoten starten“: Die Zeilen aktualisieren sich beim Knotenwechsel.
  • Nichts passiert: Dein Knoten muss mit einem verbundenen Knoten beginnen, und der Aufrufknoten muss mit einem Ereignis verbunden sein.
