Wie nutzt man Neigung und Schütteln des Handys?

Anleitung für Einsteiger · ohne Code

Français · English · Español · Deutsch · Italiano · Português · Русский · 中文 · 日本語 · العربية

ℹ️ Benötigt Yop2D ab Version 1262 (die letzte Zahl der Versionsnummer, zum Beispiel 1.0.1262). Ist deine Version älter, aktualisiere Yop2D.

Dein Handy merkt, wenn du es neigst oder schüttelst. Yop2D lässt dich das ohne Code nutzen: eine Figur, die beim Neigen läuft, eine Murmel, die durch ein Labyrinth rollt, ein Würfel, der beim Schütteln fällt.

Du brauchst:
  • ein im Editor geöffnetes Projekt;
  • ein Handy oder Tablet: der Sensor gehört zum Gerät.

Schritt 1: Neigung in einer Formel lesen

  1. Öffne einen Knoten mit einem Formelfeld, zum Beispiel „Eigenschaft ändern“.
  2. Öffne im linken Bereich die Gruppe Handy neigen.
  3. Tippe auf inclinaison.x (links-rechts) oder inclinaison.y (oben-unten auf dem Bildschirm): Die Formel schreibt sich selbst.
👉 Die Werte gehen von -1 bis 1. 0 = so, wie du das Handy beim Spielstart gehalten hast; 1 = voll geneigt (etwa 30°) nach rechts bei x, zum unteren Bildschirmrand bei y. Es funktioniert im Hoch- und Querformat.

Schritt 2: eine Figur, die beim Neigen läuft

  1. Wähle deine Figur und tippe im Inspektor auf Verhalten des Objekts.
  2. Wähle eine Plattform-Figur oder eine Figur in der Draufsicht.
  3. Tippe in der Zeile Steuerung auf Neigen.
  4. Stelle die Empfindlichkeit ein: sanft, normal oder stark.
  5. Bei einer Plattform-Figur brauchst du einen Sprungknopf: Neigen lässt sie nicht springen.

Die Vorlage „Durch Neigen bewegen“ zeigt das alles fertig.

Schritt 3: eine rollende Murmel

  1. Erstelle ein rundes Objekt (ein Murmelbild oder einen farbigen Kreis).
  2. Tippe auf Verhalten des Objekts, dann auf Realistische Physik.
  3. Hake Murmel: rollt, wenn du das Handy neigst an. Yop2D stellt runde Form, Abprallen und Schwerkraft selbst ein.
  4. Setze Wände: Objekte mit demselben Verhalten, auf Fest gestellt.
  5. Ist die Murmel zu schnell oder zu langsam, ändere die Empfindlichkeit.

Die Vorlage „Murmel-Labyrinth“ enthält eine Murmel, Wände, schwarze Löcher, die neu starten, und einen grünen Kreis als Ziel.

Schritt 4: auf Schütteln reagieren

  1. Füge im Blueprint das Ereignis „Handy geschüttelt“ hinzu.
  2. Verbinde es mit dem, was du willst: mischen, würfeln, Objekte umwerfen…
  3. Schüttle dein Handy: Es braucht zwei kurze, kräftige Stöße. Eine einfache Bewegung reicht nicht, und zwischen zwei Schüttelbewegungen liegt eine Sekunde Pause.

Die Vorlage „Schütteln zum Würfeln“ schreibt bei jedem Schütteln eine Zufallszahl, random(1, 6), in den Text eines Würfels.

Neigung auf Null setzen

Die Null ist die Handyhaltung beim Spielstart. Um sie neu zu setzen (der Spieler ändert die Haltung, neues Level), füge den Knoten „Neigung auf Null setzen“ hinzu.

  • Der Bildschirm dreht sich nicht: Nutzt ein Spiel die Neigung, bleibt der Bildschirm in der Startlage, sonst würde er beim Neigen kippen.
  • Gerät ohne Sensor: Der Wert bleibt 0 und nichts bewegt sich.
