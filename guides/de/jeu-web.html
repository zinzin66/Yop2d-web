Wie mache ich aus meinem Spiel ein Web-Spiel (HTML)?

Anleitung für Einsteiger · ohne Code

Français · English · Español · Deutsch · Italiano · Português · Русский · 中文 · 日本語 · العربية

ℹ️ Benötigt Yop2D ab Version 1300 (die letzte Zahl der Versionsnummer, zum Beispiel 1.0.1300). Ist deine Version älter, aktualisiere Yop2D.

Seit Version 1300 kann Yop2D ein Web-Spiel erstellen: dein ganzes Spiel (Bilder, Töne, Knoten) passt in eine einzige .html-Datei. Diese Datei läuft in einem Browser (Chrome empfohlen) auf Handy, Tablet oder Computer, ohne Installation und ohne Internet.

Du brauchst:
  • Yop2D ab Version 1300;
  • ein Spiel, das funktioniert, wenn du es im Editor mit ▶ testest;
  • den Browser Chrome auf dem Gerät, auf dem gespielt wird (empfohlen).

Schritt 1: die Datei erstellen

  1. Tippe auf dem Startbildschirm dein Projekt an, um es auszuwählen.
  2. Tippe auf APK erstellen. Ein Fenster Spiel erstellen öffnet sich.
  3. Wähle Web-Spiel (HTML).
  4. Wähle den Speicherort (zum Beispiel Downloads) und warte auf die Meldung „Dein Web-Spiel ist fertig!“.
👉 Die Datei enthält das ganze Spiel: ein Spiel mit vielen Bildern oder Musikstücken ergibt eine größere Datei (oft 1 bis 5 MB).

Schritt 2: spielen

  1. Öffne die Datei mit Chrome (Dateimanager → Downloads → Datei antippen → Chrome).
  2. Das Spiel startet. Tippe einmal auf den Bildschirm: Ton und Vollbild werden eingeschaltet.
  3. Am Computer spielt man mit der Maus; die Esc-Taste wirkt wie die Zurück-Taste des Handys.
👉 Manche Apps (Messenger, Dateibetrachter) öffnen die Datei in einem kleinen Fenster ohne Vollbild: das Spiel zeigt das in Orange an. Öffne sie dann mit Chrome.

Schritt 3: dein Spiel teilen

  • Mit einem Freund: schick einfach die .html-Datei (E-Mail, Messenger, USB-Stick). Er braucht Yop2D nicht.
  • Auf itch.io: benenne die Datei in index.html um, pack sie in eine .zip-Datei, lade das Zip auf deine itch.io-Seite hoch und kreuze „This file will be played in the browser“ an. Dann läuft dein Spiel direkt auf der Seite.
  • Dein Spiel gehört dir: kein Yop2D-Logo, keine Werbung, du kannst es verschenken oder verkaufen.

Was im Web-Spiel funktioniert

Das Web-Spiel liest dieselben Knoten wie die Android-App: Physik, Licht, Partikel, Bildschirmfilter, Übergänge, Kacheln, Prefabs, Joysticks, Verhalten, Tower Defense, rundenbasierte Spiele, Geschichten mit Entscheidungen und Spielständen, Galerie und Spielereinstellungen… Spielstände („Variablen speichern“, die 💾-Plätze einer Geschichte) werden im Browser des Geräts gespeichert: sie bleiben, wenn man das Spiel schließt und wieder öffnet.

Wenn es nicht klappt

  • Keine Auswahl „Web-Spiel (HTML)“: dein Yop2D ist älter als Version 1300: aktualisiere es.
  • Weißer Bildschirm oder nichts bewegt sich: öffne die Datei mit Chrome, nicht mit einem Dateibetrachter.
  • Kein Ton: tippe einmal auf den Bildschirm (Browser warten auf eine erste Berührung). Auf iPhone und iPad werden manche Töne vielleicht nicht abgespielt: das ist noch nicht geprüft.
  • Der Spielstand ist weg: er wird gelöscht, wenn man die Browserdaten löscht; in einem anderen Browser oder auf einem anderen Gerät gibt es ihn nicht.
  • Etwas funktioniert anders als in der App: das Web-Spiel ist neu. Sag es uns auf Discord mit dem Namen des Knotens: wir beheben es schnell.
