Die Ein- und Ausgänge der Knoten

Anleitung für Einsteiger · ohne Code

Français · English · Español · Deutsch · Italiano · Português · Русский · 中文 · 日本語

Ein Knoten hat Kreise: das sind seine Ein- und Ausgänge. Die Leitungen dazwischen legen fest, in welcher Reihenfolge die Knoten laufen. Eine einfache Regel: ein Ausgang hat nur eine Leitung, ein Eingang kann mehrere haben.

Die Kreise eines Knotens

Links der Eingangskreis (Eingang): Dort bekommt der Knoten den Befehl zu laufen. Rechts die Ausgangskreise (zum Beispiel Weiter): Dort gibt der Knoten an den nächsten weiter. Manche Knoten haben mehrere Ausgänge, etwa eine Bedingung mit Wahr und Falsch.

Ein Ausgang nimmt nur eine Leitung auf

Wenn du von einem bereits verbundenen Ausgang eine neue Leitung ziehst, ersetzt sie die alte. Ein Ausgang kann also nur an eine Stelle führen.

Ein Eingang nimmt mehrere Leitungen auf

  1. Ziehe eine Leitung von einem ersten Ausgang zum Eingangskreis des gewünschten Knotens.
  2. Ziehe eine zweite Leitung von einem anderen Ausgang (oder einem anderen Knoten) zum selben Eingangskreis.
  3. Die erste Leitung bleibt bestehen: Der Knoten läuft, sobald einer dieser Wege bei ihm ankommt.
👉 Beispiel: Ein Countdown hat einen Ausgang, der jede Sekunde auslöst, und einen weiteren am Ende. Verbinde beide mit demselben Knoten, der einen Text ändert: Die Zeit erscheint in beiden Fällen, ohne den Knoten doppelt zu bauen.

Der Text im Fenster { }

Im Blueprint-Fenster { } steht das Skript als Text. Erreichen zwei Wege einen Knoten, wird er nur einmal beschrieben; der andere Weg endet mit einem Pfeil ↩, der bedeutet „dieser Knoten wurde weiter oben schon beschrieben“.

👉 Um eine Leitung zu trennen, tippe sie an. Um sie woanders neu zu ziehen, ziehe eine neue vom Ausgang.
