Wie fügt man Partikel und Effekte hinzu?

Anleitung für Einsteiger · ohne Code

Français · English · Español · Deutsch · Italiano · Português · Русский · 中文 · 日本語

Yop2D erzeugt Partikel auf zwei Arten: Der Node „Partikeleffekt“ stößt auf einmal einen Schwall aus (perfekt für eine Explosion), und das Objekt Partikel erzeugt sie ohne Pause (Feuer, Rauch, Regen, Spur…). Weitere Nodes fügen Effekte auf dem ganzen Bildschirm hinzu: Blitz, Tönung, abgedunkelte Ränder und Überblendung.

Du brauchst:
  • ein funktionierendes Spiel mit einer Figur namens player, die sich bewegen kann;
  • Gegner mit dem Tag ennemi.
👉 Um alle diese Effekte in Aktion zu sehen, öffne das Beispiel Effects showcase auf dem Startbildschirm von Yop2D: eine Taste pro Effekt, mit dem Namen des passenden Knotens.

Schritt 1: eine Explosion, wenn man einen Gegner berührt

  1. Öffne den Blueprint der Szene.
  2. Füge das Ereignis „Wenn Objekt Tag berührt“ hinzu: Ziel player, Tag ennemi.
  3. Füge „Partikeleffekt“ hinzu. Wähle als Ziel Das beteiligte Objekt: Das ist der Gegner, den der Spieler gerade berührt hat. Vorlage: Explosion.
  4. Füge „Objekt zerstören“ hinzu, mit demselben Ziel Das beteiligte Objekt.
  5. Verbinde die drei Nodes der Reihe nach, starte dann das Spiel und berühre einen Gegner: Er explodiert, bevor er verschwindet.

⚠️ Die Reihenfolge zählt: „Partikeleffekt“ muss vor „Objekt zerstören“ kommen. Sobald der Gegner zerstört ist, gibt es kein Objekt mehr, an dem die Explosion erscheinen kann.
👉 Du kannst die Farbe ändern (zum Beispiel #FF40D0 für eine magentafarbene Explosion) und die Größe (2 = doppelt so groß). Probiere auch Funken, Konfetti oder Rauch.

Schritt 2: ein Schweif hinter der Figur

  1. Füge ein Objekt hinzu: Wähle in der Kategorie Effekte den Eintrag Partikel. Im Editor erscheint es als orange gestrichelter Bereich, im Spiel ist es unsichtbar.
  2. Tippe im Inspektor, Bereich PARTIKEL, auf Vorlage: und wähle Schweif.
  3. Tippe ebenfalls im Inspektor auf die Schaltfläche Parent: Keine und wähle player: Das Objekt folgt der Figur überallhin.
  4. Setze es direkt hinter die Figur, starte dann das Spiel und bewege dich: Ein langer leuchtender Schweif folgt der Figur.
👉 Im Blueprint ist nichts nötig: Ein Partikel-Objekt arbeitet von selbst, solange Aktiv ab Spielbeginn angehakt ist. Um es während des Spiels ein- oder auszuschalten, nutze den Node „Partikel ein / aus“.
  • Feuer: eine Fackel oder ein Lagerfeuer.
  • Rauch: über einem Schornstein.
  • Regen oder Schnee: Ziehe das Objekt über den ganzen oberen Bildschirmrand.
  • Hyperraum und Geschwindigkeitslinien: für ein Gefühl von hoher Geschwindigkeit.

Schritt 3: Effekte auf dem ganzen Bildschirm

  • „Bildschirmblitz“: ein farbiger Blitz. Zum Beispiel rot, 0,5 Sekunden, direkt nachdem der Spieler getroffen wurde.
  • „Bildschirmtönung“: eine Farbe über dem ganzen Spiel. Dunkelblau mit 55 % für die Nacht, und Stärke 0, um zum Tag zurückzukehren.
  • „Abgedunkelte Ränder“: Die Bildschirmränder werden dunkler, wie im Kino.
  • „Bildschirmüberblendung“: Der Bildschirm wird schwarz und erscheint dann wieder.

Schritt 4: Stromschlag und Treffer-Standbild

  • „Stromschlag“: Blitze knistern um ein Objekt, das blinkt und zittert. Dauer 0 = endlos: ideal für eine elektrische Falle, die den Spieler warnt.
  • „Trefferstopp“: eine sehr kurze Zeitlupe (0,08 Sekunden) im Moment des Treffers gibt einer Explosion richtig Wucht.

Wenn es nicht funktioniert

  • Die Explosion erscheint nicht: Prüfe, dass „Partikeleffekt“ vor „Objekt zerstören“ steht.
  • Der Schweif folgt der Figur nicht: Prüfe, dass das Partikel-Objekt player als Eltern-Objekt hat und dass Aktiv ab Spielbeginn angehakt ist.
  • Die Partikel haben die falsche Farbe: Die Farbe „Keine“ behält die Farben der Vorlage; wähle eine echte Farbe, um sie zu ändern.
  • Der Bildschirm bleibt schwarz: Nach einem „Bildschirmüberblendung“ Ausblenden (zur Farbe) braucht es ein „Bildschirmüberblendung“ Einblenden (aus der Farbe).
