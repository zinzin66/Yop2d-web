Wie sammle ich Münzen und zähle Punkte?

Anleitung für Einsteiger · ohne Code

Français · English · Español · Deutsch · Italiano · Português · Русский · 中文 · 日本語

Wenn der Spieler eine Münze berührt, wollen wir drei Dinge: Die Münze verschwindet, der Punktestand steigt um 1, und der neue Punktestand erscheint auf dem Bildschirm.

Du brauchst:
  • eine Figur namens player, die sich bewegen kann (siehe Eine Figur bewegen);
  • ein paar Münzen: Objekte Kreis (oder Bilder), zum Beispiel coin1, coin2, coin3;
  • ein Objekt Text namens scoreText, oben auf dem Bildschirm, mit dem Text „Punkte: 0“.

Schritt 1: allen Münzen denselben Tag geben

Ein Tag ist ein Etikett. Dank ihm funktioniert ein einziges Stück Blueprint für alle Münzen, selbst wenn du 50 hinzufügst.

  1. Wähle eine Münze aus.
  2. Schreibe im Inspektor, Feld „Tag (Etikett)“, piece.
  3. Mach dasselbe bei jeder Münze (die Taste „Liste“ neben dem Feld zeigt die schon benutzten Tags).

Schritt 2: die Variable „score“ anlegen

Eine Variable ist ein Kästchen, das sich im Spiel eine Zahl merkt.

  1. Öffne im linken Bereich Variablen und lege eine Variable an.
  2. Name: score · Gültigkeit: Lokal · Typ: Ganze Zahl · Startwert: 0.
👉 Lokal = die Variable gibt es nur in dieser Szene. Wähle Global, wenn der Punktestand im nächsten Level weitergehen soll (siehe Zum nächsten Level).

Schritt 3: der Blueprint

  1. Öffne den Blueprint der Szene.
  2. Füge das Ereignis „Wenn Objekt Tag berührt“ hinzu: Ziel player, Tag piece.
  3. Füge „Objekt zerstören“ hinzu. Wähle als Ziel Das beteiligte Objekt: Das ist die Münze, die der Spieler gerade berührt hat.
  4. Füge „Zu Variable hinzufügen“ hinzu: Variable score, Hinzuzufügender Wert = 1.
  5. Füge „Text ändern“ hinzu: Ziel scoreText, Neuer Text = ="Punkte: " + score
  6. Verbinde die vier Knoten der Reihe nach, Ausgang mit Eingang.
  7. Speichere, starte das Spiel und berühre eine Münze.

👉 Das Zeichen = am Anfang des Textes sagt Yop2D, dass es den Text berechnen soll, statt ihn so hinzuschreiben. Ohne es würde der Bildschirm wörtlich "Punkte: " + score zeigen. Die Anführungszeichen umschließen den Teil, der sich nicht ändert.
👉 Das Ereignis läuft nur einmal pro Berührung: Wer auf einer Münze stehen bleibt, bekommt nicht mehrere Punkte.

Bonus: gewinnen, wenn man alle Münzen hat

  1. Füge nach „Text ändern“ den Knoten „Bedingung“ hinzu, mit Bedingung = =score >= 3 (3 = Anzahl der Münzen).
  2. Verbinde seinen Ausgang Wahr mit einem Knoten „Toast“ mit der Nachricht Gewonnen! oder mit „Nächste Szene“.

Wenn es nicht klappt

  • Die Münze verschwindet nicht: Prüfe, ob der Tag überall gleich geschrieben ist (piece) und ob das Ziel von „Objekt zerstören“ das beteiligte Objekt ist.
  • Der Text zeigt die Formel: Das = am Anfang fehlt.
  • Der Punktestand bleibt bei 0: Prüfe, ob „Zu Variable hinzufügen“ die Variable score benutzt.
  • Zum Vergleich öffne das Beispielspiel „Plattform“, das mit Yop2D kommt: Es sammelt Münzen genau so.
