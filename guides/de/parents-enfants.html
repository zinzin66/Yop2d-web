Wie mache ich ein Objekt zum Kind eines anderen?

Anleitung für Einsteiger · ohne Code

Français · English · Español · Deutsch · Italiano · Português · Русский · 中文 · 日本語 · العربية

Was ist ein Kind?

Ein Kind ist ein Objekt, das an ein Elternobjekt gebunden ist: Verschiebst du das Elternobjekt, folgt das Kind. Praktisch für Text auf einem Button, eine Waffe in der Hand, einen Schatten unter einer Figur.

Die obere Leiste

Die obere Leiste ist auf Tablet und Handy gleich (auf dem Handy nur Symbole): ＋ Objekt, Assets, Speichern, Rückgängig, Wiederholen, Kopieren, Löschen, Verschieben, Ansicht ▾ (Hand, Raster, Zentrieren, Zoom), Blueprint, Menü und Spielen.

Methode 1: über den Inspektor

  1. Wähle das Objekt, das das Kind werden soll.
  2. Öffne den Inspektor (Pfeil oben rechts, falls geschlossen), Bereich Erweitert.
  3. Tippe auf die Zeile Eltern und wähle das Elternobjekt in der Liste.

Methode 2: per Ziehen

  1. Öffne die Hierarchie (linkes Panel).
  2. Halte den Finger auf dem Kind-Objekt, bis es sich löst.
  3. Lass es auf dem Elternobjekt los: Das Elternobjekt bekommt einen grünen Rahmen, das Kind erscheint darunter mit dem Symbol └.

Ein Kind lösen

Halte das Kind gedrückt und lass es auf der Zeile Szene oder auf einem Ordner los. Es behält seinen Platz auf dem Bildschirm.

Gut zu wissen

Beide Methoden führen zum selben Ergebnis: Inspektor und Hierarchie stimmen immer überein. Die Koordinaten eines Kindes zählen von der linken oberen Ecke des Elternobjekts. Zwei Objekte können nicht gegenseitig Eltern sein.
