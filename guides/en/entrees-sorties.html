The inputs and outputs of nodes

Beginner guide · no code

Français · English · Español · Deutsch · Italiano · Português · Русский · 中文 · 日本語

A node has circles: these are its inputs and outputs. The wires between them say in which order the nodes run. One simple rule to remember: an output has only one wire, an input can have several.

The circles of a node

On the left, the input circle (Enter): this is where the node receives the order to run. On the right, the output circles (for example Next): this is where the node hands over to the next one. Some nodes have several outputs, like a Condition with True and False.

An output takes only one wire

If you pull a new wire from an output that is already connected, the new one replaces the old one. So an output can only lead to one place.

An input accepts several wires

  1. Pull a wire from a first output to the input circle of the node you want.
  2. Pull a second wire from another output (or from another node) to the same input circle.
  3. The first wire stays in place: the node runs as soon as one of these paths reaches it.
👉 Example: a countdown has one output that fires every second and another when it is finished. Connect both to the same node that changes a text: the time shows in both cases, without building the node twice.

The text of the { } window

In the Blueprint { } window, the script is written as text. When a node is reached by two paths, it is described only once; the other path ends with an arrow ↩, which means “this node was already described above”.

👉 To cut a wire, tap it. To redo it elsewhere, pull a new one from the output.
