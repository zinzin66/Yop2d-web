How to make a menu with buttons, a switch and a slider?

Beginner guide · no code

Français · English · Español · Deutsch · Italiano · Português · Русский · 中文 · 日本語

A game menu needs good-looking buttons and settings: a switch for the sound, a slider for the volume, a counter for the score. In Yop2D, every element is a single object with its text inside, and its whole look is set in one window. You can also download the UI kit example (Examples tab): it shows every element.

You need:
  • a project open in the editor;
  • the "UI kit" example if you want to see the result first (optional).

Step 1: add an element

  1. Tap the + of the editor, then the Interface elements section.
  2. Choose between Button, Switch, Checkbox, Slider, Panel and Counter.
  3. The element arrives in the middle of the screen: move it with your finger and resize it with the handles, like any object.
👉 The text of a button is inside it: write it in the Inspector, no need to place a text on top of the button anymore.

Step 2: change its style

  1. Select the element and tap Element style… in the Inspector.
  2. In Shape, choose rectangle, rounded, pill, circle, cut corners or hexagon.
  3. In Image, choose Inside the shape (the image keeps the shape), Replaces the shape (the image IS the button) or Icon + text.
  4. In Colors and outline, set the color, the gradient, the outline, the shadow and the glow (neon).
  5. In Text, choose the font, the size, the color and the outline of the letters.

Step 3: give it a behavior

  1. In Behavior, turn on Stays pressed (ON / OFF) for a button that keeps its state.
  2. Choose a sound on touch and, if you like, a vibration.
  3. For a slider, set the minimum value, the maximum value and the starting value.
👉 A disabled (greyed) element no longer reacts to touch: handy for a "Continue" button that is not available yet.

Step 4: read the value in the game

  1. A switch or a checkbox equals its minimum value (off) or maximum value (on); a slider equals its position.
  2. In a formula, write object_name.progression: for example "=volume.progression" in “Set a property” of a text to display the volume.
  3. For a button, add the event “On Object Click” in the Blueprint and choose your button.

The old Yop2D buttons keep working: these new elements are added, they replace nothing.
