How to make your own blocks (functions)?

Beginner guide · no code

Français · English · Español · Deutsch · Italiano · Português · Русский · 中文 · 日本語

A function is a small group of nodes that you give a name to. You build it once, then run it whenever you want with a single node, from any scene. It is your way of making your own blocks: you don't redo the same thing ten times and your Blueprints stay tidy.

You need:
  • a project open in the editor.

Step 1: create the function

  1. Open the Resources panel (on the left of the editor) and unfold the Functions part.
  2. Tap ＋, type a short name (for example Give_points) and confirm.
  3. Tap your function's name to select it, then the button that opens its Blueprint (the icon of linked nodes).
👉 A function is a file of your project: it is exported with your game and works in every scene.

Step 2: put nodes inside

  1. You are in the function's Blueprint (the title says “Function: …”). Place the “On Start” event: this is where the function starts.
  2. Then connect the nodes you want. For this example: “Add to Variable” (variable score), then “Small message at the bottom of the screen”.
  3. Save with 💾.

Step 3: call the function

  1. In a scene's Blueprint, add the “Call function” node.
  2. Tap the Function line and choose your function.
  3. When this node is reached, the function's nodes run, then the Blueprint carries on.
👉 Be careful not to put “Call function” under “Every frame” by accident: the function would start again on every frame.

Step 4: add settings (inputs)

Without settings, a function always does the same thing. Inputs let you set it on every call: how many points, which message, what speed…

  1. In the function's Blueprint, tap the Function inputs button (a sliders icon, in the top bar).
  2. Tap + Add an input. Give it a name (for example points), a type (Number, Text or Yes / no) and a starting value (for example 10). Confirm, then save with 💾.
  3. Inside the function, use the input by writing =points in place of a number. For example, put =points in the value of “Add to Variable”. For a message, put =message in the text setting of “Small message at the bottom of the screen”.
  4. Go back to the scene's Blueprint: the “Call function” node now shows one line per input. Change the value: 50 points here, 10 points elsewhere.
👉 An input can also receive a calculation, for example =score * 2. If you leave the line as it is, the starting value is used. Inside the function, an input takes priority over a variable with the same name.

If it doesn't work

  • “Function not found”: it was renamed or deleted. Choose it again in “Call function”.
  • Nothing happens: check that there is a “On Start” event at the start of the function, and that you saved with 💾.
  • The setting lines don't appear: save the function with its inputs first, then reopen the “Call function” node.
  • An input name is refused: write it as one word (letters, digits and _), without spaces.
  • A function that calls itself: Yop2D stops after a few calls so the game doesn't freeze.
