How to make your own nodes (My nodes)?

Beginner guide · no code

Français · English · Español · Deutsch · Italiano · Português · Русский · 中文 · 日本語

A node of your own is a small group of nodes that you give a name to (programmers call it a “function”). You build it once, then run it whenever you want with a single node, from any scene. It is your way of making your own blocks: you don't redo the same thing ten times and your Blueprints stay tidy.

You need:
  • a project open in the editor.

Step 1: create your node

  1. Open the Resources panel (on the left of the editor) and unfold the My nodes part.
  2. Tap ＋, type a short name (for example Give_points) and confirm.
  3. Tap your node's name to select it, then the button that opens its Blueprint (the icon of linked nodes).
👉 Your node is a file of your project: it is exported with your game and works in every scene.

Step 2: put nodes inside

  1. You are in your node's Blueprint (the title says “My node: …”). Place the “On Start” event: this is where your node starts.
  2. Then connect the nodes you want. For this example: “Add to Variable” (variable score), then “Small message at the bottom of the screen”.
  3. Save with 💾.

Step 3: run your node

  1. In a scene's Blueprint, add the “Run one of my nodes” node.
  2. Tap the choice line and pick your node.
  3. When this node is reached, the nodes you put inside run, then the Blueprint carries on.
👉 Be careful not to put “Run one of my nodes” under “Every frame” by accident: your node would start again on every frame.

Step 4: add settings

Without settings, your node always does the same thing. Settings let you adjust it each time: how many points, which message, what speed…

  1. In your node's Blueprint, tap the My node settings button (a sliders icon, in the top bar).
  2. Tap + Add an input. Give it a name (for example points), a type (Number, Text or Yes / no) and a starting value (for example 10). Confirm, then save with 💾.
  3. Inside your node, use the setting by writing =points in place of a number. For example, put =points in the value of “Add to Variable”. For a message, put =message in the text setting of “Small message at the bottom of the screen”.
  4. Go back to the scene's Blueprint: the “Run one of my nodes” node now shows one line per setting. Change the value: 50 points here, 10 points elsewhere.
👉 A setting can also receive a calculation, for example =score * 2. If you leave the line as it is, the starting value is used. Inside your node, a setting takes priority over a variable with the same name.

If it doesn't work

  • “Node not found”: it was renamed or deleted. Choose it again in “Run one of my nodes”.
  • Nothing happens: check that there is a “On Start” event at the start of your node, and that you saved with 💾.
  • The setting lines don't appear: save your node with its settings first, then reopen the “Run one of my nodes” node.
  • A setting name is refused: write it as one word (letters, digits and _), without spaces.
  • A node that runs itself: Yop2D stops after a few calls so the game doesn't freeze.
