Cutting a sprite sheet into animations

Beginner guide · no code

Français · English · Español · Deutsch · Italiano · Português · Русский · 中文 · 日本語

Many characters come on a single sheet: all the walking or jumping pictures side by side, in rows. Yop2D cuts it up and makes the animations for you, so you don't have to save each picture.

You need:
  • a project open in the editor;
  • a sprite sheet (PNG) whose cells are all the same size.

Step 1: choose the sheet

  1. Open the Assets window and tap the Sheet button.
  2. Pick your picture in the library. To use another one later: Change image.

Step 2: count the pictures

Answer How many pictures in the sheet?: the number of columns and rows (− and + buttons, or type the number). Yop2D suggests a number and tells you it guessed: count on your sheet and fix it if needed. The grid must fall exactly between the pictures.

👉 A file name like "16x16" helps Yop2D guess the size of a cell.

Step 3: choose the animations

  • One animation per row (suggested when there are several rows): each row becomes an animation. Yop2D suggests names; tap ✎ to change them. With 4 rows it suggests walk_down, walk_left, walk_right, walk_up: these names are recognized by behaviors, so the animation plays by itself.
  • Pick the pictures by hand: for an animation that spans several rows. Tap New animation if needed, pick the animation in the list, then tap the first picture on the sheet and slide to the last one.
  • Skip empty cells: skips the empty cells of the sheet (ticked automatically if there are some).

Step 4: preview and create

  1. Watch the Preview: it moves, so you can check the pictures flow well. The Preview speed setting only changes this preview.
  2. Tap Create N animations.
👉 The game's speed is set in the “Play animation” node (frames per second), not in the preview.

The pictures are stored in Images, in a folder named after the sheet, and the animations appear in the animation list. Then use the “Play animation” node to play them.
