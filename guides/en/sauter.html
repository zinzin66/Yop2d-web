How to make a character jump?

Beginner guide · no code

Français · English · Español · Deutsch · Italiano · Português · Русский · 中文 · 日本語

For a character to jump, you need three things: it must fall (gravity), a floor to land on, and a button that pushes it upwards, only when it is standing on something.

You need:
  • a character named player (a Square or an Image);
  • a floor: a wide, flat Square named floor, at the bottom of the scene;
  • a button named btnJump (a Button or a Square), at the bottom right of the screen.

Step 1: give the character gravity

  1. Select player.
  2. In the inspector, section “Physics & Environment”, tick “Enable physics body (Collisions)”.
  3. Tap the “Physics: Static ►” button so that it becomes “Physics: Dynamic ▼”. “Dynamic” means the object falls.
👉 The “Gravity (ex: 1.0)” setting changes how fast it falls: 0.5 to fall slowly, 2 to fall fast.

Step 2: add a solid floor

  1. Select floor.
  2. Tick “Enable physics body (Collisions)” too, but leave it as “Physics: Static ►”: a static object does not move and stops objects that fall on it.
  3. Put player a little above the floor.
👉 You can make platforms the same way: static squares placed higher up.

Step 3: the jump button

  1. Open the scene's Blueprint.
  2. Add the “On Object Click” event and choose btnJump as its target.
  3. Add the “If on ground” node (category Logic & Conditions) and choose player as its target.
  4. Add the “Impulse (jump)” node (category Movements & AI): target player, Vertical force (negative = up) = -15.
  5. Link the output of “On Object Click” to the input of “If on ground”, then the True output of “If on ground” to the input of “Impulse (jump)”.
  6. Save, then start the game and tap the button.

👉 Why “If on ground”? Without it, the player could jump again in mid-air and fly away by tapping the button several times.
👉 Negative = upwards. In Yop2D, Y numbers grow towards the bottom of the screen. -15 makes a small jump, -20 a big one.

What about moving while jumping?

Add the left and right buttons from the guide Move a character (method 1). You can keep one finger on “right” and tap “jump” with another finger.

If it doesn't work

  • The character doesn't fall: check that it is set to “Physics: Dynamic ▼”.
  • It goes through the floor: the floor must have “Enable physics body (Collisions)” ticked, and stay static.
  • Nothing happens when you tap: check that the wires are linked, and that the output used is True. Remember to save before starting the game.
  • To compare, open the “Platform” example game that comes with Yop2D: it uses exactly this setup.
