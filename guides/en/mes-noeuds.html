How to create your own nodes?

Beginner guide · no code

Français · English · Español · Deutsch · Italiano · Português · Русский · 中文 · 日本語 · العربية

ℹ️ Needs Yop2D version 1281 or newer (the last number of the version, for example 1.0.1281). If your version is older, update Yop2D.

When you build the same series of nodes several times (for example: an enemy that blinks, plays a sound and loses life), you can put it into a single node of your own. You write it once, then you run it anywhere, with settings that change from place to place (the speed, the message, the target object…).

You need:
  • a project open in the editor;
  • a small series of nodes you would like to reuse.

Step 1: create your node

  1. In the editor, open the Resources panel and find My nodes.
  2. Touch + and give it a name, for example Take_hit.
  3. Select it and touch the Blueprint icon: you land on an empty Blueprint reserved for this node.
  4. Build your series of nodes as usual, then save (💾). The Blueprint title says My node: Take_hit.

Step 2: give it settings

  1. In your node's Blueprint, touch the My node settings button (at the top).
  2. Touch + Add an input: give it a name (for example speed), choose its type and its starting value.
  3. In the nodes of your node, write the input's name in a formula: =speed.
  4. A Number input is a number; Text, a message; Yes / no, a switch; Object, the name of an object in the scene.
👉 The Object type: whoever runs your node chooses which object it acts on. In the nodes of your node, open On what?: a My node settings group offers "Input … of my node". The same node can then make an enemy, a chest or the hero blink.

Step 3: place it in a Blueprint

  1. Open the Blueprint of a scene.
  2. In the nodes panel, the My nodes category is at the top of the list: touch your node.
  3. A Run one of my nodes node arrives already set to yours, with one line per setting: fill them in (a number, a formula, an object name…).

Step 4: share a node

  1. Open your node's Blueprint and touch the selection button ⬚, then select all the nodes (draw a frame in the empty space).
  2. Touch ⧉ Copy, and paste the result in a message for your friend.
  3. Your friend creates an empty node, opens its Blueprint, touches "{ }" and pastes: the series appears.
👉 Sharing carries the nodes, not the images or sounds they use: send those separately. The settings (inputs) are recreated with the My node settings button.

If it does not work

  • My node is not in the menu: it must be saved; close and reopen the Blueprint to refresh the list.
  • My setting line is missing: open the "Run one of my nodes" window: the lines update when you change node.
  • Nothing happens: your node must start with a node linked to the rest, and the call node must be linked to an event.
