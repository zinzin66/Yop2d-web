Comment transformer mon jeu en jeu web (HTML) ?

Guide débutant · sans code

Français · English · Español · Deutsch · Italiano · Português · Русский · 中文 · 日本語 · العربية

ℹ️ Demande la version 1300 de Yop2D ou plus récente (le dernier nombre du numéro de version, par exemple 1.0.1300). Si ta version est plus ancienne, mets Yop2D à jour.

Depuis la version 1300, Yop2D sait créer un jeu web : ton jeu entier (images, sons, nœuds) tient dans un seul fichier .html. Ce fichier se joue dans un navigateur (Chrome conseillé), sur un téléphone, une tablette ou un ordinateur, sans rien installer et sans internet.

Il te faut :
  • Yop2D en version 1300 ou plus récente ;
  • un jeu qui marche quand tu le testes avec ▶ dans l'éditeur ;
  • le navigateur Chrome sur l'appareil qui va jouer (conseillé).

Étape 1 : créer le fichier

  1. Sur l'écran de démarrage, touche ton projet pour le choisir.
  2. Touche Build APK. Une fenêtre Créer le jeu s'ouvre.
  3. Choisis Jeu web (HTML).
  4. Choisis où enregistrer le fichier (par exemple Téléchargements), puis attends le message « Ton jeu web est prêt ! ».
👉 Le fichier contient tout le jeu : un jeu avec beaucoup d'images ou de musiques donne un fichier plus gros (souvent 1 à 5 Mo).

Étape 2 : jouer

  1. Ouvre le fichier avec Chrome (gestionnaire de fichiers → Téléchargements → toucher le fichier → Chrome).
  2. Le jeu démarre. Touche l'écran une fois : le son et le plein écran s'activent.
  3. Sur ordinateur, on joue à la souris ; la touche Échap fait comme le bouton retour du téléphone.
👉 Certaines applications (messageries, visionneuses de fichiers) ouvrent le fichier dans une petite fenêtre qui refuse le plein écran : le jeu l'écrit en orange. Ouvre-le alors avec Chrome.

Étape 3 : partager ton jeu

  • À un ami : envoie simplement le fichier .html (e-mail, messagerie, clé USB). Il n'a pas besoin de Yop2D.
  • Sur itch.io : renomme le fichier en index.html, mets-le dans un fichier .zip, envoie ce zip sur ta page itch.io et coche « This file will be played in the browser ». Ton jeu se joue alors directement sur la page.
  • Ton jeu reste à toi : pas de logo Yop2D, pas de publicité, tu peux le donner ou le vendre.

Ce qui marche dans le jeu web

Le jeu web lit les mêmes nœuds que l'application Android : physique, lumières, particules, filtres d'écran, transitions, tuiles, prefabs, joysticks, comportements, tower defense, jeux au tour par tour, histoires à choix avec sauvegardes, galerie et réglages du joueur… Les sauvegardes (« Sauvegarder les variables », cases 💾 d'une histoire) sont gardées dans le navigateur de l'appareil : elles restent quand on ferme puis rouvre le jeu.

Si ça ne marche pas

  • Pas de choix « Jeu web (HTML) » : ta version de Yop2D est plus ancienne que la 1300 : mets-la à jour.
  • Écran blanc ou rien ne bouge : ouvre le fichier avec Chrome, pas avec une visionneuse.
  • Pas de son : touche l'écran une fois (les navigateurs attendent un premier toucher). Sur iPhone et iPad, certains sons peuvent ne pas être lus : ce cas n'est pas encore vérifié.
  • La sauvegarde a disparu : elle est effacée si on vide les données du navigateur ; elle n'existe pas non plus dans un autre navigateur ou sur un autre appareil.
  • Un détail ne marche pas comme dans l'application : le jeu web est nouveau. Dis-le-nous sur Discord avec le nom du nœud : on le corrige vite.
