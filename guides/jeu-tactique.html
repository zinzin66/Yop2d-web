Comment faire un jeu de tactique ?

Guide débutant · sans code

Français · English · Español · Deutsch · Italiano · Português · Русский · 中文 · 日本語

Dans un jeu de tactique, on joue chacun son tour sur une grille : on choisit une unité, on voit les cases où elle peut aller, on la déplace, puis elle attaque. Ce guide fait le jeu le plus simple possible : un héros et un monstre. Tout est déjà prêt dans l'exemple Tactics tutorial (onglet Exemples de l'écran de démarrage) : ouvre son Blueprint, chaque étape est dans un cadre de couleur avec un petit ? qui l'explique.

Il te faut :
  • un décor en tuiles de ton choix (la grille du jeu est la grille de ce décor) ;
  • une Image nommée hero1 avec le tag joueur, et une autre nommée foe1 avec le tag ennemi ;
  • une Zone nommée terrain qui couvre toute la carte (c'est elle qu'on touche pour choisir une case) ;
  • une variable etat (entier, locale) pour savoir où on en est : 0 = choisir un héros, 1 = héros choisi, 2 = héros déplacé.
👉 Les terrains (forêt, sable, montagne…) se règlent dans l'éditeur de tuiles, partie Terrains des tuiles : coût en pas, case bloquée ou non, bonus de défense. La montagne bloque le passage, la forêt coûte 2 pas.

Étape 1 : les fiches des unités

  1. Ajoute l'événement « Au Démarrage ».
  2. Ajoute « Donner une fiche d'unité » pour hero1 : vie 20, attaque 6, défense 2, mouvement 4, portée 1.
  3. Ajoute un deuxième « Donner une fiche d'unité » pour foe1, avec ses propres nombres.
  4. Relie les nœuds à la suite, puis ajoute « Passer au tour suivant » avec les équipes joueur,ennemi.
👉 La fiche est enregistrée dans l'objet : tu peux la relire partout avec une formule, par exemple =hero1.vie.

Étape 2 : le tour du joueur

  1. Ajoute l'événement « Événement Local » et écris le nom tour_joueur. Il part tout seul au début du tour du joueur.
  2. Mets etat à 0 avec « Modifier Variable », puis « Cacher les cases » pour effacer les anciennes cases.

Pour chaque équipe, « Passer au tour suivant » lance l'événement local « tour_ » suivi du nom de l'équipe : tour_joueur, puis tour_ennemi.

Étape 3 : toucher le héros, voir les cases bleues

  1. Ajoute « Au Clic sur Objet » sur hero1.
  2. Ajoute « Si c'est le tour de… » avec l'équipe joueur, puis sur la sortie Vrai une « Condition » etat < 2.
  3. Ajoute « Modifier Variable » : etat = 1.
  4. Ajoute « Montrer les cases accessibles » sur hero1 : type de zone Déplacement (les murs comptent), nombre de pas =hero1.mouvement, couleur bleue, Écrire le nombre de pas sur chaque case = oui, Ces tags bloquent le passage = joueur,ennemi.
👉 Les chiffres sur les cases sont le nombre de pas pour y arriver. Les cases de forêt en coûtent 2 : le héros va moins loin.

Étape 4 : toucher une case bleue, le héros marche

  1. Ajoute « Au Clic sur Objet » sur terrain, puis une « Condition » etat = 1.
  2. Ajoute « Si la case est accessible ». Pour la colonne et la ligne, touche 🔗 et choisis les nœuds verts « Colonne touchée » et « Ligne touchée » : aucune formule à écrire.
  3. Sur la sortie Vrai : « Modifier Variable » etat = 4 (le héros marche), puis « Aller à la case (chemin) » sur hero1, avec les mêmes nœuds verts et Ces tags bloquent le chemin = joueur,ennemi.
  4. Sur la sortie Arrivé, appelle l'événement local apres_deplacement avec « Appeler un événement ».

Étape 5 : la zone d'attaque, puis l'attaque

  1. Dans l'événement local apres_deplacement : « Cacher les cases », etat = 2, puis « Montrer les cases accessibles » en type Attaque / portée (passe au-dessus des murs), nombre de pas =hero1.portee, couleur rouge, avec le nom de zone attaque.
  2. Ajoute « Au Clic sur Objet » sur foe1, une « Condition » etat = 2 et « Si la case est accessible » avec le nom de zone attaque.
  3. Sur Vrai : « Attaquer » (objet A = hero1, objet B = foe1). Les dégâts sont l'attaque, moins la défense du monstre, moins la défense de son terrain.
  4. Sortie Encore en vie : mets à jour son texte de vie. Sortie Plus de vie : le monstre est détruit, ajoute la victoire.

Étape 6 : le tour des monstres

  1. Ajoute l'événement local tour_ennemi.
  2. Ajoute « Aller vers un objet (chemin) » sur foe1, objet B = hero1, S'arrêter = Sur une case voisine, bien centré, Ces tags bloquent le chemin = joueur,ennemi.
  3. Sur la sortie Arrivé, appelle un événement local où foe1 « Attaquer » hero1.
  4. Après quelques secondes (« Attendre »), « Arrêter le chemin » puis « Passer au tour suivant » : le tour revient au joueur.

Pour aller plus loin

  • Plusieurs héros : ajoute « Marquer comme ayant joué » et « Si l'unité a déjà joué » pour qu'un héros ne joue qu'une fois par tour (c'est ce que fait l'exemple Tactics demo).
  • Une barre de vie : lis =hero1.vie et =hero1.vie_max dans un texte ou une barre de progression.
  • Soigner : « Soigner » rend des points de vie sans dépasser le maximum.
  • Un jeu de plateau : « Déplacer le pion d'une case » déplace une pièce d'une case, bien centrée (boutons ◀ ▶ ▲ ▼).

Si ça ne marche pas

  • Aucune case bleue : le héros doit avoir le tag écrit dans « Si c'est le tour de… », et « Passer au tour suivant » doit avoir été lancé au démarrage.
  • Les cases ne correspondent pas au dessin : la grille est celle du premier décor en tuiles de la scène. Sans décor en tuiles, les cases font 80 px.
  • Le héros ne bouge pas : vérifie que la case touchée est bleue, et que etat vaut bien 1 à ce moment-là.
  • Pour comparer, ouvre l'exemple Tactics tutorial : chaque partie du Blueprint est dans un cadre qui l'explique.
