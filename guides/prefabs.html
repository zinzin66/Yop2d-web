Comment ajouter un objet prêt à l'emploi ?

Guide débutant · sans code

Français · English · Español · Deutsch · Italiano · Português · Русский · 中文 · 日本語

Un prefab est un objet qui a déjà son comportement : par exemple un bouton qui tourne, brille ou s'anime quand on le touche. Tu le télécharges, tu le poses dans ta scène, et c'est prêt, sans rien relier. Tout est libre de droits (CC0) : tu peux t'en servir dans tes jeux, même pour les vendre.

Il te faut :
  • un projet ouvert dans l'éditeur ;
  • une connexion internet pour télécharger (ensuite, les prefabs restent dans ton projet, même hors ligne).

Étape 1 : télécharger un prefab

  1. Ouvre la Bibliothèque Yop2D (bouton ＋ → Image, ou le bouton Bibliothèque du panneau Ressources).
  2. Touche l'onglet ⬇ Prefabs à télécharger, à côté de « Packs à télécharger ».
  3. Touche un prefab pour le télécharger. Pour en prendre plusieurs d'un coup, touche ☐ Choisir plusieurs, coche ceux que tu veux, puis ⬇ Télécharger.
👉 Un prefab téléchargé est rangé dans le dossier Prefabs de ton projet : tu n'as pas besoin de le télécharger deux fois.

Étape 2 : l'ajouter à la scène

  1. Dans l'onglet ⬇ Prefabs à télécharger, touche ＋ Ajouter à la scène sous un prefab déjà téléchargé.
  2. Un objet « scène liée » apparaît au centre de l'écran : il montre le prefab. En plus, une scène à son nom est créée dans la liste des Scènes (rangée sous la scène qui l'utilise).
  3. Tu peux en poser plusieurs : toutes les copies partagent la même scène, mais chacune garde son propre état (par exemple un interrupteur allumé et un autre éteint).
👉 Autre chemin : ＋ → Prefab pose un emplacement ; sélectionne-le, touche Image dans l'Inspecteur et choisis un prefab dans la grille.

Étape 3 : le personnaliser

  1. Lance le jeu (▶) et touche ou survole le prefab pour voir son comportement.
  2. Dans la liste des Scènes, touche la ligne ↳ du prefab : sa scène s'ouvre. Change l'image, le texte, la police ou la couleur avec l'Inspecteur.
  3. Ouvre le Blueprint pour changer ce qui se passe au toucher (par exemple ajoute « Changer de scène » pour lancer une partie).
👉 Tout est modifiable : ce sont de vrais objets et de vrais nœuds, comme si tu les avais faits toi-même.

Des éléments d'interface prêts à l'emploi

  • Interrupteur ON/OFF : un toucher le passe de gris à vert avec une glissière animée ; il retient son état dans la variable « etat ».
  • Barre de vie animée : verte, puis orange, puis rouge qui clignote ; la vie (variable « vie ») va de 0 à 100.
  • Score qui « pop » : le chiffre grossit à chaque point, avec des étincelles ; le score est dans la variable « score ».
  • Fenêtre de pause : un bouton ⏸ ouvre Reprendre, Recommencer et Quitter sur un fond assombri ; le bouton retour du téléphone l'ouvre aussi.

Ajouter tes propres prefabs

  • Depuis un zip : dans le panneau Ressources, le bouton d'import accepte un projet Yop2D en .zip (une seule scène) : il est rangé dans le dossier Prefabs.
  • Pour les partager : un prefab est un petit projet à une seule scène. Si tu en as fait un joli et libre de droits, parles-en sur le Discord de Yop2D.

Si ça ne marche pas

  • La liste est vide : connecte-toi à internet, puis rouvre l'onglet.
  • Le bouton ne bouge pas : lance le jeu avec ▶ ; les animations ne tournent pas dans l'éditeur.
  • Il manque une image : les prefabs copient leurs images dans ton projet ; regarde dans le panneau Ressources.
