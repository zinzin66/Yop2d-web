Comment ramasser des pièces et compter le score ?

Guide débutant · sans code

Français · English · Español · Deutsch · Italiano · Português · Русский · 中文 · 日本語

Quand le joueur touche une pièce, on veut trois choses : que la pièce disparaisse, que le score augmente de 1, et que le nouveau score s'affiche à l'écran.

Il te faut :
  • un personnage nommé player qui peut se déplacer (voir Faire bouger un personnage) ;
  • quelques pièces : des objets Rond (ou des images), par exemple piece1, piece2, piece3 ;
  • un objet Texte nommé texteScore, en haut de l'écran, avec le texte « Score : 0 ».

Étape 1 : donner le même tag à toutes les pièces

Un tag est une étiquette. Grâce à lui, un seul morceau de Blueprint marche pour toutes les pièces, même si tu en ajoutes 50.

  1. Sélectionne une pièce.
  2. Dans l'inspecteur, champ « Tag (Étiquette) », écris piece.
  3. Fais pareil pour chaque pièce (le bouton « Liste » à côté du champ propose les tags déjà utilisés).

Étape 2 : créer la variable « score »

Une variable est une case qui garde un nombre en mémoire pendant le jeu.

  1. Dans le panneau de gauche, ouvre la section Variables et crée une variable.
  2. Nom : score · Portée : Locale · Type : Entier · Valeur initiale : 0.
👉 Locale = la variable existe seulement dans cette scène. Choisis Globale si le score doit continuer au niveau suivant (voir Passer au niveau suivant).

Étape 3 : le Blueprint

  1. Ouvre le Blueprint de la scène.
  2. Ajoute l'événement « Si objet touche Tag » : cible player, Tag piece.
  3. Ajoute « Détruire Objet ». Comme cible, choisis L'objet impliqué dans l'événement : c'est la pièce que le joueur vient de toucher.
  4. Ajoute « Ajouter à Variable » : variable score, Valeur à ajouter = 1.
  5. Ajoute « Modifier Texte » : cible texteScore, Nouveau texte = ="Score : " + score
  6. Relie les quatre nœuds dans l'ordre, sortie vers entrée.
  7. Sauvegarde, puis lance le jeu et va toucher une pièce.

👉 Le signe = au début du texte dit à Yop2D de calculer le texte au lieu de l'écrire tel quel. Sans lui, l'écran afficherait mot pour mot "Score : " + score. Les guillemets entourent la partie qui ne change pas.
👉 L'événement ne se déclenche qu'une fois par contact : rester sur une pièce ne compte pas plusieurs points.

Bonus : gagner quand on a toutes les pièces

  1. Après « Modifier Texte », ajoute le nœud « Condition » avec Condition = =score >= 3 (3 = le nombre de pièces).
  2. Relie sa sortie Vrai à un nœud « Toast » avec le message Gagné !, ou à « Scène suivante ».

Si ça ne marche pas

  • La pièce ne disparaît pas : vérifie que le tag est écrit pareil partout (piece, sans accent) et que la cible de « Détruire Objet » est bien l'objet impliqué.
  • Le texte affiche la formule : il manque le = au début.
  • Le score reste à 0 : vérifie que « Ajouter à Variable » vise bien la variable score.
  • Pour comparer, ouvre le jeu d'exemple « Plateforme » fourni avec Yop2D : il ramasse des pièces exactement comme ça.
